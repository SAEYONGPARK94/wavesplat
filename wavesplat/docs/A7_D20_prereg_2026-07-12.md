## A-7 — 준단색파 국소 미세 은행 하이브리드

**가설**: BF2 1comp류 붕괴는 은행 양자화(δk=kp/10 > 요구 2π/L≈0.026)가
원인 — 준단색 감지 시 피크 주변 국소 미세 은행을 덧붙이면 위상 코히런스
회복, 광대역에선 발동하지 않아 무손상.

**설계 (동결)**:
- 감지: beamform 파워맵의 피크 집중도(상위 1셀 에너지 비율) ≥ θ이면
  발동 — θ는 1comp vs 5comp 합성으로 보정하되 **발동/미발동의 결과
  게이트가 판정 기준**(θ 자체는 튜닝 허용, 판정 창 밖 데이터로).
- 미세 은행: 감지된 피크 k₀ 주변 |k−k₀|/k₀ ≤ 0.25, 각도 ±15° 영역에
  δk = kp/40 격자 추가(기존 은행 유지, 추가 성분의 prior는 모 셀 에너지
  승계). hand 팔(명시적 은행 MMSE 경로 — d3_m3_point_eval의
  point_gamma_mmse가 명시적-은행 패턴 전례)에 적용.

**게이트 (동결)**:
- **G-A7-1 (회복)**: BF2 1comp fixedT 에피소드(가용 전부)에서 전장
  corr(lead 0) ≥ 0.5 AND 조우 rho ≥ 0.5 — 과반 에피소드에서.
- **G-A7-2 (무해)**: 합성 대표 6 에피소드(부록 시트 세트, BF3–BF5)에서
  Δ전장 ≥ −0.01 AND 실측 YS17 12창 스팟에서 Δ조우 ≥ −0.02.
- FAIL 분기: "은행 양자화 처방으로 부족(위상 요구가 감지·정렬 오차보다
  엄격)" 기록 — BF2 하한은 방법 공통 한계로 논문 유지.

### ★A-7 판정 (2026-07-12 집행)

**G-A7-1 FAIL (0/5 회복) / G-A7-2 PASS (완전 무해 — 미발동 시 Δ 정확히
0, hand 경로 재현 diff 0.000)**. `a7_finebank_eval.json`.

원인 2중 (에이전트 진단, 검수 수용):
1. 감지 통계량(top-1 집중도)이 kp-의존 — BF3–5로 보정한 θ=0.122가
   BF2(kp 0.77, sidelobe 오염으로 집중도 0.004–0.05)에 전이 실패, 발동 0.
2. 강제-발동해도 1/5만 회복 — **병목은 은행이 아니라 피크 초분해**:
   5시드 중 3개는 beamform 최대가 sidelobe(|k0| 1.0–1.76 vs 참 0.77).
   오라클 참-k 단일원자는 corr 0.993(정보는 존재), seed1 강제-발동
   0.008→0.84는 "피크가 신뢰될 때 미세은행이 위상 코히런스를 복원"의
   존재 증명.

**폐쇄문**: BF2/준단색 하한은 방법 공통 한계로 유지하되, 원인을 "은행
양자화"에서 **"저SNR 희소 관측의 단일선 초분해"**로 정밀화. 재개
조건: 연속-k 파라메트릭 폴리시(NOMP/RELAX류 단일선 정제)를 감지 위에
얹는 설계 — 07-03 파라메트릭 강점(BF3/4 1comp 0.44/0.63)과 정합, 미착수.

## A-7 v2 사전등록 — 재개 조건 충족 실행 (2026-07-12 밤 동결, 방법 후보 B-1)

> 재개 근거: A-7 폐쇄문의 재개 조건("연속-k 파라메트릭 폴리시")을 그대로
> 실행 — 규칙 위반 아님. 목적: 지도교수 메모의 방법 후보 B-1(레짐-적응
> 하이브리드)의 1차 실증. 지시: "대안 제시보다 미리 해보고 결과 지참".

**설계 (동결)**:
1. **정제기**: beamform 상위 M=8 후보 피크 각각을 연속-k로 국소 정제
   (분산-구속 시공간 설계행렬에서 단일 성분 최소제곱/Newton) 후,
   **피크 파워가 아니라 데이터 적합(검증-분할 잔차)으로 후보 선택** —
   사이드로브 후보는 정제 후 적합이 나빠진다는 가설. (기존 자산:
   d18_relax_estimator의 RELAX 단일성분 경로, a7의 solve_mmse_bank.)
2. **감지 v2 (kp-불변)**: 정제-후보들의 적합 격차 기반 통계량(1위/2위
   잔차비 등 — kp 비의존)으로 준단색 판정. 보정은 판정 밖 데이터
   (BF3/BF4 1comp vs 5comp + BF2는 판정셋이므로 보정 사용 금지).
3. **하이브리드**: 감지 시 정제된 k에 미세 원자 추가(기존 solve_mmse_bank
   경로), 미감지 시 기존 hand 그대로(무해 보장 구조 유지).

**게이트 (동결 — A-7 원판 승계)**:
- **G-A7v2-1 (회복)**: BF2 1comp fixedT 5시드에서 전장 corr(lead0) ≥ 0.5
  AND 조우 rho ≥ 0.5 — **과반(≥3/5)**.
- **G-A7v2-2 (무해)**: 합성 6종 Δ전장 ≥ −0.01 AND YS17 12창 Δ조우 ≥ −0.02.
- **G-A7v2-3 (기제)**: 정제-후보 선택이 사이드로브를 실제로 기각하는지 —
  5시드에서 선택된 k의 참-k 오차 |Δk|/k_true 보고 (진단, 게이트 아님).
- FAIL 분기: "정제-선택으로도 저SNR 사이드로브 기각 불가"를 수치로 기록
  — B-1 후보의 리스크가 실현됐음을 메모에 반영.

## D-20 — 실측 리플레이 폐루프 (learned-FF의 첫 오지정 제어 무대)

**가설**: 실측(오지정 존재)에서는 learned-FF가 hand-FF보다 잔여 운동이
작다 — 추정 이득(+0.088 트랙)이 제어 가치로 전달된다.

**설계 (동결)**:
- 무대: 녹화 실측 장(스테레오)을 교란으로 재생. **d71 잔여-운동
  프레임워크 우선**(m(t)=η_recorded(선체위치, t), RAO≈1 히브 proxy;
  잔여 = m(t) − 명령(t), 명령은 t−τ 발행) — hydrofoil 전체 플랜트
  이식은 stretch(구조 장애 시 d71 방식으로 판정하고 공시).
- 레코드: YS17·AA15b·LJ18g(3사이트), 동결 60창 기하 그대로(레코드당
  12창 = 리플레이 구간), U는 실측-판정 관행. τ ∈ {0.5, 1.0} s.
- 팔: persistence(τ) / hand-FF / **learned-FF** (둘 다 스트리밍 1 s
  재추정, D-18 프로토콜) / oracle(녹화 참값, 천장).

**게이트 (동결)**:
- **G-D20-1 (예보 가치 실측 재현)**: 스트리밍 예보-FF(hand)가
  persistence(τ)를 잔여 RMS에서 이김 — 3레코드 중 2 이상, 양 τ.
- **G-D20-2 (★헤드라인)**: learned-FF 잔여 ≤ hand-FF — 창-짝지음 평균
  AND 레코드 부호 2/3 이상. (등록 예측: 오지정 무대라 learned 승 —
  틀리면 "추정 이득의 제어 전달 실패"를 그대로 기록.)
- **G-D20-3 (예산)**: learned 스트리밍 재추정 GPU 경로 ≤ 100 ms/회.
- FAIL 분기 각각 수치와 함께 기록 — 어느 쪽이든 논문 응용 절의 결정
  데이터.
