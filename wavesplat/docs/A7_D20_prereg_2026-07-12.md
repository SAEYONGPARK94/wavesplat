## A-7 — 준단색파 국소 미세 은행 하이브리드

**가설**: BF2 1comp류 붕괴는 은행 양자화(δk=kp/10 > 요구 2π/L≈0.026)가
원인 — 준단색 감지 시 피크 주변 국소 미세 은행을 덧붙이면 위상 코히런스
회복, 광대역에선 발동하지 않아 무손상.

**설계 (동결)**:
- 감지: beamform 파워맵의 피크 집중도(상위 1셀 에너지 비율) ≥ θ이면
  발동 — θ는 1comp vs 5comp 합성으로 보정하되 **발동/미발동의 결과
  게이트가 판정 기준**(θ 자체는 튜닝 허용, 판정 창 밖 데이터로).
- 미세 은행: 감지된 피크 k₀ 주변 |k−k₀|/k₀ ≤ 0.25, 각도 ±15° 영역에
  δk = kp/40 격자 추가(기존 은행 유지, 추가 성분의 prior는 모 셀 에너지
  승계). hand 팔(명시적 은행 MMSE 경로 — d3_m3_point_eval의
  point_gamma_mmse가 명시적-은행 패턴 전례)에 적용.

**게이트 (동결)**:
- **G-A7-1 (회복)**: BF2 1comp fixedT 에피소드(가용 전부)에서 전장
  corr(lead 0) ≥ 0.5 AND 조우 rho ≥ 0.5 — 과반 에피소드에서.
- **G-A7-2 (무해)**: 합성 대표 6 에피소드(부록 시트 세트, BF3–BF5)에서
  Δ전장 ≥ −0.01 AND 실측 YS17 12창 스팟에서 Δ조우 ≥ −0.02.
- FAIL 분기: "은행 양자화 처방으로 부족(위상 요구가 감지·정렬 오차보다
  엄격)" 기록 — BF2 하한은 방법 공통 한계로 논문 유지.

## D-20 — 실측 리플레이 폐루프 (learned-FF의 첫 오지정 제어 무대)

**가설**: 실측(오지정 존재)에서는 learned-FF가 hand-FF보다 잔여 운동이
작다 — 추정 이득(+0.088 트랙)이 제어 가치로 전달된다.

**설계 (동결)**:
- 무대: 녹화 실측 장(스테레오)을 교란으로 재생. **d71 잔여-운동
  프레임워크 우선**(m(t)=η_recorded(선체위치, t), RAO≈1 히브 proxy;
  잔여 = m(t) − 명령(t), 명령은 t−τ 발행) — hydrofoil 전체 플랜트
  이식은 stretch(구조 장애 시 d71 방식으로 판정하고 공시).
- 레코드: YS17·AA15b·LJ18g(3사이트), 동결 60창 기하 그대로(레코드당
  12창 = 리플레이 구간), U는 실측-판정 관행. τ ∈ {0.5, 1.0} s.
- 팔: persistence(τ) / hand-FF / **learned-FF** (둘 다 스트리밍 1 s
  재추정, D-18 프로토콜) / oracle(녹화 참값, 천장).

**게이트 (동결)**:
- **G-D20-1 (예보 가치 실측 재현)**: 스트리밍 예보-FF(hand)가
  persistence(τ)를 잔여 RMS에서 이김 — 3레코드 중 2 이상, 양 τ.
- **G-D20-2 (★헤드라인)**: learned-FF 잔여 ≤ hand-FF — 창-짝지음 평균
  AND 레코드 부호 2/3 이상. (등록 예측: 오지정 무대라 learned 승 —
  틀리면 "추정 이득의 제어 전달 실패"를 그대로 기록.)
- **G-D20-3 (예산)**: learned 스트리밍 재추정 GPU 경로 ≤ 100 ms/회.
- FAIL 분기 각각 수치와 함께 기록 — 어느 쪽이든 논문 응용 절의 결정
  데이터.
