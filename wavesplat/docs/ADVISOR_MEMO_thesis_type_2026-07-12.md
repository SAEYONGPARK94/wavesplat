# 지도교수 결정 메모 — 논문 유형과 방법 축 (2026-07-12)

> 목적: 랩미팅 '요청 1'의 실체. v1(WaveSplat) 발표 때 "기존 방법론의 조합
> 아니냐, 주제로 적절한가"라는 지적을 받았고, 이번 결과들도 같은 기준을
> 적용하면 같은 지적을 받는다. 이 문제는 화법이 아니라 **논문 유형의
> 선택**이며, 그 선택지와 각각의 근거·리스크·일정 영향을 정리한다.

## 0. 정직한 현황

- litcheck(반복 수행): 부품 수준 방법-신규성 없음 — amortized spectral
  prior(AHGP), 위상분해 ML 예측(다수), 결정-지향 학습(DFL), 레이더+학습
  (Ehlers) 전부 선행 존재. "조합+보장+도메인"이 현 주장 형식.
- 확보된 것: ①검증된 시스템(무학습 레시피 조우 0.96, 실측 zero-shot 8/8,
  스트리밍 5 ms) ②새 지식(검출 법칙·작동영역·오지정 기울기 −0.041/+0.070/
  +0.033·실패-창 법칙·제어 전달 t −4.02) ③평가 방법론(사전등록 게이트,
  가짜 양성 7건 자체 차단) ④비자명성 증거(작동하는 조합은 드묾 — 판정
  20여 건 중 실패 조합 다수를 수치로 보유).

## 1. 선택지 A — "문제-우선(system + science)" 논문으로 확정

**내용**: 방법-신규성을 주장하지 않고, "주어진 센서의 가능 한계 확정 +
학습의 자리 지도 + 검증된 배포 시스템"을 기여로 하는 유형.

- 근거: 해양공학 분야 표준 유형(Ehlers 계열·FutureWaves·벤치마크 논문들
  전부 새 네트워크 없이 성립). 투고 무대(OE/JOE/OCEANS)의 심사 기준은
  검증 엄밀성이며 이미 충족(군집-보정·HOS 재현·시드 재현·제어 전달).
- 리스크: **연구실 내부 기준과의 정면 충돌** — v1 때의 지적이 재현될 것.
  교수님이 이 유형을 명시적으로 수용해야만 성립.
- 일정: 즉시 집필 전환 가능(자산 완비). 최단 경로.

## 2. 선택지 B — 방법 후보를 개발해 방법 축을 세움

### 후보 B-1: 레짐-적응 하이브리드 추정기 (신규 개발)

준단색 감지 → 연속-k 파라메트릭 정제 / 광대역 → 은행-MMSE / 오지정 →
학습 슬롯을 **하나의 추정기로 정식화 + 전환 규칙 자체를 판정**.

- 근거(이미 확보): 레짐 지도 측정 완료(파라메트릭은 1comp 0.44/0.63 승자,
  은행은 광대역 승자, 학습은 오지정 승자), BF2 실패는 모든 방법 공통의
  열린 문제, A-7 존재증명(피크 신뢰 시 0.008→0.84, 오라클 0.993).
- 신규성 논거: 저SNR 희소 이동-관측에서의 검출-게이트 레짐 전환 추정기 —
  litcheck 필요하나 구체 조합은 미발견 상태.
- 리스크: 핵심 난제(저SNR 단일선 초분해)를 우리가 직접 풀어야 함 —
  실패 가능성 실재(우리 스스로 판정한 어려움). 일정 +1~3개월.

### 후보 B-2: 미분가능 물리-사후 관통 task-loss 하이퍼 학습의 방법론화

s2-head 계열(분산-구속 은행의 잡음바닥·prior를 우도가 아닌 **과제 손실**로,
미분가능 사후분포를 관통해 학습)을 방법 절로 정식화.

- 근거(이미 확보): 실측 3중 판정 완료 — 창-수준 유의(군집 생존), 시드
  재현, **제어 가치 전달(t −4.02, 3/3 레코드)**까지. 방법 후보 중 유일하게
  "끝까지 검증된" 것.
- 신규성 논거: differentiable filtering(KalmanNet류)·GP 우도 학습과의
  차별 = ①분산-구속 스펙트럴 은행 ②비-우도 task-loss(잔차-선택이 실패
  한다는 판정이 동기) ③실측 zero-shot ④제어까지의 전달 검증. litcheck
  1회 더 필요.
- 리스크: "새 네트워크"가 아니라 "새 학습 배치"라 심사자 성향에 따라
  방법으로 안 쳐줄 수 있음. 일정 +2~4주(정식화·차별화 서술).

## 3. 권고 (연구 상태 기준)

**B-2를 방법 절로 승격 + A의 지식·시스템 기여를 본문 골격으로 유지**하는
혼합형이 리스크-대비-근거가 가장 좋다. B-1은 매력적이나 미해결 난제를
새로 짊어지는 것이므로, 학위 일정이 허락할 때만 별도 장으로.

## 3b. ★1차 실증 결과 반영 (2026-07-12 밤 — "미리 해보고 결과 지참")

- **B-1: 리스크 실현 → 보류 권고로 하향.** A-7 v2(정제-후보 홀드아웃
  선택 + kp-불변 감지) 실행 결과 G-A7v2-1 FAIL(0/5): 감지의 kp-의존은
  해소했으나(보정 완전 분리 J=1.00 — 이 감지기는 소득), 저SNR에서
  **판별 마진 붕괴**(전 후보 잔차 <2 % 차이)로 선택 자체가 불능. BF2
  하한은 v1·v2 2중 판정으로 방법 공통 한계 확정. B-1을 학위 방법 축으로
  세우려면 이 벽을 넘어야 하는데 2회 시도가 모두 벽의 실재를 확인.
- **B-2: 정식화 완료 + litcheck 완료 → 실행 가능 확정.** 방법 절 초안
  (`DRAFT_method_B2_2026-07-12.md`, 수식 9·차별화 4축·검증표), litcheck
  결과 선행(AHGP·Bitzer'23·PFN-스펙트럴 2026·KalmanNet 계열·DFL)이 전부
  우도/task-agnostic — "우도 실패의 판정이 동기가 된 비-우도 task-loss"
  가 최예리 차별점으로 확정. 검증 사슬(창-수준 군집 생존·시드 재현·HOS
  재현·제어 전달 t −4.02)은 이미 완비.
- **갱신된 권고**: B-2 방법 절 승격 확정 + B-1은 "시도했고 벽을 정량화
  했다"는 예비 결과로만 발표에 포함(이 자체가 성실성 증거).

## 4. 발표에서의 화법 규율 (유형과 무관하게 적용)

- "조합"이라는 단어를 우리 입으로 쓰지 않는다. difference-first:
  "AHGP가 못 하는 것 4가지(분산 구속·task-loss·이동 연산자·실측
  zero-shot)를 한다".
- 비자명성 증거를 먼저: "조합이 자명하다면 아무 조합이나 작동해야 한다 —
  우리는 대부분의 조합이 죽는다는 것을 20건의 사전등록 판정으로 보였다.
  작동하는 조합을 찾고 왜 작동하는지 증명하는 것이 이 연구다."
- v1 지적("조합 아니냐")에는: "그 지적을 받아들여 이번엔 ①한계를 정량
  진단하고 ②그 진단이 설계한 후속기를 만들고 ③어느 조합이 왜 작동하는지
  판정 체계로 증명했습니다. 남은 것은 유형 결정입니다."
