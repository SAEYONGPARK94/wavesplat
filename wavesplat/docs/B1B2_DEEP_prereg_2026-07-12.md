## B-2 심화 — 목적함수 정면 대결 (방법 절의 핵심 주장 인증)

**주장 인증 대상**: "하이퍼는 우도가 아니라 과제-손실로 학습해야 한다"
(방법 절 M.1.2). 지금까지 근거는 잔차-**선택**의 실패(n-독약)였고,
잔차/우도로 **훈련한** amortizer와의 정면 대결은 미실시 — 이것이 방법
주장의 결정 실험.

**설계 (동결)**:
- 두 팔, 전부 동일: 아키텍처(PriorNet+SmultHead), init(v7fan 사전훈련),
  데이터(bwtask 8,000 셔드, val 666), **12,000 step**(기존 4k의 3배,
  500step마다 val, best-ckpt), 시드 {0, 1}.
  - **팔 T (task-loss)**: 기존 task_loss_one (질의점 과제 오차).
  - **팔 L (우도형)**: 동일 배관에서 손실만 교체 — 관측 20% 홀드아웃
    z-잔차 (n-독약이 선택에서 쓰던 그 신호로 **훈련**; 구현은 홀드아웃
    관측점 예측 MSE). 그 외 전부 동일.
- 판정: 동결 60창 (net_gamma_mmse + 각자의 head, use_em=False, kp_hint) —
  4모델(2팔×2시드) 각각.

**게이트 (동결)**:
- **G-B2D-1 (주장 인증)**: 창-짝지음 Δcorr(T − L) — 실패창(hand<0.5)
  평균 **≥ +0.05** AND 양 시드 방향 일치. (등록 예측: L은 n-독약 기제로
  실패창에서 바닥·prior를 잘못 배워 T에 짐.)
- **G-B2D-2 (충분학습 무해)**: T-12k가 현직(T-4k, bw_s0+head) 대비 전창
  평균 **≥ −0.01** (더 길게 배워서 나빠지지 않음; 이득이면 보고).
- 수렴 확인 의무: 두 팔 모두 val 곡선 플래토 확인(마지막 2k step 개선
  <0.002), 미수렴 시 step 연장.
- FAIL 분기: T가 L을 못 이기면 "task-loss 우위는 선택 단계 한정" —
  방법 절 M.1.2를 그 스코프로 축소(정직 기록).

## B-1 심화 — 학습 피크 식별기 (판별-마진 붕괴의 우회 가설)

**새 가설 (v2 FAIL이 열어준 것)**: 홀드아웃 잔차는 후보별 국소 통계라
저SNR에서 마진이 붕괴하지만, **사이드로브 기하는 샘플링 패턴의 결정론적
함수**다 — 전체 beamform 맵을 보는 학습기는 PSF 구조를 역산해 참 피크를
식별할 수 있다. (기존 폐쇄 셀과 구분: 비평가=실측 팔-선택 학습 FAIL이었고,
이것은 **라벨이 정확한 합성 지도학습** — 미판정 셀.)

**설계 (동결)**:
- 훈련 데이터: 해석적 1comp 장면 무제한 생성 — k ~ 로그균일(0.05–1.2),
  방향 균일, 진폭 ~ Hs/2 (Hs 0.2–1.0 저SNR 강조), 위상 균일, 관측 =
  a7v2와 동일 층화 기하 + 잡음 2 cm. 라벨 = 참 (kx, ky). **≥30,000 장면,
  ≥20,000 step, 수렴 확인 의무.**
- 모델: beamform 파워맵(51×51, kp-정규화 — 기존 입력 레시피) → 소형 CNN
  → 참-피크 위치 soft-argmax 회귀(+신뢰도 헤드). BF2 판정셋 정보 사용
  금지(k 분포에 BF2 특정값 몰아주기 금지 — 광대역 로그균일 유지).
- 판정 경로: 학습 식별기 k̂ → a7v2의 연속-k 정제 + 미세 원자 은행(기존
  배관) → 회복 채점.

**게이트 (동결)**:
- **G-B1D-1 (식별)**: 동결 BF2 5시드에서 |Δk|/k_true ≤ 0.05 — **≥3/5**
  (잔차-선택 v2는 2/5였음).
- **G-B1D-2 (회복)**: 식별 통과 시드에서 전장 corr(lead0)·조우 rho ≥ 0.5
  — 전체로 ≥3/5면 G-A7v2-1 소급 PASS 선언.
- **G-B1D-3 (무해)**: 식별기 신뢰도 게이트로 광대역(합성 6종 + YS17
  12창)에서 Δ ≥ −0.01/−0.02 (발동 억제 구조 유지).
- FAIL 분기: "전역 PSF 정보로도 저SNR 식별 불가 = BF2 하한은 정보 한계"
  로 3중 확정 — 이 역시 발표 실탄.

### ★B-1 심화 판정 (2026-07-12 집행)

**G-B1D-1 FAIL (1/5 < 잔차-선택의 2/5) / G-B1D-2 FAIL / G-B1D-3 공허
PASS(발동 0)** — 훈련 사양 준수(40k 장면·20k step·수렴 확인·89k params).
`b1deep_eval.json`, `b1deep_peaknet.pt`.

**그러나 판정의 진짜 산출 = BF2 하한의 3분해 (등록 FAIL 분기의 정밀화)**:
1. **가설 기제 자체는 인-분포 성립**: 해석적 장면에서 PSF 역산 id@.05
   0.85/id@.10 0.96 — 단 그 분포에선 argmax가 이미 95% 정답.
2. **★BF2 실패의 주인은 등록 생성모델 밖의 관측 클러터**: BF2 에피소드
   관측의 잔차 std가 잡음 모델(2 cm)의 **1.5–3.4배**, 참-k 코히런트
   성분은 공칭 진폭의 1–30 %뿐 — 지배 로브는 샘플링 PSF가 아니라 이
   클러터가 만든다. "맵 = 참피크×PSF+백색잡음" 전제가 BF2에서 깨짐.
   (→ 미결 질문: 이 클러터의 근원 — wavesim 레이캐스트/메시 해상도
   아티팩트 가능성 점검 필요. 신규 작업 항목 E-1로 등록.)
3. **시드별 3분해**: s2/s3 = 엄밀 정보 한계(참-k 진폭 ≤0.003 = 잡음
   이하) / **s0·s4 = 정보 존재**(참-k 정합필터 예보 0.97–1.00!)하나
   식별·fine-bank 해법 둘 다에 막힘 / s1 = 회복 가능(0.82).
4. **회복 경로의 독립 병목 발견**: 오라클 참-k도 fine-bank로는 1/5,
   단일성분 정합필터로는 3/5 (0.97–1.00) — G-A7v2/G-B1D-2의 회복
   게이트는 fine-bank 경로 상한에 눌려 있었음(소급 주석).
5. **신뢰도 헤드는 전이 성공**(성공 시드 0.967 vs 실패 0.07–0.14) —
   "못 찾는 걸 스스로 앎" = 무해 구조의 실질 근거.

**갱신된 폐쇄문**: "BF2 하한 = (a) 부분적 정보 한계(2/5) + (b) 미모델링
관측 클러터와 해법 병목(2/5 — 원리상 회복 가능: 정합필터 존재증명) +
(c) 가용(1/5)". 다음 공격로(등록 밖, 미착수): wavesim-연산자 통과 훈련
데이터 + 단일성분 회복 경로 — E-1(클러터 근원 점검) 선행 권고.
