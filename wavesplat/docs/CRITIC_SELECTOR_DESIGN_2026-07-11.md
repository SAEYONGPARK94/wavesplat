# 새 방법론 설계 — 학습된 비평가-선택기 (Learned Critic-Selector) v1

날짜 2026-07-11 밤 · 방향 고정("무조건 학습") 하의 신규 설계
· 공격 대상 = 한계 원장(LIMITATIONS_ledger)의 **문서화된 학습 한계 5개를 한 구조로**

---

## 1. 어떤 한계를 뚫는가 (원장 대조)

| 원장 | 한계 | 이 설계가 뚫는 방식 |
|---|---|---|
| **B9** | 관측 잔차는 후보를 줄 세우지 못함(무학습 선택기 3종 전부 편향 실패; 상금 +0.021 존재, 미시도 처방 = 비평가 망) | **비평가 망이 선택기가 된다** — 오늘의 실증: val-잔차 floor 선택이 실패 창에서 체계적으로 틀렸고 고정 대체가 +0.21 회수 (B9 상금의 조우-과제판은 10배 큼) |
| **B7** | 사전분포 강건화 실패 — "게이팅이 답" | 비평가의 실패-확률 헤드 = 학습된 게이트 |
| **B8** | 학습 prior는 실측 전이 실패, **게이트만 전이됨** | 비평가는 장(場)을 안 만들고 품질만 예측 → 전이 유리(게이트 계열) |
| **A3/C0** | UQ는 순위만, conformal은 분포 밖 무보장 | 과제-품질 직접 회귀 + 신뢰 규칙 래핑 |
| 오늘 | 창-안 잔차 ≠ 창-밖 품질 (floor 병리) | 비평가의 라벨이 **창-밖(조우 트랙) 품질** 그 자체 |

핵심 재배치: **"추정기를 학습하지 말고 검증자를 학습하라."** 이 관측 클래스에서
표현(정확도)의 학습 여지는 정리·측정으로 닫혔지만, **선택·검증의 학습 여지는
문서화된 채로 열려 있고(B9), 오늘 +0.21로 크기가 실측됐다.**

## 2. 구조

**후보 격자** (전부 인증 추정기 — 최악도 B1 캡 안, B9 처방 그대로):
band {[0.35,2.5], [0.15,2.5]} × floor smult {1, 3, 10} × γ {hand-beamform, net}
= 창당 12 후보.

**비평가 입력** (배포-관측가능, 후보당): 관측 요약(n, r-커버리지, Hs, kp,
스펙트럼 폭, split-half 빔포밍 불일치 p1↔p2 — 기존 X 지도 재사용) +
후보 진단(진폭비 std(f)/std(z), 대역-내 에너지 분율, 잔차 스펙트럼 백색도,
val-잔차 — **규칙이 아니라 특징으로 강등**, smult, band) + 분산관계 일치도.

**출력 2헤드**: ① 조우-트랙 corr 회귀(선택은 argmax) ② 실패 확률
P(corr<0.5) (게이팅). 장은 절대 출력하지 않음(설계법칙 2 준수).

**훈련**: 합성 아레나에서 라벨 무한 생산 — fixed-T v2 55에피소드(+head-sea v2)
× HOS(H7 배관) × bw 주입, 창마다 12후보 전부 진짜 과제-품질 라벨 계산.
L3 영-일치: 후보가 전부 동률인 쉬운 창 혼입(선택기가 "아무거나"를 배우게).
LORO(레코드/바다-계열 단위) 분할.

**배포**: 신뢰 규칙 래핑(B8 교훈: 게이트만 전이) — 비평가 확신이 낮으면
hand 기본값으로 후퇴. 12후보 × solve는 2k-점에서 100 ms 예산 안(병렬 가능).

## 3. 사전등록 게이트 (실행 전 동결)

- **G-C1 선택 가치**: 실측 60창에서 비평가-선택 ≥ val-잔차-선택 + 0.05
  (pooled, 창-군집 t ≥ 2.5). 오늘의 간극(실패 창 ~0.15–0.2)이 상금의 하한 추정.
- **G-C2 게이트**: 실패 창(corr<0.5) 예측 AUC ≥ 0.8 (zero-shot 실측).
- **G-C3 무해**: hand-후퇴 래핑 하에서 어떤 레코드에서도 hand 대비 < −0.01 금지.
- **G-C4 영-일치**: 동률 창에서 선택 분포 ≈ 균일(특정 후보 지문 암기 금지).
- 실패 시: 어느 게이트가 왜 깨졌는지가 결과 (B9의 "선택기 병목" 정밀화).

## 4. novelty 사전 점검 (실행 중 litcheck 필수)

"학습된 검증자/품질 예측"은 일반 ML에 존재(regression quality estimation,
learned model selection). **차별점 후보**: ①위상분해 파랑 예보의 배포 게이트로서
②창-안/창-밖 괴리(오늘 정량화)를 라벨 설계로 정면 공격 ③인증-후보 가족 위에서
최악 보증 유지 ④실측 zero-shot 판정. 과대톤 금지 — 조합+보장+도메인 주장.

## 5. 실행 계획

1. 라벨 공장: v2 에피소드 → 창 × 12후보 × 과제-품질 (스크립트, ~수시간 배치)
2. 비평가 학습 (특징은 수치 벡터 — 작은 MLP면 충분, N5 교훈)
3. 실측 60창 zero-shot 판정 (게이트)
4. 통과 시: L4(결정-손실)와 결합 — 비평가 라벨을 마루-도착시각 오차로 교체한
   변형이 자연스러운 다음 층
