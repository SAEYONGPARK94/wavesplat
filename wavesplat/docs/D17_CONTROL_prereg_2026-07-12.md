# D-17 사전등록 — 기설계 제어기 폐루프 시험 (2026-07-12 동결)

> 사용자 지시: 제어 응용 검증(시험→튜닝→토론), 필요시 재설계 허용.
> 本末 규율: 제어는 응용시연 — 주장은 "예보의 제어 가치"이지 제어기
> 자체가 아니다.

## 무대 (기존 자산 재사용)

- 제어기: `hydrofoil` 패키지 — Candela C-8 설정(11.3 m/s 합의 작동점),
  PD + 파고 피드포워드(FF), `hydrofoil.sim.run_simulation`.
- 바다: `d3_e2e_stream_ff.SEAS` 관행 유지(합성 다성분; BF2–BF5 커버
  여부를 보고에 명기). 시드 ≥ 2.
- FF 입력 팔 (동결):
  | 팔 | FF 명령 |
  |---|---|
  | no-FF | 0 (PD만) |
  | persistence | 현재 파고 유지 (무예보 경쟁자) |
  | hand-FF | mmse_gpu(kp_hint) 조우예보 |
  | **learned-FF** | net_gamma_mmse + smult_head 조우예보 (현직) |
  | GT-FF | 참 파고 (천장) |

## 지표·게이트 (동결)

- 지표: 잔여 히브 운동 RMS(무보상 대비 %), 회복률 =
  (persistence − 팔)/(persistence − GT).
- **G-D17-1 (예보의 제어 가치, 주)**: learned-FF 잔여 RMS <
  persistence-FF (전 해상 평균, 시드 2 재현).
- **G-D17-2 (추정→제어 전달, 서술)**: learned-FF vs hand-FF 부호를
  그대로 보고 — **깨끗한 합성에선 hand 우위가 정상**(07-12 부호 반전
  법칙)이므로 이 항은 게이트가 아니라 전달률 측정. 실측-오지정 무대의
  제어 시험은 실측 창 재생(리플레이) 후속 항목으로 분리.
- **G-D17-3 (예산)**: FF 산출 경로 ≤ 100 ms/스텝.
- FAIL 분기: 예보-FF가 persistence를 못 이기면 "이 제어기·해상에서
  예보 preview 가치 없음"을 수치로 기록(τ·대역 원인 분해 D-18로).

## 주장 형식 (동결)

"예보 기반 FF가 무예보 기준선 대비 잔여 운동을 X % 줄이고 GT 천장의
Y %를 회수한다" — learned vs hand 비교는 오지정 유무 조건부로만 서술.

## ★판정 결과 (2026-07-12, 동결 게이트 집행 + 검수 캐비엇)

**G-D17-1 FAIL**: 추정-FF(hand/learned)가 persistence-FF에 패배 (z RMS
learned 0.1264 vs persist 0.1010; 전 시드). 사전등록 FAIL 분기 발동 →
D-18 원인분해. **G-D17-2**: hand < learned 근소(깨끗한 합성 = 부호 반전
법칙 정합). **G-D17-3 혼재**: hand GPU 129 ms(경계), learned는 CPU
numpy 참조구현 2.4 s — 구현 아티팩트(GPU 포팅 시 ~130 ms 예상), 예산
판정은 GPU 경로 기준으로 유보.

**핵심 수치**: 무보상 대비 z RMS 감소 — persistence +26 %, GT 천장
+30 %, hand −6 %, learned −8 %. **GT조차 persistence 대비 근소**(0.0967
vs 0.1010) = 이 작동점(τ=0.5 s 프리뷰, 11.3 m/s)의 프리뷰 한계이득
자체가 얇음 (07-06 ctrl_tune 진단과 정합).

**검수 캐비엇 (판정의 유효 범위 제한, 메인 에이전트)**:
1. **동결-예보 프로토콜 아티팩트**: 구현은 20 s 워밍업 1회로 예보장을
   동결 — 30 s 주행(345 m) 동안 재추정 없음. 실배포는 10 FPS 스트리밍
   재추정(07-06: RLS 40 ms/frame)이므로, 관측 부채꼴(~90 m) 밖 탈상관
   (corr 0.83→0.01)은 상당 부분 이 단순화의 산물. **따라서 이 FAIL은
   "동결-예보 FF는 무가치"까지만 확정** — 스트리밍-FF는 미판정.
2. 커버리지: SEAS = BF3/BF4만(스크립트 관행). BF2/BF5 미커버.
3. 에이전트의 기제 분해는 유효: BF4(장파장, 원거리 corr 유지)에서도
   persistence에 패 → 개구 축과 별개로 τ=0.5 s 프리뷰-이득 축이 실재.

**D-18 스펙 (이 판정으로 확정)**: ①스트리밍 재추정-FF 팔(매 1 s 재추정,
캐비엇 1 해소) ②τ 스윕 0.5→3 s(액추에이터 지연 커지면 persistence 붕괴
— 예보 가치의 등장 지점 탐색) ③lp_alpha×preview 재튜닝(07-06 자산)
④UQ-게이팅. 게이트: 스트리밍-FF가 어느 τ*부터 persistence를 이기면
"τ ≥ τ* 액추에이터에서 예보 FF 가치"로 스코프 확정; 전 구간 패배면
"이 제어기 클래스·속도에서 preview 무가치" 종결.

## ★D-18 판정 (2026-07-12) — G-D18-1 PASS, τ\* = 0.5 s

`d18_ctrl_tune.json`, `scripts/d3_d18_ctrl_tune.py`. **설계 변경 판정
(수용)**: literal τ=preview_dt는 스모크에서 퇴화 확인(GT 천장 자체가
τ와 악화 — 플랜트 지연 없는 sim에서 공간 프리뷰는 전 팔에 오차만 추가)
→ τ를 **액추에이터 정보 지연**으로 구현(명령은 t−τ 발행) — 등록문의
"진짜 지연 모사·persistence 붕괴 기대"의 충실한 구현으로 메인 검수 수용.

- **스트리밍 hand-FF가 전 τ(0.5–3 s)·전 시드·전 해상(BF3/4/5)에서
  persistence 승**: z RMS 0.199–0.203 vs persist 0.248–0.293; noFF 대비
  +15~18 % 감소, GT 천장의 79–95 % 회수. persistence는 지연 하에서
  **능동적 해악**(noFF보다 나쁨 — 조우주파수 위상 오류, τ≈조우주기/4
  최악, 물리 정합).
- **스트리밍이 D-17 캐비엇 1을 직접 해소**: 전방-FF skill 20–30 s 구간
  frozen 0.15 → streaming 0.70 (부채꼴이 배를 추종).
- 예산: 재추정 평균 35 ms — 100 ms PASS. UQ-게이팅 무해무득(부채꼴 내
  σ 균일). learned 팔은 CPU 구현 비용으로 생략(공시; 깨끗한 합성에선
  hand≈learned 부호 반전 법칙상 결론 불변 예상, 실측-리플레이 시 재론).

## D-19 결과와 토론 (논문 응용 절 초안)

**결과 문장**: "스트리밍(1 s 재추정) 예보 피드포워드는 액추에이터 정보
지연 τ ≥ 0.5 s의 전 구간(0.5–3 s)에서 히브 응답을 무보상 대비 15–18 %
줄이고 완전-예지 천장의 79–95 %를 회수한다(C-8, 11.3 m/s, BF3–BF5,
시드 2). 반면 지연된 현재-파 반응(persistence)은 조우주파수 위상 오류로
무보상보다 나쁘다(−13~−32 %). 예보의 제어 가치는 '조우주기 대비
비무시(≥0.5 s ≈ 조우주기의 1/8) 액추에이터 지연'에서 등장하며, 그
가치의 전제는 관측 부채꼴이 선체를 추종하는 스트리밍 재추정이다(동결
예보는 20 s 내 skill 0.70→0.15로 붕괴)."

**토론 3점**: ①추정→제어 전달의 병목은 추정 정확도가 아니라 **예보
프로토콜**(스트리밍 여부)과 **지연 구조**였다 — D-17(동결·무지연)과
D-18(스트리밍·지연)의 대조가 그 증명. ②UQ-게이팅은 부채꼴 내 균일-σ
탓에 이 무대에서 무득 — 실측-오지정 무대(σ 요동)로 이월. ③learned-FF의
제어 이득은 깨끗한 합성에선 기대 불가(부호 반전 법칙) — 실측 창
리플레이 폐루프가 미래 항목(D-20 후보; 실측 스테레오 표면 위 가상 주행).
한계: 히브 단자유도 proxy(RAO≈1), BF2 미커버, learned 팔 GPU 미포팅.
