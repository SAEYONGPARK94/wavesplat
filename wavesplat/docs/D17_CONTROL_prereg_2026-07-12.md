# D-17 사전등록 — 기설계 제어기 폐루프 시험 (2026-07-12 동결)

> 사용자 지시: 제어 응용 검증(시험→튜닝→토론), 필요시 재설계 허용.
> 本末 규율: 제어는 응용시연 — 주장은 "예보의 제어 가치"이지 제어기
> 자체가 아니다.

## 무대 (기존 자산 재사용)

- 제어기: `hydrofoil` 패키지 — Candela C-8 설정(11.3 m/s 합의 작동점),
  PD + 파고 피드포워드(FF), `hydrofoil.sim.run_simulation`.
- 바다: `d3_e2e_stream_ff.SEAS` 관행 유지(합성 다성분; BF2–BF5 커버
  여부를 보고에 명기). 시드 ≥ 2.
- FF 입력 팔 (동결):
  | 팔 | FF 명령 |
  |---|---|
  | no-FF | 0 (PD만) |
  | persistence | 현재 파고 유지 (무예보 경쟁자) |
  | hand-FF | mmse_gpu(kp_hint) 조우예보 |
  | **learned-FF** | net_gamma_mmse + smult_head 조우예보 (현직) |
  | GT-FF | 참 파고 (천장) |

## 지표·게이트 (동결)

- 지표: 잔여 히브 운동 RMS(무보상 대비 %), 회복률 =
  (persistence − 팔)/(persistence − GT).
- **G-D17-1 (예보의 제어 가치, 주)**: learned-FF 잔여 RMS <
  persistence-FF (전 해상 평균, 시드 2 재현).
- **G-D17-2 (추정→제어 전달, 서술)**: learned-FF vs hand-FF 부호를
  그대로 보고 — **깨끗한 합성에선 hand 우위가 정상**(07-12 부호 반전
  법칙)이므로 이 항은 게이트가 아니라 전달률 측정. 실측-오지정 무대의
  제어 시험은 실측 창 재생(리플레이) 후속 항목으로 분리.
- **G-D17-3 (예산)**: FF 산출 경로 ≤ 100 ms/스텝.
- FAIL 분기: 예보-FF가 persistence를 못 이기면 "이 제어기·해상에서
  예보 preview 가치 없음"을 수치로 기록(τ·대역 원인 분해 D-18로).

## 주장 형식 (동결)

"예보 기반 FF가 무예보 기준선 대비 잔여 운동을 X % 줄이고 GT 천장의
Y %를 회수한다" — learned vs hand 비교는 오지정 유무 조건부로만 서술.
