# 명제 A — "지연·속도 우위를 어떤 형태로도 주장할 수 없고 전부 철회해야 한다"

## 판정: **잘못 세워졌다. 기소한 용의자가 진범이 아니다.**

### ★A-1. "게스트 시계 +3.9% rate error" 는 **존재하지 않는다** (3인 독립 확인)
스텝 사이에서 `CLOCK_REALTIME` 은 `CLOCK_MONOTONIC` 과 **−0.00 ± 0.01 ppm** 일치.
"3.9%" = **1255.5 ms ÷ 32,496 ms = 3.86%** — **같은 결함을 두 번 센 것**이고 **부호도 반대**다
(평균 집계 시간은 **과소**계상). ⟹ 08-05 초기 보고 2건 철회:
⛔"모든 짧은 구간이 3.9% 과대" · ⛔"WS 만 불리하게 오염(정정하면 보수적)".
베이스라인 4종도 **전부 같은 `time.time()` 래퍼**(`etkf_grid.py:125` 등) ⟹ 편향은
**N·프레임비용·팔에 무관한 보편 곱셈 상수 −3.86%** 이고 **같은 박스 비에서 정확히 상쇄**된다.
검증: ep100 −2.83% · batchB −4.25% · batchC −3.94% (전부 예측 −3.86%의 1 Poisson SE 내).
**중앙값은 사실상 면역**(mean 11.008→11.329 vs median 10.062→**10.081**).

### ★★A-2. 진범은 **BLAS 스레드 수**이고 크기가 **370배**다 (2인 독립, 다른 경로)
같은 코드·데이터·박스, `etkf_grid.py` 는 P0 이후 **무수정**:

### ★A-3. 초록 지연 괄호에 **검증 가능한 거짓 4개** (`paper/wavesplat.tex:52–53`)

2. **"132.6"** — 16스레드 unpinned 레짐 값
3. **"on a single CPU thread"** — 132.6 은 single-thread 측정이 **아니다** ⟹ 문장이 **자기를 반증**
4. **"Intel i7-12700H"** — 실제 박스는 **AMD Ryzen 7 7800X3D**(`/proc/cpuinfo` 확인)

진짜 비가 9.90×→12.05× 로 움직였는데 산문은 "~10×" 를 유지했다.

### A-5. 미기록 사실 2건

- **타이밍은 연구 설계에 실제로 피드백됐다**(척추 ≤100 ms · 사전등록 모델예산 ≤5 ms ·
  accuracy–latency frontier 게이트 · 지진학 이식안 기각 근거). 전부 **배율 게이트**라 −4% 는 뒤집지 못한다
  ⟹ **정확도 결론은 오염되지 않았다.**

### 다시 쓴 명제 (NEUTRAL 안, 내가 채택)
> **A′-1** 측정 위생: 팔당 −2.8~−4.3% 하향 편향. 처방은 철회가 아니라 **`perf_counter` + median + 대칭 재감사**.

> **A′-4** 보고 무결성: 초록 괄호의 사실 주장 4/4 거짓. **이것이 실제 사고이고 시계는 하나도 안 만들었다.**
> **A′-5** 범위: 전면 철회는 과잉. 배율 40–80× 주장과 시계 독립 진술은 산다.

# 명제 B — "혼잡 붕괴는 구현 결함이고 novelty 후보 (B) 는 죽었다"

## 판정: **반증도 확증도 아니다 — (B) 는 이 우주에서 한 번도 시험된 적이 없다.**

### ★★★B-1. 생성기가 (B) 의 전제를 실현한 적이 없다 (NEUTRAL·CON 독립 확인)
`wave_generator.py:222` = `rng.normal(dir_rad, spread_rad, n_components)` ⟹ **주파수 빈 1개당 방향 1개**.
실현 `spread_band_deg` 중앙 **3.9e−07°** (CDIP 실측 29.28°).
⟹ **합성 진리 자체가 유한 이산 성분집합이고 모델 클래스가 진리를 정확히 포함한다. 근사 오차 = 0.**
⟹ (B)*"이산 집합은 확산에 성분을 지불한다"* 는 **증명도 반증도 불가**.
★그리고 **확산 교차설계도 (B) 를 시험하지 않는다** — 30→60°는 원자를 각도상 흩뿌릴 뿐 연속 D(θ;f) 를
만들지 않는다. ⟹ 사전등록 `AMENDMENT 1` 로 §8 반증 공약을 **B2 로 약화**(혼잡 셀 산출 전, 노출 공개).

### B-2. 명제는 4층위를 뭉쳤다
| 층위 | 증거 상태 |
|---|---|
| (i) 구현 결함이 격차의 **일부**를 설명 | **방향 일치, α=0.05 양성 0건** |
| (ii) 구현을 고치면 격차가 **사라진다** | **증거 0건** — 가지치기 전면 제거해도 LETKF 격차 **80.9% 잔존** |
| (iii) 따라서 표현에 원리적 비용 **없음** | **물을 수 없는 문장**(B-1) |
| (iv) 격차의 원인이 곧 (B) 의 **확산 기제** | **미분리** — 오늘 증거는 전부 **성분수 축** |

### ★B-3. 결정적 검정 2건, 각각 자기 진영에 불리하게 나왔다
- **PRO 의 검정**: 가지치기 **미발동** OURS 런만 vs EXT-M → OURS **5/7 패, 중앙 +12.3%**.
  ⟹ 가지치기는 격차를 ~2배로 키우지만 **유일 원인이 아니다**. (단 e2e 격차 부호 = init 격차 부호가 **12/12**,
  회귀 ρ=+0.784, 기울기 0.535 ⟹ **혼잡 팔 격차의 73%가 초기화 배치**.)
- **CON 의 검정**: EXT-M 이 **LETKF 를 3/4** 로 이긴다(15comp 는 **시드 6/6 전부**).
  ⟹ CON 이 **n=15 층을 통째로 항복**. (B) 를 n=15 에서 인용 금지.

### ★★B-4. "혼잡 4지표 패배" 의 상당 부분이 **수축(shrinkage) 아티팩트**다 (CON 신규, 양쪽을 다 친다)
정규화 MSE = 1 − 2ρ√v + v 는 v=ρ² 에서 최소. n=30 에서 LETKF ρ=0.457 ⟹ 최적 VR 0.209, 실측 **0.15**
= **MSE-최적점에 거의 정확히 앉아 있다**(1% 이내). WS 는 VR 0.85 인데 ρ²=0.10 ⟹ 자기 최적보다 **28% 위**.
**양팔 최적 수축 시 WS vs LETKF 16/40, p=0.268 = 무승부.**
수축 불변 지표(Pearson ρ)로 층을 다시 보면:

| 층 | WS ρ | LETKF ρ | WS 승(ρ) | WS 승(nRMSE) |
|---|---|---|---|---|
| ≤5comp (60) | **0.999** | 0.326 | 60/60 | 60/60 |
| 15comp (20) | 0.504 | 0.477 | **12/20 p=0.503 (동률)** | 5/20 p=0.041 |
| 30comp (20) | **0.313** | 0.457 | **4/20 p=0.0118** | 1/20 p=4.0e−5 |

⟹ **방어 가능한 혼잡 패배는 n=30 에서만**이고, nRMSE/SS 는 ρ 가 낮을 때 주로 **진폭 캘리브레이션**을 잰다.

### ★B-5. **성분 예산은 한 번도 소진된 적이 없다** (PRO 신규)
`configs/estimation.yaml`: `max_n: 30`, 그런데 혼잡 36런 관측 `final_n` **최대 22 / 중앙 ~19**.
`coarse_to_fine.py:63` `stages=[3,8,15]` ⟹ **초기화 탐색은 GT 가 30성분이어도 15개에서 멈춘다**(성장만 초과 가능, 1회).
그리고 벽의 최대 상승은 **예산 여유 3배 구간**에서 난다: BF4 5→15comp **×15.7(OURS) / ×4.79(EXT-M)**,
예산이 실제로 절반 되는 15→30comp 는 **×1.22 / ×1.36**.
⟹ **(B) 가 명명한 기제("성분을 지불한다")가 직접 반증되는 방향.**

### ★B-6. 내가 전달한 `ρ=+0.316` 은 **원자료에 없다** (2인 독립 재현 실패)
기소 대상 OURS 팔: **ρ = −0.729, p = 0.007**(성분이 많을수록 **좋다**). batchC 100ep n≥15: **−0.514, p=0.0007**.
