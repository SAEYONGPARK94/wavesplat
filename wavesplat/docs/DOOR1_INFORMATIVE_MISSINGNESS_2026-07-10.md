# Door 1 — 결측이 정보다: 학습이 정직하게 살아남는 유일한 문

날짜 2026-07-10 · 외부 감사(fable) + 직접 측정 · `wavesim/raydrop_slope.py`, `data/episode_*_{uniform,slope}.h5`

---

## 0. 오늘의 마지막 반전

오늘 하루가 **학습을 여섯 번 죽였고**, 두 외부 감사가 *"과학적으로 well-posed한 학습
질문은 없다"*고 판정했다. 그 판정의 근거는 전부 **C1 — 가우시안 최적성**이었다.

> **그런데 C1은 관측 연산자가 η에 대해 선형이고, 결측이 무시 가능(ignorable)할 때만 성립한다.**
>
> **LiDAR는 둘 다 아니다.**

## 1. 왜 C1이 깨지는가 (두 개의 이유)

**① 정반사 결측 (specular dropout).**
`wavesim/raydrop_slope.py`는 실제 물리를 구현한다: 반환은 **표면 법선이 광선을 센서 쪽으로
반사할 때만** 존재한다.

```
mask_j = 1[ |∇η · n̂_j| < τ ]        선형 범함수의 문턱(threshold)
```

**② 가시성/가림 (occlusion).**
광선은 **처음 만나는 면**에 맞는다. 어느 면이 먼저 보이느냐는 **파형 자체**에 달렸다.

두 경우 모두 결합 우도가

```
p(z, mask | η) = p(z | η, 관측된 점) · p(mask | η)
```

이고 **두 번째 인자가 η에 대해 가우시안이 아니다** (probit/Tobit 절단 회귀).
⇒ **사후평균은 비선형이다. C1이 구속하지 않는다.**

이것은 손짓이 아니라, **선형 평활기가 증명 가능하게 최적이 아닌** 절단회귀 체제다.

## 2. 직접 측정: 반환점은 경사에 편향돼 있는가

레포에 **같은 시드의 `uniform` / `slope` 짝**이 100개 있다. 통제 실험이 준비돼 있었는데
아무도 돌리지 않았다.

**첫 시도는 틀린 통계를 썼다.** `|∇η|`로 재니 아무것도 안 나왔다(t = −0.7).
정반사는 **광선 방향의 부호 있는 경사** `∂η/∂r`에 달렸지 경사의 크기가 아니다.
크기는 정보가 있는 성분(광선 방향)과 없는 성분(가로 방향)을 **섞어 버린다.**

**옳은 통계로 다시:**

| 에피소드 | 광선방향 경사 편향 (같은 사거리 배경 대비, σ 단위) | t |
|---|---|---|
| uniform BF4 5comp | **+0.1560 ± 0.0497** | +3.1 |
| **slope** BF4 5comp | **+0.2469 ± 0.0336** | **+7.3** |
| uniform BF3 5comp | +0.1444 ± 0.0624 | +2.3 |
| **slope** BF3 5comp | +0.1875 ± 0.0342 | +5.5 |
| uniform BF4 30comp | +0.1970 ± 0.0599 | +3.3 |
| **slope** BF4 30comp | +0.2118 ± 0.0381 | +5.6 |

### 2.1 읽는 법 — 그리고 내 해석의 정정

**반환점은 센서 쪽으로 기운 면에 확실히 편향된다.** 그러나 **`uniform` 에피소드에서도
그렇다** (t = 3.1, 2.3, 3.3).

> **편향의 대부분은 정반사 결측이 아니라 가시성/가림에서 온다.**
> 정반사가 더하는 몫은 `+0.247 − 0.156 = +0.091 σ`이며, 이 표본에서는 **유의하지 않다**
> (se ≈ 0.060, t ≈ 1.5). BF3에서는 +0.044, BF4 30comp에서는 +0.015.

**이것은 Door 1을 죽이지 않고 넓힌다.** C1이 깨지는 경로가 **두 개**이고, 그중 **더 큰 것은
정반사가 아니라 가림**이다. 그리고 가림은 **모든 전방 주사 LiDAR에 존재한다** — raydrop
모델을 켜든 끄든.

**정직한 진술**: *"반환점의 광선방향 경사는 배경보다 +0.16 σ 높다(t ≈ 3). 정반사 결측을
켜면 +0.25 σ로 오르지만, 그 증분은 이 표본에서 유의하지 않다. 관측 과정의 비선형성은
주로 가시성에서 온다."*

## 3. 감사의 네 문 판정

| 문 | 판정 | 이유 |
|---|---|---|
| **1. 정보를 가진 결측 (MNAR)** | **활짝 열림** | C1을 **원리적으로** 깬다. 마스크는 질의 격자 **전체**(수천 화소)에 정의된 **화소당 1비트 경사 측정**이다. 결측률 30–40%는 1비트 센서의 **최대 엔트로피 작동점**이다. S1이 보인 prior 지배 체제(c < 0.2)에서, 수천 개의 저-SNR 경사 비트가 수축을 실질적으로 올릴 수 있다 |
| 2. 함수를 바꾼다 (Brier/CRPS) | **지표로는 열림, 학습으로는 닫힘** | 최적 파봉 예보는 `Φ((μ−c)/σ)`이지 plug-in `1[μ>c]`가 아니다. 그건 **실제 격차**이고 ρ²의 재진술이 아니지만, **학습이 필요 없다** — 솔버가 이미 분산을 준다. DPS는 사후가 비가우시안일 때만, **즉 Door 1 안에서만** 값을 한다 |
| 3. 센서를 배운다 | **Door 1의 부품** | `R(r)`은 잔차 프로파일에서 적합 — 배관. `p(반환 \| 경사, 사거리)`는 **Door 1이 필요로 하는 결측 우도**다. 독립 챕터가 아니다 |
| 4. 과소결정 체제 (prior 지배) | **반쯤 열림 = L1의 함정** | `c < 0.2`면 오차를 γ(k)가 지배한다. 그런데 **같은 c < 0.2가 잘못된 prior를 데이터로 탐지하는 것도 굶긴다.** 탐지기가 추정기만큼 굶는다. Door 1 실패 시에만 |

## 3.5 측정: 마스크는 실제로 몇 비트인가 (`scripts/d3_s2_mask_information.py`)

망을 만들기 전에, **S1과 같은 방식으로** 마스크의 정보를 직접 쟀다. **아무것도 채점하지
않고, 아무것도 학습하지 않는다.**

광선의 광선방향 경사 `s_j = G_j a`는 bank 계수에 **선형**이다
(`G_j = (k·r̂)·[−sin ψ ; cos ψ]`). 반환 사건이 `p_j = f(s_j)`인 베르누이면, 1비트가 더하는
Fisher 정보는

```
I_j = (p_j′)² / (p_j(1−p_j)) · G_jᵀG_j ,   사후 정밀도 = Γ⁻¹ + ΦᵀR⁻¹Φ + Σ_j I_j
```

**600 진폭(σ₀ = 0.20 m) + 2,000 발사 광선**, τ = 0.10, 반폭 δ = 0.05, σ_s = 0.05:

| 마스크 모형 | 0.1–0.2 | 0.2–0.35 | 0.35–0.6 | 0.6–1.0 | 1.0–1.6 | 1.6–2.5 | 평균 Fisher 가중 |
|---|---|---|---|---|---|---|---|
| 없음 | 0.1976 | 0.1412 | 0.1099 | 0.0920 | 0.0831 | 0.0914 | 0 |
| **MCAR** | 0.1976 | 0.1412 | 0.1099 | 0.0920 | 0.0831 | 0.0914 | **0** |
| **two-sided (정반사 띠)** | **0.2212** | 0.1559 | 0.1219 | 0.1025 | 0.0946 | **0.1117** | 170.3 |
| one-sided | 0.2097 | 0.1487 | 0.1160 | 0.0973 | 0.0890 | 0.1022 | 52.5 |

### 3.5.1 세 가지

**① MCAR은 정확히 0을 더한다.** `p′ = 0 ⟹ I = 0`. **실험이 아니라 항등식이다.**
음성 대조군이 수치로 확인됐다(최대 |Δc| = 0.00e+00).
⇒ **MCAR에서 선형 MMSE를 이기는 학습기는 과적합이다.** 그리고 이것이
**C1이 구속하는 곳에서 망이 선형 해로 붕괴해야 함을 인증**한다.

**② 정반사 마스크는 진짜 정보를 갖는다**: 수축을 **+0.012 ~ +0.024** 더한다.
그리고 **양측 띠가 단측보다 더 정보가 많다**(Fisher 가중 170 vs 52) — 띠의 **가장자리
기울기**가 가파르기 때문이다. `τ = 0.10 ≠ 0`이므로 띠가 0 주위로 비대칭이고,
**부호 정보가 살아 있다.**

**③ 상대 이득이 짧은 파에서 가장 크다** — 예측대로.

| k/k_p | 0.1–0.2 | 0.6–1.0 | 1.0–1.6 | **1.6–2.5** |
|---|---|---|---|---|
| 상대 이득 | +11.9% | +11.4% | +13.8% | **+22.2%** |

마스크는 **경사**를 재므로 민감도가 `|k|`에 비례한다.
**진폭 관측이 가장 약한 곳(S1: c = 0.0831)을 정확히 보강한다.**

### 3.5.2 한계 (전부 실재한다)

- **Fisher 정보는 사전평균 `s = 0`에서 평가한 *기대* 정보**다. 실제 사후는 비가우시안이고
  진짜 이득은 다를 수 있다.
- **τ, δ, σ_s는 내가 골랐다.** `raydrop_slope.py`의 실제 상수로 보정하지 않았다.
  크기가 이 값들에 **강하게 의존**한다.
- **진폭과 마스크를 독립 추출했다.** 실제로는 반환점이 곧 `mask = 1`인 곳이다. **결합돼 있다.**
- 발사 광선 2,000개는 가정이다. Falcon의 실제 발사율로 다시 해야 한다.

### 3.5.3 절차 노트 (정직)

이 측정을 **감사의 예측이 도착하기 전에** 돌렸으므로 **엄밀한 사전등록이 아니다.**
다만 감사는 내 수치를 **보지 못한 채** 예측을 내므로, 그것이 도착하면 **표본 밖 검증**이 된다.

## 4. 사전등록 (Door 1)

| | |
|---|---|
| **학습 대상** | 마스크를 **입력 채널**로 받는 amortized 사후분포 (또는 Tobit-EM 웜스타트 후 amortize) |
| **학습 분포** | HOS + 선형 JONSWAP × Falcon 연산자 × raydrop. **무제한, 독립 GT** (시뮬레이터 상태 — 스테레오 재구성 아님, **누출 없음**) |
| **라벨** | 시뮬레이터의 참 해면 |
| **지표** | **파봉 초과확률의 CRPS/Brier**. nRMSE가 아니다 — 윈도우 sd 0.108이 묻어버린다 |
| **게이트** | 마스크를 버리는 선형 MMSE 대비 **CRPS +0.010 이상**, z-std ∈ [0.7, 1.4] |
| **★음성 대조군** | **MCAR 결측**(경사 무관 무작위 35%)으로 재생성. 마스크에 정보가 **0**이므로 망은 **선형 MMSE를 이기면 안 된다.** 이기면 과적합이다 — 죽인다. 동시에 이 대조군은 **C1이 구속하는 곳에서 망이 선형 해로 붕괴함을 인증**한다 |
| **반증** | MNAR 이득 ≤ 0.010, 또는 MCAR 대조군 이득을 못 넘음 |
| **비용** | ~10 GPU-day |

**추가 대조군(내가 붙인다)**: `uniform` 에피소드는 **가림만** 있고 정반사 결측은 없다.
`uniform` vs `slope` 이득 차이가 §2.1의 `+0.09σ`와 정합해야 한다. 안 그러면 망이
가림이 아니라 다른 것을 쓰고 있다.

## 5. 실측에 대한 정직한 한계

- **스테레오 결측(저질감·백파·가림)은 Falcon의 정반사 결측과 다른 기전**이다.
  13 레코드는 Falcon-MNAR을 **직접 검증하지 못한다.**
- 할 수 있는 것: **실측 마스크를 공간적으로 섞어** 보고 성능이 나빠지는지 본다.
  나빠지면 마스크 **위치**가 정보였다는 뜻이다. **기술적 증거이지 헤드라인이 아니다.**

## 6. Door 1이 실패하면 — 위원회가 받아들일 음성 챕터

> ### **"선형의 천장: 성긴 LiDAR 파랑 추정은 추정기가 아니라 prior에 구속된다"**

| 주장 | 무엇이 그것을 **논문**으로 만드는가 (피로 보고가 아니라) |
|---|---|
| **1. 결측이 무시 가능한 곳에서는 C1이 구속한다** | **MCAR vs MNAR 실험**: MCAR에서 학습 이득이 **0**임을 보인다. 불가능성의 증명 |
| **2. 존재하는 비가우시안성은 ρ²에 예속된다** | HOS 급경사 스윕: 선형 MMSE − Stokes 보정 격차 < 0.010, `corr(비선형부, ρ²) = +0.997` |
| **3. 이 체제는 prior 지배(c < 0.2)이고, 데이터는 틀린 prior를 탐지하지 못한다** | **S1 수축 지도** + `c → 0`에서 held-out 잔차 탐지력이 붕괴함을 보인다 |

**세 개의 측정된 기전으로 된 불가능성 증명.** 방어 가능한 챕터다.

**그러나 Door 1을 먼저 돌린다.** 물리로 보면 **열릴 가능성이 있는 유일한 문**이고,
연구실에 **정직하게** 학습 챕터를 준다.
