# H7/H7b — HOS 아레나 판정: 레시피는 비선형에서 재현되고, 시뮬의 학습 방은 ~0.02뿐

날짜 2026-07-11 밤 · `scripts/d3_h7_hos_arena.py`, `d3_h7b_linear_twin.py`
· `results/direction3/h7_hos_arena.json`, `h7b_linear_twin.json`
· 설계 v2의 P2/P3 방 측정 (회계-먼저) + #7 HOS 재현 게이트 (상시지시)

## 0. 두 판정

**① #7 게이트 PASS — 레시피 헤드라인이 완전 비선형(HOS M=3)에서 재현된다.**
고정-T + 층화 2k + 잡음바닥, head-sea, 조우 rho @ M3:

| | seed 0 | 1 | 2 | 3 | 평균 |
|---|---|---|---|---|---|
| Hs 1.2 | 0.94 | 0.95 | 0.99 | 0.80 | **0.92** |
| Hs 3.0 (가파름) | 0.93 | 0.95 | 0.98 | 0.76 | **0.91** |

"주어진 센서로 조우예보 rho ~0.9"는 이제 선형 가정에 의존하지 않는다.
(남는 실측 게이트는 별도 — Bergamasco 이식이 다음.)

**② 시뮬의 학습 방 = 예측보다 작다 (등록 예측 부분 기각).**
같은 초기 위상의 **선형 쌍둥이**(a₀·e^{−iωt}, 부호 검증 rho 0.995) 대비 M3의
skill 손실 = 비선형성이 만드는 학습 가능 상금 상한:

| 방 (twin−M3 rho) | Hs 1.2 | Hs 3.0 |
|---|---|---|
| 환형 | −0.008±0.007 | −0.007±0.010 |
| 부채꼴 | +0.002±0.007 | +0.012±0.004 |
| 조우 | −0.001±0.003 | +0.023±0.018 (t 1.3) |

steepness 단조 방향은 맞으나(P2 0 → P3 +0.01~0.02) **크기가 등록 예측
(0.03–0.08)의 절반 이하, 유의성 미달**. G-HOS 게이트(≥0.01, t≥3)에 도달할
학습 상금이 사실상 없다 — L0b(Stokes-2)가 먹을 몫을 빼면 더 작다.

**해석**: 표고를 직접 주는 LiDAR에서는 가파른 비선형 바다도 "보이는 대로
적합"이 거의 최적 — Ehlers급 학습 이득의 주원천은 비선형 파가 아니라
**나쁜 관측 연산자(레이더 강도)**라는 설계 v2 §2의 예측이 정면 확인됐다.

## 1. 살아남은 학습 무대 (도전의 다음 수)

| 무대 | 근거 | 상태 |
|---|---|---|
| **P4 실측** (광대역·해류·미지 스펙트럼·GT잡음) | net-MMSE +34 %가 이미 증명한 방 | **유일하게 크기가 증명된 무대 — 다음 세션 본체** |
| L4 결정-지향 (MSE 아닌 손실) | posterior mean 비최적성(정리) | 미측정 |
| 계산 (88 k↔100 ms) | amortization | 열려 있음 |

시뮬 P2/P3의 L1/L2/L3 훈련은 **뛰지 않는다** — 상금이 게이트 아래임을 회계가
먼저 보였다 (설계법칙 1이 학습 실행 전에 낭비를 끊은 세 번째 사례).

## 2. 기록

- **H7의 M=1 팔이 Hs 3.0에서 NaN 폭주** (HOS M=1은 자유표면 BC의 부분
  비선형이 남아 순수 선형이 아님; NaN→hos_modes 필터 전멸→평평한 바다 위장,
  #58). 선형 기준은 쌍둥이(위상회전)로 교체 — 무조건 안정·정확 짝지음.
- seed 3의 조우 0.76–0.84는 쌍둥이도 낮음(0.84) → 비선형성 아닌 바다-특이
  (H4 seed 4 계열). 장면-적응/게이팅 축의 표본.
- 캐비엇: rho pooled corr, n=4 seeds, 단일 Tp·수심 50 m·head-sea. HOS 아레나는
  #7 재현용으로 충분하나 학습-방 정밀 회계는 실측(P4)에서 다시.
