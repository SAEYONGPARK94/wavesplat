## 1. 확정된 사실 (2026-07-11까지의 지도 — 재측정 불필요)

1. **규약 반전 (H3-OD)**: 구 벤치마크의 top-k 50점 규약이 과제 사망을 제조했다
   (정보반경 20 m는 인공물). 센서의 실제 고정-임계 법칙(T_MANUAL_50=0.01733,
   `wavesim/raydrop_threshold.py`)에선 복귀 ~88 k/에피소드·r90 73 m·조우예보
   부활. **모든 새 실험은 fixedT 에피소드로** (`data/episode_*_fixedT*.h5`,
   55개 dir0 + 10개 dir180(head-sea, 조우-인과)).
2. **무학습 배포 레시피**: 고정-T + 범위-층화 2,000점 + 잡음바닥(no_em,
   pexp=1, smult≈3~10) = 조우 rho 8/8 바다 0.90+, HOS M=3 재현(0.92/0.91).
   fan 전 벤치마크 +0.84 (BF2 1comp 0.19 = 하한).
3. **학습 불가 지대는 정리다**: 선형-가우시안·올바른-은행·MSE에서 posterior
   mean을 이기는 학습은 없다 (3중 계기 확인: H1/τ-스윕/H2). 표고-직접 센서라
   시뮬 비선형(HOS) 방도 ~0.02뿐 (H7) — Ehlers급 이득의 주원천은 나쁜 관측
   연산자(레이더)임을 확인. **학습의 방은 오지정(실측)·목적함수·검증·계산.**
4. **확보된 학습 양성**: ① net-MMSE 실측 8/8 레코드 +34 % (7/5, 커밋 4c66346)
   ② 실패-창 구조 +0.21 t4.6 (60창; 해부 결과 = 과제-보정 고정 바닥 ≈3σ₀의
   자동 발견 — "장면-적응"은 아님) ③ amortizer 111×.
5. **val-잔차 선택은 실패 창에서 체계적으로 틀린다** (H5의 n-독약 = 실측 판정
   파이프라인 동일 기제). 창-안 적합 ≠ 창-밖(조우) 품질. **장-겉보기 ≠
   트랙-정확도** (AA14 w10: 장 corr은 hand 우위인데 트랙은 −0.43 vs +0.32).

## 4. 규칙 (상시지시 — 위반 금지)

1. **회계 먼저**: 학습 실행 전 상금/천장을 닫힌 형식이나 무학습 사다리로 측정.
   천장 < 분해가능 효과면 학습을 돌리지 않는다. **단 천장 자체도 계기다** —
   과신 posterior의 회계는 유령 표적을 만든다(#55).
2. **사전등록·동결 게이트**: 숫자를 보기 전에 판정 기준을 문서에 동결. 게이트
   FAIL도 결과로 커밋. (오늘 하루 가짜 4건을 이 방식이 걸렀다.)
3. **학습 없는 경쟁자 먼저**: 모든 학습 주장 옆에 최강 무학습 팔(고정 상수,
   층화, 해석 보정)을 짝지어 측정.
4. **검증엔 HOS 비선형 필수, 헤드라인은 HOS·실측 재현 후에만.**
5. **novelty 주장 전 litcheck(WebSearch)**: "최초/유일/winning" 금지. 원리
   선점 확인 후 "조합+보장+도메인"으로만.
6. **fact-check**: 요약·보고 수치는 JSON에서 재도출 가능해야 함.
7. **출력은 우도/보정/품질 공간**: 망이 장(場)을 직접 내지 않는다(mean-collapse).
   예외는 결정론적 물리 사상(bound-wave 헤드)뿐.
8. **scratch는 레포 `tmp/`**, 시스템 /tmp 금지. 대용량(.pt/.log/92 MB h5)은
   git 미추적(gitignore 준수), 결과 JSON·문서·스크립트는 커밋.
9. **커밋 규율**: 실험 아크마다 `research(phd): [branch] ...` + 자기수정 번호
   (#현재 58까지) 기록.
10. **논문에서 "어떻게 잘 맞는가" 설명이 핵심** (사용자 지시): 기제 사슬 +
    장-겉보기 vs 트랙 대비 + GIF("자신있게 틀림 vs 겸손하게 맞음").

## 5. 주의사항 (자주 틀리는 함정)

- **top-k 50 에피소드(구 uniform/slope)로 조우예보 실험 금지** — 죽은 작동점.
- **val-잔차로 하이퍼(특히 잡음바닥) 선택 금지** — 실패 창에서 체계적 오선택.
- pooled corr을 forecast skill로 인용 금지 (07-05 혼용 금지 명령 유지).
- HOS M=1은 순수 선형이 아님 — steep에서 NaN 폭주 후 "평평한 바다"로 위장
  (#58). 기준 팔은 위상회전 쌍둥이로. 모든 기준 팔에 자명성 감사(sig 출력).
- 실측 GT(AA15a 등) 잡음 오염 — 교사는 계산(합성·닫힌형식)으로.
- 학습 net의 장면-전역 상수 특징(sig_z류)은 지문 암기 유발(C3/W7 기제).
- 이동/SA 서사, 적응 관측(M6), 신경과정(M4), 자기지도 pretext(M10)는 문서화된
  NO-GO — 재개하려면 그 문서를 먼저 반박할 것.
- 시뮬레이터/추정기 하이퍼는 **작동점이 바뀌면 재검증** (#57: 새 작동점에서
  EM 기본값이 이봉성 오진을 낳았다).
