# 학습 설계 v2 — 오지정이 있는 곳에서만 학습은 이길 수 있고, 그곳에서 이겨야 한다

날짜 2026-07-11 밤 · 사용자 챌린지("Ehlers 같은 선행연구는 다 거짓말인가? 우리가
방법을 못 찾은 것 아닌가?")에 대한 정지-검토-재설계 문서 · 실행 전 설계만

---

## 1. 챌린지 판정: 선행연구는 거짓말이 아니다. 오늘의 폐쇄와 무대가 다르다

| | Ehlers 2023 (OE) 계열 | 오늘의 H1/H2 폐쇄 |
|---|---|---|
| 바다 | **HOS 비선형** (bound wave, 뾰족 마루) | 선형 (JONSWAP 성분합) |
| 관측 | **레이더 후방산란 강도** — 그림자+기울기 변조, 표고를 직접 주지 않음 | LiDAR = **표고 직접 샘플** (z=η+2 cm 가우시안) |
| 모델 | 역연산자 미지 (MTF 보정 필요) | 올바른 분산 은행 보유 |
| 결론 | 오지정 2겹 → U-Net/FNO가 역연산자+비선형 학습 → **정당한 승리** | 선형-가우시안 → Bayes 닫힌 형식 → **학습 여지 0은 정리** (C1) |

- 우리 저장소의 자체 증거가 이 표와 정합: **net-MMSE 실측 8/8 레코드 +34% (G3
  PASS, 4c66346)**, DPS 성분 prior의 HOS 승리 — 오지정(실측 광대역/비선형)이
  있는 곳에서 우리도 학습으로 이겼다.
- 사용자 직관의 옳은 절반: **H2는 학습에게 이길 수 없는 무대를 준 실험이었다.**
  정리가 지배하는 곳에서 "학습이 못 이겼다"는 발견이 아니라 확인이다. 학습의
  공정한 무대(오지정)에서의 실험은 오늘 하지 않았다 — 그것이 이 문서다.
- 오늘의 폐쇄가 기여하는 것: "어디서 학습이 못 이기는지"의 **경계 증명** — 선행
  연구들이 밝히지 않는 부분(그들의 무대에서 오지정이 얼마나 기여하는지의 회계).

## 2. 우리 센서의 정직한 예측 (등록)

LiDAR는 레이더보다 **훨씬 온순한 관측 연산자**다 (직접 표고, 결측 4.8% @T_m50).
따라서 Ehlers급 개선폭을 기대하는 것은 물리적으로 부정직하다. 학습의 여지는
남은 오지정의 크기만큼만 존재한다:

| 무대 | 오지정 원천 | 예측 학습 이득 (사전 등록) |
|---|---|---|
| P1 시뮬·선형 (오늘) | 없음 | **0** (정리; 오늘 3중 확인) |
| P2 시뮬·HOS Hs 1.2 | bound 에너지 ~(ka)² ≈ 1–2 % | nRMSE ≤ 0.02 (작음) |
| P3 시뮬·HOS Hs 3.0 | ka ~ 0.1+, 마루 비대칭 | 0.03–0.08 (기제 서명: **이득이 steepness와 함께 증가해야 함**) |
| P4 실측 Bergamasco | 광대역·해류·미지 스펙트럼·GT잡음 | 기존 +34 % 위에 s2/floor 학습 +0.02–0.05 추가 |

기제 서명(P2→P3 증가)이 나오지 않으면 이득은 오지정 학습이 아니라 다른 것이다.

## 3. 학습 사다리 (설계법칙 4: 학습 없는 경쟁자 먼저)

**L0 (무학습, 필수 선행)**: 레시피(층화 2k+잡음바닥) + **해석적 Stokes-2 보정**
(`_compute_stokes2_correction_np` 재사용) — bound wave의 닫힌 형식 몫을 먼저
회수. L1–L3의 이득은 전부 L0 대비로만 인용.

**L1 — amortized 모델 지도** (net-MMSE v3 계보의 확장, 최우선):
net(장면 관측가능 통계) → **(s2, γ(k) prior-gain, 대역)**. 오늘 H5가 s2가 묶는
하이퍼임을 증명했고 현재 손맞춤(smult 10) — 이것을 장면-적응으로. 학습:
task-loss, HOS Hs-sweep + 선형 바다 혼입(L3 영-일치: 선형 장면의 목표 = 레시피
값). 등변성·정규화 k/kp 입력(G3 열쇠 재사용). **이미 실측 G3를 통과한 계보라
성공 확률 최고.**

**L2 — bound-wave 읽기 헤드** (Ehlers 기제의 우리-버전):
자유파 posterior 계수 → bound 보정장. 물리상 **결정론적 사상**(자유파가 주어지면
bound는 함수)이므로 mean-collapse 무대가 아님 — "장 출력 금지" 법칙의 예외가
성립하는 유일한 자리 (통계 회귀가 아니라 물리 연산자 학습). 교사 = HOS 진리 −
선형 최적 재구성. Stokes-2(L0)가 하한 경쟁자, 초과분만 학습의 몫.

**L3 — Ehlers-형 end-to-end 재현 팔** (공정성 대조):
그들의 방법(U-Net/FNO, 시공간 창 입력→장 출력)을 **우리 센서·우리 무대**에서
정직 구현. 예측: P3·P4에서 L0 대비 양수, P1에서 0±, 그리고 **L1+L2 조합이 L3와
동급 이상** (구조 삽입 > 무구조 학습, UQ는 우리만 보존). 이 팔이 있어야 "선행
연구 방법을 돌려는 봤는가"에 정직하게 답할 수 있다.

## 4. 게이트 (사전 등록, 실행 전 동결)

- G-HOS: P3에서 L1(또는 L2)이 L0 대비 nRMSE ≥ 0.01, t ≥ 3 (n ≥ 12 HOS seas,
  짝지음) AND P2 < P3 (steepness 단조 — 기제 서명)
- G-REAL: P4에서 L1이 현행 net-MMSE+레시피 대비 ≥ 0.01, 8-record 다수결
- G-ZERO: 선형 바다에서 |L1 − 레시피| ≤ 0.002 (영-일치; L3 법칙 — loss 아닌
  목표 혼입으로 보장, H2의 교훈)
- G-UQ: B1 캡·coverage 95 유지 (L2 보정 후에도)
- 판정문: 어느 게이트든 FAIL 시 해당 사다리 칸은 숫자와 함께 닫는다. L3가
  이기고 L1+L2가 지면 "구조 삽입 가설"이 틀린 것 — 그대로 보고.

## 5. 실행 순서 (다음 세션)

① HOS × fixed-T 장면 배관 (#7과 동일 배관 — 두 목적 공용) ② L0 측정
③ L1 학습·게이트 ④ P3 통과 시 L2 ⑤ L3 공정성 팔 ⑥ P4 실측 이식.
예산: 배관 반나절, L0–L1 반나절, L2–L3 하루.

## 6. 오늘 폐쇄문의 문구 수정 (정확성)

"정확도 학습 전 채널 폐쇄"는 **"선형-가우시안·올바른-은행 무대의 전 채널"**로
읽어야 한다. H1/H2/MAP 문서에 이 한정을 이미 담고 있으나("이 시뮬레이터 작동
클래스에서"), 논문에서는 §1의 표를 명시해 선행연구와의 정합을 보일 것 —
그들의 무대(오지정)는 우리의 P2–P4이고, 그곳의 학습은 우리 자신의 결과로도
살아 있다.
