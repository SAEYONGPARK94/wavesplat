# 기존 방법론의 학습 전이 가능성 — 블록별 검토 (2026-07-04)

질문(사용자): "기존의 방법론들은 학습으로 전이시켜서 대부분 할 수 있을 것 같은데 검토해줘."

답의 요지: **구조적으로는 맞다 — 파이프라인의 거의 모든 블록에 학습 대응물이 존재한다.
실증적으로는 절반만 맞다** — 이 프로젝트가 이미 시도한 결과로 보면, 블록별 성패가 갈리고,
어떤 블록을 학습으로 바꾸든 넘을 수 없는 게이트가 둘 있다(정보/식별가능성 한계, sim2real).
아래는 전 방법론 스택을 블록별로 "학습 전이: 입증 / 반증 / 미검증 / 무의미"로 분류한 것.

## A. 추정 파이프라인 블록별

| 블록 | 현 방법(물리) | 학습 전이 상태 | 근거 |
|---|---|---|---|
| k-space front-end | beamform matched filter | **무의미** (이미 최적·선형·0원) | 학습의 *입력*으로 쓸 때 돌파가 남 (beamform-detect 0.06–0.08) |
| 성분 검출 + 모델차수 | RELAX greedy + CV | **합성 입증 / 실측 반증** | neural-guided RELAX가 합성 sparse/고성분서 RELAX 이김(15중 10), OOD 일반화. 실측 직접전이 실패(BS net ~0 vs RELAX 0.6–0.7) |
| A·φ 적합 | ridge LS (닫힌형) | **무의미** (선형-가우시안 최적해) | 학습이 이길 공간 자체가 없음 |
| off-grid polish | Adam/GN on dispersion manifold | **무의미~보완** | 모든 학습법의 핵심 레버가 *이것*이었음("polish가 핵심"). 학습은 초기값 제공으로 이미 결합됨 |
| 장 prior/posterior | (없음)/GP | **입증** (가장 강한 학습 성공) | DPS set-diffusion prior: 복잡해·고성분·HOS 비선형서 RELAX 이김 + UQ 보정 (B1 0.113) |
| UQ | GP 무학습 UQ | **부분 입증** | DPS UQ 보정됨(합성). 기준: GP 무학습 UQ를 이겨야 의미 |
| 예보 전파 | 선형 dispersion (정확) | **미검증** (비선형 보정만 여지) | HOS-증강 *nowcast* 학습은 무효과였음; forecast 비선형 보정은 미시도 |
| 순차 갱신 | sequential update / ETKF | **미검증** (학습 필터 가능하나 동기 약함) | ETKF는 baseline이지 병목 아님 |
| 관측 계획 | (수동) / acq_net 시도 | **미검증** (sim 한정 가능) | d40 acq_net 존재; 오늘 판단rule은 얕은학습 실패(n=10) |

## B. 분석/설계 방법론 (메타 레벨)

- **CRB/FIM 분석**: 학습으로 "전이"되는 대상이 아니라 **모든 학습기의 상한**.
  오늘 확정한 이동-샘플링 식별붕괴는 데이터/기하의 성질이라 어떤 detector(CNN·diffusion)도
  못 넘는다는 게 R1(detector swap null)에서 이미 실증됨.
- **이동판단 rule**: 얕은학습 실패(LORO 0.67 < 항상음수 0.78). 합성증강+실측검증 또는
  CRB-유도 rule(무학습)이 경로.

## C. 모든 블록에 공통인 두 게이트

1. **정보/식별가능성 게이트**: 학습은 정보를 만들지 못한다. 이 프로젝트에서 학습이
   물리를 이긴 모든 사례는 *정보는 있는데 물리 추정기가 못 쓰는* 구간(복잡해 prior,
   sparse 고성분 검출)이었고, 정보가 없는 구간(개구벽, 오늘의 식별붕괴)에서는 전부
   물리 이하로 수렴했다.
2. **sim2real 게이트**: 물리는 무학습이라 공짜로 전이, 학습망은 실측 직접전이가
   반복적으로 실패(BS/YS). 전이시키려면 realistic 학습분포(broadband+잡음+기하+스케일
   정규화) 또는 실측 fine-tune(총 13 record뿐)이 필요. **어떤 블록을 학습으로 바꾸든
   이 게이트가 최종심.**

## D. 이 프로젝트 증거가 가리키는 승리 패턴

"학습이 물리를 대체"는 반복 실패(raw 회귀 mean-collapse ×5, DETR, self-sup 정체).
**"물리 구조 안에 학습을 끼워넣기"만 이겼다**:
beamform(물리) → 검출/prior(학습) → LS+polish(물리) → CRB(상한 검증).
오늘의 track-aware 재학습(+150% 상대회복, 단 RELAX 미달)도 같은 패턴의 연장.

## E. 권고 실행 순서

1. **FIM/CRB 식별가능성 정량화** (무학습, Direction I 자산) — 고정 vs 이동 연산자의
   FIM을 스펙트럼별로: 학습이 도달 가능한 상한을 이론이 먼저 결정. 상한이 낮으면
   해당 블록 학습 투자 자체가 무의미.
2. **실패레짐 합성재현** (10 Tp 창·실측 broadband 스펙트럼) — 오늘 합성(2.2 Tp)은
   실측 이동붕괴를 재현 못함. 실패가 재현되는 지점에서만 학습 GO/NO-GO가 유의미.
3. **그 레짐에서 track-aware neural-guided RELAX 재구축** (잔차반복 스크립트는
   scratchpad 소실 — 재구현 필요) + DPS prior의 이동-track 조건화.
4. **실측 fine-tune 프로토콜**: 13 record LORO(레코드 단위 held-out)로 sim2real 검증.
   이것 없이는 어떤 학습 전이도 "합성 데모"에 머무름.

## 판정 한 줄

"대부분 학습으로 할 수 있다"는 **블록 커버리지로는 맞고**(9블록 중 7개에 학습 대응물),
**가치 기준으로는 선별적이다**: 이길 수 있는 곳은 검출(합성)·prior·UQ 세 블록뿐이고,
이미 최적인 블록(LS·polish·beamform)은 바꿀 이유가 없으며, 모든 전이는 정보한계와
sim2real 두 게이트를 통과해야 한다 — 그리고 그 게이트는 학습이 아니라 물리(CRB)와
실측 검증이 지킨다.
