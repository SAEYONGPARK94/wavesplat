# M3 표현 팔(점군-native amortizer) — 사전등록 (2026-07-12 동결)

> 착수 지시(사용자, 디스코드). 토론 II 행동항목 #5의 정의를 따른다:
> **산출물 = 아키텍처 민감도 표** — 승패 무관 가치. 기대-보정 상태
> (지도상 예측: 표현 용량은 무관[G1·wiener2·속박파], 승부처는 계산·실측).

## 검정 대상 가설

**H-M3**: beamform 파워맵 단계가 점-수준 정보를 버린다 → 점군을 직접
인코딩하면 (a) 실측 정확도 동등 이상 + (b) 계산 이득(맵 단계 제거)이
가능하다. v1은 기하 정보만(x, y, t, z) — **CNN 팔과 정보 동등**(부가
채널(강도·입사각)은 실측 창에 없으므로 v2로 분리, 합성 전용).

## 팔·데이터·목적함수 (공정성 규약)

| 항목 | CNN 현직 (l1s2bw run 2a) | M3-point v1 |
|---|---|---|
| 입력 | beamform 6ch 51×51 맵 | 원시 점군 P(400,3)+z(400), kp·Hs 정규화 |
| 출력 | Ylog 51×51 (γ) + smult 헤드 | 동일 인터페이스 (γ 맵 + log-smult) |
| 데이터 | bwtask 셔드 8,000 | **동일 셔드 동일 분할** (val = 앞 666) |
| 목적함수 | task_loss_one (미분가능 MMSE) | **동일** |
| 초기화 | v7fan 사전훈련 + 4,000 step | 콜드스타트 + **12,000 step** (사전훈련 부재 보상 — 공시; 공정성 축은 데이터·목적함수·판정이며 FLOPs 아님) |
| 판정 | 동결 60창 (bw_s0_head) | 동일 창, 동일 kp_hint·시드 규약 |

아키텍처: perceiver-형 소형 set-encoder — 점 토큰(MLP) → self-attn 2블록
→ 51×51 격자 질의((kx,ky)/kp 임베딩)의 cross-attn 디코드 + 풀링 smult
헤드. 파라미터 ≤ 1.5 M(현직 CNN과 동급 규모), 추론 시 점 수에 선형.

## 게이트 (동결 — 숫자 산출 전)

- **G-M3-1 (실측 동등, 주)**: 동결 60창 짝지음 Δcorr(point − CNN현직)
  전체 평균 **≥ −0.01** AND 실패 창(hand<0.5) 평균 **≥ −0.02**.
  (우월 요구 없음 — 동등이면 계산 축으로 승부.)
- **G-M3-2 (계산)**: RTX 4080에서 88 k-점 fixedT 구름 1프레임의
  인코더+γ+MMSE 트랙-질의 총 지연 **≤ 100 ms**; beamform+CNN 경로와
  단계별 ms 비교표.
- **G-M3-3 (민감도 표, 무조건 산출)**: {hand, CNN 현직, M3-point} ×
  {전창, 실패창} corr 표 + 훈련 곡선. **승패 무관 논문 자산.**
- **G-M3-4 (시드)**: G-M3-1 통과 시 시드 1개 추가로 방향 재현 후 승격.
- **FAIL 분기**: "표현 축 이득 없음 — 정보 병목 재확인(G1·wiener2·속박파
  계보의 4번째 판정)"으로 기록, 민감도 절 재료로 사용.
