# 지도 — 이 관측 클래스에서 무엇이 학습 가능한가

날짜 2026-07-10 밤 · 통합 문서 (네 병렬 트랙의 결과가 이 지도의 셀을 채운다)
· 좌표계: 정보 채널 × 판정 · 모든 수치는 측정 또는 정리

> 원칙 전환: **길(후보를 하나씩 열어보기)이 아니라 지도(채널 전체를 격자로).**
> 오늘 45개 자기수정이 지도의 좌표를 만들었다. 학습이 살 수 있는 곳이
> "어디인지"가 아니라 **"어디뿐인지"**를 읽는다.

## 2. 지도에서 도출된 설계 법칙 (= 학습법)

1. **회계 먼저.** 채널의 정보 천장을 닫힌 형식(MI 통화)으로 계산하기 전 학습 금지.
   천장 < 분해가능 효과면 셀은 계산으로 닫는다 (#43·#45)
2. **출력은 장이 아니라 우도 공간.** 망은 모형(site·잡음·과정 파라미터)을 내고 추정기는 선형 solve (C1)
3. **영-일치 환원.** 안전한 출력 = 정확한 물리 해, 그리고 무정보 배치(MCAR·정상 바다)를
   그 목표와 함께 학습 분포에 넣는다 (C3·C4의 해독제)
4. **학습 없는 경쟁자 먼저.** 스칼라 λ·warm-start EP·peak-picker·정확 공식 (N2)
5. **교사 = 계산.** 수렴 EP·닫힌 형식·합성 진리. 오염된 스테레오 GT 금지 (AA15a)
6. **게이트는 천장 아래, 배포 작동점에서, 동등성 여백과 함께** (#39·#41·#45)

## 3. 지도가 강제한 아키텍처 (트랙 A1이 구현 중)

**우도-공간 배전반**: 망은 장을 절대 내지 않는다. 세 primitive, 전부 오늘의 결과에서 유도:

| Primitive | 유래 | 성질 |
|---|---|---|
| **EP-뉴런** — 활성함수 = 절단 가우시안 moment match | #40의 부호 수정 | `τ=0` ⇒ 항등 ⇒ R1이 아키텍처 성질 |
| **정보 게이트** — 학습 보정 × **계산된** `c_i` | S1의 수축 | **T1: 지지집합 암기(C3) 불가능** — 증명 대상 |
| **파동군 등변성** — 복소 진폭, 위상회전·SO(2)·k/k_p 스케일 | G3의 정규화 승격 | 해상상태 일반화가 구조 |

학습 자유도는 셋뿐: 광선/제약 위 attention(활성 3% 찾기 = amortized active-set),
message 스케줄, 회계가 연 채널의 헤드. **아키텍처는 정보를 만들지 못한다** —
정확도 천장은 지도의 숫자 그대로.

## 5′. 최종 판정 (2026-07-10 심야, 네 트랙 전부 귀환)

| 트랙 | 결과 |
|---|---|
| **A1** | 4/4 테스트 통과 (R1 2.27e-14, C3 주입 = 이론상한 = prior의 2.09 %). T1 증명, T2 모드별 증명 |
| **A2** | **시간 채널 닫힘**: 간극 +0.0038 < 0.005, 드리프트 4×에도 불변, val-선택 회수 0. λ-망 학습 안 함. H3 amortizer 111×, 오차 1.4–1.9 % |
| **A3** | **F2 발화**: Falcon = 임계 검출기 (p.13 사양 언어 + p.105 confidence/multi-return) ⇒ 마스크 배포 재개방 17.15 %. novelty: 원리 수준 없음, 조합+보장+경험만 |
| **A4** | **F1 불발화**: HOS 예산 0.53 %/MI 0.12 % — 보존적 비선형성은 전후 대칭이라 경사 채널을 못 연다. 잔여 = F1′(쇄파/바람), 그리고 폐쇄는 해상상태-조건부 (Hs 3.0에서 예산 2.47 %) |

> ### 지도의 최종 문장 (F2b로 확정):
> **시뮬레이터 안에서 정확도 학습은 전 채널 닫혔고 (HOS 포함),**
> **배포에서는 단 하나의 문이 열려 있다: 임계 검출 아래의 선택-인지 추론.**
> **F2b 측정 (게이트 사전등록 PASS)**: 배포 희소도·M=1에서 마스크/진폭 = **17.13 %**
> (계측기 3중 검증: MC 0.1 %, 기준 계측기와 mult 2.46 % 일치, model check).
> 반증자(M-look 평균화)는 **비어 있다** — 평균화가 비트를 벼려 M=16에서 48.6 %.
> 해상상태-조건부: 완만한 바다(Hs 1.2)에선 3.07 %. 대략 천장 ≈ **+0.049 nRMSE** (거친 바다).
> **→ G0b·③ 완결 (07-11 새벽)**: 선택-인지 EP의 짝지은 gain = **−0.0000 ± 0.0020 (null)** —
> 17 %는 광선 위치의 **경사** 정보이지 원거리 **위상** 정보가 아니며, 임계 top-k가 복귀를
> 20 m 안에 집중시켜(정보 반경 ~20 m) 진폭 자체가 부채꼴 과제에서 무기력(naive 1.31).
> **"50점→200 m" 에피소드 규약이 임계 법칙과 모순 — 벤치마크 운용 영역 재검토 필요.**
> ③ site-헤드: R1 정확(0.00e+00)·**MCAR-zero 학습됨**(τ 0.3–0.8 % of MNAR, L3 법칙 검증)·
> 17× 가속(6.0 s→0.35 s) — 그러나 **amortize할 교사 gain이 없고** 100 ms 예산 미달(350 ms).
> 남은 정확도 질문 단 하나: **마스크 17 %의 행선지 = 경사/Hs/통계 산출물** (미측정).

## 5. 결과가 지도를 어떻게 바꾸는가

- **A2 간극 ≥ 0.005** → 시간 셀이 학습 표적을 갖는 유일한 정확도 셀로 확정, λ-망 학습 개시
- **A2 간극 < 0.005** → "스칼라가 시간 채널을 포화한다" — 셀이 숫자와 함께 닫히고,
  학습의 정확도 자리는 F2에만 남는다
- **A3 임계형 확인** → 마스크 행이 2.5 %→17 %로 재개방, WaveEP가 정확도 챕터로 승격,
  시뮬레이터에 임계 raydrop 모델 추가 + s2c 재실행이 다음 실험
- **A4 F1 발화** → "닫혔다"는 논문에 못 들어가고, HOS에서 재개방된 상금을 정량
- **전부 음성** → "The Linear Ceiling"이 여섯 기제 완비로 확정, 학습 챕터는
  A1 아키텍처의 **증명 가능한 설계 방법론** + 속도 상금으로 선다

어느 조합이든 논문이 서 있다. **그것이 지도를 만드는 이유다.**
