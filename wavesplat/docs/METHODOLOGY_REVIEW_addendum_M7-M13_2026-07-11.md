# 방법론 검토 증보 — 추가 후보 M7–M13 (병렬 검토, 2026-07-11 심야)

본편(M1–M6) 위에 사용자 지시("다른 가능성·새 설계도 병렬로")로 추가 검토.
판정 기준 동일: 100 ms · UQ/무해 · 실측 전이 · 한계 원장 정합.

| # | 설계 | 요지 | 선행 | 판정 |
|---|---|---|---|---|
| **M7** | **조우-축 시계열 학습** | 장 복원을 건너뛰고 [상류 관측 회랑 → 배 위치 미래 η(t)] 직접 seq 학습. 1D 출력 = 소형 모델, 100 ms 자명, M2 손실 자연 결합 | WEC 제어의 상류-프로브 LSTM 레인 확립([LSTM 여기력 예측](https://www.sciencedirect.com/science/article/pii/S0029801824013611), [확률 확산-LSTM MPC](https://www.sciencedirect.com/science/article/abs/pii/S1568494624007804), [위상분해 비선형 ML](https://arxiv.org/pdf/2007.15250)) | **GO — M2의 아키텍처로 병합** (차별점: 점 프로브가 아닌 전방-fan LiDAR 2D + 설계선속 11.3 이동 + 결정-손실) |
| **M8** | **물리-잔차 부스팅** | 인증 레시피 예보의 조우-트랙 잔차만 학습(영-초기화 = 레시피 무해). 진폭 수축·군속도 타이밍 편향 같은 체계 오차 회수 (07-08: nRMSE≈√(1−ρ²), amp≈ρ 최적수축 — 리드별 보정 학습 여지) | 부스팅/residual learning 일반 | **GO — 소형·저위험 퀵윈 후보** (M2 손실로 훈련하면 mean-collapse 회피) |
| **M1b** | **후보 소프트-가중(MoE/BMA)** | 비평가가 하드 선택 대신 12 인증후보 가중 혼합 | BMA/MoE 표준; 내부 BMA 양성(빔 아크) | **GO — M1의 공짜 변형** (비평가 훈련 후 즉시 시험) |
| **M11** | **비평가의 실측 LORO 미세조정** | 실측 레코드에는 스테레오 진실이 있으므로 **비평가의 라벨(트랙 corr)은 실측에서 직접 계산 가능** — 합성 사전학습 + 실측 LORO 미세조정. 장 추정기가 아니라 품질 예측기라 GT-오염(AA15a) 위험 낮음 | selective-prediction 보정 표준 | **GO — M1 판정 후 2단계** (60창 소표본 주의, 비평가는 초소형) |
| **M13** | **conformal-on-critic 게이트** | 비평가 점수 위 split-conformal로 게이트 커버리지 보정(레코드-내) | conformal 표준, C0 한계(OOD 무보장) 내 | **GO — 게이트 헤드 마감재** |
| M9 | 학습 forgetting/시간 융합 λ(k) | 스트리밍 축 | A2가 구 작동점서 폐쇄; 신 작동점(88k)·실측 드리프트에선 미회계 | **HOLD — 회계 먼저** (신 작동점 A2 재실행 후) |
| M10 | 실측 자기지도 미세조정(pretext) | — | B2(사전과제↔하류 역상관) 문서화 | **NO-GO** (M11이 정당한 대체) |

## 통합 로드맵 (본편과 합침)

**1층 검증·선택**: M1 비평가 (+M1b 소프트가중, +M13 conformal, 2단계 M11 실측 미세조정)
**2층 목적함수·시계열**: M2 결정-손실 ⨉ M7 조우-축 seq (병합 실행) + M8 잔차 부스팅(퀵윈)
**3층 표현**: M3 점군-native (공정성 팔)

세 층이 전부 학습이고, 각 층의 실패 조건이 사전 정의됨(원장 정합). 실행 순서:
비평가 판정(진행 중) → M8 퀵윈 프로토타입 → M2+M7 본편 → M1b/M13/M11 마감재.
