## 0. 왜 조사가 아니라 **대조표**인가

오늘 하루가 **어떤 망은 원리적으로 불가능한지**를 증명했다. 그러므로 조사는
"무엇이 유행인가"가 아니라 **"우리 제약을 통과하는가"** 여야 한다.

**오늘 확정된 제약 (전부 실험으로 얻음)**

| 코드 | 제약 | 근거 |
|---|---|---|
| **C1** | 가우시안 해면 + 가우시안 잡음 → 사후평균이 선형·MSE 최적 | 정리 |
| **C2** | 실측 아카이브에 **바다가 13개** — 라벨 붙은 사상을 적합·검증 불가 | G1 축 분리 |
| **C3** | 학습된 γ(k)는 **지지집합을 외운다** → 분포 밖 −45% | L1, A |
| **C4** | 학습된 γ(k)는 **UQ를 파괴한다** (z-std 68,710) | L3 |
| **C5** | 적대적 학습으로 **강건화되지 않는다** (게이트 4/4 실패) | L2 |
| **C6** | 합성엔 **고칠 편향이 없다** — 잔차 규칙이 이미 최적 | N1, O1 |
| **C7** | 잔차·모델에 **읽을 서명이 없다** (q ≡ 0) | E4 |
| **C8** | **시간이 정보다.** 분산관계가 정적 오염의 판별자 | E3, C2 |
| **C9** | 보상(장 오차)은 **배포 시 관측 불가** → RL·밴딧 오프라인 학습 필요 | N1 |

## 2. 우리만의 망: **WaveKF** — 분산관계로 고정된 스펙트럼 칼만 필터

### 2.1 발상은 오늘의 결과가 강제한다

- **C8**: 시간이 정보다. 지금 우리 추정기는 20초 창을 **한 덩어리 배치**로 푼다.
- **E3**: 시간-전방 잔차가 유일한 판별자였다.
- **O1**: 편향을 빼면 남는 최대 결함은 **창 안의 비정상성**(regret +0.010).
- **박사 방향**: 스트리밍·재귀, 지연 ≤ 100 ms (메모리: 스트리밍 RLS ≡ 배치, 40 ms/frame).

이 넷이 **같은 물건**을 가리킨다.

### 2.2 구조

상태는 분산관계 껍질 위 각 모드의 **복소 진폭** `a_k(t)`.

```
전이 (물리, 학습 안 함):     a_k(t+Δ) = e^{−i ω_k Δ} a_k(t) + ε_k
관측 (기하, 학습 안 함):     z(x_j, t) = Σ_k Re[ a_k(t) e^{i k·x_j} ] + n_j

학습하는 것:  ε_k ~ N(0, Q(k/k_p))     ← 모드가 창 안에서 얼마나 표류하는가
              n_j ~ N(0, R(r_j))       ← 사거리 의존 관측잡음
```

**두 개의 반경 함수만 학습한다.** 각각 ~1k 파라미터. 나머지는 전부 물리다.

### 2.3 오늘의 제약을 통과하는 이유 — 하나씩

| 제약 | WaveKF가 통과하는 방식 |
|---|---|
| **C1** 가우시안 최적성 | 여전히 **선형-가우시안 상태공간**이다. 사후평균은 주어진 모형에서 **정확히 최적**. 학습은 **추정기가 아니라 모형**을 고친다 — γ(k)의 자리를 **시간축으로 확장**한 것 |
| **C2** 바다 13개 | Q, R은 **합성 바다에서 학습**한다. G1이 그 축을 이미 풀었다 |
| **C3** 지지집합 암기 | Q는 **분산**이지 이득이 아니다. `Q → 0`이면 **현재의 정상 모형으로 정확히 환원**된다. 학습이 틀려도 배치 MMSE로 되돌아간다 |
| **C4** UQ 파괴 | 칼만은 **공분산을 전파**한다. Q가 크면 sd도 커진다. **과신이 구조적으로 불가능** |
| **C5** 적대적 취약 | B1 증서가 그대로 유효(진폭 캡). 그리고 최악은 "Q를 잘못 잡음" = 배치 모형 |
| **C6** 시뮬레이터 결함 | Q가 겨냥하는 **비정상성은 우리가 시뮬레이션할 수 있다**(O1의 `nonstat`, regret +0.010). **고칠 것이 학습 데이터에 있다** |
| **C7** 서명 부재 | 필터의 **innovation**이 곧 시간-전방 잔차다. **오늘 이긴 기준이 필터의 우도 그 자체**가 된다 |
| **C8** 시간이 정보 | 구조 전체가 시간축 위에 있다 |
| **C9** 보상 관측 불가 | 학습 신호는 **합성의 GT**, 배포 시엔 필요 없음 |

> **오늘 죽은 여섯 개의 학습 시도가, 살아남는 하나의 형태를 조각해 냈다.**

### 2.4 무엇이 새로운가 (그리고 문헌 검증)

[Neural EKF](https://journals.sagepub.com/doi/10.1177/14759217231179912), [KalmanNet](https://www.emergentmind.com/topics/neural-network-aided-kalman-filtering),
[적응 Q 추정](https://ieeexplore.ieee.org/document/8455394)은 **모두 선행 연구다.**
전이·관측을 망으로 대체하거나 칼만 이득을 학습한다.

**우리 것의 차이(주장 아님, 검증 대상)**:
1. **전이를 학습하지 않는다.** `e^{−iωΔ}`는 분산관계로 **고정**. 물리를 지운 자리에
   망을 넣는 것이 아니라, **물리가 못 정하는 두 분산만** 학습한다.
2. **B1 증서가 붙는다.** 학습된 필터에 **가정 없는 상한**이 따라온다.
3. **실패 모드가 증명 가능하게 온건하다**: `Q → 0`이면 현재 추정기.

**⚠ 노벨티 주장 금지.** 위 세 가지가 선행 연구에 없는지 **정독 검증 전**에는 쓰지 않는다.
특히 "physics-fixed transition + learned process noise"는 구조동역학·항법에서 흔할 수 있다.

### 2.5 사전등록 (구현 전에 못 박는다)

**합성 게이트 (실측을 건드리기 전에 — #26의 교훈)**
1. `Q → 0` 극한에서 배치 MMSE와 `|diff| < 0.005` (환원 검증, P0와 같은 형식)
2. **비정상 바다**(O1의 `nonstat`)에서 배치 MMSE 대비 nRMSE **−0.010 이상** 개선
3. **정상 바다**에서 손해 **≤ 0.005**
4. **보정**: 모든 모집단에서 z-std ∈ [0.7, 1.4] (L1은 68,710이었다)
5. **음성 대조군**: Q를 **상수**로 고정(반경 의존 없음)하면 이득이 절반 이하로 줄어야 한다.
   안 줄면 반경 함수를 학습한 게 아니다

**실측 게이트 (합성 5개를 다 통과한 뒤에만)**
6. 30 셀에서 배치 대비 **−0.010 이상**, 잔잔한 레코드에서 손해 ≤ 0.005
7. **지연 ≤ 100 ms/frame** (제어 제약)

**예상 상금**: `nonstat`의 regret +0.010 + 스트리밍 이득. **작다.** 정직하게 말하면
오늘 확정한 효과(+0.021)의 **절반 수준**이고, 윈도우 sd(0.108)를 생각하면 실측에서
**분해 가능성이 빠듯하다.**

## 3. 더 작지만 더 확실한 둘

### 3.1 이분산 관측잡음 `R(r)` — 오늘 못 본 모형 오류
우리 σ₀는 **상수**다. 실제 LiDAR 잡음은 **사거리에 따라 자란다**(그리고 실측 스테레오는
원거리에서 재구성 오차가 커진다 — 원장 C1). MMSE의 가중이 틀려 있다.
**학습도 필요 없을 수 있다**: 잔차의 사거리 프로파일에서 직접 적합.

### 3.2 `k_p` 추정 — 배포에 필수, 지금은 GT에서 받는다
`kp_hint`가 **정답에서 온다.** 실전엔 없다. 15% 오차만으로 regret이 +0.0042 (O1).
빔포밍 파워에서 k_p를 추정하는 작은 망. **장을 만들지 않고, 실패해도 대역이 조금 어긋날 뿐.**

## 4. 정직한 결론

- **넓은 조사의 결과는 "대부분 막힌다"이다.** 장을 만드는 모든 계열이 C1에 걸리고,
  amortized 사후추정은 C6에 걸리며, 선택기·비평가는 C6·C7에 걸린다.
- **살아남는 것은 "물리가 정하지 못하는 분산을 배우는" 형태뿐**이다.
  γ(k)는 그 공간 버전이었고 실패했다(C3·C4). **Q(k)는 그 시간 버전**이고, 실패 모드가
  구조적으로 온건하다.
- **상금은 작다.** 이것을 헤드라인으로 삼으면 안 된다. 헤드라인은 여전히
  **D1(벽의 정체)**, **B1(증서)**, **E3(분산관계가 판별자)**다.
- **WaveKF의 진짜 가치는 정확도가 아니라 형태**일 수 있다:
  스트리밍·재귀·제어 호환·증서 부착 — **박사 골격이 요구하는 그것**.
