## 전체 3-챕터 골격

**Ch.A — The detection law defines the operating domain (규약 반전)**
- 주장: 벤치마크의 top-k 50 규약은 센서의 실제 검출 물리(고정 임계, 매뉴얼
  250 m@10 %)와 모순이며, 과제 가족의 사망(정보반경 20 m, 조우예보 rho 0.10)을
  제조했다. 실제 법칙에서는 복귀 88 k·결측 4.8 %·r90 73 m — 경사 0.87, 조우 부활.
- 증거: H3-OD T-스윕, H1 mcar 대조(같은 600점 살포 시 enc 0.86 — 예산 무죄),
  벤치마크 v2 (fixedT 에피소드 + E2E).
- 그림: T-스윕 표, mcar 대조.

**Ch.B — A no-learning recipe achieves encounter forecast (배포 레시피)**
- 주장: 고정-T + 범위-층화 2,000점 + 오지정 잡음바닥(no_em, smult 10) =
  조우 rho 8/8 바다 0.90–0.99, 100 ms 예산 내, HOS M=3 재현(0.92/0.91).
- 기제: n-독약(잔차-선택이 대용량에서 바닥을 죽임 — GP 오지정/nugget 문헌 정합),
  이봉성 = 추정기 병리(정보 벽 아님).
- 그림: H4 사다리, H5 팔 비교, H7 HOS 재현.

**Ch.C — Learning: provably useless where the model is right, provably
useful where it is wrong (학습 챕터)** — 아래 상세.

## Ch.C 상세

### C.1 The Linear Ceiling (음성 반쪽 = 정리 + 3중 계기)
- 선형-가우시안·올바른-은행·MSE 무대에서 posterior mean은 최적(정리).
  실험 확인 3중: 선택-인지 EP gain −0.0000±0.0020(G0b) / 행선지 전수 null(H1)
  / τ-스윕 유령 판정 + task-loss 학습 2런 전 게이트 FAIL(H2, 예측 공개 적중).
- 회계 교훈: "천장도 계기다" — 7×-과신 posterior의 분산-수축 지도는 존재하지
  않는 학습 표적을 만든다(#55).
- 시뮬 비선형(HOS)조차 방이 ~0.02(H7 선형 쌍둥이): 표고-직접 센서에서 Ehlers급
  이득의 주원천은 비선형이 아니라 관측 연산자다 — 선행연구 정합 표 (설계 v2 §1).

### C.2 The promoted positive (양성 반쪽 — 해부 후 최종 문장)
- **최종 주장 (해부 반영): 창-안 val-잔차로 잡음바닥을 고르는 것은 예보
  과제에서 실패 창일수록 체계적으로 틀리며(작은 바닥 선택 — H5의 n-독약
  기제가 실측 판정 파이프라인 안에도 존재), 과제-보정된 고정 바닥
  (smult≈3, task-loss 학습이 수렴한 값)으로 대체하면 실패 창이 구조된다.**
  5 레코드 60창: 나쁜 창(hand<0.5, n=25) Δ(head−hand) 시드 3개
  +0.198/+0.211/+0.227, 합동 +0.212±0.046 (t 4.62); 좋은 창 무해.
- **해부 (head_anatomy.json)**: head ≈ 상수 3.3±0.15 (fix3가 효과 전부 재현:
  나쁜 창 +0.211 vs head +0.227; 좋은 창 −0.009 vs −0.012), saliency ≈ 0
  (bias 항), corr(smult, 실패) −0.06 — **"장면-적응" 아님**. fix10은 나쁜 창
  최고(+0.270)나 좋은 창 손상(−0.047) — fix3/head가 균형점.
- **학습의 정직한 역할**: task-loss 훈련이 그 상수를 자동 발견(3.3 ≈ 균형점) —
  발견 도구로서 유효했으나 대체 가능(1-D 스윕). 세 번의 강등(γ-net 평균회귀,
  오지정-주입 기제, 장면-적응)을 거쳐 남은 것은 **추정기 공학 법칙 + 학습이
  그것을 찾아냈다는 방법론적 사례**.
- 기각 기록(게이트·해부가 죽임): γ-net 단독(+0.071, t 1.79), 오지정 주입
  (클린 대조 86 %), 장면-적응(상수로 환원).
- 그림: 60창 head-vs-hand 산점(bad 음영), GIF 스틸(AA14 w10: hand −0.43 →
  +0.32), fix3/fix10/head 나쁜-좋은 창 막대.
- **캡션 소재 (사용자 관찰 검증, 2026-07-11; 07-12 정밀화)**: AA14 w10에서
  hand는 **lead-0** 장 corr +0.72(head +0.66)로 "그럴듯해 보이지만" ★조우
  트랙은 −0.43(head +0.32) — 시각적 질감 유사 ≠ 조우점 위상 정확도. 바닥의
  효과는 정확히 "장 적합 −0.06의 비용으로 조우 위상 +0.75 회복". LJ18g
  w5/w10은 장 기준으로도 head 우위(0.81/0.76 vs 0.62/0.70). 눈은 진폭·질감을
  보존한 hand(진폭비 0.73× vs head 0.61×)를 선호하나 제어가 필요한 것은
  트랙이다. **07-12 리드별 재계산**(`d3_external_figs.py`, 그림
  fig_ext2): hand 장 corr은 lead 0 +0.72 → 10 s −0.06으로 붕괴, head는
  ~7 s에 장 기준으로도 교차 우위; 0–10 s 풀링은 +0.34 vs +0.35 동률 —
  "장 우위" 인용 시 반드시 lead-0으로 한정할 것.

### C.2b "어떻게 잘 맞는가" — 설명 절 (★사용자 지시 2026-07-11: 핵심으로 다룰 것)
- **기제 사슬 (정량과 함께)**: 창-안 val-잔차 선택은 창을 잘 맞추는 작은 바닥을
  고름 → 비구속 고-k/방향 성분에 과신 에너지 → 창 밖(조우점 미래)에서 위상
  폭주 → "자신있게 틀림". 고정 바닥 ≈3σ₀ → 비구속 성분 수축 → 진폭은 흐려지나
  구속된 구조의 위상 보존 → "겸손하게 맞음".
- **장-겉보기 vs 트랙-정확도** (AA14 w10: 장 hand +0.72 > head +0.66인데 트랙
  −0.43 < +0.32): 시각적 질감 유사 ≠ 조우점 위상. 평가 방법론 절에 경고로.
- 시각 증거: rescue GIF 5종(+동률 대조 1) — truth/hand/head 3패널, ★ 조우점.
- 이 절이 챕터의 설득력 본체: 숫자 표보다 "왜"의 서사가 먼저.

### C.3 방법론 기여 (승격 게이트)

### C.4 Limitations
