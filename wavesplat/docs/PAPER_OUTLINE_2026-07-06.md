## Contribution 문장 (페르소나 토론 v1 확정 + ⑬ 반영)
- **C1 정보 지평 설계 법칙**: lead\* ≈ R_max/(U+c_g); 조우주기 단축으로
  제어 preview 요구도 동시 스케일 → 주어진 Falcon×C-8 조합의 설계 판정
  (FF 대역 0.94-0.95 @22 kt, 지평 밖 붕괴 실증). + **정보 한계 3종 확정**:
  관측예산 무효(48 pt/frame 실측치에서 포화), 스펙트럼 oracle 갭 +0.06,
  기울기 상한 0.49(oracle도) — "추정기는 종결, 남은 것은 정보".
- **C2 제어-호환 스트리밍**: bank-MMSE ≡ 사전 있는 RLS(등가 7e-14),
  AR(1)-toward-prior 유한기억, 프레임당 40-47 ms(설계점)/15 ms(실측),
  10분 무드리프트, 온라인 γ 슬롯. (CN-RLS/DSWP 인용, 차별점 명시)
- **C3 실측 검증 + 자기진단 게이트**: 실측 스테레오 3레코드에 Falcon
  연산자 — pooled 0.7, 창-간 이질성(0.85-0.95 절반 / 0.4-0.5 절반)의
  법의학(용의자 5종 기각, bimod 마커, 사이트별 실패모드) → **사이트-적응
  val-residual 게이트: 3레코드 Spearman −0.38(p=0.021), 운용 곡선
  무게이트 0.49 → 50% 가용 0.68 / 30% 가용 0.73**.

## 장-절 구조 (수치·자산 매핑)

### 1. Introduction
- 하이드로포일 FF 제어의 파도 preview 요구(0.1-0.5 s; hydrofoil 논문
  11-41% 감소) ↔ 주어진 센서(Falcon FK24 사양표) + 주어진 차량(C-8 22 kt).
- 질문: "이 조합으로 제어-호환 실시간 조우예보가 성립하는가 + 시스템이
  자기 신뢰를 아는가".
- 선행 정직 배치: US10259544/US10538299(개념), FutureWaves(레이더 상용),
  LiDAR DSWP(OE 2023), preview servo(OE 2004), CN-RLS(RS 2024),
  풍력 LiDAR-FF 패러다임. 공백 = 정량 설계판정·지연 실측·실측 zero-shot·
  자기진단.

### 2. Problem Setting & Information Analysis (C1)
- 관측 클래스: 전방 팬 ±60°, 20-100 m, 10 FPS, ~48 pt/frame(사양 모사
  실측치), 2 cm; 궤적 외생; 지연 ≤100 ms.
- 정보 지평 법칙 + 설계점 검증 표 (`falcon_hos_probe_design22kt.json`:
  FF 0.94-0.95 / 0-10 s 0.72-0.80 / 붕괴).
- 정보 한계 지도: 관측예산 스윕(YS17 0), oracle 갭(+0.06), 기울기 상한
  (0.488) — 그림 후보: 3-패널 "한계 지도".

### 3. Streaming Estimator (C2)
- bank MMSE(무식별, beamform-power prior, val-select+EM) → 가중치-공간
  RLS 등가(수식 + assert 7e-14), AR(1)-toward-prior(파군 코히어런스 해석).
- 2-시간스케일(고속 필터 + 저속 γ). 지연 표: 40/64(설계점 m48 기준
  재측정 필요 — TODO), 15/32(실측), 10분 안정성(`stream_longrun.json`).
- net prior 슬롯: v3 zero-shot parity, v6fan(20k) 0.609 — "학습은
  oracle 갭(+0.06) 안에서만" 프레임. (v7 50k 평가 대기 — 검토 시 반영)

### 4. Validation (3-leg)
- 합성(linear probe 0.91) / HOS M=3(0.94-0.96; 비선형 비용 무) / 실측
  (YS17·AA15a·AA14).
- 강건성 표: 포즈 0.05-0.3°(0.96-0.92), 차폐 0.96, 사선파 0.99/0.95,
  BF2/BF5 0.90/0.95, U-스윕. GIF 자산 6종.
- 실측: pooled 0.70(2사이트), 스트리밍 0.76-0.78@15 ms, 창-간 이질성.

### 5. Self-Diagnosed Reliability (C3)
- 법의학 서사: 용의자 기각(GT 백색잡음/스프레드/해류/순진 드리프트/
  관측예산) → bimod 마커(−0.84, 선상 −0.78) → 홀드아웃 실패 →
  사이트별 실패모드 → **사이트-적응 게이트**(running-median 상대화).
- 3레코드 판정(−0.38, p=0.021) + **운용 곡선 그림**(`figs/gate_roc.png`).
- 캐비엇: 셀 n=36, 사이트-내 강도 이질(−0.66/−0.41/−0.20).

### 6. Control Closure (응용 시연)
- FF 제어 E2E: GT-FF 마진 6-16%, Stream 19-47% 회수(정직) → 기울기
  정보한계(oracle 0.49)로 귀속 + vel-가중 무효 → **제어기 측 레버**
  (LP 위상지연 0.8 Hz vs 조우 0.5 Hz) — 튜닝 실험 결과 반영(진행 중).
- 메시지: "corr는 필요조건; 제어 이득은 (기울기 정보한계) × (제어기
  설계)의 곱" — 요구-역산 관점.

### 7. Limitations / Future
- raydrop v1(반사율/입사각 무); 포즈 프레임-상관 오차 미검증(짐벌 가정);
  실선 시험 부재; GT=스테레오 상호오염; 나쁜창 원인 사이트별 미규명;
  control-aware 학습은 정보한계로 상한 제한; 22 kt 실측 불가(패치).

## 내용 검토 (2026-07-06 심야 — 사용자 지시 "2+4 기반", 결과 반영판)

**[검토 1] v7(50k 전면 재학습) — oracle 예측 적중, 정보한계 3중 확인**
v7fan mean 0.595(=v3), 나쁜 셀 0.214(전 모델 최고), 좋은 셀 0.751(소폭↓)
— 학습 5×/12×를 부어도 총합은 oracle 갭(+0.06) 안에서 재분배만 됨.
→ **2장 정보한계 지도의 세 번째 기둥으로 승격**: 관측예산(무효)·
스펙트럼 oracle(+0.06)·학습 스케일(4k→50k 정체). net 사용 권고:
v6fan(총합 0.609) 또는 v7fan(나쁜창 우선) — 차이는 논문에서 각주 수준.

**[검토 2] 제어기 튜닝 — 6장 톤 = "반양성" 확정**
preview 0.5→0.2 s로 GT-FF 마진 2배(11-28%; 논문 hydrofoil의 최적
0.1-0.3 s와 일치 — 기존 E2E가 부최적 설정이었음을 명시). lp_alpha는
0.05 유지가 최선(위상지연 가설은 preview로 흡수됨). Stream 회수율은
~20%로 불변 = **기울기 정보한계가 유일 병목으로 남음**. 6장 메시지:
"FF 접근은 유효(GT 2배 회복) + 회수율은 관측 사양의 한계 — 요구-역산:
기울기까지 원하면 어떤 센서가 필요한가"로 종결. (양/음 균형이 오히려
심사 방어에 유리)

**[검토 3] C1-C3 방어성**
- C1: oracle/예산/학습 3중 한계 확인으로 "분석 종결" 주장이 강해짐. 단
  lead\* 법칙의 조선 preview 문헌 재확인 1회 잔여(litcheck).
- C2 vs CN-RLS: 차별점 = ①등가성 명시 증명+assert ②주어진-Falcon 지연
  실측 ③2-시간스케일 γ ④실측 zero-shot. 논문에서 CN-RLS를 표로 직접
  대비할 것(회피하면 리뷰어가 지적).
- C3: 게이트 n=36·사이트-내 이질(−0.66/−0.41/−0.20)은 "예비 검증"
  수위로 서술; 운용 곡선(0.49→0.68@50%)은 강력하나 과주장 금지.

**[검토 4] 리뷰어 예상 공격과 응답**
① "실선 없음" → 사양-모사+실측 스테레오 3레코드+강건성 스윕 표로 응답,
한계절 명시. ② "3레코드 일반화" → '사이트-적응' 자체가 주장(보편 임계값
을 주장하지 않음)임을 명확히. ③ "개념 선행(특허)" → 방법·수치·공개
재현이 기여임을 서론에서 선제. ④ "GT 상호오염" → 부록에서 정량 논의.

**[검토 5] 재현성 부록**: 전 수치 ↔ JSON ↔ 생성 스크립트 매핑 표 작성
(오늘 세션 문서 ①-⑬가 원장; 스크립트 22종).
