사용자 지시: *"아까 낸 아이디어까지 합쳐서 순서를 세워줘. GPU를 사용하는 쪽으로."*

두 목록을 합친다: `DAY_SUMMARY_and_WILD_IDEAS`(W1–W14) +
`CRAZY_LEARNING_IDEAS`(CL1–CL13).

# 0. 순서를 정하는 두 사실

## (a) 의존성 — **W1이 여섯 개의 전제다**

```
W1 (GPU torch MMSE 솔버, 미분가능)
 ├─→ W8/앙상블 사후샘플 (1,000× 솔브)
 ├─→ W4/CL5 적대적 바다·자기대전 (∂nRMSE/∂sea 필요)
 ├─→ W14 관측 선택 최적화 (미분가능)
 ├─→ CL4 제어기 통과 학습 (추정기가 그래프 안에 있어야)
 ├─→ CL1 비가우시안 사후보정 (학습 데이터 = 수만 개의 MMSE 사후평균)
 └─→ CL9 물리 MCMC 제안분포 (가능도 평가 수천 회)
```

오늘 측정 [계산]: `n=2400, B=200,000` 에서 **111 ms** (CPU 대비 **80×**,
bank는 **100×**). **W1은 미친 아이디어가 아니라 병목 제거다.**

## (b) 정리 — **가우시안에서는 무엇을 해도 학습이 못 이긴다**

그러므로 **CL1(비가우시안 사후보정)이 유일하게 승리 가능한 실험**이고,
나머지 학습 실험은 **그 위에서만 의미**를 갖는다.
→ **W1의 첫 용도는 bank 확장이 아니라 CL1의 학습 데이터 생성이다.**

# 1. 일정 (GPU 점유율 포함)

## 🌅 P0 (오전, 2–3 h) — **W1 GPU 솔버** + 정합성 검증

**작업**: `mmse_bank_estimate` 를 torch로 포팅.
`K = ΦΓΦᵀ + σ²I` (n×n) → Cholesky. `Φ_q` 는 청크. 전 과정 미분가능.

**필수 검증 게이트** (사전검사 ④ 특권정보·정확성):
- torch fp32 해 vs numpy fp64 해: **부채꼴 안 nRMSE 차 < 0.005**
- 통과 못 하면 **그날 나머지 전부 무효.** 여기서 멈춘다.

**동시 처리** (30 분, 오늘 철회분 재수립):
- **I1** σ₀ 를 관측 밀도로 스케일 (`σ₀ ∝ √(n_ref/n)`)
- **I4** 영역별 zero-predictor 기준선으로 보고 (1.0 아님)
- **W10** fp16 검증: fp16 vs fp32 해 차 < 0.01 인가

**GPU 점유**: 20–40 % (검증은 작은 문제)

**부산물**: 이 시점부터 **한 장면 111 ms** → 오늘 하루치 실험을 **몇 분에** 재현.

### ⚠️ 오늘 밤 스모크 테스트 — P0는 "포팅"이 아니다 [계산]

최소 torch 구현을 돌렸다(같은 기하, 같은 분산관계 껍질, `B=3,836`):

| | 부채꼴 안 nRMSE | 시간 |
|---|---|---|
| numpy MMSE (γ prior + val 선택 + EM) | **0.558** | 2,472 ms |
| torch 최소구현 (**flat prior**) | **6.453** | 305 ms |

- **GPU 경로·기하·분산관계는 재현된다.** 같은 bank에서 **8×** 빠름.
  (오늘 잰 80×는 `B` 가 커져 **gram이 지배**할 때의 수치다. 현재 `B` 에서는 8×.)
- **그러나 flat prior면 nRMSE 6.45 — 쓰레기다.**

**교훈**: MMSE를 작동시키는 것은 **솔버가 아니라 `γ(k)` prior와 정규화**다.
오늘 σ₀ 교훈과 같은 말이다. 그러므로 **P0의 진짜 작업은 "솔버 포팅"이 아니라
`γ(k) 구성 + val 선택 + (선택적) SBL-EM` 을 torch로 옮기는 것**이며,
검증 게이트(numpy와 0.005 이내)는 **prior까지 옮긴 뒤에만 의미가 있다.**

**시간 재추정**: 2–3 h → **3–4 h.** P1은 그만큼 뒤로.

---

## ☀️ P1 (오전 후반, 1 h) — **W1의 첫 과학 실험: bank 20만**

**질문**: 부채꼴 안 nRMSE가 **0.505 아래로** 내려가는가?

- 내려가면 → 오늘의 "물리 20% 우위"는 **c(k) 이산화 손실이었을 뿐**이고
  bank를 키우면 사라진다 (가우시안 정리와 정합).
- **안 내려가면** → **정보의 벽이 먼저**임이 확정. 그것도 결과.

**주의** (오늘 배운 것): B를 키우면 **자유도 과잉**. σ₀·정규화를 **밀도와 함께**
재조정해야 한다(사전검사 ⑤). 대역도 hold-out으로 다시 고른다.

**GPU 점유**: 70 %

---

## 🔥 P2 (정오~오후, 3–4 h) — **CL1: 정리가 예측하는 유일한 승리**

### 사전등록 (지금 박아둔다)

- **모델**: MMSE 사후평균 → 관측 조건부 **정규화 흐름** 보정
  (또는 학습된 Langevin 3 step)
- **지표**: 부채꼴 안 nRMSE 이득 `Δ = nRMSE(MMSE) − nRMSE(MMSE+flow)`
- **설명변수**: 그 바다의 **excess kurtosis**
- **판정선**:
  1. 회귀 기울기 > 0, `R² ≥ 0.5`
  2. **음성 대조군**: 선형(가우시안) 바다에서 `Δ ≤ 0.01`
  3. 둘 다 만족해야 "학습이 비가우시안에서 이긴다"
- **실패 시 결론**: 학습은 **비가우시안조차 못 쓴다** (강한 음성 결과)

### 바다 사다리 (첨도 순)

| 바다 | excess kurt | 성격 |
|---|---|---|
| 합성 선형 | −0.19 | **음성 대조군** |
| 합성 2차 Stokes | +0.19 | 약한 비가우시안 |
| HOS M=3 | ? (측정) | 중간 |
| **극단 Stokes(가파른 바다)** | ? | 강한 비가우시안 |
| 실측 YS17 | −0.21 | 실측·가우시안 |
| **실측 LJ18g** | **+1.12** | **강한 비가우시안** ← 오늘 안 돌린 곳 |

**⚠️ LJ18g는 CL7 이후에만.** kurt 1.12가 **파도인지 재구성 오차인지 모른다.**
안 가르면 **flow가 잡음을 학습**한다.

**GPU 점유**: **90 %** (수만 장면 × MMSE + flow 학습)

---

## 🧪 P3 (오후, 2 h) — **CL7 → LJ18g의 CL1**

**CL7**: 관측 신뢰도 학습. 스테레오 픽셀별 로버스트 가중치.
**kill test**: LJ18g 오라클 병리(+0.235)가 사라지는가.
**부수 효과**: kurt 1.12 를 **파도 성분 / 잡음 성분**으로 분해.

분해가 되면 **P2의 사다리에 LJ18g를 정당하게 올린다.**

**GPU 점유**: 60 %

---

## 🌊 P4 (오후 늦게, 2 h) — **CL2 포락선 + W8 앙상블** (ρ² 법칙의 두 자식)

같은 뿌리에서 나온 두 실험. **둘 다 사전등록.**

### CL2 — 포락선 예보
- **지표**: 포락선(Hilbert amplitude, 5 m 스무딩) nRMSE
- **판정선**: **사거리 밖에서 skill > 0.1** (필드는 skill 0으로 확정)
- 성공하면 → **"정보의 벽은 필드에만 있고 포락선에는 없다"** → 한계 지도 재작성

### W8 — 앙상블 극파 확률
- W1으로 사후 샘플 1,000개 (GPU에서 수 초)
- **지표**: "3 초 뒤 crest > 2 m" 의 **Brier score / CRPS**
- **판정선**: 사후평균 기반 예보를 이기는가
- **미리 선언**: **nRMSE는 보고하지 않는다** (후크 방지)

**GPU 점유**: 85 %

---

## ⚔️ P5 (저녁, 2 h) — **CL4 제어기 통과 학습** (오늘의 최대 결함)

미분가능 foil 시뮬 + W1 솔버 → **heave RMS 가속을 손실로** 역전파.

- **판정선**: GT-FF 완벽 preview 마진(−11~−28 %) 중 **Stream-FF의 20 % 회수율 초과**
- **미리 선언**: **nRMSE는 나빠져도 무방하다.**

**GPU 점유**: 70 %

---

## 🌙 P6 (야간, 무인) — GPU를 재우지 않는다

두 개를 **밤새** 돌린다.

1. **W7 자기지도 사전학습 (42 GB 실측)** — MAE/대조학습으로 해상상태 표현.
   γ-net 조건으로 붙여 실측 zero-shot 개선을 본다. **GPU 100 %.**
2. **W4/CL5 적대적 바다·자기대전** — 생성망이 추정기를 부수는 바다를 탐색.
   **실패 아틀라스** + CL1 회귀의 표본 확대(첨도 축을 넓힌다).

**아침에 확인**: 찾아낸 최악의 바다가 **물리적으로 그럴듯한가**.
