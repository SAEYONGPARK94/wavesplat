## 2. 무엇이 확정됐나 (해석)

1. **영역별 최적이 다르다:**
   - 요구대역(0-2s, 제어용) + 폭풍 → **net v3 단독** 최고 (0.508 / 0.697)
   - 풍파 나쁜창(0-10s) → **net+bound-wave** 최고 (0.867, hand 대비 −18%)
2. **요구대역은 near-floor.** 모든 구성이 0.51–0.56에 몰림(스프레드 0.05).
   P5 dense-oracle floor(0.4–0.6)와 정합 = 이 대역은 물리적으로 더 짤 여지
   거의 없음. corr로 보면 0.86(진폭 정상, 위상/타이밍 양호).
3. **폭풍은 net이 극적 개선**(hand 1.31→net 0.70) — "학습 가치=prior 미스매치
   크기" 법칙(broadband서 hand 단봉 가정 붕괴).
4. **간단한 게 이긴다:** zero-shot net(+bound-wave)이 무거운 재학습을 이김.
   재학습(v8bw)은 폭풍 일반화 상실로 순손해.
5. **천장의 원인 = 모델 클래스(단일대역 자유파) × 데이터(이봉)** — 사다리
   0.19→0.46→0.55가 통제-실험으로 격리(real도 센서도 아닌 모델클래스).

## 3. 남은 방안 — 고민 (우선순위·정직한 payoff/effort)

### A. "공짜/저비용" (기존 결과 조합)
- **A1 영역-적응 블렌드** [effort 낮음 / payoff 확실-소]: 이미 있는 결과에서
  최적만 선택 — 요구대역·폭풍은 net 단독, 풍파 나쁜창은 net+bw. 규칙 하나로
  best-of-both. 새 실험 불필요.
- **A2 P1 리드-감쇠 + net+bw 결합** [낮음 / 소]: 오늘 P1(진폭 포락 감쇠)은
  hand에만 적용. net+bw의 장리드에도 얹으면 폭주 억제 추가 가능.

### B. 추정기 레버 (아직 안 해본 것)
- **B1 교차-상호작용 bound wave** [중 / 불확실-중]: 오늘은 self-super-harmonic
  (2k,2ω)만. cross-Tp의 지배 bound wave는 **교차항 (k₁+k₂, ω₁+ω₂)**. 상위-K
  피크 쌍의 합·차(set-down 포함) 후보를 bank에 추가 → 요구대역(self로는 무효)
  이 움직일 가능성. 유일하게 남은 미시도 추정기 레버.
- **B2 재학습 v9 (폭풍/broadband 학습분포 추가)** [높음 / 낮음]: v8bw 폭풍
  퇴행을 학습분포 확장으로 치유. 단 재학습 자체가 순손해였으므로 기대 낮음.
- **B3 2차 Stokes forward 연산자** [높음 / 중]: bound wave를 선형 후보가 아니라
  weakly-nonlinear forward로 직접 모델. 근본적이나 큰 작업.

### C. "0.5가 추정기 탓인가" (측정·해석 재프레임)
- **C1 GT 자기일관성 (K4 본 테스트)** [중 / 높음-해석]: P5는 요구대역이
  GT/모델 floor라 했는데, **스테레오 GT 자체 오차(상한 0.45σ 미확정)**가 그
  0.5의 일부면 "추정기는 GT-한계에 근접"으로 재해석 = 0.5가 추정기 실패가
  아님을 입증. RMSE를 안 낮춰도 결과의 의미가 바뀜.
- **C2 corr/진폭 분리 보고** [낮음 / 중]: FF preview 제어는 타이밍(corr 0.86)을
  씀. nRMSE 0.5 대신 "요구대역 corr 0.86 + 진폭비 1.0"으로 보고하면 성능이
  가혹지표에 가려지지 않음.

### D. 판을 바꾸는 것 (추정 밖)
- **D1 UQ/신뢰도를 산출물로** [중 / 중]: DPS 생성 prior(공짜 UQ)+게이트(K5) →
  "낮은 RMSE"가 아니라 "믿을 수 있는 예보+정직한 불확실성"으로 가치 재정의.
- **D2 센서 기하 재설계** [범위 밖]: 연속추적·광각 팬은 floor 자체를 바꾸나
  이건 추정 개선이 아니라 요구-역산 센서설계(별도 방향).

## 4. 추천 (정직한 판단)

**"RMSE를 더 낮춘다"의 현실:**
- 요구대역은 near-floor라 물리적으로 막힘(더 짜기 헛수고 위험 큼).
- 진짜 개선 여지는 (i) 풍파 나쁜창 — 이미 net+bw로 −18~22% 뚫음,
  (ii) 폭풍 — net으로 이미 −47%.
- 유일하게 안 해본 추정기 레버 = **B1 교차 bound wave**(요구대역 마지막 시도).

**추천 순서:**
1. **A1 영역-적응 블렌드** — 즉시, 확실한 best-of-both 정리.
2. **B1 교차-상호작용 bound wave** — 요구대역을 움직일 마지막 추정기 카드.
   되면 좋고, 안 되면 "요구대역 = 모델클래스로 뚫을 수 없는 정보 floor" 확정.
3. **C1 GT 자기일관성** — 0.5의 얼마가 추정기 vs GT인지 판정(해석 재프레임,
   RMSE 안 낮춰도 결과 의미 상승).
4. 이후 판단: 요구대역이 정말 floor면 **C2/D1로 가치 재정의**(성능→신뢰/타이밍)
   가 학위 서사에 더 정직·강함.

**한 줄:** RMSE 절대치는 요구대역 near-floor라 크게 못 낮추지만, 나쁜창/폭풍은
이미 크게 뚫었고, 남은 카드는 B1(교차 bound wave)·C1(GT 재프레임) 둘이며,
그마저 막히면 "성능이 아니라 신뢰/타이밍/한계지도"로 가치를 재정의하는 게
정직한 최적해.
