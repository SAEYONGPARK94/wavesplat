## ③ 스트리밍 순차 MMSE (d3_stream_seqmmse.py, 신규) — 제어 지연 실증

가중치-공간 뷰: bank 계수 w 정적(분산관계 시간의존은 설계행 안에), 사전 N(0, diag γ)
→ **배치 MMSE ≡ 사전 있는 RLS** (등가성 assert 7e-14 PASS). 유한 메모리 =
AR(1)-toward-prior (w←aw, P←a²P+(1−a²)Γ, a=exp(−dt/τ)) — 정상해가 사전과 일치하는
칼만 역학(물리 해석: 파군 코히어런스 시간). 2-시간스케일 구조: 고속 루프(프레임당
필터) + 저속 루프(γ 재선정 — beamform/EM 또는 net prior, ~10 s 주기, 스텁).

BF4_15comp 에피소드, 최적화 knob (prune K=300, m=20/frame, τ=30 s):

| 항목 | 수치 |
|---|---|
| corr now/f2/f4 | **0.634 / 0.622 / 0.594** |
| 프레임당 지연 | **중앙값 40 ms, p95 64 ms** (numpy CPU) → **100 ms 예산 PASS** |
| 같은 에피소드 배치-600 벤치 | 0.50 (스트리밍이 상회 — 윈도우 캡 없이 전 프레임 동화) |

- **디버그 교훈: 품질 붕괴(corr 0.06)의 원인은 fade가 아니라 P 대칭화 누락**
  (300+ 스텝 랭크-m 다운데이트의 수치 비대칭 누적). `P←(P+Pᵀ)/2` 한 줄로 해소.
  fade(τ=30)는 오히려 순수 RLS보다 소폭 우수(0.634 vs 0.611).
- 문헌 정직성: RLS/칼만 파랑 동화는 기존(CN-RLS, DSWP) — 기여는 주어진-Falcon
  연산자에서의 지연 실측 + 등가성 + net-prior 슬롯이지 필터 자체가 아님.

## ⑥ UQ 신뢰도 게이팅 (사용자 지시 #1) `uq_gating_real.json`

- **교정: z-std 2.05 (×2 과신), cov95 0.80** — 고정-prior 사후분산은 실측에서
  무교정(GT 노이즈 미차감 캐비엇).
- **게이팅: 셀(윈도우) 수준 실패** (Spearman +0.05, 신뢰/위험 절반 0.65/0.61) —
  분산은 관측 기하만 알고 모델 오지정(비정상성)을 모름. 점 수준만 약한 분리
  (0.73/0.60).
- **★대안 게이트 발견: 추정기 내부 held-out val-residual** (`val_gate_probe.json`,
  12셀 W=20): Spearman −0.44(p=0.15), **신뢰 절반 0.78 vs 위험 절반 0.56** —
  인과 신호(윈도우 내 데이터만 사용)로 K_ff 게이팅 후보. n=12라 유의성 미달 —
  표본 확대 필요.

## ⑦ 갭 해부: 합성 0.9 vs 실측 0.7 (사용자 지시 #2)

- **해류 기각**: Uc 스윕(3윈도우×5값) 평탄, 최적 Uc 이득 ≤ +0.03.

**★재프레임: 갭은 균일하지 않다** — 윈도우 skill 이봉 분포: 절반은
**0.85–0.95(합성급, 갭 없음)**, 절반은 0.4–0.5. per-window 평균 0.66 ≈ pooled
0.70 (채점 아티팩트 아님). 잔존 용의자 = **비정상성/윈도우 이질성**(레코드 내
Tp 5.5→7.2 s 드리프트), raydrop v1, 스펙트럼 미세형상. → "나쁜 창 검출"이
