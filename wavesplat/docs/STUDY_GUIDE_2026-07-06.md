# 1. 왜 이 문제인가 (배경)

## 1.1 하이드로포일과 파도
Candela C-8 같은 포일링 선박은 날개(포일)로 선체를 물 밖에 띄워
달립니다. 포일이 받는 힘은 물의 흐름 각도(받음각)에 민감한데, 파도는
두 경로로 받음각을 흔듭니다:
- **파면 기울기(slope, ∂η/∂x)**: 물 표면이 기울면 유효 받음각이 변함
- **궤도 수직속도(w)**: 파도 아래 물입자가 위아래로 움직이며 만드는
  상대 유속
제어기의 FF(feedforward) 항이 정확히 이 둘을 씁니다:
`α_wave = −slope − w/U`. **즉 제어가 소비하는 것은 η 자체가 아니라
slope와 w** — 이 사실이 나중에 "기울기 상한" 이야기의 뿌리입니다.

## 1.2 preview 요구
FF는 "미리 알기"가 필요합니다. 동반 논문(hydrofoil)의 결론: 최적
preview는 **0.1–0.3초**(운용 0.5초). 왜 이렇게 짧은가 — 포일-파도
상호작용의 시간 스케일이 그 정도이고, 너무 긴 preview는 오히려 위상이
어긋납니다(우리가 E2E에서 재확인: preview 0.5→0.2초로 줄이니 GT-FF
이득이 2배).

## 1.3 "주어진" 이라는 제약
센서(Falcon FK24)와 차량(C-8, 22kt)이 정해져 있습니다. 우리는 궤적도
센서도 설계하지 않습니다. 질문은 "무엇을 사면 되나"가 아니라 "산 것으로
어디까지 되나"입니다. 이 프레임이 특허·상용 시스템과의 차별점입니다
(그들은 "된다"를 보였고, 우리는 "어디까지·왜 거기까지"를 보임).

# 2. 파도 물리 기초 (필수 암기 수준)

## 2.1 선형 파도 모델
바다 표면을 코사인 성분들의 합으로 씁니다:
```
η(x, y, t) = Σ_i A_i cos(k_xi·x + k_yi·y − ω_i·t + φ_i)
```
- **A**: 진폭, **k=(kx,ky)**: 파수 벡터(방향+파장; |k|=2π/λ),
  **ω**: 각진동수, **φ**: 위상.
- 이 모델이 성립하면 "지금의 (A, k, φ)를 알면 미래는 공짜"입니다 —
  ω가 시간 진화를 완전히 결정하니까. **예보의 본질 = 성분 파라미터
  추정.**

## 2.2 분산관계 (dispersion relation) — 이 연구의 심장
```
ω = √( g·|k|·tanh(|k|·d) )     (g=9.81, d=수심)
```
- 깊은 물(tanh→1): ω=√(g k). **파장이 길수록 빠르다** (분산).
- 왜 심장인가: k를 알면 ω가 공짜 → 공간 스냅샷들이 시간 예보로
  변환됨. 우리의 모든 추정기는 이 관계를 **하드 제약**으로 씁니다.
- 위상속도 c_p = ω/k (마루가 가는 속도), **군속도 c_g = dω/dk**
  (에너지/정보가 가는 속도). 깊은 물에서 **c_g = c_p/2**. 마루는
  파군을 앞질러 가서 앞에서 소멸 — 그래서 "정보"는 c_g로 갑니다.
- 숫자 감각: Tp=7s → λ=g·Tp²/(2π)≈76m, c_p≈10.9m/s, c_g≈5.5m/s.

## 2.3 스펙트럼과 JONSWAP
실제 바다는 수천 성분의 랜덤 합입니다. 통계로 기술: 파워 스펙트럼
S(ω) 또는 S(kx,ky). JONSWAP은 표준 형태(Hs=유의파고, Tp=피크주기,
γ=피크 뾰족함, 방향 spreading). 보퍼트 등급 매핑(이 과제 합의):
BF2(0.3m/4s) BF3(0.6/5.5) BF4(1.2/7) BF5(2/9).
- **파형 경사 ka**: 비선형성의 크기. 우리 범위에서 0.027–0.035 —
  아주 완만해서 선형 모델이 잘 통하고, 2차 묶임파(bound wave)는
  ~mm 수준이라 무시 가능(우리가 실험으로 확인).

## 2.4 조우주파수 (encounter frequency)
움직이는 배가 느끼는 파도의 주파수:
```
ω_e = ω + k·U   (정면파; 추파는 ω − k·U)
```
- 22kt(11.3m/s), Tp7 정면파: ω_e≈1.9rad/s → 조우주기 ~3.4s.
- **추파에서 U≈c_p면 ω_e≈0** — 배가 파도와 나란히 달려 조우장이
  "얼어붙음". 우리 추파 실험(FF 0.954)이 잘 나온 이유.

# 4. 정보 지평 (predictable zone) — C1의 핵심

## 4.1 직관
배가 리드 ℓ초 뒤에 만날 물은 "지금" 배로부터 U·ℓ 앞에 있고, 그 물의
파 에너지는 지금 더 멀리 (U+c_g)·ℓ 지점에서 오고 있습니다. 센서가
R_max까지밖에 못 보면:
```
ℓ* ≈ R_max / (U + c_g)
```
- 설계점: 100/(11.3+5.46) ≈ **5.96초**.
- 실측 검증: skill-vs-lead 곡선이 FF 대역에서 평탄(0.91) → 4.5초부터
  어깨 → 6초 근처에서 무너짐(fig_horizon). **이론선이 데이터의 어깨에
  정확히 앉아 있는 것**이 이 논문에서 제일 예쁜 그림입니다.

## 4.2 요구-능력 동시 스케일 (방어 필살 논거)
"빠른 배는 지평이 짧다(나쁨)"에서 끝나지 않습니다 — 빠른 배는
조우주기도 짧아져 FF preview 요구(0.1–0.5s)는 그대로인 반면 지평 6초는
요구의 10배 이상. **속도가 능력과 요구를 같은 비율로 줄여서 마진이
유지됩니다.** (선행 predictable-zone 문헌엔 이 조우-좌표 재해석이
없음 — 단, 이론 자체는 Naaijen 계열 선행이므로 "적용·실증"으로 주장.)

## 4.3 레이더와의 관계 (Al-Ani 2020 원문 기준)
그들: X-band, km² 관측 → 리드 '분' 단위, corr 0.95→0.8. 우리: 100m
팬 → 리드 6초, 0.91. **다른 성능이 아니라 같은 법칙(ℓ*∝R)의 두 지점.**
"동급" 표현 금지 — "법칙의 두 검증점 + 다른 축(실시간 18ms·zero-shot·
자기진단)"으로 말할 것.

# 5. 추정기 — bank MMSE를 단계별로

## 5.1 왜 "식별"을 버렸나 (역사)
자연스러운 접근: 성분을 하나씩 찾아내기(RELAX류 greedy 식별). 우리의
SA 아크 결론: greedy는 유령 성분을 만들고, 진짜 상금은 "몇 개를
찾느냐"가 아니라 "모델 차수를 크게 두고 잘 정규화하는 것"이었습니다.
그래서 **식별 없는** 추정기로 전환:

## 5.2 bank (사전 후보군)
kp(피크 파수)를 중심으로 환대역(0.35–2.5 kp)을 kp/10 간격 격자로 덮는
**~1,900개 고정 후보 성분**. 각 후보는 cos/sin 쌍(=진폭+위상을 선형
계수 두 개로). 성분당 ω는 분산관계로 고정. → 미지수는 선형 계수
벡터 w (2×1900차원)뿐. **비선형 탐색이 사라지고 선형 추정이 됩니다.**

## 5.3 beamform power → prior (γ)
어느 후보가 진짜 에너지를 갖는지 관측이 힌트를 줍니다:
```
P_b = |Σ_j z_j e^{−i(k_b·x_j − ω_b t_j)}|²   (후보 b의 정합 파워)
```
관측과 위상이 맞는 후보는 파워가 큼 → **prior 분산 γ_b ∝ P_b^p**
(모양 지수 p와 노이즈 배율은 25% 홀드아웃으로 선택). 이후 val-게이트
EM이 γ를 데이터로 다듬습니다.

## 5.4 MMSE (베이즈 선형 추정)
모델: z = Φw + ε, w~N(0,Γ), ε~N(0,σ²I). 사후 평균:
```
ŵ = ΓΦᵀ(ΦΓΦᵀ + σ²I)⁻¹ z,     η̂(q) = φ(q)ᵀ ŵ
```
- 직관: "prior가 허락하는 성분들로, 노이즈 대비 믿을 만큼만" 데이터를
  설명. γ가 큰 성분은 자유롭게, 작은 성분은 0으로 수축(shrinkage).
- **수축이 nRMSE 진폭축소의 원인**이자, corr(위상 정합)이 좋은 지표인
  이유입니다.

## 5.5 하이퍼파라미터 위생 (quasi-held-out 주의)
val 분할(25%)은 (p, 노이즈배율) 선택과 EM 게이팅에 쓰입니다. 단
**beamform 파워 자체는 전체 관측으로 계산** — 그래서 잔차 신호는
엄밀히 "quasi-held-out"입니다(논문 Methods에 명시; 창 간 균일 누출이라
게이트 순위엔 편향 없음).

# 6. 스트리밍 — 왜 배치와 "정확히" 같은가 (C2)

## 6.1 핵심 관찰
설계행 φ에 −ω_b t가 **이미 들어있으므로**, 정상 선형 바다에서 계수
w는 시불변입니다. 시불변 선형계수 + 순차 관측 = 교과서 **RLS**:
```
P₀=Γ;  프레임마다: S=ΦPΦᵀ+σ²I, K=PΦᵀS⁻¹,
w←w+K(z−Φw), P←P−KΦP
```
이것이 배치 MMSE와 **대수적으로 동일**(우리 검증: 최대 편차 3×10⁻¹⁴,
단위테스트로 고정).

## 6.2 유한 기억 = AR(1)-toward-prior
실제 바다는 서서히 변하므로: `w←a·w, P←a²P+(1−a²)Γ, a=e^{−Δt/τ}`.
- 정상분포가 정확히 prior N(0,Γ) — 수학적으로 깔끔한 망각.
- 물리 해석: τ = 파군 코히어런스 시간.

## 6.3 두 가지 실전 교훈 (구술시험 단골감)
1. **대칭화 버그**: 수백 번의 랭크-m 다운데이트 후 P가 비대칭 →
   skill이 0.6→0.06으로 조용히 붕괴. `P←(P+Pᵀ)/2` 한 줄로 해결.
   "수치선형대수는 이론의 각주가 아니다."
2. **2-시간스케일**: 빠른 루프(18ms)는 prior를 건드리지 않고, 느린
   루프(~10s, 0.8s 비동기)가 γ 재선정+상태 재구축. 관심사 분리.

## 6.4 지연 수치 읽는 법
18.5ms(중앙)/30.8ms(p95) — 단독 실행·48리턴/프레임·CPU numpy 기준.
과거 보고된 47ms는 실험 동시실행 경합 오염(정정됨). 예산 100ms 대비
5.4배 여유.

# 8. 정보 한계 사다리 (C1의 뒷면) — 그리고 아티팩트 사건

## 8.1 사다리의 논리
"추정기가 못하는 것인가, 정보가 없는 것인가"를 가르는 방법: 추정기에
**초능력을 하나씩 쥐여주고** 얼마나 나아지는지 측정.
- 참 스펙트럼 oracle: **갭 ≈0** (0.652 vs 0.648) ← 가장 강한 근거
- 관측 4배: 실측 0 / 학습 12배: 재분배만 / 해상도 2배: 0 /
  비선형 보정: 0 / 샘플 정책: 오히려 −0.20
→ **"검토한 모델·개입 클래스 내 포화"** (절대적 "종결"이라 말하지
않기 — 심사 대비 표현).

## 8.2 아티팩트 사건 (반드시 자기 입으로 말할 수 있어야 함)
처음 oracle 실험은 **200-성분 합성 바다**에서 돌았고, 거기서
①선형 테스트베드가 HOS보다 이상하게 어렵고 ②oracle이 achieved보다
나빠지는 역전이 있었습니다. 원인: 성분 200개는 스펙트럼이 이산
선(line)들이라 바다가 인위적으로 어려워짐. **2,000성분으로 올리자
선형=HOS 일치, 역전 소멸.** 여파 두 가지:
- 기울기 상한 수치가 0.49→**0.65**로 정정
- "인접 클러스터 샘플링 +0.13" 결과가 아티팩트 바다에서만 성립 →
  **철회** (깨끗한 바다에선 −0.14; 실측 패턴에서도 역효과 — 고정
  예산에서 커버리지가 왕)
교훈 문장: "oracle도 구현을 가진다 — 상한 주장은 상한의 구현을
검증한 뒤에만."

## 8.3 기울기가 왜 어려운가
미분은 k를 곱합니다(∂η/∂x = −Σ A k_x sin ψ) → 고파수 성분의 비중이
커지는데, 고파수는 에너지가 작아 위상 식별이 원래 어렵고 수축도 큼.
η corr 0.94여도 slope 0.65인 이유이고, E2E에서 Stream-FF가 GT-FF의
~20%만 회수하는 이유입니다.

## 10.3 사전등록(pre-registration)과 forking paths

  무의미해짐(garden of forking paths).
- **처방**: 프로토콜·판정 기준을 **실행 전에 git 커밋**(타임스탬프

- 방어 포인트: "실패를 이렇게 처리한 것 자체"가 방법론 기여입니다.

# 11. 제어 폐쇄 (E2E) — 숫자를 어떻게 읽나

- 완벽 preview(GT-FF)조차 이 제어기·시나리오에서 heave 가속 −11~−28%

- Stream-FF는 그 마진의 ~20%만 회수 — 병목은 기울기 상한(§8.3).

- 논문 메시지: **corr는 필요조건. FF 이득 ≈ (기울기 정보) ×
  (제어기 설계).** 요구-역산: 기울기 티어를 원하면 관측 클래스가
  바뀌어야 한다(샘플 구조·ROI·학습으론 안 됨 — 전부 실험 기각).

# 12. 학습 접근의 전체 역사 — 실패의 지도와 두 번의 돌파

## 12.1 왜 학습이 필요했나
hand 추정기의 prior(beamform 파워^p)는 손튜닝된 휴리스틱입니다. 바다
스펙트럼의 구조(피크 모양·방향 spreading·대역폭)는 데이터에서 배울 수
있는 사전지식이고, "amortized"란 레코드마다 최적화를 다시 푸는 대신
**한 번 학습해두고 새 관측엔 forward pass 한 번으로 즉시 답하는 것** —
실시간 제약과 정확히 맞는 형태입니다.

## 12.2 실패의 지도 — mean-collapse 시대
점구름→성분/장을 직접 회귀하는 시도는 전부 실패했습니다: raw 점 회귀,
판별망, amortized 직접 회귀, mode-seeking 모두 **mean-collapse**(출력이
흐릿한 평균≈0으로 붕괴). 원인은 모델 크기가 아니라 문제의 구조 —
위상·방향이 다봉(multimodal)인데 픽셀 MSE는 다봉 분포에서 봉우리가
아닌 평균을 맞히는 게 최적이기 때문입니다. **회귀 목적함수가 원리적으로
부적합했던 것.**

## 12.3 돌파 1 — 표현(도메인)을 바꾸니 뚫림
입력을 점구름이 아니라 **beamform 파워맵**(k-공간)으로 바꾸자 단순
CNN 검출+잔차 반복이 RELAX급이 됐습니다. 도메인 지식이 다봉성을 제거해
준 것 — k-공간에서 에너지 위치는 유일하니까. 연장선의 Neural-guided
RELAX: net이 전 성분을 **동시에** 제안(component-distill, Chamfer
거리 손실)하고 물리 refine이 다듬음 → greedy가 막히는 sparse/고성분
격자에서 RELAX를 이김(15중 10).

## 12.4 돌파 2 — 생성 prior (DPS set-diffusion)
성분 집합의 분포 자체를 diffusion 모델로 학습하고, 관측 가능도로
조건화(DPS)해 사후 샘플을 뽑는 접근. 복잡/고성분/HOS 비선형에서
강점 + UQ가 공짜(사후 샘플들의 산포). 단순한 경우엔 물리만으로 충분 —
"단순=반복 검출, 복잡=생성 prior"의 상보 구조로 정리됐습니다.

## 12.5 sim2real의 벽
합성-clean으로 학습한 망은 실측 직접 전이에 실패(≈0 vs RELAX
0.6–0.7). 원인: broadband+노이즈+스케일 gap. 물리 기반(RELAX/MMSE)은
무학습이라 그대로 전이됨. 처방 = realistic 분포로 학습 + **정규화로
레코드 의존성 제거** — 이것이 다음 절 네트워크의 두 열쇠입니다.

# 13. 네트워크 해부 — amortized prior net (최종 승자 구조)

## 13.1 구조적 아이디어: "net은 prior만"
물리(MMSE·분산관계·Woodbury 해)는 그대로 두고, 네트워크는 **γ(k)
prior 맵만** 공급합니다. 물리가 보증할 수 있는 것(위상 정합, 분산
제약)은 학습에 맡기지 않고, 데이터가 더 잘 아는 것(스펙트럼 모양)만
학습 — 실패해도 hand prior로 폴백되는 안전한 분업입니다. G3 통과의
열쇠로 확인된 구조.

## 13.2 입출력 — record-agnostic 정규화
- 입력 6×51×51: **정규화 파수 격자 k/kp ∈ [−2.5, 2.5]²** 위의
  beamform 파워맵 3장(관측 전반부 / 후반부 / 둘의 min) + 같은 3장의
  log10 스케일.
  - **min 채널**: 두 반쪽 모두에 있는 피크만 통과 → 노이즈 유령 억제
  - **log 채널**: 선형 맵은 피크 근처에서 포화 — "48-리턴의 상금은
    약한 모드에 있다"는 진단으로 v2에서 추가
- 출력: 같은 51×51 격자의 log10 γ(각 파수 후보의 prior 분산).
- **kp로 정규화**했으므로 어떤 레코드든 입력 분포가 같음 — 실측
  zero-shot 전이의 열쇠.

## 13.3 몸통 — 작은 U-Net풍 CNN
인코더 3블록(채널 48→96→192, AvgPool로 51→25→12), bilinear 업샘플 +
skip 연결 디코더, GroupNorm+SiLU, 1×1 conv 출력. 파라미터 수는 작음 —
**표현이 좋으면 큰 망이 필요 없다**는 §12.3 교훈의 재확인.

## 13.4 학습 데이터 — 합성 분포 설계
전부 정규화 k-공간 합성: Tp~U[5,11]s, Hs~U[1,3]m, JONSWAP γ~U[1.5,6],
spreading~U[15,45]°, 방향 U[0,360)°, 노이즈 2–10%, 관측 1/3 고정 /
2/3 이동(U/c_p~U[0.1,1.2]). 증강 2종: 전방 팬 기하(fan_frac), 교차해
(bimodal_frac — 2차 계 에너지비 0.15–0.5). 조우-동결 대역까지 학습
분포가 덮은 것이 r0.7 이상 해소의 원인.

## 13.5 v1→v2→v3 — "목적함수가 병목"
- **v1/v2 (라벨 회귀)**: 참 γ 맵을 SmoothL1로 회귀(대역 마스크 +
  고에너지 가중). → G1 실패(이동 동률, 고정 −0.05). 이유: 라벨 회귀는
  hand prior가 이미 쓰는 정보의 재가공일 뿐이고, 라벨 자체가 1-draw
  확률 노이즈를 가짐.
- **v3 (task-loss)**: net의 γ를 **미분가능 MMSE(torch Woodbury)에
  통과시켜** 홀드아웃 질의점의 장(field) 오차를 직접 최소화. 전역
  노이즈 배율도 공동 학습. → G1 통과.
- 같은 망, 같은 데이터에서 목적함수만 바꿔 실패→성공. 라벨이 아니라
  **태스크에 손실을 붙여라.**

## 13.6 실측 성적 — G3와 8-record
- **G3** = 프로젝트 최초의 학습 실측 양성 전이: BS11a fixed 0.579
  (hand 0.474), AA14 0.582(hand 0.505), 이동 9/10셀 net>hand.
- **8-record 3-way**: net-MMSE fixed 0.538(+34%, 8/8승), supra-band
  0.375(+48%) — 무-fine-tune 실측 최강.
- **UQ 보정**: net prior가 이동 관측의 과신까지 교정(z-std 1.47→1.17,
  cov95 0.90+). 정확도+대역 해소+UQ의 3박자.

# 14. 학습이 준 것과 못 준 것 (그리고 왜 본 논문엔 hand prior인가)

| 학습이 준 것 (실측·미스매치 영역) | 학습이 못 준 것 (설계점) |
|---|---|
| 실측 prior 개선 +34%/+48% (8/8승) | 설계점 skill: 4k→20k→50k 학습 = 0.552/0.609/0.595 vs hand 0.595 |
| supra-band·kp-shift 치유, r0.7 해소 | 스케일 무효 — oracle 갭≈0의 예측 그대로 |
| UQ 과신 교정 | |

왜 이 대비가 말이 되나: **학습의 가치 = prior 미스매치의 크기.**
실측은 hand prior의 가정(단봉 JONSWAP형)이 깨지는 곳(광대역·교차해·
조우 시프트)이라 채울 공간이 있고, 설계점 합성은 가정이 정확해 공간이
없습니다. 그래서 본 논문(설계점+실측 협대역)은 단순한 hand prior로
가고, net prior는 미스매치 상황용 확장으로 남습니다.

선행연구: **AHGP(NeurIPS 2020)** 가 amortized spectral prior의 선행 —
인용 필수. 차별점 = 물리 분산-구속 + task-loss ablation(v2 vs v3) +
이동 관측 연산자 + 실측 zero-shot.

방법론 교훈 4개:
1. mean-collapse는 목적함수/표현의 문제다(모델 크기 아님)
2. 충분히 학습한 뒤 판단하라(수만 step + 수렴 확인)
3. "안 된다" 결론 전에 격리실험+하이퍼파라미터+multi-seed
4. 라벨이 아니라 태스크에 손실을 붙여라

# 15. 이동 개구 아크 — "개구의 벽은 대부분 알고리즘의 벽"

가설은 매력적이었습니다: 센서가 이동하면 궤적이 합성 개구(synthetic
aperture)가 되어 파수 해상도가 좋아진다. 여정:
1. DPS×이동 +0.51 발견 → 15윈도 평균 +0.04로 **요행 판명**
2. 추정기가 강해질수록 이동 이득이 소멸: corr(gain, 개구크기)
   −0.58→−0.24→−0.11; 3회 재현됐던 BS11a 앵커 +0.31도 net-fixed
   0.58 앞에서 증발; "gain≥0.1 집합"이 {BS11a}→∅
3. 대표본(n=32) 교정: hand 이동 gain 0(시드 요동 수준), net×고속만
   +0.069±0.033

결론: **약한 추정기의 이동 이득은 대부분 그 추정기의 결함을 이동이
보상해준 것.** 진짜 상금은 모델 차수+정규화에 있었고(§5.1의 bank
MMSE가 여기서 태어남), "이득"이 아니라 "이득의 증발" 자체가
발견입니다. 이동의 가치를 주장하려면 반드시 강한 추정기 기준으로.

# 16. 해류 비식별성 소정리

해류 U_c가 있으면 분산관계가 Doppler 시프트됩니다:
```
ω = √(g·k·tanh(k·d)) + k·U_c
```
- 0.15 m/s의 해류에도 hand 추정기의 이동 이득이 전멸할 만큼 민감.
- **맹목 복원 5/5 실패**: val-선택, shell 탐색, GP-증거, multi-window,
  BMA 전부 — evidence가 틀린 U_c에서 뾰족(=편향)해서 원리적으로 실패.
  → "sparse 이동 궤적에서 해류는 비식별"이라는 소정리.
- 단 oracle(U_c와 kp를 알려주면)은 완전 복원; kp만 알아도 손실 미미 →
  **주 채널은 kp/대역 배치**였음.
- 처방: 외부 U_c(해류 예보/ADCP), kp_hint 전달, 광대역 밴드.
- v4 해류-증강 학습은 무효 — γ-prior는 "어디를 볼지"를 정할 뿐,
  스펙트럼 좌표계의 시프트를 보상하지 못합니다(구조적 한계의 좋은
  예).

# 17. 통계 도구 미니 사전 (심사에서 튀어나올 것들)

- **Pearson corr**: 선형 동행도. 우리 주지표(위상 정합 의미).
- **Spearman**: 순위 상관 — 게이트(순서만 중요)에 사용.
- **단측 p값**: 방향을 미리 선언했을 때(사전등록) 절반.
- **bootstrap CI**: 데이터를 복원추출로 재표집해 통계량 분포를 얻음.
  우리는 sea/창 단위로 재표집(점 단위가 아니라 — 상관 구조 존중).
- **효과크기 vs 유의성**: 분리 +0.17이라도 CI가 0을 포함하면 불확실.
  둘 다 보고.
- **탐색 vs 확증**: 가설을 만든 데이터로 검정하면 탐색. 우리는 라벨을
  전 결과에 부착.

# 18. 예상 심사 문답 (페르소나 토론 요약본)

**Q. 개념은 특허/FutureWaves/LiDAR DSWP가 다 했다. 새로운 게 뭔가?**
A. 그들은 가능성을, 우리는 경계를 보였습니다. 주어진 사양의 정보
한계 지도(oracle 사다리·용의자 법의학·요구-역산), 등가성이 증명된
실시간 구현(18ms), 실측 5사이트 zero-shot, 그리고 자기진단의 정직한
원장 — 이 조합은 선행에 없습니다.

**Q. 레이더는 0.95를 분 단위 리드로 한다는데?**
A. 같은 법칙(ℓ*∝R)의 다른 지점입니다. km² 관측이 분 지평을, 100m 팬이
6초 지평을 줍니다. 우리 축은 관측 3천분의 1로의 정보 효율과 실시간·
무튜닝·자기진단입니다.

**Q. 게이트는 확증에 실패했는데 왜 논문에 있나?**
A. 방향이 3개 독립 평가에서 일관했고, 운용 곡선의 효과가 크며(0.49→
0.68), 실패를 사전등록 원장으로 공개하는 것이 이 분야에 필요한 관행
이라 믿기 때문입니다. 기여가 아니라 예비 발견으로 명시했습니다.

**Q. 실선/수조 없이 남의 데이터만으로 충분한가?**
A. 주장의 대상이 관측 클래스이므로 공개 실측 zero-shot이 정합한
프로토콜입니다. 센서-실물 통계(리턴 인접성)만 시뮬 기반임을 라벨했고,
해당 원시 데이터 요청을 진행 중입니다.

**Q. 학습(net prior)은 왜 기여가 아닌가?**
A. oracle 갭이 ≈0이라 학습이 채울 공간 자체가 없음을 보였습니다 —
4k→50k 스케일링이 예측대로 정체. "학습이 안 통하는 곳의 지도"가
학습 만능 시대에 우리가 내는 기여입니다(AHGP 인용).

**Q. 기울기 0.65 상한의 대응은?**
A. 관측 클래스의 속성입니다. 샘플 구조(철회)·ROI(+0.01)·학습(정체)
전부 기각했고, 요구-역산으로 "기울기 티어는 다른 관측이 필요"를
사양 문장으로 남겼습니다. 제어 쪽에선 preview 튜닝으로 GT 마진을
2배 회복했습니다.

**Q. 왜 net prior를 본 논문의 추정기에 쓰지 않았나?**
A. 설계점에선 oracle 갭이 ≈0이라 net이 채울 공간이 없고(4k→50k
스케일링 정체로 실증), hand prior가 더 단순·검증 용이합니다. net
prior의 가치는 prior 미스매치 영역(광대역 실측 supra-band +48%)에
있고, 그곳이 net의 자리임을 함께 보였습니다.

**Q. 이동 플랫폼이면 합성 개구 이득이 있어야 하지 않나?**
A. 약한 추정기에선 보이던 이득(+0.31 앵커 포함)이 강한 추정기 기준
대표본(n=32)에서 증발했습니다(hand 0, net×고속 +0.069±0.033뿐).
"이동 이득은 대부분 알고리즘 결함의 보상"이라는 부정적 결과 자체가
발견이며, 이동 가치 주장은 반드시 강한 추정기 기준이어야 합니다.

**Q. 해류가 있으면 분산관계가 깨질 텐데?**
A. Doppler 시프트에 민감한 건 사실이고, sparse 이동 궤적에선 맹목
복원이 비식별임을 5개 방법의 체계적 실패(+편향 증거)로 보였습니다.
처방은 외부 U_c·kp_hint·광대역 밴드이고, 본 논문의 전방-팬 구성은
이 민감도가 완화되는 구성입니다.

# 19. 용어집 (15초 설명 연습용)

- **조우예보(encounter forecast)**: 배의 미래 위치에서 만날 η(t).
- **predictable zone**: 군속도 기하로 예보 가능한 시공간 영역.
- **bank**: 고정 파수 후보 격자(식별 없는 표현).
- **beamform power**: 후보 파수와 관측의 위상 정합 에너지.
- **MMSE/수축**: 베이즈 최적 선형 추정 / prior가 진폭을 줄이는 효과.
- **RLS**: 순차 최소제곱 — 우리 스트리밍의 수학적 정체.
- **NIS**: 정규화 혁신 제곱 — 필터 건강 신호.
- **raydrop**: 반사 실패로 리턴이 사라지는 현상.
- **zero-shot**: 대상 데이터 무튜닝 적용.
- **oracle**: 진실 일부를 아는 가상의 추정기(상한 탐침).
- **사전등록**: 실행 전 프로토콜 고정·공증.
- **quasi-held-out**: 부분적으로만 분리된 검증(우리 잔차 신호).
- **요구-역산**: 성능 목표→관측 사양의 역방향 설계.
- **amortized 추론**: 최적화를 학습으로 선지불하고 추론은 forward
  pass 한 번으로.
- **task-loss**: 라벨이 아니라 최종 태스크 오차(미분가능 파이프라인
  관통)로 학습하는 손실.
- **mean-collapse**: 다봉 분포를 MSE로 회귀할 때 출력이 평균으로
  붕괴하는 실패 모드.
- **DPS / set-diffusion**: 생성(diffusion) prior를 관측 가능도로
  조건화해 사후 샘플을 뽑는 방법 / 성분 집합에 대한 그 변형.
- **Chamfer 거리**: 두 점 집합 간 최근접 매칭 거리 — 성분 집합 학습의
  손실.
- **합성 개구(SA)**: 센서 이동 궤적을 큰 가상 개구로 쓰는 아이디어.
- **Doppler 시프트(해류)**: ω에 k·U_c가 더해져 분산관계가 이동하는
  효과.
- **G1/G3**: 학습 접근의 사전 정의 관문(G1=합성 이득, G3=실측 전이).
- **supra-band**: kp보다 높은 파수 대역(조우 시프트로 실측에서 중요).
