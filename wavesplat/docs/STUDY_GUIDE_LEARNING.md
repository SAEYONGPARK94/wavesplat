## 0. 한 문단 요약
배에 달린 LiDAR로 주변 바다 표면(파도)을 측정해서 **지금 파도장을 복원**하고 **몇 초 앞을 예보**하는
문제다. 핵심 결론:
1. **이 문제의 한계는 "정보"다** — Cramér–Rao 바운드(CRB)라는 이론적 천장이 있고, *어떤* 추정기도
   이걸 못 넘는다.
2. **고정 데이터에선 학습이 고전방법(RELAX)을 못 이긴다** — 5가지 학습방법으로 다 시도해서 *왜*
   못 이기는지 엄밀히 보였다(정밀도 장벽).
3. **그런데 분야 표준 벤치마크가 *이산 성분* 데이터라 고전방법에 유리하게 편향돼 있었다.** *현실의
   연속 스펙트럼* 파도에선 **학습(DPS)이 고전을 이긴다(−16%, 통계적으로 유의).**
4. 정보의 벽을 *옮기는* 레버(능동센싱)는 자유롭게 측정할 수 있으면 균일샘플링이 이미 최적이라 학습
   우위가 없다.

## 1. 문제 정의 — 배 위 LiDAR로 파도 추정
**관측:** LiDAR 레이저가 수면에 맞고 돌아와 점들 `{(xₘ, yₘ, tₘ, zₘ)}`을 준다. 희소(sparse)하고
불규칙(스캔패턴+raydrop 누락).

**모델:** 수면을 자유파 합으로:
```
z(x,y,t) = Σᵢ wᵢ · cos(kxᵢ·x + kyᵢ·y − ωᵢ·t + φᵢ)
```
- `wᵢ`=진폭, `(kxᵢ,kyᵢ)`=파수(방향+파장), `φᵢ`=위상.
- `ωᵢ`=각진동수, **자유롭지 않다** — 분산관계로 파수에 묶임:
  `ωᵢ = √(g·|kᵢ|·tanh(|kᵢ|·d))` (g=중력, d=수심). 강한 물리 제약(hard constraint).

**목표:** 점들 → 성분 `θ={(wᵢ,kxᵢ,kyᵢ,φᵢ)}` 추정 → 수면장 복원 + 예보.
**비유:** 연못에 돌 여러 개 던진 물결을, 드문드문 찍힌 몇 점만 보고 "어떤 돌이 어디서 어떤 세기로"를
역추정.

## 2. 핵심 이론 — CRB와 "정보의 벽"

### 2.1 Fisher 정보 & CRB
**질문:** 데이터가 미지수를 얼마나 세게 잡아주나? 직관: 파라미터를 살짝 바꿨을 때 예측이 *많이*
바뀌면 데이터가 그걸 잘 본다(정보 많음).
- Fisher 정보행렬 `F = (1/σ²)·JᵀJ`, `J=∂(예측)/∂θ` (민감도).
- **CRB 정리:** 어떤 불편추정량이든 오차분산 ≥ `F⁻¹`. 이걸 수면장으로 전파 → **field nRMSE의
  하한 = 정보의 벽.** 추정기 종류와 무관(NN·GP·RELAX 다 막힘).

### 2.2 결정적 통찰 — "시간이 곧 개구다" 🛰️
Jacobian 핵심 항: `∂ψ/∂kx = x − c_g·(kx/k)·t` (c_g=dω/dk=군속도=정보 전파속도).
- 시각 t의 관측은 위치 r이 아니라 **`r − c_g·k̂·t`**(전파방향으로 c_g·t 이동)에서 본 것과 등가.
- → T_obs 동안 모으면 점구름이 전파방향으로 c_g·T_obs 늘어남 = 더 큰 개구:
  **`D_eff = L_footprint + c_g·T_obs`** (유효 합성개구). σ_|k| ∝ 1/D_eff (기울기 −1.09 검증).
- **비유:** 합성개구레이더(SAR). 안테나를 키우는 대신 *시간에 걸쳐 움직이며* 측정해 큰 안테나처럼.
  여기선 *파가 흘러가는 시간*이 개구를 키운다.

### 2.3 정보의 벽 T_wall
field-CRB가 zero-predictor(0 예측, nRMSE≈0.25) 아래로 처음 내려가는 T_obs.
- T_wall ≈ 0.1초(5성분)·4.3초(15성분)·9.7초(30성분). 복잡할수록 가파르게↑(성분 촘촘→큰 개구 필요).

### 2.4 predictable zone = 식별성 (기하 cone 아님)
"어느 영역 복원 가능?"을 고전은 군속도 cone(기하)이라 하지만, CRB는 spectral identifiability
(기하+시간이 성분을 분해하느냐)가 정한다 — CRB가 엄밀.

## 3. 고전 방법 — RELAX (off-grid matching pursuit)
반복적으로 성분을 하나씩: (1)잔차 빔포밍(dispersion 제약)→강한 파수 검출, (2)국소 정밀화
(off-grid refine), (3)차감→반복. **왜 잘 되나:** 각 단계가 국소볼록이라 정밀도 도달; 빔포밍이
합성개구로 1/D_eff 해상도. **한계:** *이산* peak엔 최적이지만 *연속* 스펙트럼엔 약함(§5.4).

---

## 4. 학습 방법 — DPS (set-diffusion prior)
스펙트럼을 **연속 atom 32개** `{(kx,ky,logE)}`로 표현(격자 없음). 분포를 확산모델 prior로 학습.
- prior: "현실적 파도 스펙트럼이 어떻게 생겼나"를 JONSWAP으로 학습한 생성모델.
- posterior: **DPS** — prior에서 노이즈를 거꾸로 제거하며 매 스텝 관측 일치도(likelihood)로 안내.
- likelihood: grid-free GP-marginal, 미분가능. 점추정: posterior 샘플 평균(BMA, *매끄러움*).
- **성질:** 연속표현+매끄러움 → 이산 성분엔 과평활화로 불리, *연속 스펙트럼엔 적절.* O(m³)라
  관측 ~200개로 제한.

---

## 5. 핵심 발견들 (실험별, 쉽게)

### 5.1 "학습은 추정에서 고전을 못 이긴다" (5중 negative)
정보의 벽 아래/고정 데이터에선 학습의 어떤 형태도 RELAX를 못 이긴다:
1. 학습 prior(DPS) — 동일예산 RELAX·GP와 동률(~0.20), 과평활화.
2. off-grid feedforward NN — 한 방에 정밀 파수 못 맞춰 zero-predictor 붕괴(0.25). 고주파 위상이
   비볼록이라 gradient로 정밀도 불가.
3. 학습 warm-start hybrid — 중립.
4. learned detection CNN(합성) — 검출 좋아져도 실제 통합 실패(기하 도메인갭).
5. learned detection(실제기하) — 여전히 실패(검출이 병목 아님).
→ **공통 원인:** off-grid 성분식별의 *정밀도*(1/D_eff)는 amortize(한 방 학습)가 안 됨. 반복(RELAX)만
도달.

### 5.2 관측 희소 crossover (학습의 niche)
m<200(희소)에선 학습 prior가 RELAX보다 좋음(−22%), m>200(조밀)엔 RELAX. 단 "학습이 좋다"가
아니라 **"학습 prior=데이터 없을 때 우아한 바닥(~0.20), RELAX=데이터 없으면 붕괴."** (사용자
의심으로 정밀화: guidance artifact 아니라 prior의 m-무관 바닥.)

### 5.3 능동센싱 — 자유센싱은 균일이 최적 (honest negative)
"어디서 측정하나"는 정보의 벽을 *옮기는* 레버(CRB −69% 여지). **그러나** 자유 aim이면 random 균일이
D-optimal 집중보다 항상 좋음(nowcast·forecast 모두). field 복원엔 공간 다양성이 필요, 집중은 손해.
→ 능동센싱 학습 우위는 *제약된 실제 returns 선택*에서만(=정보적 subsampling).

### 5.4 ⭐ The Flip — 벤치마크 편향과 현실에서의 학습 승리 (핵심 발견)
분야 표준 벤치마크는 *이산 15~30 성분* — *이산 추정기(RELAX)에 유리하게 편향*(데이터-모델 일치).
- **이산 벤치마크:** RELAX 0.119 ≪ DPS 0.206 → 고전 승, 학습 과평활화로 짐.
- **현실 연속 스펙트럼(HOS):** RELAX 0.277 ≫ DPS 0.234 → **학습 승 (−16%, 9/9 윈도우, p<0.001).**
- **왜 뒤집히나:** 현실 파도는 *연속* JONSWAP 스펙트럼(무한 모드). RELAX의 *이산 32 atom*은 이걸
  표현 못 함(atom 64로 늘려도 *전혀* 개선 안 됨=용량 아님). DPS의 *학습된 연속 prior*는 현실
  연속스펙트럼 구조를 알아서 더 잘 표현.
→ **"이산 벤치마크가 학습-win을 가렸다. 현실에선 학습이 이긴다."**

### 5.5 비선형성 자체는 갭이 아님
HOS M=1(선형) vs M=3(비선형) 통제: 순수 비선형성 갭 ≈0. RELAX는 비선형을 선형만큼 처리. §5.4의
갭은 *비선형*이 아니라 *연속 스펙트럼 표현*이 원인.

## 7. 용어집
- **CRB:** 어떤 불편추정기든 못 넘는 오차 하한("정보의 천장").
- **Fisher 정보:** 데이터가 파라미터를 얼마나 제약하는지 = 민감도²/노이즈².
- **합성개구 D_eff:** 시간에 걸친 측정이 만드는 유효 공간 개구 = L + c_g·T_obs.
- **군속도 c_g:** 파 에너지(정보) 전파속도 = dω/dk.
- **분산관계:** 파장↔속도 물리법칙 ω=√(g|k|tanh|k|d).
- **정보의 벽 T_wall:** 그 아래선 어떤 추정기도 무의미한 최소 관측시간.
- **nRMSE:** 정규화 RMSE = RMS오차/Hs. zero-predictor ≈ 0.25.
- **RELAX:** 반복 off-grid matching pursuit(빔포밍 검출+정밀화+차감).
- **DPS:** Diffusion Posterior Sampling — 학습 prior + 관측 likelihood로 posterior 샘플.
- **BMA:** posterior 샘플 평균(매끄러움).
- **HOS:** Higher-Order Spectral — 비선형 파도 시뮬(연속 스펙트럼).
- **D-optimal:** Fisher 정보를 최대화하는 샘플 선택(능동센싱).
- **off-grid:** 파수를 격자 칸이 아니라 연속값으로 추정.

## 8. 핵심 수식 한 장
```
관측:     z = Σᵢ wᵢ cos(kxᵢx+kyᵢy−ωᵢt+φᵢ),  ωᵢ=√(g|kᵢ|tanh|kᵢ|d)
Fisher:   F=(1/σ²)JᵀJ,  J=∂z/∂θ,  θ=(w,kx,ky,φ)
CRB:      Cov(θ̂) ⪰ F⁻¹  → field-CRB(하한)
합성개구: ∂ψ/∂kx = x − c_g(kx/k)t → D_eff=L+c_g·T_obs,  σ_|k| ∝ 1/D_eff
정보의 벽: T_wall = min T_obs s.t. field-CRB(T) < 0.25
```

## 9. 논문 한 줄 스토리 + 열린 방향
**스토리:** "이 역문제의 한계는 정보(CRB)다. 분야 표준 *이산* 벤치마크는 고전 이산추정기에 유리하게
편향돼 학습의 가치를 가렸다. *현실 연속스펙트럼*에선 학습된 연속표현(DPS)이 고전을 이긴다."
**DPS 향상 방향 (d49로 확정):** DPS는 연속HOS서도 관측수에 **평탄**(m=100→800, nRMSE 0.239→0.236
변화없음; 게다가 m=100만으로 RELAX-full 0.279를 이김). → **D1(scalable likelihood, 관측↑)은 레버가
아님. 병목은 *prior 표현*** (d5에서 10× 스케일업도 ε-loss 바닥서 무효였던 것과 일치). → **DPS 향상 = 표현 레버(D2)인데, *단순 용량증가는 안 통함*:** atom 64로 재학습(d50)해도
0.247(32-atom 0.234보다 *나쁨*). d47(RELAX-64=32)·d49(obs 평탄)과 일관 — **−16% win은 *학습된
prior 구조*에서 오지 capacity에서 오는 게 아님.** → 더 키우려 *근본적* 방법 4개(F1-F4) 검토했으나(d51/d52, `fundamental_F1F4_VERDICT.md`): **~0.233이
연속스펙트럼 *정보한계*, 아무도 못 넘음.** F1(비학습 dense+평활)=DPS(학습)0.233 동률, F4(학습
operator)0.250 더 나쁨. → **중요 재정밀화: 연속 win은 "학습"이 아니라 "*연속 표현*"이다**(비학습도
동률). 학습은 정보한계를 못 넘음(전 영역 일관). 정직한 논문 = CRB정보벽+이산벤치마크편향 비판+
"현실엔 연속표현 필요"(DPS=UQ 주는 한 옵션). "표현이 승자, 정보가 한계."
