PART 0문제 정의

왜 파도를 추정하는가?

선박과 해양 구조물은 파도에 의해 지배적인 외력을 받는다. 파도를 정확히 알 수 있다면:

  1. 선박 운동 예측 — 화물 고박 타이밍, 헬기 착함 판단
  2. 능동 제어 — 하이드로포일 안정화, 파랑 feedforward (이 논문의 응용)
  3. 구조물 하중 예측 — 피로 수명 계산, 위험 경보
  4. 항로 최적화 — 연료 절감, 승객 안전

파도 관측 방법 비교

방법측정 범위공간 해상도시간 해상도실시간
파고 부이점 (0D)높음높음O
X-band 레이더수 km (2D)~10m~1HzO
위성 SAR수백 km~100m수 시간X
LiDAR10-250m (2D)~0.1m10HzO

LiDAR는 높은 시공간 해상도를 제공하지만, 관측 점이 극도로 희소하다 (50~200점/프레임, 250m×250m 영역).

LiDAR 관측의 어려움

  1. 희소성: 250m×250m에 점이 ~100개뿐
  2. 불균일: 가까이 = 밀집, 멀리 = 희박
  3. 노이즈: 물방울, 진동, 반사 각도에 따른 신호 손실 (raydrop)
  4. 비정렬: 매 프레임 점의 위치가 달라짐 — 격자 위에 있지 않다!

핵심 문제

입력: 시공간적으로 희소한 LiDAR 점 $\{(x_j, y_j, z_j, t_j)\}_{j=1}^{M}$
출력: 임의의 $(x, y, t)$에서의 수면 높이 $\hat{\eta}(x, y, t)$

조건: (1) 실시간 100ms 이내, (2) 물리적으로 유효, (3) 시간 연속, (4) 격자 불필요

PART 1파도의 물리학

단일 평면파

바다의 가장 기본적인 구성 요소는 하나의 평면파(plane wave)이다:

단일 평면파 수식
$$\eta(x, y, t) = w \cos(k_x x + k_y y - \omega t + \varphi)$$

각 변수의 의미:

변수의미단위직관
$w$진폭m파도 높이의 절반. 파고 $H = 2w$
$k_x, k_y$파수 벡터rad/m파도의 방향과 파장을 결정
$\omega$각주파수rad/s파도가 얼마나 빨리 지나가는지. 주기 $T = 2\pi/\omega$
$\varphi$위상rad파도의 시작점 (시간 오프셋)

파수 벡터 $(k_x, k_y)$ — 파도의 '지문'

파수 벡터 $\mathbf{k} = (k_x, k_y)$는 파도의 공간적 특성을 완전히 결정한다:

  • 파장: $\lambda = 2\pi / |\mathbf{k}|$ — $|\mathbf{k}|$가 크면 짧은 파도(잔물결), 작으면 긴 파도(너울)
  • 방향: $\theta = \arctan(k_y / k_x)$ — 파도가 어디서 오는지
비유: 라디오에서 주파수를 맞추듯, 바다에서 $(k_x, k_y)$로 '채널'을 맞춘다.

분산관계 (Dispersion Relation)

파도의 물리학에서 가장 중요한 법칙이다:

분산관계
$$\omega^2 = g\,|\mathbf{k}|\,\tanh(|\mathbf{k}|\,d)$$

심해 ($d \gg \lambda$): $\omega \approx \sqrt{g\,|\mathbf{k}|}$   |   천해 ($d \ll \lambda$): $\omega \approx |\mathbf{k}|\sqrt{gd}$

직관적 의미:

  • 긴 파도(큰 $\lambda$, 작은 $|\mathbf{k}|$)는 빠르게 이동
  • 짧은 파도(작은 $\lambda$, 큰 $|\mathbf{k}|$)는 느리게 이동
  • 수심 $d$가 얕으면 모든 파도가 느려짐
핵심 통찰: 파장($|\mathbf{k}|$)이 결정되면 속도($\omega$)는 자동으로 결정된다.
WaveSplat은 $\omega$를 자유변수로 두지 않고 분산관계로 강제한다.
→ 추정할 파라미터: 5N → 4N개로 감소 (물리적으로 불가능한 해를 원천 차단)

다성분 중첩 — 실제 바다

실제 바다는 여러 방향, 여러 파장의 파도가 겹쳐진 것이다:

다성분 파도 모델
$$\eta(x,y,t) = \sum_{i=1}^{N} w_i \cos(k_{x,i}\,x + k_{y,i}\,y - \omega_i\,t + \varphi_i)$$ $$\text{where}\quad \omega_i = \sqrt{g\,|\mathbf{k}_i|\,\tanh(|\mathbf{k}_i|\,d)} \quad\text{(분산관계로 결정)}$$
해상 조건성분 수 $N$예시
너울 (swell)1~3먼 바다에서 온 긴 파도
BF3 혼합해5~10바람 + 너울
BF4-5 복잡해15~30다방향, 다주파수
총 자유 파라미터: $4N$개
각 성분: $(w_i, k_{x,i}, k_{y,i}, \varphi_i)$ — $\omega_i$는 분산관계에서 자동 결정
$N=15$일 때 60개 (ETKF의 120,000개와 비교!)

JONSWAP 스펙트럼

바람에 의해 생성된 파도의 전형적 에너지 분포. 핵심 파라미터:

  • $H_s$ = 유의파고 (상위 1/3 파고의 평균)
  • $T_p$ = 피크 주기 (가장 에너지가 큰 파도의 주기)
  • $\gamma$ = 피크 형상 계수 (좁으면 너울, 넓으면 풍파)
BF 등급$H_s$ [m]$T_p$ [s]상태
BF2~0.3~3잔잔
BF3~0.88~5보통
BF4~1.88~7거친 해상
BF5~3.25~9험한 해상

선형 파도 모델의 충분성

BF2-4 범위에서 파고/파장 비(steepness)가 < 0.05이므로 선형 중첩 모델이 충분히 정확하다. 관측 노이즈가 비선형 오차보다 훨씬 크기 때문에, cos 합으로 모델링하는 것이 실용적으로 최선의 선택이다.

PART 2공간 영역 방법 — ETKF

격자 기반 접근의 기본 아이디어

수면을 $N \times M$ 격자로 나누고, 각 격자점의 높이를 상태 벡터로 정의한다:

ETKF 상태 벡터
$$\mathbf{x} = [h_{1,1},\; h_{1,2},\; \ldots,\; h_{N,M}]^\top$$

$G = 40 \times 30 = 1{,}200$ 격자점 → 1,200차원 벡터

LiDAR 관측이 50~200개인데 상태가 1,200개 — 심하게 underdetermined (해가 무한히 많음). 사전 정보(prior)가 필수 → 칼만 필터.

칼만 필터 기초

Predict-Update 2단계 반복:

Step 1: Predict (예측)

$$\mathbf{x}_{\text{pred}} = F \cdot \mathbf{x}_{\text{prev}} \qquad\text{(물리 모델로 다음 상태 예측)}$$ $$P_{\text{pred}} = F\,P\,F^\top + Q \qquad\text{(불확실성 증가)}$$

Step 2: Update (보정)

$$K = P_{\text{pred}}\,H^\top\,(H\,P_{\text{pred}}\,H^\top + R)^{-1} \qquad\text{(칼만 이득)}$$ $$\mathbf{x}_{\text{new}} = \mathbf{x}_{\text{pred}} + K\,(\mathbf{z} - H\,\mathbf{x}_{\text{pred}}) \qquad\text{(관측으로 보정)}$$
  • $K$가 크면 → 관측을 더 신뢰
  • $K$가 작으면 → 예측(모델)을 더 신뢰
문제: $P$가 $1200 \times 1200$ 행렬 → 직접 계산 불가능!
→ 앙상블 칼만 필터(EnKF): $N_e$개의 샘플로 $P$를 근사

앙상블 칼만 필터 (ETKF)

$N_e$개의 '앙상블 멤버'(격자 파도장 샘플)로 공분산을 근사한다:

$$P \approx \frac{1}{N_e-1} \mathbf{X}_{\text{ens}} \mathbf{X}_{\text{ens}}^\top$$

$\mathbf{X}_{\text{ens}}$ = 앙상블 편차 행렬, $N_e = 100$이면 대략적 공분산 구조 포착

동작 순서:

  1. $N_e$개의 격자 파도장을 초기화 (랜덤 위상의 스펙트럼에서 생성)
  2. Predict: 각 멤버를 FFT 기반 물리 모델로 전파
  3. 관측이 오면: 각 멤버에서 관측 위치의 높이 추출
  4. Update: 관측과 가까운 멤버에 더 큰 가중치
  5. 앙상블 평균이 최종 추정값

ETKF의 근본적 한계

한계 1: 격자 해상도 vs 계산량

격자 설정격자점$N_e$소요 시간비고
$40 \times 30$1,200100132.6ms실시간 초과
$100 \times 75$7,500200~1초완전 불가

격자를 촘촘히 하면 정밀하지만 느리고, 성기면 짧은 파도를 놓친다. 차원의 저주 — 해상도 2배 → 계산 ~16배.

한계 2: 분산관계 미활용

ETKF의 상태는 '격자점 높이'이지, 파도의 주파수나 방향이 아니다. 앙상블이 시간 전파를 통해 간접적으로 물리를 학습해야 하는데, $N_e$가 부족하면 물리가 '깨진다'.

ETKF는 '사진'을 맞추려는 것이고, WaveSplat은 '악보'를 찾는 것이다.
악보를 알면 언제든 사진을 생성할 수 있지만, 사진에서 악보를 추출하기는 어렵다.

실패 모드: "진폭은 맞지만 위치가 틀림"

지표ETKF 값의미

해석: ETKF는 "파고 1m짜리 파도가 있다"는 맞추지만, "어디에 있는지"는 거의 맞추지 못한다. nRMSE만 보면 0.319로 나쁘지 않아 보이지만, VR/ρ 조합으로 보면 진단적 가치가 매우 낮다.

PART 3공간 영역 방법 — GPR

가우시안 프로세스(GP)란?

함수의 확률 분포이다. "이 함수가 이런 모양일 확률이 높다"를 수학적으로 표현한다.

점을 찍고 매끄러운 곡선으로 잇기 — 관측점 근처는 확실하고, 멀면 불확실하다. 매끄러움의 정도는 커널 함수가 결정한다.

GPR 수식

GPR 예측 평균과 분산
$$\mu(\mathbf{x}^*) = \mathbf{k}(\mathbf{x}^*, X) \left[K(X,X) + \sigma^2 I\right]^{-1} \mathbf{z}$$ $$\sigma^2(\mathbf{x}^*) = k(\mathbf{x}^*,\mathbf{x}^*) - \mathbf{k}(\mathbf{x}^*, X) \left[K + \sigma^2 I\right]^{-1} \mathbf{k}(X, \mathbf{x}^*)$$
  • $\mathbf{x}^*$ = 예측 위치, $X$ = 관측 위치들, $\mathbf{z}$ = 관측값 (수면 높이)
  • $k(\cdot,\cdot)$ = 커널 함수 (두 점 사이의 '유사도')
  • $K(X,X)$ = 관측점끼리의 유사도 행렬 ($M \times M$)

Matern 커널

WaveSplat 논문에서 사용한 GPR baseline: Matern $\nu$=5/2, length scale $l$=20m

$$k(r) = \left(1 + \frac{\sqrt{5}\,r}{l} + \frac{5\,r^2}{3\,l^2}\right) \exp\!\left(-\frac{\sqrt{5}\,r}{l}\right)$$

$l = 20$m → "20m 이내의 점들은 강하게 연관". 파도에는 여러 스케일이 동시에 존재하므로 하나의 $l$로는 모든 스케일을 포착할 수 없다.

GPR의 근본적 한계

한계 1: 시간을 무시함

GPR 커널 $k(\mathbf{x}_1, \mathbf{x}_2)$는 공간 거리만 본다. 파도가 이동한다는 사실을 모른다.

예시: $t=0$에서 점 A의 파고가 1m, $t=0.1$에서 0.5m (파도가 이동). GPR은 두 관측을 평균하여 0.75m로 추정 — 파도의 이동을 전혀 반영하지 못한다.

한계 2: $O(M^3)$ 계산

PART 4왜 주파수 영역 Splatting이 필요한가

공간 vs 주파수 — 근본적 차이

공간 영역주파수 영역
질문"여기 높이가 얼마?""어떤 파도들이 섞여있나?"
표현격자점 높이스펙트럼 성분 (w, k, φ)
파라미터해상도에 비례파도 복잡도에만 비례
외삽관측 영역 내에서만시공간 어디서든
음악 비유:
시간 영역(파형) = 마이크로 녹음한 소리 — 데이터가 방대, "어떤 악기인지" 알기 어려움
주파수 영역(악보) = 음(주파수) × 크기(진폭) — 간결, 언제든 파형을 재생 가능

LiDAR 관측 = 희소한 녹음,  WaveSplat = 녹음에서 악보 추출,  ETKF = 녹음 직접 복원,  GPR = 녹음 사이 보간

주파수 파라미터를 알면 어디서든 복원 가능

$(w, k_x, k_y, \varphi)$를 한번 추정하면:

  1. 관측 영역 밖에서도 예측 — 선박 전방 500m도 계산 가능
  2. 미래 시점도 예측 — $t$만 바꾸면 됨 (분산관계가 전파 속도 결정)
  3. 격자 제한 없음 — 연속 함수이므로 임의의 $(x,y)$에서 평가

시간이 자연스럽게 포함되는 이유

$\cos(k_x x + k_y y - \omega t + \varphi)$에서 $t$는 변수이다. 분산관계 $\omega = f(\mathbf{k}, d)$가 '시계' 역할을 한다:

  • 각 성분이 고유 속도로 전파: 장파는 빠르게, 단파는 느리게
  • ETKF가 'predict step'에서 FFT로 전파하는 것을 WaveSplat은 수식 하나로 해결
  • GPR는 시간을 아예 모름 → 매 프레임 독립 추정 → 불연속

PART 5주파수 영역의 기존 방법들

  • 균일 격자 위의 등간격 샘플 필요 — LiDAR 점은 불규칙
  • 충분한 샘플 수 필요 (Nyquist) — 50~200점으로는 부족
  • 매 프레임 위치가 변경 — 일관된 격자 구성 불가

MUSIC 알고리즘

MUSIC (Multiple Signal Classification): 신호 부분공간과 잡음 부분공간을 분리하여 초고해상도 피크 검출.

원리

  1. 데이터의 공분산 행렬 $R = \mathbb{E}[\mathbf{x}\mathbf{x}^H]$ 계산
  2. $R$의 고유분해: 큰 고유값 = 신호, 작은 고유값 = 잡음
  3. 잡음 부분공간에 '수직'인 방향 탐색 → 매우 날카로운 피크
MUSIC이 LiDAR에 부적합한 이유:
MUSIC은 고정된 센서 배열을 가정한다 (안테나처럼 같은 위치에서 반복 관측).
LiDAR는 매 프레임 관측 위치가 다르다 (선박 움직임 + 스캔 패턴).
→ '같은 위치'에서의 반복 관측이 없음 → 공분산 행렬 추정 불가.
Capon(MVDR), ESPRIT 등 모든 부분공간 방법이 같은 이유로 부적합하다.

PART 6WaveSplat — 빔포밍 초기화

전체 흐름

다중 프레임 축적 (10프레임) → 분산관계 인식 빔포밍 → Greedy 피크 추출 → 선형 최소제곱 (w, φ) → 초기 파라미터 확보

빔포밍 수식

분산관계 인식 빔포밍
$$P(k_x, k_y) = \left|\sum_{j=1}^{M} z_j \exp\!\Big(-i\big(k_x x_j + k_y y_j - \omega(\mathbf{k})\,t_j\big)\Big)\right|^2$$ $$\text{where}\quad \omega(\mathbf{k}) = \sqrt{g\,|\mathbf{k}|\,\tanh(|\mathbf{k}|\,d)}$$

직관적 의미: "만약 $(k_x, k_y)$ 방향의 파도가 있다면, 관측값에 위상 보정을 하면 모두 같은 방향을 가리킬 것이다. 그 합의 크기가 클수록 그 방향의 파도가 실제로 존재한다."

  • $\exp(-i\ldots)$ = 위상 보정 (steering). 정렬이 잘 되면 보강 간섭 → $P$ 큼
  • 탐색 격자: $k_x, k_y \in [-4.0, 4.0]$ rad/m, $81 \times 81 = 6{,}561$ 후보 (직교좌표)
  • 격자 해상도 $\Delta k \approx 0.10$ rad/m, 파장 범위 ~1.6 m ~ 130 m (BF2~5 커버)

Greedy 피크 추출

  1. $P(k_x, k_y)$에서 최대 피크 $(k_x^*, k_y^*)$ 찾기
  2. 이 피크를 성분 목록에 추가
  3. 피크 주변 Cartesian 반경 0.15 rad/m 억제 (sidelobe 제거)
  4. 다음 최대 피크 찾기
  5. 반복 ($N_{\max}$개까지 또는 임계값 이하까지)

0.15 rad/m 억제 이유: 직교 격자에서 같은 파도의 sidelobe를 별도 성분으로 오인하는 것을 방지하면서, 교차해(crossing seas)를 분리 해상도 내에서 분리한다.

선형 최소제곱 — 진폭과 위상 초기화

$k_x, k_y$가 정해지면 $\cos(k_x x + k_y y - \omega t)$은 '알려진 기저'가 된다:

삼각함수 전개 → 선형 문제
$$z_j = \sum_i \left[a_i \cos(k_{x,i} x_j + k_{y,i} y_j - \omega_i t_j) + b_i \sin(\ldots)\right]$$ $$\text{행렬 형태: } \mathbf{z} = A\,\mathbf{c} \qquad\Rightarrow\qquad \mathbf{c} = (A^\top A)^{-1} A^\top \mathbf{z}$$

$a_i, b_i$에서 진폭과 위상을 복원:

$$w_i = \sqrt{a_i^2 + b_i^2}, \qquad \varphi_i = \arctan(-b_i / a_i)$$
결과: $N$개 성분의 초기 파라미터 $(w_i, k_{x,i}, k_{y,i}, \varphi_i)$ 확보. $k_x, k_y$는 빔포밍 해상도 범위 내에서 대략적이고, $w, \varphi$도 이에 영향받는다. → 충분히 좋은 출발점이지만 정밀하지 않음 → 비선형 최적화로 미세 조정 필요.

PART 7WaveSplat — 비선형 최적화

왜 초기화만으로 부족한가

빔포밍의 $|\mathbf{k}|$ 해상도는 ~0.0075 rad/m이다. 실제 파도의 $k$가 격자 사이에 있으면:

  • $|\mathbf{k}|$ 오차 2.4% → 주기 오차 ~1.2%
  • 30초 후 위상 오차 ~10° → 추적 시 성능 저하

이 '작은' 초기 오차가 시간이 지나면 누적된다 → $k_x, k_y$를 연속값으로 미세 조정해야 한다.

Loss 함수

WaveSplat Loss 함수 (3개 항)
$$\mathcal{L} = \underbrace{\frac{1}{M}\sum_j c_j\big(z_j - \hat{z}_j\big)^2}_{\text{데이터 항}} + \underbrace{\lambda_1 \sum_i |w_i|}_{\text{L1 희소성}} + \underbrace{\lambda_s \sum_i (\Delta w_i)^2}_{\text{스펙트럼 평활화}}$$

$\hat{z}_j = \sum_i w_i \cos(k_{x,i} x_j + k_{y,i} y_j - \omega_i t_j + \varphi_i)$,   $\lambda_1 = 10^{-3}$, $\lambda_s = 10^{-4}$

데이터 항: 관측과 예측의 차이

가중 평균제곱오차. 가중치 $c_j$는 Fresnel confidence로, 관측의 신뢰도를 반영한다.

Fresnel Confidence $c_j$

$$c_j = \frac{\cos\theta_j}{d_j / d_{\text{ref}}}$$
  • $\theta_j$ = 입사각. 수직($\cos \approx 1$)이면 반사 신호 강함 → 신뢰도 높음
  • $d_j$ = 관측 거리. 가까울수록 점 밀도 높고 노이즈 적음 → 신뢰도 높음
  • $d_{\text{ref}} = 125$m (최대 사거리의 절반)

물리적 근거: Fresnel 반사 법칙 — 수면은 거의 정반사(specular)하므로 입사각이 중요하다. 원거리 저각도 관측은 자동으로 가중치가 감소한다.

L1 정규화 — 자동 모델 선택

$\lambda_1 \sum |w_i|$의 역할:

L2 ($\sum w_i^2$)L1 ($\sum |w_i|$)
효과모든 $w$를 조금씩 줄임일부 $w$를 정확히 0으로
결과0이 되는 성분 없음자동 가지치기

BF2 너울에서 $N=15$로 시작해도 L1이 나머지 12개를 0으로 밀어낸다 → 수동으로 $N$을 결정할 필요 없음.

스펙트럼 평활화

$\lambda_s \sum (\Delta w_i)^2$: 인접 주파수 성분의 진폭이 급변하는 것을 방지. 데이터 항 대비 0.1% 수준으로 약하게 작용.

Gradient 계산

진폭 $w_i$에 대한 gradient
$$\frac{\partial\mathcal{L}}{\partial w_i} = -\frac{2}{M}\sum_j c_j(z_j - \hat{z}_j)\cos(\ldots) + \lambda_1 \operatorname{sign}(w_i)$$
파수 $k_{x,i}$에 대한 gradient (chain rule 포함)
$$\frac{\partial\mathcal{L}}{\partial k_{x,i}} = \frac{2}{M}\sum_j c_j(z_j - \hat{z}_j)\,w_i\!\left(x_j - \frac{\partial\omega_i}{\partial k_{x,i}} t_j\right)\sin(\ldots)$$

$\frac{\partial\omega_i}{\partial k_{x,i}} = \frac{k_{x,i}}{|\mathbf{k}_i|}\cdot\frac{\partial\omega}{\partial|\mathbf{k}|}$ — $\omega$가 $\mathbf{k}$의 함수이므로 chain rule 적용. PyTorch autograd로 자동 계산.

핵심: 모든 gradient가 해석적(analytic)으로 계산됨. $\cos/\sin$의 미분은 $\sin/\cos$ — 정확한 gradient, 수치 미분 불필요.

경사하강법(SGD)에서 Adam까지

Step 1: SGD (Stochastic Gradient Descent)

$$\theta_{\text{new}} = \theta - \eta \cdot \nabla\mathcal{L}$$

$\eta$ = 학습률. 너무 크면 진동/발산, 너무 작으면 느림. 문제: 모든 파라미터에 같은 학습률 — $k_x$(민감)와 $w$(둔감)가 같은 속도로 업데이트됨.

Step 2: Momentum

$$v_{\text{new}} = \beta \cdot v_{\text{old}} + \nabla\mathcal{L} \qquad \theta_{\text{new}} = \theta - \eta \cdot v_{\text{new}}$$

$\beta = 0.9$ — 이전 방향의 90% 유지. 일관된 gradient 방향은 가속, 진동 방향은 상쇄. 하지만 여전히 모든 파라미터에 같은 학습률.

Step 3: Adam Optimizer

Adam — 적응적 학습률
$$m \leftarrow \beta_1 m + (1-\beta_1)\,g \qquad\text{(1차 모멘트: 방향)}$$ $$v \leftarrow \beta_2 v + (1-\beta_2)\,g^2 \qquad\text{(2차 모멘트: 크기)}$$ $$\theta \leftarrow \theta - \eta \cdot \frac{\hat{m}}{\sqrt{\hat{v}} + \epsilon}$$
변수의미값효과
$m$ (1차 모멘트)gradient의 이동 평균$\beta_1 = 0.9$최근 10 step의 방향 안정화
$v$ (2차 모멘트)gradient 제곱의 이동 평균$\beta_2 = 0.999$최근 1000 step의 변동폭 추정
$\eta / \sqrt{v}$실효 학습률—변동 크면 조심, 작으면 과감
WaveSplat에서 Adam의 효과:
$k_x$ (gradient 변동 큼, 민감) → $v$ 큼 → 학습률 자동 감소 → 신중하게 업데이트
$w$ (gradient 변동 작음, 둔감) → $v$ 작음 → 학습률 자동 증가 → 과감하게 업데이트
→ 각 파라미터의 특성에 맞는 최적 속도로 수렴

PART 8Coarse-to-Fine + Adaptive N

Coarse-to-Fine 전략

N=3 (200 iter) → N=8 (200 iter) → N=15 (200 iter) → Adaptive N

각 단계의 수렴된 파라미터가 다음 단계의 초기값이 된다. 총 600 iterations, lr = $5\times10^{-3}$.

왜 단계적으로 해야 하는가?

  • $N=3$: 12개 파라미터 → landscape가 비교적 매끄러움 → global minimum 수렴 쉬움
  • $N=15$: 60개 파라미터 → local minima가 매우 많음 (성분 간 간섭)
그림 그리기: 밑그림(큰 구도) → 중간 톤 → 세부 묘사.
한 번에 세부부터 그리면 전체 구도가 어긋난다.

적응형 모델 차수 (Adaptive N)

Step 1: 에너지 기반 가지치기 (Pruning)

  1. 에너지 계산: $E_i = w_i^2$
  2. 에너지 내림차순 정렬
  3. 상위 90% 에너지를 커버하는 최소 $N'$개 선택 ($\tau_E = 0.90$)
  4. 나머지 제거
예시: 5성분의 에너지 $[0.50, 0.30, 0.10, 0.05, 0.05]$
누적: $[0.50, 0.80, \mathbf{0.90}, 0.95, 1.00]$ → $N'=3$으로 가지치기 (90% 도달)

Step 2: 안전 롤백 (Safety Rollback)

가지치기 후 RMSE가 130% 초과하면 원복한다 ($\tau_S = 1.30$). 중요 성분을 실수로 잘라내는 것을 방지 — 특히 교차해에서 에너지가 비슷한 성분이 많을 때.

Step 3: 잔차 기반 성장 (Residual Growth)

  1. 잔차 $r_j = z_j - \hat{z}_j$ 계산
  2. $\text{RMS}(r) > \tau_R = 0.05$m이면: 잔차에 빔포밍 다시 적용 → 놓친 성분 발견 → 추가
결과: 너울($N_a=1$)에서 복잡해($N_a=21$)까지 자동 적응.
고정 $N=15$ 대비 6.4% 추가 nRMSE 개선.

위상 전파 (Predict Step)

$$\varphi_i(t+\Delta t) = \varphi_i(t) + \omega_i \cdot \Delta t$$

$\Delta t = 0.1$s (10Hz), $\omega_i$는 분산관계에서 결정 — 분산관계가 '예측기' 역할

이 예측이 정확한 이유: 분산관계가 정확히 성립하면 위상 예측이 완벽하다. 실제 편차(비선형 효과, 모델 오차)는 매우 작으므로 Update에서 소량의 보정만으로 충분하다.

속도 비교:
ETKF predict: $N_e$개 앙상블 각각 FFT로 전파 → $O(N_e \cdot G \log G)$ = 느림
WaveSplat predict: $N$개 위상에 덧셈 → $O(N)$ = 즉시

w_phi 모드 — 왜 $k_x, k_y$를 고정하는가

추적 시 $w$(진폭)와 $\varphi$(위상)만 업데이트하고, $k_x, k_y$는 초기화에서 확정 후 고정한다.

실험으로 확인된 이유:

모드단기 (5프레임)장기 (50프레임)
full (전부 업데이트)loss 약간 더 낮음$k_x, k_y$ drift → 급격한 성능 저하
w_phi (w, φ만)loss 약간 높음안정적 추적 유지
full 모드의 문제: $k_x, k_y$가 drift하면 분산관계에서 벗어남 → 위상 전파 예측이 점점 틀려짐 → 10프레임 이후 급격한 성능 저하.

슬라이딩 윈도우

현재 프레임 + 이전 2프레임 = 3프레임 윈도우 ($K_w = 3$):

  • 단일 프레임: 50~200점 → 노이즈에 취약
  • 3프레임: 150~600점 → 노이즈 평균화
  • 3프레임 = 0.3초 = 파도 주기(~5초)의 6% → 파도 변화를 놓치지 않으면서 충분한 평균화

결론: 주파수 영역 Splatting이 필요한 이유

희소 LiDAR → 파도장 복원 문제의 4가지 요구사항:
  1. 관측이 극도로 희소 → 강력한 사전 지식 필요 → 주파수 영역: 분산관계 직접 내장
  2. 관측이 불규칙 → 격자 없는 표현 필요 → Splatting: 격자 없는 파라메트릭 표현
  3. 실시간 필요 → 적은 파라미터 + 빠른 추적 → 4N개, 위상 전파로 즉시 예측
  4. 시간 예측 필요 → 시간이 모델에 내장 → $\cos(\ldots - \omega t + \varphi)$

이 4가지를 동시에 만족하는 방법은 WaveSplat이 유일하다.

  • ETKF: VR=0.90(에너지 OK) but $\rho$=0.11(형상 NG) → "에너지는 맞추지만 위치가 틀림"

한계와 향후 연구

최대 약점: Dir $R^2$ = −0.25 (방향 추정)
BF4에서 일부 성분의 방향($k_x$ 부호)이 반전됨. 원인: 선박 전방 LiDAR의 1D 관측 geometry — $k_x > 0$ (다가오는 파도)와 $k_x < 0$ (멀어지는 파도) 구분이 어려움.

향후 해결 방향:

  1. 다중 프레임 방향 추적 (시간에 따른 위상 변화로 방향 추론)
  2. 3D FFT $(k_x, k_y, \omega)$ 초기화
  3. 방향 신뢰도 기반 feedforward 게이팅
  4. 수조 실험(Ch5)으로 sim-to-real gap 검증
