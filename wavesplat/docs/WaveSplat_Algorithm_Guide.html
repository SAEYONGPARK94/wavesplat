PART 0문제 정의

왜 파도를 추정하는가?

선박과 해양 구조물은 파도에 의해 지배적인 외력을 받는다. 파도를 정확히 알 수 있다면:

  1. 선박 운동 예측 — 화물 고박 타이밍, 헬기 착함 판단
  2. 능동 제어 — 하이드로포일 안정화, 파랑 feedforward (이 논문의 응용)
  3. 구조물 하중 예측 — 피로 수명 계산, 위험 경보
  4. 항로 최적화 — 연료 절감, 승객 안전

PART 1파도의 물리학

단일 평면파

바다의 가장 기본적인 구성 요소는 하나의 평면파(plane wave)이다:

단일 평면파 수식
$$\eta(x, y, t) = w \cos(k_x x + k_y y - \omega t + \varphi)$$

각 변수의 의미:

변수의미단위직관
$w$진폭m파도 높이의 절반. 파고 $H = 2w$
$k_x, k_y$파수 벡터rad/m파도의 방향과 파장을 결정
$\omega$각주파수rad/s파도가 얼마나 빨리 지나가는지. 주기 $T = 2\pi/\omega$
$\varphi$위상rad파도의 시작점 (시간 오프셋)

파수 벡터 $(k_x, k_y)$ — 파도의 '지문'

파수 벡터 $\mathbf{k} = (k_x, k_y)$는 파도의 공간적 특성을 완전히 결정한다:

  • 파장: $\lambda = 2\pi / |\mathbf{k}|$ — $|\mathbf{k}|$가 크면 짧은 파도(잔물결), 작으면 긴 파도(너울)
  • 방향: $\theta = \arctan(k_y / k_x)$ — 파도가 어디서 오는지
비유: 라디오에서 주파수를 맞추듯, 바다에서 $(k_x, k_y)$로 '채널'을 맞춘다.

분산관계 (Dispersion Relation)

파도의 물리학에서 가장 중요한 법칙이다:

분산관계
$$\omega^2 = g\,|\mathbf{k}|\,\tanh(|\mathbf{k}|\,d)$$

심해 ($d \gg \lambda$): $\omega \approx \sqrt{g\,|\mathbf{k}|}$   |   천해 ($d \ll \lambda$): $\omega \approx |\mathbf{k}|\sqrt{gd}$

직관적 의미:

  • 긴 파도(큰 $\lambda$, 작은 $|\mathbf{k}|$)는 빠르게 이동
  • 짧은 파도(작은 $\lambda$, 큰 $|\mathbf{k}|$)는 느리게 이동
  • 수심 $d$가 얕으면 모든 파도가 느려짐
핵심 통찰: 파장($|\mathbf{k}|$)이 결정되면 속도($\omega$)는 자동으로 결정된다.
WaveSplat은 $\omega$를 자유변수로 두지 않고 분산관계로 강제한다.
→ 추정할 파라미터: 5N → 4N개로 감소 (물리적으로 불가능한 해를 원천 차단)

다성분 중첩 — 실제 바다

실제 바다는 여러 방향, 여러 파장의 파도가 겹쳐진 것이다:

다성분 파도 모델
$$\eta(x,y,t) = \sum_{i=1}^{N} w_i \cos(k_{x,i}\,x + k_{y,i}\,y - \omega_i\,t + \varphi_i)$$ $$\text{where}\quad \omega_i = \sqrt{g\,|\mathbf{k}_i|\,\tanh(|\mathbf{k}_i|\,d)} \quad\text{(분산관계로 결정)}$$

위상 속도 vs 군속도 — 분산관계에서 파생되는 두 속도

분산관계에서 두 가지 중요한 속도가 도출된다:

위상 속도 (Phase velocity)
$$v_p = \frac{\omega}{|\mathbf{k}|} \quad\text{— 파봉(crest)이 이동하는 속도}$$
군속도 (Group velocity)
$$v_g = \frac{\partial\omega}{\partial|\mathbf{k}|} = \frac{g}{2\omega}\left[\tanh(|\mathbf{k}|d) + |\mathbf{k}|d\operatorname{sech}^2(|\mathbf{k}|d)\right]$$
위상 속도 $v_p$군속도 $v_g$
정의파봉의 이동 속도에너지(파군)의 전파 속도
심해 비율$\omega/|k|$$v_p / 2$
WaveSplat에서 역할위상 전파: $\varphi += \omega \Delta t$$k$ gradient의 분산 경로: $\partial\omega/\partial k_{x}$ (Part 7)
왜 미리 알아야 하나: Part 7에서 $k_x$에 대한 gradient를 계산할 때 $v_g$가 분산관계 chain rule의 핵심으로 등장한다. 공간 항($x_j$)과 시간-분산 항($t_j \cdot v_g$)의 경쟁이 $k$ 추정의 정밀도를 결정한다.

Gerstner wave란?

1802년 Franz Josef von Gerstner가 유도한 유한 진폭 파도의 정확해(exact solution)이다. 선형 파도와 달리 물 입자가 진원 운동이 아닌 트로코이드(trochoid) 궤적을 따른다:

Gerstner 파도 — 단일 성분
$$x(u,t) = u - \frac{A k_x}{|\mathbf{k}|}\sin(k_x u + k_y v - \omega t + \varphi)$$ $$y(v,t) = v - \frac{A k_y}{|\mathbf{k}|}\sin(k_x u + k_y v - \omega t + \varphi)$$ $$z(u,v,t) = A\cos(k_x u + k_y v - \omega t + \varphi)$$

$(u,v)$ = 정적 Lagrangian 좌표 (파도가 없을 때의 수면 위치)
$(x,y)$ = 실제 관측 위치 (수평 변위 포함) — $(u,v)$와 다르다!

선형 파도와의 핵심 차이:

특성Linear sinusoidalGerstner
수평 변위없음 (z만 진동)있음 ($x,y$도 진동)
파봉 형상대칭 (cos)뾰족한 파봉 + 넓은 파배 (비대칭)
steepness 한계제한 없음 (비물리적)$kA \leq 1$ (자체 제한, 파봉 꼭대기에서 cusp)
에너지 보존정확정확 (비압축성, 무회전)
Z 값 차이$\Delta z \sim O(\epsilon^2) = O((kA)^2)$ — BF4에서 ~1.5-6mm

왜 시뮬레이터에 Gerstner를 사용하는가?

  1. 물리적 현실성: 실제 해양파의 비대칭 형상(뾰족한 파봉, 넓은 파배)을 재현 — 선형 모델은 이를 표현하지 못함
  2. 정확한 표면 법선: Lagrangian 메시에서 $\partial(x,y,z)/\partial(u,v)$로 해석적 법선 계산 가능 → LiDAR 반사 시뮬레이션(Fresnel confidence $c_j$)에 필수
  3. 다성분 중첩: 각 성분의 수평 변위를 합산하여 복잡한 해면 재현 ($Q$ 파라미터로 steepness 제어)
  4. GPU 병렬 계산: 해석적 공식이므로 격자 기반 수치 시뮬레이션(CFD)보다 수천 배 빠름 — 100 에피소드 생성 가능
핵심 설계 결정:
GT(시뮬레이터)는 Gerstner(비선형), 추정기는 linear(선형). 이 "의도된 불일치"는:
  • BF3-4에서 $\Delta z \sim 1.5$-$6$mm < LiDAR noise($\sim$20mm) → 실질적 영향 없음
  • Linear 추정기가 weakly nonlinear GT에 robust함을 검증하는 실험 설계
  • Gerstner 역변환 $(x,y) \to (u,v)$ 없이 해석적 gradient 계산 가능 → 속도 이점
  • Part 8에서 이 불일치의 정량적 오차 분석 상세 설명

Gerstner 파도 적용 방식 — WaveSim 시뮬레이터에서

  1. JONSWAP 스펙트럼에서 $N$ 성분 추출: $(A_i, k_{x,i}, k_{y,i}, \omega_i, \varphi_i)$ — 각 성분의 에너지는 스펙트럼 밀도에서 결정
  2. Lagrangian 메시 생성: 정적 격자 $(u,v)$에 대해 각 성분의 수평/수직 변위를 합산 → 실제 수면 $(x,y,z)$ 계산
  3. 표면 법선 계산: $\mathbf{n} = \frac{\partial\mathbf{r}}{\partial u} \times \frac{\partial\mathbf{r}}{\partial v}$ → 각 메시 점에서 정확한 법선 벡터
  4. LiDAR ray-mesh 교차: 선박 위치에서 발사된 LiDAR ray가 Gerstner 메시와 만나는 점 $(x_j, y_j, z_j)$과 입사각 $\theta_j$ 계산
  5. Confidence 가중치: 법선 $\mathbf{n}$과 ray 방향에서 $c_j = \cos\theta_j / (d_j / d_{\text{ref}})$ → 시뮬레이션에서는 정확한 법선 사용 가능
실측 LiDAR에서는?
Gerstner 메시가 없으므로 표면 법선을 모른다 → $\mathbf{n} \approx \hat{\mathbf{z}}$ (flat 가정)으로 근사. BF4에서 ~3° 법선 오차 → $\cos\theta$ 오차 <2% (θ<30°), ~9% (θ≈60°). Part 7 confidence 절에서 상세 설명.

선형 파도 모델의 충분성

BF2-4 범위에서 파고/파장 비(steepness)가 < 0.05이므로 선형 중첩 모델이 충분히 정확하다. 관측 노이즈가 비선형 오차보다 훨씬 크기 때문에, cos 합으로 모델링하는 것이 실용적으로 최선의 선택이다.

A1 Ablation 미리보기: 만약 $\omega$를 분산관계로 제약하지 않고 자유 파라미터로 두면? Part 7에서 상세히 다루겠지만, 결론: R̄=0.51로 과적합이 발생한다. 물리적으로 불가능한 $(k, \omega)$ 조합이 허용되어 optimizer가 관측 노이즈까지 fit하게 됨.

PART 2공간 영역 방법 — ETKF

격자 기반 접근의 기본 아이디어

수면을 $N_x \times N_y$ 격자로 나누고, 각 격자점의 파고 $\eta$와 시간 미분 $\dot\eta$ 둘 다를 상태 벡터에 포함한다:

ETKF 상태 벡터 ($G = N_x N_y$ 격자점)
$$\mathbf{x} = \begin{bmatrix} \boldsymbol{\eta} \\[4pt] \dot{\boldsymbol{\eta}} \end{bmatrix} = \begin{bmatrix} \eta_{1,1}, \eta_{1,2}, \ldots, \eta_{N_x,N_y} \\[4pt] \dot\eta_{1,1}, \dot\eta_{1,2}, \ldots, \dot\eta_{N_x,N_y} \end{bmatrix}^\top \in \mathbb{R}^{2G}$$

$40 \times 30 = 1{,}200$ 격자점 → $\mathbf{x} \in \mathbb{R}^{2{,}400}$

왜 $\dot\eta$도 필요한가? 선형 파동 방정식이 2차 시간 미분 방정식이기 때문이다. 진자(harmonic oscillator)의 다음 상태를 알려면 위치 + 속도가 모두 필요한 것과 같다. $\eta$만 있으면 $\partial^2/\partial t^2$ 적분에 모호성 발생 → 파도가 어느 방향(접근/후퇴)으로 진행 중인지 알 수 없음.

LiDAR 관측이 50~200개인데 상태가 2,400개 — 심하게 underdetermined (해가 무한히 많음). 사전 정보(prior)가 필수 → 칼만 필터.

칼만 필터 기초

Predict-Update 2단계 반복:

Step 1: Predict (예측)

$$\mathbf{x}_{\text{pred}} = F \cdot \mathbf{x}_{\text{prev}} \qquad\text{(물리 모델로 다음 상태 예측)}$$ $$P_{\text{pred}} = F\,P\,F^\top + Q \qquad\text{(불확실성 증가)}$$

$F$의 정체 — 선형 파동 방정식이 물리 모델

$F$는 단순한 행렬이 아니라 선형 자유표면 파동 방정식의 정확한 시간 진화 연산자이다. 분산관계 $\omega^2 = g|\mathbf{k}|\tanh(|\mathbf{k}|d)$를 만족하는 파동이 $\Delta t$ 동안 어떻게 진화하는지를 그대로 코드화한 것.

출발: 선형 자유표면 파동 방정식

2차 시간 미분 방정식
$$\frac{\partial^2 \eta}{\partial t^2} = -g\,|\hat{\nabla}|\tanh(|\hat{\nabla}|\,d)\,\eta$$

여기서 $|\hat{\nabla}|$은 푸리에 공간에서 $|\mathbf{k}|$로 작용하는 비국소 연산자. 각 푸리에 모드 $\hat\eta(\mathbf{k}, t)$가 자기 고유 진동수 $\omega(\mathbf{k}) = \sqrt{g|\mathbf{k}|\tanh(|\mathbf{k}|d)}$로 진동.

해 $\Delta t$ 동안의 정확한 시간 진화 (모드별 propagator)

각 푸리에 모드 $\mathbf{k}$에 대해 단순조화운동(SHM) 형태로 풀린다:

모드별 $2 \times 2$ propagator $F_\mathbf{k}$
$$\begin{bmatrix} \hat\eta(\mathbf{k}, t+\Delta t) \\[4pt] \hat{\dot\eta}(\mathbf{k}, t+\Delta t) \end{bmatrix} = \underbrace{\begin{bmatrix} \cos(\omega \Delta t) & \dfrac{\sin(\omega \Delta t)}{\omega} \\[10pt] -\omega\,\sin(\omega \Delta t) & \cos(\omega \Delta t) \end{bmatrix}}_{F_\mathbf{k}} \begin{bmatrix} \hat\eta(\mathbf{k}, t) \\[4pt] \hat{\dot\eta}(\mathbf{k}, t) \end{bmatrix}$$
항물리적 의미
$\cos(\omega\Delta t)$ (대각)같은 위상으로 회복 (재진동)
$\sin(\omega\Delta t)/\omega$ (위)속도 $\dot\eta$가 위치 $\eta$에 기여 (속도 → 위치 적분)
$-\omega\sin(\omega\Delta t)$ (아래)위치 $\eta$가 속도 $\dot\eta$에 기여 (복원력 → 가속)
$\det F_\mathbf{k} = 1$에너지 보존 (symplectic) — 진폭 감쇠 없음
이 $F_\mathbf{k}$는 진자/스프링 시스템의 정확한 시간 진화 행렬과 동일한 형태이다. 파도의 각 푸리에 모드를 "고유 진동수 $\omega(\mathbf{k})$를 가진 독립 진자"로 보는 관점.

전체 격자 $F$ — 푸리에 분해

공간 격자에서 $F$는 $2G \times 2G = 2{,}400 \times 2{,}400$ dense matrix가 되어 직접 곱은 비효율($\sim$5.7M 원소). 푸리에 공간으로 보내면 모드별로 독립해 $2 \times 2$ 블록 대각:

$$F = \mathcal{F}^{-1} \cdot \mathrm{diag}\bigl(\{F_\mathbf{k}\}_\mathbf{k}\bigr) \cdot \mathcal{F}$$

$\mathcal{F}$ = 2D FFT, $\mathcal{F}^{-1}$ = 역 FFT. 한 번 FFT → 모든 모드에 동시 propagator 적용 → 한 번 IFFT.

실제 코드 흐름 (etkf_grid.py:55-83)

$\eta, \dot\eta$ 격자 → FFT $\hat\eta, \hat{\dot\eta}$ (모드별) → $F_\mathbf{k}$ 진화된 $\hat\eta', \hat{\dot\eta}'$ → IFFT $\eta', \dot\eta'$ 격자
사전 계산 (한 번만)
$$\omega(\mathbf{k}) = \sqrt{g\,|\mathbf{k}|\tanh(|\mathbf{k}|\,d)}, \quad \cos\omega\Delta t,\;\; \sin\omega\Delta t,\;\; \mathrm{sinc}\,\omega\Delta t \equiv \sin(\omega\Delta t)/\omega$$
매 predict step (각 앙상블 멤버)
$$\hat\eta' \;=\; \hat\eta\,\cos\omega\Delta t \;+\; \hat{\dot\eta}\,\mathrm{sinc}\,\omega\Delta t$$ $$\hat{\dot\eta}' \;=\; -\hat\eta\,\omega\sin\omega\Delta t \;+\; \hat{\dot\eta}\,\cos\omega\Delta t$$

앙상블 칼만 필터 (ETKF)

$N_e$개의 '앙상블 멤버'(격자 파도장 샘플)로 공분산을 근사한다:

$$P \approx \frac{1}{N_e-1} \mathbf{X}_{\text{ens}} \mathbf{X}_{\text{ens}}^\top$$

$\mathbf{X}_{\text{ens}}$ = 앙상블 편차 행렬, $N_e = 100$이면 대략적 공분산 구조 포착

동작 순서:

  1. $N_e$개의 격자 파도장을 초기화 (랜덤 위상의 스펙트럼에서 생성)
  2. Predict: 각 멤버를 FFT 기반 물리 모델로 전파
  3. 관측이 오면: 각 멤버에서 관측 위치의 높이 추출
  4. Update: 관측과 가까운 멤버에 더 큰 가중치
  5. 앙상블 평균이 최종 추정값

PART 3공간 영역 방법 — GPR

가우시안 프로세스(GP)란?

함수의 확률 분포이다. "이 함수가 이런 모양일 확률이 높다"를 수학적으로 표현한다.

점을 찍고 매끄러운 곡선으로 잇기 — 관측점 근처는 확실하고, 멀면 불확실하다. 매끄러움의 정도는 커널 함수가 결정한다.

GPR 수식

GPR 예측 평균과 분산
$$\mu(\mathbf{x}^*) = \mathbf{k}(\mathbf{x}^*, X) \left[K(X,X) + \sigma^2 I\right]^{-1} \mathbf{z}$$ $$\sigma^2(\mathbf{x}^*) = k(\mathbf{x}^*,\mathbf{x}^*) - \mathbf{k}(\mathbf{x}^*, X) \left[K + \sigma^2 I\right]^{-1} \mathbf{k}(X, \mathbf{x}^*)$$
  • $\mathbf{x}^*$ = 예측 위치, $X$ = 관측 위치들, $\mathbf{z}$ = 관측값 (수면 높이)
  • $k(\cdot,\cdot)$ = 커널 함수 (두 점 사이의 '유사도')
  • $K(X,X)$ = 관측점끼리의 유사도 행렬 ($M \times M$)

Matern 커널

WaveSplat 논문에서 사용한 GPR baseline: Matern $\nu$=5/2, length scale $l$=20m

$$k(r) = \left(1 + \frac{\sqrt{5}\,r}{l} + \frac{5\,r^2}{3\,l^2}\right) \exp\!\left(-\frac{\sqrt{5}\,r}{l}\right)$$

$l = 20$m → "20m 이내의 점들은 강하게 연관". 파도에는 여러 스케일이 동시에 존재하므로 하나의 $l$로는 모든 스케일을 포착할 수 없다.

GPR의 근본적 한계

한계 1: 시간을 무시함

GPR 커널 $k(\mathbf{x}_1, \mathbf{x}_2)$는 공간 거리만 본다. 파도가 이동한다는 사실을 모른다.

예시: $t=0$에서 점 A의 파고가 1m, $t=0.1$에서 0.5m (파도가 이동). GPR은 두 관측을 평균하여 0.75m로 추정 — 파도의 이동을 전혀 반영하지 못한다.

왜 GPR이 flat prediction을 하는가 — 수학적 메커니즘

GPR의 예측이 거의 0에 가까운 이유는 세 가지 요인의 결합이다:

GPR 예측 = 가중합
$$\mu(\mathbf{x}^*) = \sum_{j=1}^{M} \alpha_j \cdot z_j \qquad\text{where}\quad \boldsymbol{\alpha} = (K + \sigma^2 I)^{-1} \mathbf{k}(\mathbf{x}^*, X)$$

요인 1: Sparse LiDAR + 단일 length scale

  • 관측점 간 평균 거리 $\sim$10-50m, 하지만 length scale $l = 20$m
  • 예측 위치 $\mathbf{x}^*$가 관측점에서 $> 2l = 40$m 떨어지면 $k(\mathbf{x}^*, x_j) \approx 0$ → 가중치 $\alpha_j \approx 0$
  • 관측점 밖의 광대한 영역에서 $\mu(\mathbf{x}^*) \approx 0$ (사전 평균으로 수축)

요인 2: 시간 무시 → 위상 평균화

  • 3프레임(0.3초)의 관측을 시간 구분 없이 동일 공간으로 취급
  • 같은 $(x,y)$ 근처에서 다른 시점의 파고가 양/음으로 섞임
  • 커널이 이들을 "유사한 관측"으로 보고 평균(≈0)으로 추정

요인 3: Matern ν=5/2 단일 스케일의 한계

  • $\nu=5/2$는 2차 미분 가능 → 충분히 매끄러움. 문제는 이것이 아님
  • 단일 $l=20$m은 짧은 파도(λ~10m)는 과평활, 긴 파도(λ~50m)는 부족
  • 다중 스케일 커널(예: 두 Matern 혼합)도 시간 무시 문제를 해결하지 못함 → 근본적 한계
수치로 보기: VR=0.065는 $\text{Var}(\hat{z}) = 0.065 \cdot \text{Var}(z)$.
파고 분산의 93.5%가 "삭제"됨 — 이것이 nRMSE=0.261인데도 SS=-0.14(zero보다 나쁨)인 이유.
nRMSE만 보면 "괜찮아 보이는" 이유: $\text{nRMSE}(0) = \text{RMSE}(0)/H_s = \sigma/H_s \approx 0.25$이므로 GPR의 0.261은 zero predictor(0.25)보다 겨우 4% 나쁜 수준.

주파수 파라미터를 알면 어디서든 복원 가능

$(w, k_x, k_y, \varphi)$를 한번 추정하면:

  1. 관측 영역 밖에서도 예측 — 선박 전방 500m도 계산 가능
  2. 미래 시점도 예측 — $t$만 바꾸면 됨 (분산관계가 전파 속도 결정)
  3. 격자 제한 없음 — 연속 함수이므로 임의의 $(x,y)$에서 평가

시간이 자연스럽게 포함되는 이유

$\cos(k_x x + k_y y - \omega t + \varphi)$에서 $t$는 변수이다. 분산관계 $\omega = f(\mathbf{k}, d)$가 '시계' 역할을 한다:

  • 각 성분이 고유 속도로 전파: 장파는 빠르게, 단파는 느리게
  • ETKF가 'predict step'에서 FFT로 전파하는 것을 WaveSplat은 수식 하나로 해결
  • GPR는 시간을 아예 모름 → 매 프레임 독립 추정 → 불연속

PART 5주파수 영역의 기존 방법들

FFT — 고전적 스펙트럼 분석

시간/공간 신호를 주파수 성분으로 분해하는 표준 방법이다. 그러나:

  • 균일 격자 위의 등간격 샘플 필요 — LiDAR 점은 불규칙
  • 충분한 샘플 수 필요 (Nyquist) — 50~200점으로는 부족
  • 매 프레임 위치가 변경 — 일관된 격자 구성 불가

MUSIC 알고리즘

MUSIC (Multiple Signal Classification): 신호 부분공간과 잡음 부분공간을 분리하여 초고해상도 피크 검출.

원리

  1. 데이터의 공분산 행렬 $R = \mathbb{E}[\mathbf{x}\mathbf{x}^H]$ 계산
  2. $R$의 고유분해: 큰 고유값 = 신호, 작은 고유값 = 잡음
  3. 잡음 부분공간에 '수직'인 방향 탐색 → 매우 날카로운 피크
MUSIC이 LiDAR에 부적합한 이유:
MUSIC은 고정된 센서 배열을 가정한다 (안테나처럼 같은 위치에서 반복 관측).
LiDAR는 매 프레임 관측 위치가 다르다 (선박 움직임 + 스캔 패턴).
→ '같은 위치'에서의 반복 관측이 없음 → 공분산 행렬 추정 불가.
Capon(MVDR), ESPRIT 등 모든 부분공간 방법이 같은 이유로 부적합하다.

왜 분산관계가 빔포밍 성능을 높이는가 — Temporal Coherence 메커니즘

핵심은 시간적 위상 정렬(temporal phase alignment)이다:

빔포밍 스펙트럼 — ω(k) 주입 전후 비교
$$P_{\text{naive}}(k_x, k_y) = \left|\sum_j z_j \exp(-i(k_x x_j + k_y y_j))\right|^2 \quad\text{(공간만)}$$ $$P_{\text{disp}}(k_x, k_y) = \left|\sum_j z_j \exp(-i(k_x x_j + k_y y_j \;{\color{#e74c3c}{- \omega(\mathbf{k})\,t_j}}))\right|^2 \quad\text{(시공간)}$$

메커니즘:

  1. 문제: 10프레임(1초) 축적 시 파도가 이동함. 같은 $(k_x, k_y)$ 파도의 위상이 $t_j$마다 다름
  2. 공간만 빔포밍: $t_j$에 따른 위상 차이를 무시 → 보강 간섭이 약해지거나 상쇄
  3. 분산관계 주입: $\omega(\mathbf{k})\,t_j$로 각 관측의 시간적 위상을 보정(de-rotate) → 모든 프레임이 같은 위상으로 정렬 → 보강 간섭 극대화
  4. 허위 피크 제거: 잘못된 $(k_x, k_y)$에 대해 $\omega(\mathbf{k})$가 실제 $\omega$와 불일치 → 시간 위상 정렬 실패 → 상쇄 간섭 → 피크 소멸
비유: 라디오에서 주파수가 맞으면 모든 시점의 신호가 보강 간섭하여 맑은 소리가 들린다. 주파수가 틀리면 각 시점의 신호가 상쇄되어 잡음만 남는다. 분산관계는 "정확한 주파수 다이얼"이다.

PART 6WaveSplat — 빔포밍 초기화

전체 흐름

왜 10프레임 축적인가?

빔포밍 전 10프레임(1초, 10Hz)을 모아서 사용하는 이유:

프레임 수관측점 수시간 aperturetrade-off
1프레임50~2000s공간만 사용, 시간 coherence 없음
5프레임250~10000.5sTp~5s의 10% — 위상 변화 부족
10프레임500~20001sTp~5s의 20% — 충분한 위상 변화 + 파도 구조 유지
20프레임1000~40002sBF3(Tp~5s)에서 파도 구조 변화 시작, 계산 느림
Pareto 최적점: 시간 aperture가 $T_p$의 ~20%이면 분산관계 $\omega(\mathbf{k})$로 시간 coherence를 활용하면서도 비선형 효과(파도 변형)가 무시 가능. 10프레임 = 초기화 시 1초 대기 → 선박 운영에서 허용 가능한 지연.
다중 프레임 축적 (10프레임) → 분산관계 인식 빔포밍 → Greedy 피크 추출 → 선형 최소제곱 (w, φ) → 초기 파라미터 확보

빔포밍 수식

분산관계 인식 빔포밍
$$P(k_x, k_y) = \left|\sum_{j=1}^{M} z_j \exp\!\Big(-i\big(k_x x_j + k_y y_j - \omega(\mathbf{k})\,t_j\big)\Big)\right|^2$$ $$\text{where}\quad \omega(\mathbf{k}) = \sqrt{g\,|\mathbf{k}|\,\tanh(|\mathbf{k}|\,d)}$$

직관적 의미: "만약 $(k_x, k_y)$ 방향의 파도가 있다면, 관측값에 위상 보정을 하면 모두 같은 방향을 가리킬 것이다. 그 합의 크기가 클수록 그 방향의 파도가 실제로 존재한다."

  • $\exp(-i\ldots)$ = 위상 보정 (steering). 정렬이 잘 되면 보강 간섭 → $P$ 큼
  • 탐색 격자: $k_x, k_y \in [-4.0, 4.0]$ rad/m, $81 \times 81 = 6{,}561$ 후보 (직교좌표)
  • 격자 해상도 $\Delta k \approx 0.10$ rad/m, 파장 범위 ~1.6 m ~ 130 m (BF2~5 커버)

Greedy 피크 추출 + Fine Refinement (2-stage)

  1. Coarse 피크: 81×81 격자 ($\Delta k_c = 0.10$ rad/m)에서 최대 $(k_x^c, k_y^c)$ 탐색
  2. Fine refinement: $(k_x^c, k_y^c)$ 주변 $\pm 0.2$ rad/m 영역을 41×41 격자 ($\Delta k_f = 0.01$ rad/m)로 재탐색 → $(k_x^f, k_y^f)$
  3. 이 피크를 성분 목록에 추가, 선형 최소제곱으로 $w, \varphi$ 계산
  4. 이 성분을 잔차에서 빼고, coarse map의 피크 주변 반경 0.15 rad/m 억제 (sidelobe 제거)
  5. 다음 성분 반복 ($N_{\max}$개까지 또는 파워가 $10^{-12}$ 이하까지)
왜 2-stage인가:
1-stage coarse만 하면 $\Delta k = 0.10$ rad/m로 $|\mathbf{k}| \approx 0.3$에서 17% 오차 → tracking 시 위상 drift.
1-stage만 fine 격자(0.01 rad/m)로 전역 탐색하면 $801 \times 801 \approx 640{,}000$ 후보 → 너무 느림.
→ coarse로 거친 위치 찾고, fine으로 국소 정밀화 (총 $81^2 + N \times 41^2 \ll 801^2$).

Sidelobe 억제 반경 0.15 rad/m — 왜 이 값인가?

Greedy 피크 추출 후 주변을 억제하는 반경의 선택 근거:

  • 하한 (Rayleigh 한계): aperture $L \sim 240$m에서 주로브 폭 $\approx 2\pi/L \approx 0.026$ rad/m. 이보다 작으면 같은 피크의 sidelobe를 놓침
  • 상한 (교차해 분리): 두 교차파의 $\Delta k$ 최소 간격은 JONSWAP 피크 폭 $\sim 0.2$-$0.3$ rad/m. 이보다 크면 인접 교차파도 억제해 버림
  • 0.15 rad/m: coarse 격자 $\Delta k = 0.10$의 1.5배 — sidelobe (±1-2 셀)을 충분히 제거하면서 교차해 분리 유지
경험적 근거: BF3 2-comp 교차해(두 파도의 $\Delta k \approx 0.3$ rad/m)에서 두 피크를 정확히 분리하면서, BF4 단일 파도의 sidelobe를 완전히 억제. 0.10은 sidelobe 잔류, 0.20은 교차파 탈락.

선형 최소제곱 — 진폭과 위상 초기화

$k_x, k_y$가 정해지면 $\cos(k_x x + k_y y - \omega t)$은 '알려진 기저'가 된다:

삼각함수 전개 → 선형 문제
$$z_j = \sum_i \left[a_i \cos(k_{x,i} x_j + k_{y,i} y_j - \omega_i t_j) + b_i \sin(\ldots)\right]$$ $$\text{행렬 형태: } \mathbf{z} = A\,\mathbf{c} \qquad\Rightarrow\qquad \mathbf{c} = (A^\top A)^{-1} A^\top \mathbf{z}$$

$a_i, b_i$에서 진폭과 위상을 복원:

$$w_i = \sqrt{a_i^2 + b_i^2}, \qquad \varphi_i = \arctan(-b_i / a_i)$$
결과: $N$개 성분의 초기 파라미터 $(w_i, k_{x,i}, k_{y,i}, \varphi_i)$ 확보. $k_x, k_y$는 빔포밍 해상도 범위 내에서 대략적이고, $w, \varphi$도 이에 영향받는다. → 충분히 좋은 출발점이지만 정밀하지 않음 → 비선형 최적화로 미세 조정 필요.

PART 7WaveSplat — 비선형 최적화

왜 초기화만으로 부족한가

Fine refinement 후에도 $|\mathbf{k}|$의 정확도는 격자 $\Delta k_f = 0.01$ rad/m 수준 (실제 SNR 따라 $0.005\sim0.01$ rad/m). $|\mathbf{k}| \approx 0.3$ rad/m에서:

  • $|\mathbf{k}|$ 오차 ~3% → 주기 오차 ~1.5%
  • 30초 후 위상 오차 ~$16°$ → 추적 시 성능 저하

격자 기반이라 본질적으로 이산화 오차가 남고, 이 '작은' 초기 오차가 시간이 지나면 누적된다 → $k_x, k_y$를 연속값으로 미세 조정(비선형 최적화)해야 한다.

Loss 함수

WaveSplat Loss 함수 (3개 항)
$$\mathcal{L} = \underbrace{\frac{1}{M}\sum_j c_j\big(z_j - \hat{z}_j\big)^2}_{\text{데이터 항}} + \underbrace{\lambda_1 \sum_i |w_i|}_{\text{L1 희소성}} + \underbrace{\lambda_s \sum_i (\Delta w_i)^2}_{\text{스펙트럼 평활화}}$$

$\hat{z}_j = \sum_i w_i \cos(k_{x,i} x_j + k_{y,i} y_j - \omega_i t_j + \varphi_i)$,   $\lambda_1 = 10^{-3}$, $\lambda_s = 10^{-4}$

데이터 항: 관측과 예측의 차이

가중 평균제곱오차. 가중치 $c_j$는 Fresnel confidence로, 관측의 신뢰도를 반영한다.

Fresnel Confidence $c_j$

$$c_j = \frac{\cos\theta_j}{d_j / d_{\text{ref}}}$$
  • $\theta_j$ = ray와 수면 법선 $\mathbf{n}$ 사이 각도 (incidence angle). $\theta_j = 0°$이면 ray가 수면에 수직하게 꽂힘 → 신뢰도 높음
  • $d_j$ = 관측 거리. 가까울수록 점 밀도 높고 노이즈 적음 → 신뢰도 높음
  • $d_{\text{ref}} = 125$m (최대 사거리의 절반)
주의 — 법선 $\mathbf{n}$을 알아야 하는 문제:
$\theta_j$는 ray와 법선 사이 각도인데, 실제 파도면의 법선은 파의 형상에 의존 (파봉은 수평, 파배 경사면은 기울어짐). WaveSim(시뮬레이션)은 Gerstner 메시에서 정확한 법선 $\mathbf{n}_{\text{true}}$를 계산하지만, 실측 LiDAR에서는 파도면을 모르므로 "수면 = 수평(flat)" 가정으로 $\mathbf{n} \approx \hat{\mathbf{z}}$로 근사한다.

오차의 실질적 영향:

  • $\theta \approx 10°$ 관측: $\cos(10°) \approx 0.985$ vs $\cos(13°) \approx 0.974$ → ~1% 차이 (무시 가능)
  • $\theta \approx 60°$ 관측(원거리/grazing): $\cos(60°) = 0.500$ vs $\cos(63°) = 0.454$ → ~9% 차이 (의미 있음)

물리적 근거 & 정직한 한계: Fresnel 반사 법칙에서 영감을 받았지만, $c_j = \cos\theta/(d/d_{\text{ref}})$는 엄밀한 Fresnel 공식이 아니라 경험적 heteroscedastic 가중치 — (1) Lambertian 투영 면적 $\cos\theta$, (2) range noise의 거리 증가. 실측에서는 "flat-surface assumption"이 내포되어 있음을 논문에서 명시해야 한다.

스펙트럼 평활화

$\lambda_s \sum (\Delta w_i)^2$: 인접 주파수 성분의 진폭이 급변하는 것을 방지. 데이터 항 대비 0.1% 수준으로 약하게 작용.

Gradient 계산 — Chain Rule 전개

설정: 주요 기호

$$\Psi_{ij} \equiv k_{x,i}\,x_j + k_{y,i}\,y_j - \omega_i\,t_j + \varphi_i$$ $$\hat{z}_j = \sum_{i=1}^{N} w_i \cos(\Psi_{ij}), \qquad r_j \equiv z_j - \hat{z}_j \;\;\text{(잔차)}$$ $$\omega_i = \sqrt{g\,|\mathbf{k}_i|\tanh(|\mathbf{k}_i|\,d)}, \qquad |\mathbf{k}_i| = \sqrt{k_{x,i}^2 + k_{y,i}^2}$$

Step 1: 전체 Loss의 출발 형태

$$\mathcal{L} = \underbrace{\frac{1}{M}\sum_j c_j\,r_j^{2}}_{\mathcal{L}_{\text{data}}} + \underbrace{\lambda_1\sum_i |w_i|}_{\mathcal{L}_{\text{L1}}} + \underbrace{\lambda_s\sum_i (\Delta w_i)^2}_{\mathcal{L}_{\text{smooth}}}$$

Step 2: 진폭 $w_i$에 대한 미분

$\hat{z}_j$는 $w_i$에 대해 선형이므로 단순함:

체인: $\mathcal{L} \to r_j \to \hat{z}_j \to w_i$
$$\frac{\partial \hat{z}_j}{\partial w_i} = \cos(\Psi_{ij}), \qquad \frac{\partial r_j}{\partial w_i} = -\cos(\Psi_{ij})$$ $$\frac{\partial \mathcal{L}_{\text{data}}}{\partial w_i} = \frac{1}{M}\sum_j c_j \cdot 2 r_j \cdot \frac{\partial r_j}{\partial w_i} = -\frac{2}{M}\sum_j c_j\,r_j\cos(\Psi_{ij})$$ $$\frac{\partial \mathcal{L}_{\text{L1}}}{\partial w_i} = \lambda_1\operatorname{sign}(w_i), \qquad \frac{\partial \mathcal{L}_{\text{smooth}}}{\partial w_i} = 2\lambda_s\,(2w_i - w_{i-1} - w_{i+1})$$ $$\boxed{\;\frac{\partial\mathcal{L}}{\partial w_i} = -\frac{2}{M}\sum_j c_j\,r_j\cos(\Psi_{ij}) + \lambda_1\operatorname{sign}(w_i) + 2\lambda_s(2w_i - w_{i-1} - w_{i+1})\;}$$

Step 3: 위상 $\varphi_i$에 대한 미분

$\Psi_{ij}$에만 영향 — $\partial\Psi_{ij}/\partial\varphi_i = 1$:

체인: $\mathcal{L} \to r_j \to \hat{z}_j \to \Psi_{ij} \to \varphi_i$
$$\frac{\partial \hat{z}_j}{\partial \varphi_i} = -w_i\sin(\Psi_{ij}), \qquad \frac{\partial r_j}{\partial \varphi_i} = w_i\sin(\Psi_{ij})$$ $$\boxed{\;\frac{\partial\mathcal{L}}{\partial \varphi_i} = \frac{2}{M}\sum_j c_j\,r_j\,w_i\sin(\Psi_{ij})\;}$$

Step 4: 파수 $k_{x,i}$에 대한 미분 (분산관계 chain rule)

$k_{x,i}$는 두 경로로 $\Psi_{ij}$에 영향:

  • 직접 경로: $k_{x,i} x_j$ 항 → $\partial\Psi/\partial k_{x,i}\supseteq x_j$
  • 간접 경로: $\omega_i(\mathbf{k})$가 $|\mathbf{k}_i|$를 통해 $k_{x,i}$에 의존 → $-t_j\,\partial\omega_i/\partial k_{x,i}$
4-1. $\omega$를 $|\mathbf{k}|$로 미분 (분산관계 그 자체)
$$\omega^2 = g|\mathbf{k}|\tanh(|\mathbf{k}|d) \;\;\Rightarrow\;\; 2\omega\,\frac{\partial\omega}{\partial|\mathbf{k}|} = g\tanh(|\mathbf{k}|d) + g|\mathbf{k}|d\operatorname{sech}^2(|\mathbf{k}|d)$$ $$\frac{\partial\omega}{\partial|\mathbf{k}|} = \frac{g}{2\omega}\left[\tanh(|\mathbf{k}|d) + |\mathbf{k}|d\operatorname{sech}^2(|\mathbf{k}|d)\right] \;\;=\;\; v_g \;\;\text{(군속도)}$$
4-2. $|\mathbf{k}|$를 $k_{x,i}$로 미분
$$|\mathbf{k}_i| = \sqrt{k_{x,i}^2 + k_{y,i}^2} \;\;\Rightarrow\;\; \frac{\partial |\mathbf{k}_i|}{\partial k_{x,i}} = \frac{k_{x,i}}{|\mathbf{k}_i|}$$
4-3. 체인 결합: $\omega$를 $k_{x,i}$로
$$\frac{\partial \omega_i}{\partial k_{x,i}} = \frac{\partial\omega}{\partial|\mathbf{k}|}\cdot\frac{\partial |\mathbf{k}_i|}{\partial k_{x,i}} = v_g \cdot \frac{k_{x,i}}{|\mathbf{k}_i|}$$
4-4. $\Psi_{ij}$를 $k_{x,i}$로 — 두 경로 결합
$$\frac{\partial \Psi_{ij}}{\partial k_{x,i}} = \underbrace{x_j}_{\text{직접 경로}} \;-\; \underbrace{t_j\,\frac{\partial\omega_i}{\partial k_{x,i}}}_{\text{분산관계 경로}} = x_j - t_j\,v_g\,\frac{k_{x,i}}{|\mathbf{k}_i|}$$
4-5. 최종: $\mathcal{L}$을 $k_{x,i}$로
$$\frac{\partial \hat{z}_j}{\partial k_{x,i}} = -w_i\sin(\Psi_{ij})\cdot\frac{\partial \Psi_{ij}}{\partial k_{x,i}}$$ $$\boxed{\;\frac{\partial\mathcal{L}}{\partial k_{x,i}} = \frac{2}{M}\sum_j c_j\,r_j\,w_i\sin(\Psi_{ij}) \left(x_j - t_j\,v_g\,\frac{k_{x,i}}{|\mathbf{k}_i|}\right)\;}$$

Step 5: $k_{y,i}$에 대한 미분 (대칭)

$$\boxed{\;\frac{\partial\mathcal{L}}{\partial k_{y,i}} = \frac{2}{M}\sum_j c_j\,r_j\,w_i\sin(\Psi_{ij}) \left(y_j - t_j\,v_g\,\frac{k_{y,i}}{|\mathbf{k}_i|}\right)\;}$$
물리적 해석: $k_x$의 gradient는 공간 항($x_j$)과 시간-분산 항($t_j v_g k_x/|k|$)의 경쟁이다. 단일 프레임(작은 $t_j$)에서는 공간 항이 지배적이지만, 여러 프레임을 누적하면 시간 항이 커져 분산관계를 따르지 않는 $k$를 강하게 거부한다. → 슬라이딩 윈도우($K_w = 3$)가 $k$ 정밀도를 올리는 이유.
핵심: 모든 gradient가 해석적(analytic)으로 계산됨. $\cos/\sin$의 미분은 $\sin/\cos$, 분산관계의 미분은 군속도 $v_g$. — 정확한 gradient, 수치 미분 불필요. PyTorch autograd가 이 체인을 자동으로 구성.

A1 Ablation: ω를 자유 파라미터로 두면? — 분산관계 hard constraint의 필요성

Part 1에서 예고한 핵심 설계 검증. $\omega$를 $\omega(\mathbf{k}, d)$로 제약하지 않고 5번째 자유 파라미터로 두면:

off-shell 비율$\omega \neq \omega(k,d)$ 성분 다수0% (물리 제약)

왜 over-fitting이 발생하는가?

  1. 추가 자유도: 각 성분에 $\omega_i$가 자유 → $5N$개 파라미터. $N=15$이면 75개 vs 60개
  2. Off-shell 해: 물리적으로 불가능한 $(k, \omega)$ 조합이 허용됨. 예: $|\mathbf{k}|=0.3$ rad/m인데 $\omega = 3.0$ rad/s (분산관계로는 $\omega \approx 1.7$)
  3. 노이즈 fitting: Off-shell $\omega$는 "원래 파도가 아닌 관측 노이즈 패턴"에 맞춰짐. 훈련 loss는 낮지만 검증 시 일반화 실패
  4. Bound harmonics 혼동: BF4에서 bound harmonics (2차 성분)은 에너지의 <0.15%뿐. A1의 높은 $\bar{R}$은 이를 잡은 것이 아니라 노이즈를 fit한 결과
핵심 논리

$\omega$를 자유롭게 두면 → optimizer가 분산관계 곡선 밖의 해를 찾음
→ train loss는 낮지만 시간 외삽 실패 ($\varphi += \omega_{\text{wrong}} \Delta t$ → 위상 drift)
→ VR=0.51 (under-energized, 노이즈에 에너지 분배) vs VR=0.661 (적절)

결론: 분산관계 hard constraint는 단순한 파라미터 감소(5N→4N)가 아니라, 물리적으로 유효한 해 공간만 탐색하게 하는 정규화(regularization)이다. 이것이 WaveSplat의 C1 novelty (Contribution 1)의 실험적 근거.

경사하강법(SGD)에서 Adam까지

Step 1: SGD (Stochastic Gradient Descent)

$$\theta_{\text{new}} = \theta - \eta \cdot \nabla\mathcal{L}$$

$\eta$ = 학습률. 너무 크면 진동/발산, 너무 작으면 느림. 문제: 모든 파라미터에 같은 학습률 — $k_x$(민감)와 $w$(둔감)가 같은 속도로 업데이트됨.

Step 2: Momentum

$$v_{\text{new}} = \beta \cdot v_{\text{old}} + \nabla\mathcal{L} \qquad \theta_{\text{new}} = \theta - \eta \cdot v_{\text{new}}$$

$\beta = 0.9$ — 이전 방향의 90% 유지. 일관된 gradient 방향은 가속, 진동 방향은 상쇄. 하지만 여전히 모든 파라미터에 같은 학습률.

Step 3: Adam Optimizer — 파라미터별 독립 적응 학습률

중요 — element-wise 연산: 아래의 $g, m, v$는 스칼라가 아니라 벡터이며, 모든 제곱·제곱근·나눗셈은 파라미터별 element-wise 연산이다. 즉 각 파라미터 $\theta_i$는 자신만의 $m_i, v_i$를 가지고, 자신만의 실효 학습률을 받는다.
Adam — 파라미터별 수식 ($i$ = 파라미터 인덱스)
$$g_i = \frac{\partial \mathcal{L}}{\partial \theta_i}$$ $$m_i \leftarrow \beta_1\,m_i + (1-\beta_1)\,g_i \qquad\text{(1차 모멘트: 방향)}$$ $$v_i \leftarrow \beta_2\,v_i + (1-\beta_2)\,g_i^{\,2} \qquad\text{(2차 모멘트: 크기, }g_i\text{ 제곱)}$$ $$\hat{m}_i = \frac{m_i}{1-\beta_1^t}, \qquad \hat{v}_i = \frac{v_i}{1-\beta_2^t}$$ $$\theta_i \leftarrow \theta_i \;-\; \eta \cdot \frac{\hat{m}_i}{\sqrt{\hat{v}_i} + \epsilon}$$

WaveSplat 파라미터 벡터 — $\theta \in \mathbb{R}^{4N}$

$N=15$일 때 60개 파라미터, 각각에 독립된 $m_i, v_i$:

$$\theta = \underbrace{[w_1, \ldots, w_N]}_{N\text{개}} \;\cup\; \underbrace{[k_{x,1}, \ldots, k_{x,N}]}_{N\text{개}} \;\cup\; \underbrace{[k_{y,1}, \ldots, k_{y,N}]}_{N\text{개}} \;\cup\; \underbrace{[\varphi_1, \ldots, \varphi_N]}_{N\text{개}}$$

파라미터별 전형적인 gradient/모멘트 크기 (BF4, step 50, 수렴 중)

파라미터$g_i$ (gradient)$v_i$ (2차 모멘트)$\sqrt{v_i}$실효 학습률 $\eta/\sqrt{v_i}$
$w_i$ (진폭)$\sim 10^{-2}$$\sim 5\!\times\!10^{-5}$$\sim 0.007$크다 → 과감
$k_{x,i}$ (파수)$\sim 5\!\times\!10^{-1}$$\sim 0.25$$\sim 0.5$작다 → 신중
$\varphi_i$ (위상)$\sim 3\!\times\!10^{-2}$$\sim 10^{-3}$$\sim 0.03$중간

$\eta = 5\times 10^{-3}$은 공통이고, $1/\sqrt{v_i}$가 파라미터별 스케일 조정자 역할. 결과적으로:

$$\Delta w_i = \eta / \sqrt{v_i^w} \sim 0.71, \qquad \Delta k_{x,i} = \eta / \sqrt{v_i^k} \sim 0.01, \qquad \Delta \varphi_i = \eta / \sqrt{v_i^\varphi} \sim 0.17$$

각 파라미터가 자신의 gradient 크기에 맞춰 자동 스케일되어 비슷한 상대 변화량으로 업데이트됨.

WaveSplat에서 Adam의 효과:
$k_x$ (gradient 변동 큼, 민감) → $v_{k_x}$ 큼 → 학습률 자동 감소 → 신중하게 업데이트
$w$ (gradient 변동 작음, 둔감) → $v_w$ 작음 → 학습률 자동 증가 → 과감하게 업데이트
→ 각 파라미터의 특성에 맞는 최적 속도로 수렴 (SGD는 모두 같은 $\eta$를 써서 $k_x$ 발산 또는 $w$ 정체)

왜 정확히 Adam인가 — SGD/Momentum이 부족한 이유

이유 1: WaveSplat의 gradient 스케일이 파라미터별로 4자릿수 차이

파라미터전형적 gradient 크기왜?
$w_i$ (진폭, $\sim$1m)$\sim 10^{-2}$$\hat z$가 $w$에 선형 → gradient $\sim \cos(\Psi) \sim O(1)$ × residual $\sim 10^{-2}$
$\varphi_i$ (위상, rad)$\sim 10^{-2}$$\hat z$가 $\varphi$에 sin 종속 → gradient $\sim w\sin\Psi \sim 0.5 \cdot 1 \cdot 10^{-2}$
$k_{x,i}$ (파수, rad/m)$\sim 10^{-1}$$\partial\Psi/\partial k_x \supseteq x_j \in [10, 250]$m → 위치 크기만큼 증폭

SGD/Momentum은 같은 $\eta$를 모두에 적용하므로 가장 큰 gradient($k_x$)에 맞춰 $\eta$를 잡으면 작은 gradient($w$)는 100$\times$ 느림. 자동 스케일링 없는 optimizer는 수동 파라미터별 lr 튜닝이 필요한데, 60개 파라미터에는 비현실적.

이유 2: C2F 단계 전환에서 gradient 분포가 급변

$N=3 \to 8 \to 15$ 전환 시:

  • 새 추가된 5~7개 성분의 $w$가 $\sim 0.01$로 초기화됨 → 초반 gradient가 큼 (data-fit 갈증)
  • 기존 성분의 $k_x, k_y$는 이미 거의 수렴 → gradient 작음
  • 같은 $\eta$로는 신/구 성분이 다른 속도로 학습되어야 함 → Adam의 자동 스케일링이 자연스럽게 처리

이유 3: 진동하는 gradient 안전 처리

$k_x$의 gradient는 sin/cos 의존성 때문에 step 간 부호가 자주 바뀜:

  • SGD: 매 step 진동 따라감 → 진동 폭만큼 손실 발생
  • Momentum: 진동 일부 상쇄($v$의 부호 평균)되지만, 진동 진폭이 큰 파라미터는 여전히 큰 step
  • Adam: 진동의 제곱(부호 무관)을 $v$에 누적 → 진동 진폭 = $\sqrt{v}$ → 진동 큰 파라미터는 자동 신중

이유 4: 600 iter로 수렴해야 하는 시간 제약

C2F 총 600 iter (init phase). SGD는 60개 파라미터에 수동 튜닝된 lr이 필요해 hyperparameter 탐색에 추가 1000$\times$ 실행. Adam은 default lr ($5\!\times\!10^{-3}$)로 거의 항상 작동 → 실험 반복 횟수 절감.

대안 검토 (그리고 기각된 이유):
RMSprop ($\hat{m}$ 없음, $\sqrt{v}$만): WaveSplat의 안정 방향 누적 효과를 잃음 → $w$ 수렴 느림.
AdaGrad ($v$ 평균 없이 무한 누적): step 수가 늘면 학습률이 0으로 수렴 → tracking phase에서 적응 못함.
L-BFGS (2차 quasi-Newton): Hessian 근사 메모리 비용 ($4N \times 4N \cdot k_{\text{history}}$), $k_x$ landscape의 비볼록성에서 collapse 위험.
최종 정당화: Adam = "이동평균 momentum" + "이동평균 분산 정규화" + "bias 보정" 셋의 결합. WaveSplat의 (a) 큰 파라미터별 스케일 차이, (b) 단계 전환의 gradient 분포 변화, (c) $k$ 진동 모두를 단일 hyperparameter set으로 처리할 수 있는 유일한 표준 optimizer. C2F 600 iter, tracking 10 iter 양쪽에서 같은 설정으로 작동.

PART 8Coarse-to-Fine + Adaptive N

Coarse-to-Fine 전략

N=3 (200 iter) → N=8 (200 iter) → N=15 (200 iter) → Adaptive N

각 단계의 수렴된 파라미터가 다음 단계의 초기값이 된다. 총 600 iterations, lr = $5\times10^{-3}$.

왜 단계적으로 해야 하는가?

  • $N=3$: 12개 파라미터 → landscape가 비교적 매끄러움 → global minimum 수렴 쉬움
  • $N=15$: 60개 파라미터 → local minima가 매우 많음 (성분 간 간섭)
그림 그리기: 밑그림(큰 구도) → 중간 톤 → 세부 묘사.
한 번에 세부부터 그리면 전체 구도가 어긋난다.

적응형 모델 차수 (Adaptive N)

Step 1: 에너지 기반 가지치기 (Pruning)

  1. 에너지 계산: $E_i = w_i^2$
  2. 에너지 내림차순 정렬
  3. 상위 90% 에너지를 커버하는 최소 $N'$개 선택 ($\tau_E = 0.90$)
  4. 나머지 제거
예시: 5성분의 에너지 $[0.50, 0.30, 0.10, 0.05, 0.05]$
누적: $[0.50, 0.80, \mathbf{0.90}, 0.95, 1.00]$ → $N'=3$으로 가지치기 (90% 도달)

Step 2: 안전 롤백 (Safety Rollback)

가지치기 후 RMSE가 130% 초과하면 원복한다 ($\tau_S = 1.30$). 중요 성분을 실수로 잘라내는 것을 방지 — 특히 교차해에서 에너지가 비슷한 성분이 많을 때.

Step 3: 잔차 기반 성장 (Residual Growth)

  1. 잔차 $r_j = z_j - \hat{z}_j$ 계산
  2. $\text{RMS}(r) > \tau_R = 0.05$m이면: 잔차에 빔포밍 다시 적용 → 놓친 성분 발견 → 추가

Gerstner vs Linear Model Mismatch

WaveSplat에서 시뮬레이터(GT)는 Gerstner wave, 추정 모델은 linear sinusoidal:

Gerstner wave (시뮬레이터 GT)
$$x(u,v,t) = u - \sum_i Q_i A_i \frac{k_{x,i}}{|\mathbf{k}_i|}\sin(\Psi_i)$$ $$y(u,v,t) = v - \sum_i Q_i A_i \frac{k_{y,i}}{|\mathbf{k}_i|}\sin(\Psi_i)$$ $$z(u,v,t) = \sum_i A_i \cos(\Psi_i)$$

$(u,v)$는 라그랑지안 파라미터(static grid), 실제 관측 $(x,y)$는 $(u,v)$에서 수평 변위된 위치. 파봉은 수평으로 뾰족, 파배는 넓음 (비대칭).

Linear sinusoidal (추정 모델)
$$z(x,y,t) = \sum_i A_i \cos(k_{x,i} x + k_{y,i} y - \omega_i t + \varphi_i)$$

수평 변위 없음 — $(x,y)$가 직접 위상 인수에 들어감. 파봉/파배 대칭.

불일치의 크기: Gerstner의 horizontal displacement는 $O(\epsilon) = O(kA)$. Z-값 차이는 이 수평 변위가 유발하는 위상 편이로 $O(\epsilon^2)$. BF4에서 $\epsilon \approx 0.05$이므로:

$$\Delta z_{\text{model}} \sim H_s \cdot \epsilon^2 / 2 \approx 1.2 \cdot 0.0025 / 2 \approx 1.5 \text{ mm} \text{ ~ } 6 \text{ mm}$$

이 값이 LiDAR noise($\sim 2$cm)보다 작으므로, linear 추정 모델로 충분히 정확한 복원 가능. 논문에서 이 mismatch는 "의도된 design choice"로 기술:

왜 일부러 linear로 추정하는가:
  (1) Gerstner는 $z(x,y,t)$를 $(u,v,t)$의 함수로 역변환해야 해서 해석적 gradient 계산이 복잡
  (2) 오차 $O(\epsilon^2)$가 BF3~4에서 노이즈 이하 → 비용 대비 이득 없음
  (3) "Linear estimator가 weakly nonlinear GT에 robust" → 논문 Discussion에서 강점으로 활용
  (4) $\tau_R = 0.05$m 설정 시 이 mismatch가 임계 아래에 있도록 설계됨

  • BF5 실험에서도 WaveSplat은 nRMSE ≈ 0.29로 동작하지만, 고차 Stokes 효과가 잔차에 포함됨

  • 향후: 2차 Stokes 보정 또는 weakly nonlinear 확장이 필요할 수 있음

$\tau_R$ 초과 = 왜 "빔포밍 실패" 신호인가

초기화에서 모든 성분이 정확히 잡혔다면 잔차 RMS는 $\sim 0.022$m (노이즈 + 모델 하한) 근처. $\tau_R = 0.05$m 초과는:

  • 원인 1: 격자 $\Delta k_c = 0.10$ rad/m 사이에 있는 성분이 주변 피크에 묻힘 → fine refinement까지 도달 못함
  • 원인 2: 고주파 성분 ($|\mathbf{k}| \geq 0.4$ rad/m)의 빔포밍 파워가 낮음. 이유:
    • aperture $L \sim 240$m 대비 파장 $\lambda = 2\pi/|\mathbf{k}| \leq 16$m → 관측 범위에 많은 주기 포함
    • 분산관계로 $\omega$가 크면 $t$에 따른 위상 진화 빠름 → 시간 aperture 정렬 어려움
    • sparse LiDAR 포인트로 고주파 신호는 spatial Nyquist 근처 (undersampled)
  • 원인 3: 사이드로브 억제 0.15 rad/m 반경 안에 두 성분 공존 → 약한 쪽 탈락

잔차에 빔포밍 재적용하면 이 놓친 성분이 잔차 신호의 최대 피크로 드러남 → 추가. 경험적으로 BF5 30-comp에서 $N=15 \to 21$로 성장, 6.4% 추가 nRMSE 개선.

Grown component는 C2F를 거치지 않는다:
초기화(Phase 1)에서 성장된 새 성분은 잔차 빔포밍 + 선형 최소제곱으로 $(k_x, k_y, w, \varphi)$가 결정되고, 이후 바로 현재 모델에 합류한다. $N=3 \to 8 \to 15$의 C2F 스케줄을 다시 실행하지 않는다.
  • 이유: 잔차 빔포밍은 이미 기존 성분이 설명하지 못한 "순수 잔차 신호"에서 피크를 찾으므로 기존 성분과의 간섭이 적음
  • trade-off: 초기화 품질이 C2F 거친 성분보다 약간 낮을 수 있지만, 계산 효율성(재C2F 시 추가 ~500ms)을 우선시
  • 실험 결과: grown component의 $k$ 정밀도는 fine refinement(Δk=0.01)로 충분하며, 추적 시 $w, \varphi$만 업데이트하므로 $k$ 오차의 영향 제한적

위상 전파 (Predict Step)

$$\varphi_i(t+\Delta t) = \varphi_i(t) + \omega_i \cdot \Delta t$$

$\Delta t = 0.1$s (10Hz), $\omega_i$는 분산관계에서 결정 — 분산관계가 '예측기' 역할

이 예측이 정확한 이유: 분산관계가 정확히 성립하면 위상 예측이 완벽하다. 실제 편차(비선형 효과, 모델 오차)는 매우 작으므로 Update에서 소량의 보정만으로 충분하다.

속도 비교:
ETKF predict: $N_e$개 앙상블 각각 FFT로 전파 → $O(N_e \cdot G \log G)$ = 느림
WaveSplat predict: $N$개 위상에 덧셈 → $O(N)$ = 즉시

w_phi 모드 — 왜 $k_x, k_y$를 고정하는가

추적 시 $w$(진폭)와 $\varphi$(위상)만 업데이트하고, $k_x, k_y$는 초기화에서 확정 후 고정한다.

Phase별 Adam optimizer 구성

같은 Adam 알고리즘이지만 각 단계에서 optimize 대상 파라미터와 hyperparameter가 다르다:

Phase 1 (초기화) — C2F: 모든 파라미터 Adam
$$\theta^{\text{init}} = \{w_i, k_{x,i}, k_{y,i}, \varphi_i\}_{i=1}^{N} \in \mathbb{R}^{4N}$$ $$\text{Adam}(\theta^{\text{init}}, \eta_{\text{init}} = 5\!\times\!10^{-3}, \beta_1=0.9, \beta_2=0.999)$$

$N=3 \to 8 \to 15$로 증가하며 각 단계 200 iter → 총 600 iter. 각 파라미터에 독립된 $(m_i, v_i)$.

Phase 2 (추적) — w_phi: $w, \varphi$만 Adam
$$\theta^{\text{track}} = \{w_i, \varphi_i\}_{i=1}^{N} \in \mathbb{R}^{2N}$$ $$\theta^{\text{frozen}} = \{k_{x,i}, k_{y,i}\}_{i=1}^{N} \;\;\text{(requires\_grad = False)}$$ $$\text{Adam}(\theta^{\text{track}}, \eta_{\text{track}} = 5\!\times\!10^{-3}, \beta_1=0.9, \beta_2=0.999)$$

매 프레임 10 Adam steps, 3-frame window의 loss에 대해 실행.
$k_x, k_y$는 initializer의 optimizer에서 제외 → backward 시에도 gradient 계산 안 함 (PyTorch freeze).

슬라이딩 윈도우

현재 프레임 + 이전 2프레임 = 3프레임 윈도우 ($K_w = 3$):

  • 단일 프레임: 50~200점 → 노이즈에 취약
  • 3프레임: 150~600점 → 노이즈 평균화

결론: 주파수 영역 Splatting이 필요한 이유

희소 LiDAR → 파도장 복원 문제의 4가지 요구사항:
  1. 관측이 극도로 희소 → 강력한 사전 지식 필요 → 주파수 영역: 분산관계 직접 내장
  2. 관측이 불규칙 → 격자 없는 표현 필요 → Splatting: 격자 없는 파라메트릭 표현
  3. 실시간 필요 → 적은 파라미터 + 빠른 추적 → 4N개, 위상 전파로 즉시 예측
  4. 시간 예측 필요 → 시간이 모델에 내장 → $\cos(\ldots - \omega t + \varphi)$

이 4가지를 동시에 만족하는 방법은 WaveSplat이 유일하다.

각 지표의 정의와 계산법

$\hat z$ = 추정 파고장, $z$ = GT 파고장 (격자 $N_x \times N_y$). 모든 metric은 한 프레임의 격자 전체에 대해 계산.

① nRMSE — Normalized RMSE (전체적 오차)

$$\text{RMSE} = \sqrt{\frac{1}{G}\sum_{i,j}(\hat z_{ij} - z_{ij})^2}, \qquad \text{nRMSE} = \frac{\text{RMSE}}{H_s}$$

$G = N_x N_y$ 격자점 수. $H_s$ = GT 유의파고 (BF4: 1.2m). 무차원화로 sea state 간 비교 가능.

  • 의미: GT 대비 평균적 절대 오차를 파고로 정규화
  • $\downarrow$ 작을수록 좋음. WS 0.223 = 평균 0.27m 오차 (BF4 1.2m 대비 22%)
  • 함정: 거의 평평한 수면 예측도 nRMSE $\approx 0.25$ (zero predictor의 한계). 즉 nRMSE 0.25 근처는 "예측한 것과 안 한 것이 비슷"이라는 신호 → nRMSE만으로는 진짜 성능 판별 불가

② VR — Variance Ratio (에너지 재현도)

$$\text{VR} = \frac{\text{Var}(\hat z)}{\text{Var}(z)} = \frac{\sigma^2_{\hat z}}{\sigma^2_z}$$

분산 비율. 파도 에너지 $\propto \sigma^2$이므로 "추정한 에너지 / 실제 에너지".

VR 값해석
VR $\approx 1$에너지 정확 재현 (이상적)
VR $\ll 1$Over-smoothing — "거의 평면" 예측 (GPR 전형)
VR $> 1.2$Over-fitting — 노이즈까지 추적

가장 중요한 진단적 지표. nRMSE 단독으로는 "맞춰서 낮은가" vs "예측 안 해서 낮은가" 구분 불가 → VR이 답을 줌. GPR의 VR=0.065는 "에너지의 6.5%만 재현" = 거의 평평하게 그림 = 진정한 추정이 아님.

③ ρ — Pearson Correlation (형상 일치도)

$$\rho = \frac{\sum_{i,j}(\hat z_{ij} - \bar{\hat z})(z_{ij} - \bar z)} {\sqrt{\sum_{i,j}(\hat z_{ij} - \bar{\hat z})^2 \cdot \sum_{i,j}(z_{ij} - \bar z)^2}}$$

공간 격자에 대한 Pearson 상관계수. 진폭과 무관하게 "모양"이 얼마나 닮았는지.

$\rho$nRMSE해석
$\rho \to 1$, nRMSE 작음—정확 추정 ✓
$\rho \to 1$, nRMSE 큼—모양 맞지만 진폭 틀림
$\rho \to 0$, nRMSE 작음—under-fitting (평균값 예측)
$\rho \to 0$, nRMSE 큼—완전 실패

ETKF의 $\rho = 0.11$은 "에너지(VR=0.90)는 맞지만 파봉/파배 위치는 거의 랜덤". 즉 "1m 파도가 있다"는 알지만 "어디 있는지" 모름 — 실제 활용 불가.

④ SS — Skill Score (사소한 baseline 대비)

$$\text{SS} = 1 - \frac{\text{MSE}(\hat z)}{\text{MSE}(\text{ref})} = 1 - \frac{\sum (\hat z - z)^2}{\sum (\text{ref} - z)^2}$$

Reference = zero predictor ($\text{ref} = 0$). Zero-mean wave field에서 MSE(ref) = Var($z$).

SS해석
SS $= 1$완벽한 예측
SS $> 0$아무것도 예측 안 한 것보다 나음 (실제 추정 가치 있음)
SS $= 0$zero predictor와 동등
SS $< 0$예측이 해롭다 — 평면을 예측한 것보다 못함
논문의 핵심 차별 지표. WaveSplat SS = +0.034 > 0으로 marginal positive — "겨우지만 zero predictor를 이기는 유일한 방법". ETKF($-0.702$)와 GPR($-0.140$)은 음수 — 아무것도 예측 안 한 것보다 못함. 이 사실이 nRMSE만 보면 안 보이고 ($\sim 0.3$), SS로만 드러남.

⑤ Dir R² — Directional R² (방향 추정 정확도)

$$\hat S(\mathbf{k}) = |\mathcal{F}_2[\hat z]|^2, \quad S(\mathbf{k}) = |\mathcal{F}_2[z]|^2 \quad\text{(2D FFT 파워)}$$ $$\text{Dir } R^2 = 1 - \frac{\sum_\mathbf{k}(\hat S(\mathbf{k}) - S(\mathbf{k}))^2} {\sum_\mathbf{k}(S(\mathbf{k}) - \bar S)^2}$$

파고장의 2D 파수 스펙트럼을 비교. DC 성분 제외. 방향별 에너지 분포가 맞는지 측정.

  • $\uparrow$ 1에 가까울수록 방향 분포 정확 (1 = 완벽)
  • 음수 값 = GT 평균 분포보다도 못함 (분산이 잘못된 방향에 집중)
  • WaveSplat $-0.253$, ETKF $+0.065$, GPR $+0.028$. ETKF가 방향에서는 가장 우수 (격자 기반이므로 방향 해상도가 높음)
  • WaveSplat의 음수 Dir R²는 forward-looking LiDAR의 $\pm\theta$ 기하학적 모호성 때문 (§11 참조)

이 지표는 sparse + forward-looking 조건의 어려움을 그대로 반영. 흥미롭게도 Dir R²에서는 ETKF(+0.065)가 가장 우수한데, 격자 기반 표현이 방향 해상도에서 유리하기 때문. WaveSplat의 $-0.253$은 LiDAR FOV의 $\pm\theta$ 모호성 때문.

⑥ H_s err — 유의파고 상대 오차

$$H_s^{\text{pred}} = 4\,\sigma_{\hat z} = 4\,\sqrt{\text{Var}(\hat z)}, \qquad \text{H}_s\,\text{err} = \frac{|H_s^{\text{pred}} - H_s^{\text{true}}|}{H_s^{\text{true}}}$$

$H_s = 4\sigma$는 표준 oceanographic 정의. 추정 파고장의 $\sigma$로부터 거꾸로 계산.

  • $\downarrow$ 작을수록 좋음. WS 0.277, ETKF 0.258 (ETKF가 약간 우수), GPR 0.780
  • VR과 직접 연결: $H_s^{\text{pred}}/H_s^{\text{true}} = \sqrt{\text{VR}}$
  • 실선 운영에서 가장 자주 사용되는 단일 파라미터 (안전 운항 판단)

ETKF H_s err=0.258이 WS의 0.277보다 약간 좋은데, VR=0.898로 에너지 재현도가 높기 때문. 반면 GPR의 0.780은 VR=0.065 (거의 평면)의 직접적 결과. WaveSplat의 VR=0.661은 adaptive pruning이 보수적으로 저진폭 성분을 제거하기 때문.

지표 간 의존성 — 왜 6개가 모두 필요한가

각 지표는 단독으로는 함정에 빠지기 쉽지만, 6개를 함께 보면 명확한 진단:

nRMSE만 보면 위험한 이유: Zero predictor의 nRMSE = $\sigma_{\text{wave}}/H_s = 1/4 = 0.25$. 즉 어떤 방법이든 nRMSE 0.25 근처면 "맞춰서 낮은가, 안 예측해서 낮은가" 구분 불가. 이게 ETKF(0.319), GPR(0.261), WaveSplat(0.223)이 nRMSE만으로는 비슷해 보이지만 SS로 보면 WS만 양수($+0.034$), 다른 둘은 음수($-0.702, -0.140$)로 결정적으로 갈리는 이유.

원인: Forward-looking LiDAR의 기하학적 모호성

선박 전방 LiDAR는 ${\sim}120°$ FOV로 전방을 관측한다. 이 geometry에서 $k_x$ 부호 구분이 근본적으로 어렵다:

방향 모호성의 기하학적 근거

Forward LiDAR 관측 영역: 주로 $x > 0$ (선박 전방)
파도 A: $k_x > 0$ (선박을 향해 오는 파도) → 위상: $\Psi = k_x x - \omega t + \varphi_A$
파도 B: $k_x < 0$ (선박에서 멀어지는 파도) → 위상: $\Psi = -k_x x - \omega' t + \varphi_B$

단일 프레임($t$ 고정)에서 두 파도는 $x > 0$ 영역에서 동일한 공간 패턴을 만들 수 있다:
$\cos(k_x \cdot x + \text{const})$ vs $\cos(-k_x \cdot x + \text{const}')$ — 위상 차이만으로 구분해야 함

왜 시간 정보로도 해결되지 않는가?

  1. 시간 aperture 부족: 슬라이딩 윈도우 $K_w = 3$ (0.3초). BF4 $T_p \approx 7$s에서 0.3s는 위상 변화 $\Delta\varphi = \omega \cdot 0.3 \approx 0.27$ rad ($\sim$15°). $k_x$와 $-k_x$의 위상 변화 차이는 $2 v_g k_x / |k| \cdot 0.3$ → 매우 작음
  2. 다성분 간섭: BF4 15-30개 성분이 겹치면 개별 성분의 방향 신호가 다른 성분의 노이즈에 묻힘
  3. FOV 편향: $x > 0$에서만 관측 → 빔포밍이 $k_x > 0$을 선호하는 편향 발생 (음의 $k_x$는 관측 영역 밖의 정보 필요)
핵심 통찰: 방향 모호성은 관측 geometry의 근본적 한계이지, 알고리즘 결함이 아니다.
360° 관측(X-band radar 등)에서는 $k_x > 0$과 $k_x < 0$ 영역을 모두 관측하므로 모호성이 사라진다.
WaveSplat은 $|k|$ (파장)과 $|k_y/k_x|$ (방위각)은 정확히 추정하지만, $k_x$의 부호가 50/50에 가깝게 불확실하다.
정확하게 추정되는 것모호한 것
$|\mathbf{k}|$ (파장) → nRMSE에 직접 영향$\text{sign}(k_x)$ (방향 부호)
$w$ (진폭) → VR=0.661$k_x > 0$ vs $k_x < 0$ 구분
$\varphi$ (위상) → ρ=0.446교차해에서 두 파도의 상대 방향

향후 해결 방향:

  1. 다중 프레임 방향 추적: 시간에 따른 위상 변화율 $\dot{\varphi}$의 부호로 방향 추론 — $K_w$를 5-10으로 확대 시 가능성
  2. 3D FFT $(k_x, k_y, \omega)$ 초기화: 전체 시공간 스펙트럼에서 분산관계 곡선 위의 피크만 추출 → 방향 모호성 해소
  3. 방향 신뢰도 기반 feedforward 게이팅: Dir R²가 낮은 성분은 feedforward 제어에서 제외
  4. 수조 실험(Ch5): sim-to-real gap 검증 + 실제 LiDAR에서의 방향 추정 성능 확인
