1. 하이드로포일이 무엇이고 왜 능동 제어가 필요한가

1.1 하이드로포일 개념

일반 선박은 부력으로 떠있어 hull(선체)이 물에 잠긴 채 항행한다. 하이드로포일(hydrofoil)은 배 아래에 비행기 날개와 유사한 작은 foil을 두고, 일정 속도 이상으로 가속하면 foil의 양력(lift)이 부력을 대체하면서 선체가 수면 위로 떠오른다. 이 상태를 foilborne이라 부르고, 그 전 hull-borne(일반 항해) 모드와 구분한다.

Foilborne 의 장점:
• Hull 의 wave-making drag 가 사라져 동일 추력으로 2~3 배 빠르게 (속도 제곱으로 항력 ↓)
• 파도가 hull 까지 올라오지 않아 승차감이 비행기처럼 부드러움 — 단, foil 만 잘 제어된다면.

1.2 왜 능동 제어가 필수인가

Foil 의 lift 는 L = ½ρV²S·CL(α) 로, AoA(받음각)α에 거의 선형 비례한다. 파도가 foil 깊이에서 변화시키는 효과:

  • Wave slope ∂η/∂x: 파면이 기울어지면 foil 입장에서는 입사각이 변함 → AoA 직접 변동
  • Orbital vertical velocity ∂η/∂t: 파도의 수직 운동이 foil 에 추가 induced angle 부여
  • Submergence h(t): 파봉/파골에 따라 foil 깊이가 변함 → free-surface 효과로 lift 변화

이 모든 외란이 foil AoA 의 0.5~5° 진동을 일으키고, 이는 foil lift 의 ±20~30% 변화에 해당한다. 가만히 두면 selfbore(=foilborne 상실)·flap 한계 도달 등의 위험이 생기므로, foil 의 flap 으로 AoA 를 능동 보상해야 한다.

PD feedback 만으로 부족한 이유:
  • PD 는 "에러를 감지한 후" 보상 — 50~100 ms 의 control loop delay 가 있다.
  • 파도 주기가 4~7 s 일 때 100 ms 는 주기의 1.4~2.5% 로 보일 수 있지만, encounter frequency 에서 본 phase 지연은 8~22° 로 커진다 (V·k 항이 추가됨).
  • 이 phase 지연은 ride comfort 에 직접 악영향. → "에러를 미리 알고 보상" 하는 feedforward (FF)가 필요.

3. 2-DOF 동역학 — Heave + Pitch 방정식

3.1 Why 2-DOF (6-DOF 가 아니라)

강체 선박은 본래 6-DOF (surge·sway·heave·roll·pitch·yaw) 운동을 하지만, foilborne hydrofoil 의 ride control 에서는 다음 이유로 heave + pitch 만 모델링한다.

DOF제어 의미본 연구 처리
Heave (z)수직 진동 → ISO 2631 승차감 직접 영향✅ 모델링
Pitch (θ)foil AoA 변동 → lift 변화 → 다시 heave✅ 모델링
Roll (φ)좌우 흔들림❌ 별도 roll-foil 이 처리 (tandem 대칭으로 자연 안정)
Yaw (ψ)방위각❌ rudder 가 처리, ride 와 분리
Surge (x)전후 진동❌ 추진 시스템이 V 일정하게 유지
Sway (y)횡방향 drift❌ 1차 근사 무시
2-DOF 채택 근거:
  • 승차감 (ISO 2631) 의 핵심은 vertical acceleration — heave 가 직접 측정.
  • Pitch 는 foil AoA 를 modulate 해서 다시 heave 로 결합 → 둘은 강한 coupling, 분리 불가.
  • Roll 은 tandem 대칭 배치로 자연스럽게 자가 안정 (Faltinsen 2005, Ch.7) + 별도 roll-foil 가 담당.
  • 나머지 4-DOF 는 다른 actuator (rudder, propulsion) 가 담당하므로 ride control 과 분리됨.

3.2 운동 방정식

Newton-Euler 식을 vertical plane (x-z plane) 에서 작성:

(m + a_33) z_ddot   = L_f + L_r − m·g − B_z · z_dot          (heave)
(I_yy + a_55) θ_ddot = L_f · x_f + L_r · x_r − B_θ · θ_dot   (pitch)

각 항의 의미:

  • m + a33: 질량 + heave 방향 added mass. Foilborne 에서 hull 이 수면 위에 있으므로 a33 ≈ 0.05·m (보수적 추정). hull-borne 대비 매우 작음 → 응답이 빠름.
  • Iyy + a55: pitch moment of inertia + added inertia.
  • Lf, Lr: 전·후 foil lift (다음 절에서 자세히).
  • xf = +2.0, xr = −2.5: CG 기준 좌표. 전방 + lift 는 nose-up, 후방 + lift 는 nose-down 모멘트.
  • Bz = 50 N·s/m, Bθ = 20 N·m·s/rad: 구조적·기생 damping. foil lift slope (\(C_{L\alpha}\)) 가 이미 hydrodynamic damping 을 자연 제공하므로, 여기는 strut drag + 구조 dissipation 만 표시.
Damping 항이 작은 이유:
foilborne 에서 가장 큰 damping 은 hydrodynamic — 즉 z_dot 이 발생하면 foil 의 effective AoA 가 −z_dot/V 만큼 감소해서 lift 가 자동으로 줄어드는 효과 (다음 절 참조). 이 항은 lift 식 안에 이미 들어있으므로, Bz, Bθ 는 strut/스트럭처 drag 의 작은 잔여만 표현.

3.3 상태 벡터

4 차원 상태 벡터로 1 차 ODE 시스템 변환:

state = [z, θ, z_dot, θ_dot]ᵀ
state_dot = [z_dot, θ_dot, z_ddot, θ_ddot]ᵀ

4. Foil 유체역학 — Lift, Drag, Submergence, Ventilation

4.1 기본 lift/drag 식

L = ½·ρ·V² · S · C_L(α)
D = ½·ρ·V² · S · C_D(α)
where  C_L(α) = C_Lα · (α − α_zl),   clipped at ±C_L,max
       C_D    = C_D0 + C_L² / (π·AR·e)   ← drag polar
기호설명본 연구 값
ρ해수 밀도1025 kg/m³
Vflow 속도 (≈ vessel speed)11.3 m/s
S = b·cplanform 면적전방 0.36 m², 후방 0.18 m²
AR = b/caspect ratio전방 9, 후방 8
C_Lαlift slope (per rad)2π × 0.85 ≈ 5.34 (전방), 2π × 0.80 ≈ 5.03 (후방)
C_L,maxstall 한계1.2 (NACA 63-series 일반값)
C_D0zero-lift drag0.008 (전방), 0.010 (후방)
eOswald efficiency0.85
α_zlzero-lift AoA(trim 계산에서 결정 — 다음 절)
NACA 63-series 채택 이유:
• 1940s 이래 가장 잘 측정된 airfoil family (Abbott & von Doenhoff 1959)
• Lift slope 2π·k_AR (k_AR ≈ AR/(AR+2)) 의 finite-span 보정이 유효
• 적당한 두께/캠버로 cavitation 시작 점이 V > 15 m/s 부근 — 본 연구 11.3 m/s 에서 안전

4.2 Trim αzl 자동 결정

α = 0 (vessel level) 일 때 자동으로 lift = mg, moment balance = 0 이 되도록 design 단계에서 αzl 을 결정한다. 이는 controller 입장에서 "외란 없으면 flap = 0" 의 nominal point 를 만든다.

From force balance:    L_f + L_r = m·g
From moment balance:   L_f · x_f + L_r · x_r = 0

→ L_f = m·g · (−x_r) / (x_f − x_r) = m·g · 2.5 / 4.5 ≈ 0.556 m·g  ← 56% 분담
  L_r = m·g ·   x_f  / (x_f − x_r) = m·g · 2.0 / 4.5 ≈ 0.444 m·g  ← 44% 분담

각 foil 에서 required CL → required α → α_zl = −α_required (zero-lift offset 으로 흡수)
이 design step 의 의미: "foil 자체가 hull weight 를 안정적으로 지지하도록 설계되어 있고, controller 는 외란만 보상한다"는 separation of concerns. Controller bug 가 있어도 vessel 은 trim 상태에서 자연 안정.

4.3 Submergence Factor σ(h) — Free Surface Effect

Foil 이 수면 가까이 가면 lift 가 떨어진다. 이는 (a) free surface 가 foil 위 압력을 외기로 풀어버리고 (b) 너무 얕으면 air 가 foil 표면으로 빨려 들어와 (ventilation) 양력을 망친다.

σ(h) = 1.0           if h/c ≥ 2.0   (deep, no FSE)
       0.7 + 0.3·(h/c − 0.5)/1.5  if h/c ∈ [0.5, 2.0]   (gradual degradation)
       0.7 · (h/c)/0.5            if h/c ∈ [0.0, 0.5]   (ventilation risk zone)
       0.0                          if h ≤ 0           (foil 이 수면 위로 노출)

L_corrected = ½ρV²·S·C_L · σ(h)
σ(h) = 0 (foil breach) 가 발생하면 catastrophic — 한 foil 의 lift 가 0 이 되면서 vessel 이 non-foilborne 으로 떨어짐 (selfbore). 이걸 피하기 위해 controller 는 foil 깊이를 항상 chord 의 0.5 배 이상으로 유지하도록 설계.
σ(h) 모델 단순화 근거:
• Faltinsen (2005, Ch.7) 의 free-surface proximity 결과를 piecewise linear approximation
• 정확한 모델은 fully-nonlinear potential flow + Kelvin wake — 본 연구 scope 밖
• 이 단순화는 controller robustness 분석에 충분 (실제 σ 보다 보수적으로 lift 감소시킴)

5. Effective Angle of Attack — 5 가지 기여 항

각 foil 에서 실제 lift 를 결정하는 effective AoA 는 5 가지 항의 합:

\[ \alpha_{\text{eff}} = \underbrace{\theta}_{\text{(1) pitch}} \underbrace{- \tfrac{\dot z}{V}}_{\text{(2) heave rate}} \underbrace{- \tfrac{\dot\theta\, x_{\text{foil}}}{V}}_{\text{(3) pitch rate}} \underbrace{- \tfrac{w}{V}}_{\text{(4) wave orbital vel.}} \underbrace{- \tfrac{\partial\eta}{\partial x_b}}_{\text{(5) wave slope}} \]
#항물리적 의미제어 처리
1θvessel 이 nose-up 이면 foil 도 nose-up → AoA 증가State-dependent → PD feedback
2−ż/Vvessel 이 위로 솟으면 foil 이 상대 flow 와 만나는 각도 감소 (자연 damping)State-dependent → PD feedback
3−θ̇·x/Vpitch rate 가 foil 위치에서 induced velocity 발생State-dependent → PD feedback
4−w/V파도 orbital motion (수직 속도 ∂η/∂t) 이 induced angle외란 → FF preview
5−∂η/∂x파면 자체가 기울어 있으면 그 위 흐름도 기울어짐외란 → FF preview
항 (4), (5) 만이 vessel state 와 무관한 외란 — 이 둘이 feedforward 가 미리 보상해야 할 대상. 나머지 (1), (2), (3) 은 state-dependent 이므로 PD feedback 으로 충분히 처리 가능.
"−ż/V" 항이 자연 damping 의 핵심:
vessel 이 위로 빠르게 움직이면 (ż > 0), foil 입장에서는 상대 flow 가 위에서 비스듬히 들어오는 것으로 보이고 → AoA 감소 → lift 감소 → vessel 이 다시 내려옴. 이게 외부 damping 없이도 foilborne 이 안정한 본질적 이유. controller 는 이 자연 damping 을 보강만 해주면 됨.

5.1 Wave slope ∂η/∂xb — body-frame 보정

Vessel heading ψ이 0 이 아니면, x-축 방향 wave slope 는 inertial 좌표의 ∂η/∂x 와 ∂η/∂y 의 조합:

\[ \partial\eta/\partial x_b = (\partial\eta/\partial x)\cos\psi + (\partial\eta/\partial y)\sin\psi \]

6. 파동 외란 + Encounter Frequency

6.1 Wave field 표현

WaveSplat 과 같은 spectral 표현 — N 개의 plane wave 의 가중합:

\[ \eta(x,y,t) = \sum_{i=1}^{N} A_i \cos(k_{x,i}\,x + k_{y,i}\,y - \omega_i\,t + \varphi_i) \]

각도 주파수는 dispersion 으로 강제 (Holthuijsen 2007):

\[ \omega_i = \sqrt{g\,|\mathbf{k}_i|\,\tanh(|\mathbf{k}_i|\,d)},\quad d = 50\text{ m} \]

6.2 Slope, vertical velocity 해석적 계산

∂η/∂x = −Σ A_i · k_x,i · sin(k_x,i x + k_y,i y − ω_i t + φ_i)
∂η/∂y = −Σ A_i · k_y,i · sin(...)
∂η/∂t =  Σ A_i · ω_i  · sin(...)
Spectral 표현의 결정적 장점: 이 세 가지 양 (η, slope, w) 모두를 임의 (x, y, t) 점에서 해석적으로 계산할 수 있다. ETKF 같은 grid 표현은 격자 보간 + 수치 미분이 필요해서 noise 누적이 큼.

6.3 Encounter Frequency

Vessel 이 V 로 움직이면 fixed point 의 wave frequency 와 vessel 이 만나는 frequency 가 다르다:

\[ \omega_e = \omega - k\,V\cos\mu \]

where μ 는 wave 진행 방향과 vessel heading 사이 각도.

μ (rad)해상 명칭ωe 비교제어 의미
0Following sea (선미파)ωe < ωencounter 가 느림 → FF preview 길이 짧아도 OK
π/2Beam sea (횡파)ωe = ωvessel 이 wave 와 평행 이동 — preview 가장 길어야 효과적
πHead sea (선수파)ωe > ω가장 빠른 encounter — preview 짧게도 충분

7. PD Feedback Controller — Collective/Differential 분해

7.1 왜 PD (PID 가 아니라)

제어 변수는 z (heave), θ (pitch). 적분 항 (I) 이 빠진 이유:

  • Steady-state error 가 본질적으로 작음: foil 의 자연 damping (−ż/V) 이 이미 강하고, trim αzl 가 design 으로 zero-error 보장
  • Integral windup 위험: actuator saturation (±15°) 가 자주 발생할 수 있는 환경에서 integral 항은 wind-up 을 일으켜 transient 악화
  • Wave 외란은 zero-mean: 시간 평균이 0 이므로 integral 누적 의미 없음

7.2 Collective + Differential 분해

두 foil 을 독립으로 다루는 대신, 두 가지 mode 로 분해해서 직관적으로 제어:

delta_collective (δ_c)  =  −K_p,z · z   −  K_d,z · z_dot       ← heave 제어
delta_differential (δ_d) =   K_p,θ · θ   +  K_d,θ · θ_dot      ← pitch 제어

flap commands:
  delta_front = δ_c − δ_d
  delta_rear  = δ_c + δ_d
Gain값의미
K_p,z0.8 [rad/m]heave error 1m → flap 0.8 rad (saturation 도달 직전)
K_d,z0.3 [rad·s/m]heave 속도 댐핑 비율 ζ ≈ 0.6 목표
K_p,θ4.0 [rad/rad]pitch 1° → flap 4° (좀 더 강하게 — pitch 가 lift 에 더 sensitive)
K_d,θ1.5 [rad·s/rad]pitch 댐핑 ζ ≈ 0.7 목표
δ_max0.26 rad (15°)servo physical limit + post-stall 회피
Collective + differential 분해의 장점:
  • 물리적으로 분리된 두 mode (heave / pitch) 가 두 actuator (전·후 foil) 에 깔끔하게 매핑됨
  • Tuning 이 직관적: heave 응답이 느리면 K_z ↑, pitch overshoot 이면 K_d,θ ↑ — 단순
  • Tandem foil 의 cross-coupling (전방 lift 변화가 pitch moment 도 만듦) 이 자연스럽게 처리
  • 2×2 MIMO 형태로 LQR 설계도 가능 — 다만 PD 로 충분한 성능 + tuning 단순성 우선

7.3 Saturation 처리

delta_front = clip(delta_front, −0.26, +0.26)
delta_rear  = clip(delta_rear,  −0.26, +0.26)

±15° 는 (a) servo physical limit, (b) post-stall AoA 회피 (C_L,max = 1.2) 의 두 이유로 결정. 구현상 전·후방 flap 을 독립적으로 clip 한다 — δ_c 와 δ_d 를 먼저 합산한 뒤 함께 saturate. 별도의 priority 로직 없음. pitch 안정성은 collective mode 가 saturate 되더라도 differential mode 가 자동으로 남은 여유 범위를 활용해 보완된다 (collective + differential 분해의 자연스러운 결과).

8. Wave-Preview Feedforward — 핵심 설계 결정

8.1 Preview 위치 계산

Vessel 이 V 로 움직이므로, "현재 시점에 Δt 후 foil 이 도달할 위치" 의 wave 를 미리 평가:

\[ x_{\text{preview}} = x_{\text{foil}} + V \cdot \Delta t_{\text{prev}} \] 
# pseudocode
x_preview_front = x_cg + x_front · cos(ψ) + V · Δt · cos(ψ)
y_preview_front = x_front · sin(ψ) + V · Δt · sin(ψ)
slope_preview_x = ∂η/∂x evaluated at (x_preview, y_preview, t_now)
"공간 preview" 라는 것이 핵심: 시간을 미루지 않고 (t = t_now 그대로), 공간상 앞쪽의 wave 를 지금 바로 계산. 이는 wave 가 V 로 vessel 에 다가오는 효과와 등가 (Galilean 변환).

8.2 Raw FF 명령 — Wave AoA 보상

Preview 위치에서 wave 가 만들 effective AoA 변화량:

\[ \alpha_{\text{wave}} = -\partial\eta/\partial x - w/V \]

그 반대 부호로 flap 을 미리 deflect:

\[ \delta_{\text{ff}} = -K_{\text{ff}} \cdot \alpha_{\text{wave}} \]
파라미터값의미
K_ff0.8 (1.0 아님)under-compensation — 추정 오차 대응
Δt_preview0.1~0.3 svessel speed × Δt = 1~3 m 전방
LP filter α0.05fc ≈ 0.8 Hz cutoff @ dt=0.01s
Kff = 0.8 인 이유 (1.0 이 아니라):
  • 완전 보상 (K = 1) 시 추정 오차 + actuator dynamics 지연 → over-correction → oscillation
  • 0.8 은 sensitivity sweep 에서 robust 영역의 중심 (0.6~0.9 모두 유효, 0.8 이 명목값)
  • Linear quadratic 관점: process noise + measurement noise 조합에서 optimal 해석 K* < 1
  • Foil actual lift slope vs ideal slope 비 ≈ 0.85 (model mismatch) → K ≈ 0.85 가 자연스러움

8.3 IIR Low-Pass Filter — 추정 노이즈 억제

WaveSplat 추정에는 노이즈가 있음. Raw FF 신호를 그대로 actuator 로 보내면 high-freq jitter 가 발생. 1 차 IIR low-pass filter 로 smoothing:

y[n] = α · x[n] + (1 − α) · y[n−1]

α = 0.05  →  effective cutoff fc ≈ α / (2π · dt) ≈ 0.8 Hz
                     (dt = 0.01 s, sampling 100 Hz)
fc = 0.8 Hz 선택 이유:
  • 파도 주기 4~7 s → wave 주파수 0.14~0.25 Hz: pass-band 에 위치 (왜곡 없이 통과)
  • WaveSplat 추정 노이즈는 주로 1 Hz 이상 high-freq → stop-band 에서 −20 dB attenuation
  • Servo bandwidth (≈ 5 Hz) 보다 훨씬 낮음 → actuator 가 추적 가능

8.4 PD + FF 합산 + Saturation

raw_ff_front = −K_ff · (−slope_pre_front − w_pre_front / V)
raw_ff_rear  = −K_ff · (−slope_pre_rear  − w_pre_rear  / V)

filtered_ff_front, filtered_ff_rear = LP_filter(raw_ff)

flap_front = clip(δ_c − δ_d + filtered_ff_front, −0.26, +0.26)
flap_rear  = clip(δ_c + δ_d + filtered_ff_rear,  −0.26, +0.26)
PD 와 FF 가 합산되는 이유: FF 가 100% 정확하면 PD 는 거의 0 이 되어야 정상이지만, 실제로는 FF 추정 오차 + 모델링 안 된 외란 (current, wind) 이 있으므로 PD 가 잔존 오차를 처리. 즉 FF 는 "주된 외란 미리 보상", PD 는 "잔여 오차 + safety net" 역할.

9. 수치 적분 — RK4 + FF Filter 타이밍

9.1 RK4 4 차 Runge-Kutta

비선형 ODE 를 dt = 0.01 s (100 Hz) 로 적분.

k1 = f(y_n, t_n)
k2 = f(y_n + dt/2 · k1, t_n + dt/2)
k3 = f(y_n + dt/2 · k2, t_n + dt/2)
k4 = f(y_n + dt · k3, t_n + dt)
y_{n+1} = y_n + (dt/6) · (k1 + 2k2 + 2k3 + k4)
RK4 채택 이유:
  • Stiffness 가 낮음 (가장 빠른 mode = pitch ~ 2 Hz, dt = 0.01 s 로 100× oversampling)
  • 4th-order 정확도로 dt = 0.01 s 면 accumulated error 가 simulation 시간 30 s 동안 ~10⁻⁴ 수준
  • Implicit method 불필요 (stiff 가 아니므로) → 계산 비용 ↓

9.2 FF Filter 의 critical timing

구현 함정: RK4 의 4 substep 안에서 FF filter 를 호출하면 filter state 가 4 번 update 되어 effective filter bandwidth 가 4× 변경됨 → 잘못된 결과.

해결: FF 필터는 main timestep 당 한 번만 호출, RK4 substep 에서는 fixed offset 으로 사용:

# main loop (per dt = 0.01 s)
ff_info = compute_preview(state, t_now)          # 한 번
raw_ff = compute_raw_ff(ff_info)                  # 한 번
filtered_ff = LP_filter.update(raw_ff)            # 한 번 (filter state advance)

# RK4 substeps — filtered_ff 를 fixed value 로 사용
for substep in [k1, k2, k3, k4]:
    state_substep = ...
    pd_command = compute_pd(state_substep)         # PD 만 substep 마다 재계산
    flap = pd_command + filtered_ff                # FF 는 고정
    derivative = compute_dynamics(state_substep, flap, ...)
이 분리는 paper Section 4.6 에서 강조한 "feedforward signal is low-pass filtered once per main timestep and passed as a fixed offset" 의 구체적 implementation. 같은 LP filter coefficient 로 다른 결과가 나오면 이 점을 의심해야 함.

11. 한계와 확장 방향

현재 한계

  • Linear lift model: stall (C_L,max clamp) 외엔 모든 영역 linear. 실제는 thick boundary layer 영역에서 nonlinear 가 약간 있음.
  • Constant V 가정: surge 무시. 추진력 변동 (waste-gate, throttle) 미모델.
  • 2D 만 고려: oblique sea (μ ≠ 0, π) 에서 roll·yaw coupling 무시.
  • Ventilation 단순 모델: σ(h) 가 piecewise linear. 실제는 air entrainment dynamics 가 nonlinear.
  • Strut drag 미모델: foil 을 hull 에 연결하는 strut 의 wave-piercing drag 가 별도 효과 (현재 Bz, Bθ 에 lumped).

확장 가능 방향

  • MPC (Model Predictive Control): PD + FF 대신 finite horizon optimal control — K_ff, Δt_preview 자동 최적화 + actuator constraint 직접 반영.
  • Adaptive K_ff: WaveSplat 의 nRMSE estimate 를 받아서 K_ff 를 실시간 조절.
  • 3-DOF (heave + pitch + roll): oblique sea 에서 roll-foil 의 FF 도 함께 설계.
  • Cavitation-aware control: foil 압력 분포 모델 + cavitation 회피 constraint 추가.
  • Sim-to-real: NEUBOAT / Candela C-8 실선 시험 데이터로 model 보정.

12.2 WaveSplatComponent 인터페이스

WaveSplatComponent 는 wavesim.WaveComponent 와 동일한 필드명 (A, omega, kx, ky, phi) 을 가진다. disturbance.py 의 함수들이 comp.A, comp.kx 등으로 접근하므로 bridge 없이 그대로 전달 가능하다. 

WaveSplatComponent:
  A     = params['w'][i]      # 진폭 [m]
  omega = params['omega'][i]  # dispersion 만족 (4N 파라미터 덕분)
  kx    = params['kx'][i]     # x-wavenumber [rad/m]
  ky    = params['ky'][i]     # y-wavenumber [rad/m]
  phi   = params['phi'][i]    # 위상 (tracking 시 매 프레임 갱신)
  Q     = 0.0                 # Gerstner 비선형항 — linear 모델로 취급
Q = 0 으로 설정하는 이유: WaveSplat 의 forward model 자체가 linear superposition 이므로, feedforward 에서도 Gerstner 비선형 보정 없이 linear 파면 정보만 사용. model mismatch 는 O(ε²) 로 작음.

15. Glossary — 비전공자용 용어 정리

AoA (Angle of Attack, 받음각): foil chord 와 incoming flow 사이 각도. lift 의 선형 함수.
Foilborne: foil lift 가 부력을 대체해 hull 이 수면 위로 부상한 운항 모드.
Hull-borne: foilborne 이전 일반 항해 모드 — hull 이 부력으로 떠 있음.
Selfbore: foilborne 에서 lift 부족으로 hull 이 다시 수면에 닿는 사건. 승차감 급변 + 추진 손실.
Cavitation: foil 표면 저압 영역에서 물이 vapor 로 변하는 현상. lift 손실 + erosion 유발.
Ventilation: foil 이 수면 가까울 때 air 가 foil 표면으로 빨려 들어와 lift 가 무너짐.
Free-surface effect: foil 이 수면 가까이 갈수록 수면 위 압력이 외기로 빠져나가 lift 가 감소하는 현상.
Tandem foil: 전방·후방 두 foil 을 분리 배치. moment balance 자유도 + 안정성.
Inverted-T foil: 위에서 보면 T 자, 단 stem 이 위를 향한 형태. 전방 foil 흔한 layout.
T-foil: 일반 T 자 형태. 후방 stabilizer 로 흔히 사용.
NACA 63-series: NACA 가 1940s 에 정의한 airfoil family. Cavitation 시작 영역이 비교적 늦어 hydrofoil 에 적합.
Aspect ratio (AR): 날개 폭 / 코드 비. 클수록 induced drag ↓, lift slope ↑.
Lift slope (C_Lα): AoA 단위 (rad) 당 lift 계수 증가율. 2D 이론값 = 2π, 3D finite-span 보정으로 작아짐.
Drag polar: C_D = C_D0 + C_L²/(π·AR·e). lift 가 클수록 drag 가 quadratic 증가.
Stall: AoA 가 너무 크면 flow separation 으로 lift 급감. 본 연구는 C_L,max = 1.2 로 단순 clamp.
Submergence (h): foil quarter-chord 가 수면 아래 깊이. h/c 가 lift 감소 인자.
Trim: 외란 없는 평형 상태. 본 연구는 z = θ = 0 에서 lift = mg, moment = 0 자동 만족.
Heave (z): vessel 의 수직 변위. 양수 = 위로.
Pitch (θ): vessel 의 종방향 회전각. 양수 = bow-up.
Encounter frequency (ω_e): 움직이는 vessel 이 만나는 wave 의 겉보기 주파수. ω - kV·cosμ.
Head/Beam/Following sea: vessel heading 과 wave 진행 방향이 각각 180°/90°/0°.
Orbital velocity (w = ∂η/∂t): 파도 표면 입자의 수직 속도. foil 에 induced angle 부여.
Wave slope (∂η/∂x): 파면의 기울기. foil 에 직접 AoA 변화 부여.
Dispersion relation: ω = √(g|k|·tanh(|k|d)). 파장 ↔ 주기를 잇는 물리 법칙.
Added mass: 가속하는 body 가 주변 물을 함께 가속시키는 inertia 추가 효과. foilborne 에서는 작음.
JONSWAP spectrum: 1968-69 북해 관측 기반 wind-wave 스펙트럼 모델. peak enhancement γ 로 sharpness 조절.
Hs (significant wave height): 파고 분포의 4σ. "체감 파고".
Tp (peak period): spectrum 이 가장 큰 주파수의 주기 (s).
Beaufort scale (BF): 풍속 기반 해상 강도. BF2 (Hs ≈ 0.3 m) ~ BF5 (Hs ≈ 2.0 m).
PD (Proportional-Derivative): 에러와 에러 변화율로 제어. integral 항 없음.
PID: PD + integral 항. steady-state error 제거에 유리하나 windup 위험.
Feedforward (FF): 외란을 미리 알고 보상. feedback 의 phase 지연 회피.
Preview control: 미래 외란 정보를 사용한 FF. vehicle suspension 의 road preview, hydrofoil 의 wave preview 등.
Saturation: actuator 가 물리 한계에 도달해 더 이상 출력을 늘릴 수 없는 상태.
IIR (Infinite Impulse Response): 과거 출력을 사용하는 디지털 필터. 1 차 IIR = exponential smoothing.
Cutoff frequency (fc): 필터의 −3 dB 통과 한계. 본 연구 LP filter fc ≈ 0.8 Hz.
RK4 (Runge-Kutta 4): 4 차 정확도의 명시적 ODE 적분. 본 연구는 100 Hz (dt = 0.01 s).
aRMS: vertical acceleration 의 RMS 값. ISO 2631 승차감 기준 [m/s²].
ISO 2631: 인체 vibration 노출 평가 표준. < 0.315 Comfortable, 0.315~0.63 Slight discomfort 등.
