1. 기초 개념 S1-S3

1.1 파도란 무엇인가?

바다의 파도는 바람에 의해 만들어지는 수면의 요동입니다. 물리적으로 파도는 여러 개의 사인파(sine wave)가 겹쳐진 것으로 근사할 수 있습니다.

파도 = 여러 사인파의 합
각 사인파는 5가지 물리량으로 설명됩니다:
  • 진폭 (A) — 파도의 높이
  • 파수 (kx, ky) — 어떤 방향으로, 얼마나 빽빽한 파도인지
  • 주파수 (ω) — 파도가 얼마나 빨리 지나가는지
  • 위상 (φ) — 파도가 지금 어디에 위치해 있는지
η(x, y, t) = Σ An cos(kxn·x + kyn·y - ωn·t + φn)

η = 수면 높이, x,y = 위치, t = 시간, n = 각 파도 성분

1.2 Statistical vs Phase-resolved 추정

Statistical (통계적) 추정

  • 유의파고 Hs, 첨두주기 Tp 등 평균값
  • "파도가 대략 2m 정도다" 수준
  • 실시간 제어에는 부족

Phase-resolved (위상 결정론적) 추정

  • 각 파도의 위치, 시점, 높이를 구체적으로
  • "x=120m에 5초 후 높이 2m 파도가 온다"
  • 이 연구의 목표

1.3 분산 관계 (Dispersion Relation)

"파도의 주파수는 파수에 의해 결정된다" — 파도 물리의 가장 중요한 법칙입니다.

ω = √(g · |k| · tanh(|k| · d))

g = 중력가속도(9.81), k = 파수, d = 수심. 긴 파도는 빨리, 짧은 파도는 느리게 이동합니다.

1.4 LiDAR (라이다)

  • 레이저로 거리를 측정하는 센서. 선박 위에서 바다 표면을 스캔
  • 한 프레임에 약 50개 유효 점, 탐지 거리 ~250m
  • Raydrop: 파도 경사로 레이저가 반사 안 됨 / Shadowing: 앞 파도가 뒤를 가림

1.5 nRMSE

nRMSE = RMSE / (max - min). 0=완벽, 1=최악. 0.2 ≈ "80% 맞춤", 0.05 ≈ "거의 완벽"

4. 선행 연구 상세 (Q&A 대비)

Wang et al. 2025 (Coastal Engineering 197)

"From points to waves" | Harbin Engineering Univ. | 우리의 주 비교 대상
  • 방법: stereo camera → sparse 3D points → Delaunay 보간 → 격자에 투영 → ETKF로 스펙트럼 추정
  • 핵심 혁신: (1) WASSfast의 constrained optimization과 Kalman filter의 이론적 등가성 증명, (2) Fuzzy logic으로 관측 노이즈 R 자동 적응, (3) sub-state localization으로 병렬화
  • 앙상블: Ne=300, state dim = 16384×1 or 65536×1 (격자 크기 의존)
  • 실험: Acqua Alta 공개 데이터셋 + 자체 현장 데이터 (선박에서 stereo camera)
  • 성능: WASSfast보다 CPU 3-4배, GPU 2배 빠름. Sparse 조건에서도 robust
  • 우리 재현: Ne=300, 80x60 grid(dx=3m), fuzzy R, Delaunay — 원논문에 충실
  • 원논문과 우리 비교의 차이: 원논문은 stereo camera(수천 점), 우리는 LiDAR(~50점)

Ehlers et al. 2025 — PFT-PINN (Phys. Rev. Fluids 10, 094901)

"Physics-informed neural networks for phase-resolved DA" | TUHH + Imperial + Oxford
  • 구조: 2개 병렬 NN — η(x,t) 수면 + Φ(x,t,z) 속도 포텐셜 동시 추정
  • NN 구조: 4 hidden layers × 200 neurons, tanh 활성화, Fourier feature embedding
  • 물리 loss: L_Lap(Laplace 방정식) + L_BC,kin + L_BC,dyn + L_BC,bot = 4개 PDE residual
  • 관측 데이터 처리: Hard constraint — η̄(x,t) = M(x,t) + R(x,t)·N_η(x,t). 관측점에서 NN 출력이 정확히 관측값이 되도록 강제
  • Loss balancing: ReLoBRaLo — 4개 loss component의 가중치를 자동 조절 (α=0.95, τ=20)
  • 학습: Adam(lr=0.0005, 5000 epoch) + L-BFGS(~35000 epoch) → RTX 3090에서 ~30분
  • 검증: (1) 해석해(LWT 3성분, deep water), (2) 실험(Imperial MARATHON wave flume, ε=0.05~0.11)
  • prediction: sequential training — 시간 도메인을 52 segment로 분할, 순차 학습
  • 결과: assimilation SSP≤0.049, prediction SSP=0.084 (1 peak period ahead)
  • 핵심 능력: 수면 측정만으로 수중 속도 포텐셜까지 추론 (우리는 수면만)
  • 한계: 1D(x+t)만, instance마다 재학습, ~30분 소요
  • 향후(논문 명시): 2D+t 확장, multi-GPU, pre-training, PINO 탐색

Ehlers et al. 2023 — FNO (Ocean Engineering 288)

"ML for phase-resolved reconstruction from sparse remote sensing" | TUHH + DLR
  • 방법: HOS(비선형)로 합성 레이더 데이터 생성 → FNO/U-Net으로 지도학습
  • 데이터: 130 (Lp,ε) 조합 × 4 랜덤 위상 = 520 HOS 시뮬레이션 → 3120 학습 샘플
  • FNO 구조: Fourier embedding → 3 Fourier layers(nm=64 modes) → linear output
  • FNO의 강점: Fourier 공간에서 전역 매핑 학습 → 파도의 주기적 구조에 inductive bias 일치
  • 결과: FNO(ns=9): nL2=0.153, SSP=0.077 / U-Net(ns=10): nL2=0.123, SSP=0.061
  • 추론 속도: ~1.9ms (RTX 3050 Ti)
  • 한계: (1) 1D만, (2) 3120개 학습 데이터 필요, (3) shadowed 영역 복원 정확도 낮음

Desmars et al. 2023 (J. Fluid Mech. 975, A8)

"Nonlinear deterministic reconstruction and prediction" | TUHH + DLR, JFM
  • 방법: HOS-Observation Coupling Method (HOS-OCM) — HOS M=1(LWT)~M=3(3차) 비교
  • 관측: 3가지 type — (1) 균일 분포 수면 높이, (2) shadowing만, (3) shadowing+tilt modulation
  • 핵심 결과: M=3 HOS가 가장 정확, 특히 extreme wave 예측. LWT는 steepness 높을수록 부정확
  • 한계: 1D 레이더 관측 기반, variational optimization (실시간 아님)
  • 우리와 차이: 센서(레이더 vs LiDAR), 차원(1D vs 2D), 표현(격자 vs 연속), 속도(offline vs 13ms)

Yan et al. 2025 — VOF-EnKF (arXiv:2510.14356)

"Sequential wave reconstruction in VOF-based numerical wave tanks" | Shanghai Jiao Tong U.
  • 방법: Navier-Stokes(VOF) + EnKF + POD 차원 축소 — wave breaking까지 재현 가능
  • 핵심 혁신: free surface에만 inflation 적용 + LWT로 속도장 물리적 일관성 보장
  • 한계: CFD 기반이라 계산 비용 매우 높음 (오프라인 수치 수조 재현 전용)
  • 우리와 관계: 경쟁이 아닌 보완. 우리=실시간 제어, 그들=정밀 재현/설계

Klein et al. 2020 (Fluids 5(1), 9)

"On the deterministic prediction of water waves" | TUHH
  • 핵심: wave steepness ε < 0.07 이면 LWT 충분히 정확 → 우리 방법 적용 범위의 근거
  • ε = k·A (파수 × 진폭). BF6까지 대부분 ε < 0.07 충족

4.5 WaveSim — 시뮬레이터 상세 S9-S10

WaveSim이란? WaveSplat 알고리즘을 평가하기 위한 합성 데이터 생성 시뮬레이터입니다. 실제 바다의 파도와 LiDAR 센서를 물리적으로 모사하여, ground truth(정답)와 관측 데이터를 동시에 생성합니다.

왜 시뮬레이터가 필요한가?

  • 실해역에서 "파도의 정답"을 알 수 없음 — 평가 자체가 불가능
  • 시뮬레이터는 정답(ηGT)을 정확히 알고 있으므로 알고리즘 평가 가능
  • 다양한 해상 상태(BF2~BF7), 파도 복잡도(1~30 comp)를 체계적으로 실험
  • LiDAR 센서의 물리적 특성(raydrop, shadowing, noise)까지 포함

파이프라인 구조 (5단계)

① 파도 생성 (wave_generator.py)

JONSWAP 스펙트럼 + Gerstner 파도
  • JONSWAP 스펙트럼: 유의파고 Hs와 첨두주기 Tp를 입력하면, 각 주파수별 에너지 분포를 계산 (Hasselmann et al. 1973)
  • 성분 추출: 스펙트럼에서 N개 주파수를 샘플링하고, 각 성분의 진폭 An = √(2·S(ωn)·Δω) 계산
  • Gerstner 파도: 단순 사인파가 아닌 Gerstner 공식으로 수면 변위 계산 — 꼭대기 뾰족, 골 평평한 현실적 형태
  • Q constraint: Σ Qn ≤ 1 — 물 입자가 겹치지 않는(particle crossing prevention) 조건 (Tessendorf 2001)
  • 분산 관계: ω = √(g·|k|·tanh(|k|·d)) — 깊은물 근사가 아닌 유한 수심 고려
  • 방향: 각 성분의 (kx, ky)를 무작위로 배정하여 2D 방향성 파도 생성
η(x,y,t) = Σn An cos(kxn·x + kyn·y - ωn·t + φn)

② Ground Truth 생성 (gt_generator.py)

  • 80×60 정규 격자(x: 10~250m, y: -100~100m)에서 파도면 높이 η(x,y,t) 계산
  • 매 시간 step(dt=0.1s, 30초간)에서 전체 격자 평가 → 300 프레임의 정답 데이터
  • 법선 벡터(Nx, Ny, Nz)도 함께 계산 — LiDAR 시뮬레이션에 사용
  • 1D 에너지 스펙트럼 S(ω) 저장 — 결과 분석용

③ LiDAR 시뮬레이션 (lidar_simulator.py)

실제 LiDAR 센서의 물리를 모사 — 단순 점 샘플링이 아님
  • 센서 설정: 높이 5m, 152채널, 10Hz, FOV 120°(수평) × 25°(수직), 탐지거리 1.5~250m
  • 빔 생성: 500(수평) × 152(수직) = 76,000개 레이저 빔을 각 프레임에서 방출
  • 수면 메시 구성: 파도면을 삼각형 메시(40×30 격자 → 2×39×29 = 2,262 삼각형)로 변환
  • Ray-mesh 교차: Möller-Trumbore 알고리즘으로 각 빔과 삼각형의 교차점 계산
  • 교차점 = LiDAR가 감지한 수면 위의 3D 점 → (x, y, zobs) 형태로 출력

④ Raydrop 모델 (raydrop_slope.py, raydrop_uniform.py)

실제 LiDAR는 모든 빔이 성공적으로 반사되지 않음 — 이를 모사하는 것이 raydrop 모델
  • Slope-based raydrop (물리 기반):
    • LiDAR는 specular reflection (정반사) 원리로 작동 — 수면 법선이 센서 방향과 정렬되어야 반사
    • 파도 경사가 가파르면 법선이 틀어져 레이저가 센서로 돌아오지 않음 → 점 누락
    • 반사 조건: r = d - 2(d·n)n에서 r·(-d) ≥ cos(αthreshold)
    • 결과: 파도 앞면(센서를 향한 면)은 잘 보이지만, 뒷면은 거의 안 보임
  • Uniform raydrop (통계적): 전체 hit점에서 무작위로 target_n_pts개만 남김 (baseline)
  • Shadowing: 앞 파도가 높으면 뒤 파도 영역에 빔이 도달하지 못함 — ray-mesh 교차에서 자연 발생
  • 최종 결과: 76,000개 빔 중 약 ~50개 유효 점만 남음

⑤ 노이즈 모델 (noise_model.py)

  • Range noise: σ = 2cm — 빔 방향으로 Gaussian 랜덤 섭동 (1550nm solid-state LiDAR 스펙 기반)
  • Angular noise: σ = 0.05° — 빔 방향 수직으로 Gaussian 섭동 (빔 확산)
  • Confidence: 각 점의 입사각 기반 신뢰도 가중치 (grazing angle이 작으면 신뢰도 낮음)

강점 (Strengths)

1. 물리 기반 LiDAR 센서 모델
대부분의 wave reconstruction 연구(Desmars 2023, Ehlers 2023)는 관측을 "격자 위의 수면 높이"로 단순화합니다. WaveSim은 실제 LiDAR의 빔 기하학 → ray-mesh 교차 → specular 반사 → raydrop → 노이즈까지 물리적으로 모사하여, 실제 센서에서 나올 데이터에 가까운 합성 데이터를 생성합니다.
2. 완전한 Ground Truth 보유
시뮬레이터이므로 파도의 모든 물리 파라미터(A, kx, ky, ω, φ)와 전체 공간의 수면 높이 η(x,y,t)를 정확히 알고 있습니다. 실해역에서는 원리적으로 불가능한 전역적 정량 평가(nRMSE)가 가능합니다.
3. 체계적 실험 설계
BF2~BF7(파고 0.3~4m), 1~30 comp(파도 복잡도), uniform/slope(raydrop 모델), 5개 random seed — 조합을 통해 100개 에피소드를 체계적으로 생성합니다. 특정 조건에서만 잘 되는지, 전반적으로 잘 되는지 판별 가능합니다.
4. 재현성 (Reproducibility)
모든 에피소드는 seed로 결정론적으로 생성됩니다. 동일 seed → 동일 파도 → 동일 LiDAR 점. 다른 연구자가 코드만 있으면 정확히 동일한 실험을 재현할 수 있습니다. HDF5 파일에 모든 중간 데이터(components, gt_fields, lidar_frames)가 저장되어 있어 시뮬레이션 재실행 없이도 분석이 가능합니다.
5. 충분한 테스트 커버리지 (39 tests)
파도 생성(JONSWAP, 분산관계, Q constraint), ray casting(Möller-Trumbore), raydrop(specular 반사), ground truth, 전체 파이프라인까지 각 모듈을 독립적으로 검증합니다. 코드 수정 시 regression을 즉시 감지할 수 있습니다.

한계 (Limitations)

1. 선형파 근사 (LWT)
Gerstner 파도는 LWT의 exact rotational solution이지만, 여전히 선형 중첩(superposition)을 가정합니다. 실제 바다에서 발생하는 비선형 효과들이 누락됩니다:
  • 파도-파도 상호작용: 두 파도가 만나면 에너지가 교환됨 (4-wave interaction)
  • Bound waves: 2차 이상의 고조파 성분이 자연 발생 (Stokes drift)
  • Wave breaking: ε > ~0.14에서 파도 꼭대기가 부서짐 — LWT로 표현 불가
Klein 2020에 따르면 ε < 0.07이면 LWT가 충분히 정확하므로, BF2~BF5에서는 유효합니다. BF6~BF7에서는 Stokes 2차 보정이 필요합니다.
2. 단순화된 해양 환경
실제 바다에는 시뮬레이터에 포함되지 않은 요소들이 있습니다:
  • 해류 (ocean current): 파도의 분산관계를 변화시킴 (Doppler shift)
  • 바람 효과: 수면 위 물보라(spray), 거품(whitecap)이 LiDAR 반사에 영향
  • 수심 변화: 고정 수심 50m 가정 — 천해역에서는 굴절/천수 효과 발생
  • 해저 지형: 균일 평탄 해저 가정
3. LiDAR 센서 모델의 단순화
실제 LiDAR와 WaveSim의 차이:
  • 수면 반사 모델: 실제는 specular + diffuse + capillary wave 혼합. WaveSim은 specular or uniform 2가지만
  • 다중 반사 (multi-path): 파도 사이에서 레이저가 여러 번 반사되는 현상 — 미반영
  • 대기 감쇠: 수증기, 물보라에 의한 레이저 감쇠 — 미반영
  • 센서 동적 특성: 스캔 중 선박 운동에 의한 motion distortion — 부분 반영
  • 수면 아래 투과: 1550nm 파장은 수면에서 거의 반사되지만, 일부 투과 가능 — 미반영
4. Sim-to-Real Gap
시뮬레이터에서 잘 작동해도 실제 환경에서 동일한 성능을 보장하지 않습니다. 이를 sim-to-real gap이라 합니다. 주요 차이 원인:
  • 실제 파도 스펙트럼은 JONSWAP보다 복잡 (swell + wind sea 혼합, bimodal spectrum)
  • 실제 LiDAR 점 분포는 센서별 특성에 크게 의존 (Seyond vs Livox vs Velodyne)
  • 실해역 raydrop 패턴은 해상 상태, 시각(태양 위치), 수면 오염도에 따라 변동
이 gap을 줄이기 위해 Avikus 자율운항 선박에서 실제 LiDAR 데이터를 수집하는 계획이 향후 연구에 포함되어 있습니다.
5. 고정 센서 구성
현재 모든 에피소드가 동일한 센서 설정(높이 5m, 152ch, FOV 120°)을 사용합니다. 실제로는 선박 크기, LiDAR 모델, 설치 위치에 따라 관측 패턴이 크게 달라질 수 있습니다. 다양한 센서 구성에서의 robustness 검증이 추후 필요합니다.
시뮬레이터의 핵심 가치 요약: WaveSim은 "완벽한 현실 모사"가 아니라 "통제된 환경에서 알고리즘의 기본 성능을 검증"하기 위한 도구입니다. 물리 기반 센서 모델을 포함함으로써 단순한 toy problem이 아닌, 실해역에 가까운 조건에서의 평가를 가능하게 합니다. 한계들은 향후 실데이터 검증과 시뮬레이터 고도화를 통해 보완할 예정입니다.

6. 방법론 상세 — 알고리즘 내부

6.1 Beamforming 초기화 (v2_konly)

Beamforming: 레이더/음향에서 신호 방향 추정에 쓰이는 기법. 여러 관측점 신호를 특정 방향으로 합산 → 그 방향 신호가 강화됨.

WaveSplat 적용:

  1. 여러 프레임 LiDAR 점군 누적 (synthetic aperture 효과)
  2. 후보 파수(kx, ky) 격자 생성
  3. 각 후보의 관측 데이터 상관 계산
  4. 피크 파수를 초기값으로 선택
"v2_konly": v1(FFT) → v2(beamforming)으로 변경하여 평균 18% 개선. "konly" = k만 초기화, ω와 φ는 분산 관계와 최적화에 맡김.

10. 향후 연구 방향 상세 S18

10.1 Stokes 2차 보정

문제: LWT는 완벽한 사인파 가정. 실제 파도는 꼭대기 뾰족, 골 평평.
Stokes 2차: 2배 주파수 성분을 추가하여 비선형 효과를 근사:
ηStokes2 = Σ Ancos(ψn) + Σn,m Bnmcos(ψn + ψm)
  • Bnm은 kn, km에서 해석적으로 계산 (추가 자유 파라미터 없음)
  • 유효 범위: ε < 0.07 → ε ~ 0.10까지 확장 (BF6~7 커버)
  • Desmars 2023도 HOS M=1→M=3으로 개선 효과 보고
  • 속도 저하 최소: 기존 파라미터에서 계산만 추가

10.2 Hybrid Init

고복잡도(15-30 comp) 역전 해결:
  1. 격자 방법(FFT/ETKF)으로 대략적 파도장 빠르게 추정
  2. 격자 결과에서 peak 추출 → WaveSplat 초기값
  3. WaveSplat 연속 최적화로 정밀도 향상
격자의 "넓은 탐색" + WaveSplat의 "정밀 추정" 결합.

10.3 Learned Init

작은 NN으로 LiDAR 점군 → 초기 파라미터 직접 예측. NN이 틀려도 WaveSplat이 최적화로 보정 → 견고한 시스템.

10.4 실해역 검증

현재: 합성 데이터만. 필요: 실제 ship-mounted LiDAR 데이터.
시뮬레이터에 포함: raydrop, shadowing, 선박 운동.
미포함: 물보라, 비선형, 해류, 바람 흔들림. Avikus 자율운항 선박에서 수집 계획.

11. 예상 질문과 답변

Q: 실제 바다에서도 작동하나요?
현재 합성 데이터에서 검증. 시뮬레이터에 raydrop, shadowing 등 LiDAR 물리 효과 포함. 실제 환경과의 차이가 크지 않을 것으로 기대하며, Avikus 선박에서 실데이터 수집 계획 중.
Q: 왜 선형 파도 이론만?
비선형(PFT-PINN, VOF-EnKF)은 30분~수시간 소요 → 실시간 불가. BF6까지 LWT 유효(Klein 2020). Stokes 2차 보정으로 비선형 영역 일부 확장 가능.
Q: Wang2025 비교가 공정한가?
원논문 세팅 그대로 (Ne=300, fuzzy R, Delaunay). 동일한 물리(LWT) + 동일한 LiDAR 데이터. 원논문은 stereo camera(dense) 사용이지만, ETKF 알고리즘은 입력 형태에 무관.
Q: 고복잡도에서 지는데?
정직하게 보고. Limitation에 명시 + 원인(초기화 한계) + 해결(hybrid init) 제시. 리뷰어는 한계 숨기기보다 정직한 보고를 높이 평가.
Q: PFT-PINN이 빨라지면?
PINN은 instance마다 40000 epoch 학습 필요 (PDE residual + backprop 반복). 실시간급 달성 원리적으로 어려움. 설령 빨라져도 응용이 다름: PINN=속도포텐셜까지 추론하는 설계 도구, 우리=수면만 빠르게 추정하는 제어 컴포넌트.
Q: FNO가 1.9ms로 더 빠른데?
FNO: 학습 데이터 3120개 필요, 1D만, 환경 변하면 재학습. 우리: 비지도, 2D, 즉시 작동. 속도는 둘 다 실시간급(100ms 이내)이라 실용적 차이 없음.
Q: "Spectral Gaussian"이 3DGS와 관련?
이름 영감만 동일. 공통점: 연속 파라미터를 직접 최적화하는 off-grid 접근. 차이: 3DGS=3D 장면 표현, WaveSplat=스펙트럼 공간에서 파도 표현.
Q: Wang2025는 stereo camera인데 같은 조건?
원논문은 수천 점 stereo, 우리 비교에서는 동일 LiDAR 데이터(~50점)를 양쪽에 제공. 우리 문제 설정이 sparse scanning LiDAR이므로 공정한 비교.
Q: Desmars 2023과 왜 비교 안 했나?
센서(레이더 vs LiDAR), 차원(1D vs 2D), 속도(offline vs 13ms) 모두 다름. 직접 비교 어려워 Related Work에서 positioning으로 다룸.
Q: VOF-EnKF와 차이?
완전히 다른 레벨. VOF-EnKF=Navier-Stokes로 파도 파쇄/유속장 재현(CFD급). 우리=수면만 빠르게. 경쟁 아닌 보완 관계.
Q: Ablation에서 D가 A보다 약간만 좋은데?
평균은 비슷하지만 에피소드별 패턴이 다름. 단순 파도에서 D가 최대 42% 우위. 핵심: D의 해가 '물리적으로 의미 있는 해'. A는 물리 불가능한 답 가능.

12. 용어 사전

Phase-resolved estimation
각 파도의 위치·시점·높이를 결정론적으로 추정. 통계적 추정과 반대.
nRMSE
정규화된 평균 제곱근 오차. 0=완벽, 1=최악.
Dispersion relation
ω = √(g·|k|·tanh(|k|·d)). 긴 파도=빠름, 짧은 파도=느림.
Wavenumber (k)
k = 2π/파장. 클수록 짧은 파도.
Wave steepness (ε)
ε = k·A. <0.07이면 LWT 유효 (Klein 2020).
Beamforming
여러 관측점 데이터를 결합하여 신호 방향 추정.
ETKF
Ensemble Transform Kalman Filter. 앙상블로 불확실성 추정 + 관측 보정.
Raydrop
LiDAR 레이저가 파도 표면에서 반사 실패로 점 누락.
Shadowing
앞 파도가 뒤 파도를 가려 측정 불가.
Synthetic Aperture
선박 이동으로 여러 시점 데이터 누적 → 가상 큰 안테나 효과.
Ablation Study
구성 요소를 하나씩 제거하여 기여도 분석.
Regularizer
최적화에서 답의 범위를 제한하는 장치.
LWT (Linear Wave Theory)
파도를 사인파 합으로 근사. 가장 단순한 파도 이론.
Stokes wave theory
LWT + 고차 보정. 2차는 꼭대기 뾰족/골 평평 효과 추가.
HOS
High-Order Spectral. 비선형 파도 계산. M=1=LWT, M=3=3차 비선형.
PFT
Potential Flow Theory. 비압축·비점성·비회전 유체. Laplace 방정식.
VOF
Volume of Fluid. N-S 방정식의 자유표면 추적. 파쇄 재현 가능.
PINN
Physics-Informed NN. 물리 법칙을 loss에 포함. 데이터 없이 학습 가능.
FNO
Fourier Neural Operator. Fourier 공간에서 전역 매핑 학습.
Adam
