패치 조건**에서 재시도한다. 프로토콜은 실행 전 고정, 결과 불문 보고.

## 고정 가설·신호·정규화 (1호와 동일)

낮을수록 실현 skill 높음).

  미사용 신규 레코드, 12윈도우, AA15a와 동일 스케일 프로토콜

## 고정 판정 (1호와 동일)
- P1(주): pooled Spearman < 0, 단측 p < 0.05.
- P2(보조): median-split 분리 > +0.10.
- 성공 = P1. P1 실패·P2 충족 = "방향성 재현, 미확증". 둘 다 실패 =
  확증 실패.

## 결과 (실행 후 추가 — 프로토콜 무변경)
- n=45 셀. **P1: FAIL** (Spearman −0.209, 단측 p=0.084).
  **P2: FAIL** (split +0.084 < 기준 +0.10; 신뢰 +0.59/위험 +0.51).
- **사전 등록 판정: 확증 실패.**
- 누적 게이트 원장: 탐색 −0.38(p=0.021, split 0.34) → 확증1 −0.11
  (p=0.23, split +0.17, CI 0 포함) → 확증2 −0.21(p=0.084, split
  +0.08). 3개 독립 평가에서 방향 일관·강도 부족.
- 학위/논문 최종 수위: **"방향-일관 예비 발견(preliminary), 사전등록
  확증 2회 기준 미달"** — 게이트를 기여가 아닌 관찰로 서술하고,
  확증 프로토콜·정직 보고 자체를 방법론 기여의 일부로 제시.

## 정오표 (코드 감사 07-06 저녁)
- 프로토콜의 "기존 창과 시간 중첩 없음"은 부정확: YS17 중간점 창의
  W=20 s 추정창이 개발 창과 2.3 s(12%) 겹침 (AA15a/AA14는 무중첩,

  a fortiori 유지된다.
