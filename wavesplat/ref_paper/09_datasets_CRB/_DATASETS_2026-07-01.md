# 공개 데이터셋 평가 — sparse ship-LiDAR 파 추정에 쓸 수 있나 (2026-07-01)

> 질문: 우리 연구(희소 ship-LiDAR phase-resolved 파 추정)에 쓸 공개 데이터가 있나?
> LiDAR 아니어도 유사 데이터를 **sparse하게 만들어** 쓸 수 있나?

## 결론 먼저
- **희소 ship-LiDAR phase-resolved 공개 데이터셋은 없음**(검색상 부재; 우리 보유 110ep도 전부 시뮬·정지).
- **그러나 실측 phase-resolved *공간장*을 sparsify해 쓰는 길은 있음** — 아래 ★가 make-or-break 후보.

## ★ 최우선 후보 — sparsify해서 실측검증 가능
**Bergamasco et al. (2020) "A data set of sea surface stereo images to resolve space-time wave fields",
*Scientific Data* 7.** (오픈, WASS 파이프라인, HAL/PMC/Ifremer 미러)
- **실측 4-D(3D공간+시간) phase-resolved 파고장**, 15–20 Hz, 면적 ~10⁴ m², 여러 해역/해상.
- 선형파이론 가정 없이 직접 표면 측정 → 비선형·rogue 포함.
- **활용**: 이 dense 공간장을 *희소 oblique 라인 + dropout*으로 서브샘플 → **ship-LiDAR 샘플링을 모사**,
  복원 GT는 dense 스테레오장. → **LiDAR 없이도 실데이터 sim-to-real 검증** 가능 (우리 최대 약점=실데이터 해소).
- Caveat: 스테레오 자체 오차/바이어스, 고정 플랫폼(선박운동 없음), 기하 다름 → "모사된 sparse"임을 명시해야.
- 코드: http://www.dais.unive.it/wass/ , 데이터: Scientific Data 링크/Zenodo.

## 보조 후보 (목적별)
- **CDIP (Datawell Waverider, 1991~) / Sofar Spotter (600+ buoy)** — 공개(THREDDS netCDF / Spotter API).
  점·**스펙트럼/방향** 데이터(위상분해 공간장 아님). 용도: *해상태 현실성·방향스펙트럼 검증·HOS 초기화*.
- **One Ocean Expedition (arXiv 2310.03101)** — 선박탑재 초음파 altimeter + 운동/항적/속도/침로, 오픈.
  실측 **선박운동 + 단일점 파고**. 용도: 실측 선박운동 통계·altimeter 교차검증(위상분해 공간장은 아님).
- **Spaceborne SAR sea-state (Nature Sci Data 2020)** — 전지구 통계 해상태. 위상분해 아님(스펙트럼 prior용).
- **Coastal scanning LiDAR (Duck NC topo-bathy; Blenkinsopp/Martins surf-zone)** — 쇄파대, 외해 장 아님.

## 권고
1. **즉시**: Bergamasco 스테레오장을 받아 *희소 oblique+dropout* 서브샘플러를 만들고, 우리 추정기를 실데이터에서
   파일럿 평가 → "sim에서만"이라는 최대 약점을 깨는 첫 발 (make-or-break).
2. CDIP/Spotter로 해상태·방향스펙트럼 현실성 보정(HOS 입력).
3. 장기: SNU 예인수조에서 실제 LiDAR 1세트(진짜 ship-LiDAR sim-to-real).
