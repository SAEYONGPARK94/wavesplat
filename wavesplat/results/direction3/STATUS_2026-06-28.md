## Full narrative (I → III → improvement → deployable)
- **Dir-I CRB:** information wall T_wall(complexity); D_eff = L + c_g·T_obs (slope −1.09);
  predictable-zone = identifiability (≠ geometric cone); not self-diagnosable from one
  window.
- **Bottleneck = information:** NN-as-estimator collapses; grid-free set-diffusion prior
  is the mandatory bias (beats grid + grid-oracle), but scaling it 10× is inert
  (ε-loss floor); post-hoc sharpening fails. Calibrated UQ (global temp → ±1σ 0.68),
  spatially matching the CRB (corr 0.65).
- **Two levers:** active sensing (−69% CRB, −32% achieved on complex seas);
  sequential time fusion (period-scaled window). Non-stationarity is NOT a practical
  limit — sea coherence ~20 min ≫ window (corrected from an earlier wrong ~10–20 s).
- **Deployable estimator:** beamform → RELAX add/prune → off-grid refine → warm-start;
  monotone, self-adapting order; the main result above; CRB-gated hybrid (−15%) as a
  routing alternative.
