# 5. ★대체 PRIMARY — 사전등록 골격 (Q2 답의 핵심)

## 5.0 배치명 `A′ — SELECT vs ROUTE` (희소 전용)

### 팔 (신선 에피소드, 기존 집합과 파일명 교집합 0)

| 셀 | 설정 | 비용 | 역할 |
|---|---|---|---|
| `SHIP` | 출하 기본값 + **`lambda_l1: 1e-4` 명시** · 시드 4개 | 1× | 기준·재시작 재료 |
| `V2K` | `init_method: v2_konly`, 학습 off · 시드 3개 | 1× | 대안 방법 |
| `SHIP-DUP` | `SHIP` 비트 복제 · 시드 1개 | — | 누출 프로브(**0/n 필수**) |
| — 파생(추가 런 0) — | | | |
| `ROUTE` | 레짐 라벨(진값)로 희소→`V2K`, 혼잡→`SHIP` | **1×** | ★**PRIMARY 비교 대상**. 진값 라벨 ⟹ **보수적**(가장 센 형태의 ROUTE 를 이겨야 한다) |
| `SELECT` | `SHIP` vs `V2K` 를 `window_resid` 로 선택 | 2× | ★**처치** |
| `RESTART` | `SHIP` 시드 a vs 시드 b 를 `window_resid` 로 선택 | 2× | SECONDARY(비용정합 널) |

### PRIMARY (**하나**)
> **H0**: 희소에서 `SELECT` 와 `ROUTE` 의 에피소드별 nRMSE 차의 중앙 = 0.
> **H1(방향 동결, 양측 검정)**: `SELECT < ROUTE`.
> **통계량**: 에피소드당 3시드 **중앙** → 짝 Δrel = (SELECT−ROUTE)/ROUTE → **양측 정확 부호검정**(동점 제외).
> **α = 0.05**, PRIMARY 1개 ⟹ **다중비교 보정 없음**.
> **혼잡은 PRIMARY 에서 사전 제외**(파일럿 n_eff=1, 원리적 무정보) ⟹ 서술적 SECONDARY + HARM 점검만.

### ★신규 필수 조항 — `SPLIT-INVARIANCE`
> `RESTART` 계열의 모든 통계량은 **가능한 시드 순서분할 전수**를 인쇄하고,
> **사전등록 분할이 통과하고 동시에 전수의 ≥80% 가 통과할 때만** 판정에 쓴다.
