희소 층은 이 저장소에서 **가장 말이 많이 바뀐 층**이다. 지금 살아 있는 문장 셋:

★**A 는 "표현이 희소에서 과분한 값을 받는다" 고 말하고, `B-16` 은 "표현이 값을 한다" 고 말한다.**
그 둘이 **같은 층에서 처음 만나는 지점**이 이 배치다. 그러므로 결과를 보기 전에
**양쪽 논거와 내 예상**을 적는다.

### 2.1 해칠 것이라는 논거
- 상대 섭동이 두 층에서 **사실상 같다**: 참 성분의 `|k|` 중앙이 혼잡 **0.1927** · 희소 **0.1844**
  ⟹ `Δk₁/|k|` 중앙이 **0.1359 vs 0.1420**(도출 명령은 §4).
- 원자가 적으면 한 원자의 오배치를 **나머지가 보상할 여지가 적다**.

### 2.2 해치지 않을 것이라는 논거
- `B-16` 혼잡에서 스냅 후 **원자가 칸으로 뭉쳤다**(고유 칸 중앙 `KGRID1` 21.5 · `KGRID2` 19.0,
  범위 10–30). 즉 혼잡 손실의 한 기제는 **성분 병합**인데, 성분이 **2~5개**뿐인 희소에서는
  칸 충돌이 거의 일어나지 않는다 ⟹ **그 기제가 빠진다.**
- 원자가 적을수록 스냅 후 `(w,φ)` **LS 재적합의 자유도 대비 관측 수 비율이 좋다** ⟹ 보상이 쉽다.

### 2.3 ★내 예상 (결과 전, 이름 걸고)
> **해친다. 그러나 혼잡보다 승수도 크기도 작다** — 병합 기제가 빠지므로.
> 구체적으로 `SHIP-NOW < KGRID1` 을 **12~14/16** 으로 예상한다.

⚠`B-11b` 에서 **내 예상이 정확히 반대 방향으로 틀렸다.** 그때 예상을 적어 둔 덕분에
과대 인용을 막았다. ⟹ **이번에도 적는다. 예상이 판정을 대신하지 않는다.**

### 2.4 ★결과 전 해석 규칙 — **세 방향 전부 좋은 결과다**
1. **해치면**(`w ≥ 12`) ⟹ ★***기여 ①이 두 층에서 절제로 지탱된다.*** 희소 우위가
   "기준선이 못해서" 만이 아님을 **우리 팔 안에서** 보인다(`B-11b` §C 의 미해결 부분에 자료가 붙는다).
2. **널이면**(`5 ≤ w ≤ 11`) ⟹ ***"연속 파수는 혼잡 층에서만 값을 한다"*** = **작동 경계**다.
   ⛔**나쁜 소식으로 쓰지 마라.** 이 논문의 주제가 *"학습된 스펙트럼 사전과 그 작동 경계"*
   이므로 경계를 하나 더 그은 것이고, 동시에 §2.2 의 **병합 기제 가설을 지지**한다.
3. **해치지 않으면**(`w ≤ 4`) ⟹ ***"희소에서 이긴 것은 표현이 아니라 적합 절차다"***.
   그 경우 논문 기여 ① 의 문안에 **층 한정어**를 넣어야 한다(혼잡 한정).
⛔**어느 결과에서도 `B-16`(혼잡) 판정을 대체하거나 수정하지 않는다.** 다른 층이다.
⛔**어느 결과에서도 `B-11b`(기준선 대비) 판정을 대체하지 않는다.** 이 배치에 외부 기준선은 **0개**다.

## 4. 격자 간격 — **희소 코퍼스에서 다시 도출했다** (결과 전)
⚠**소제목의 *"손복사 아님"* 은 2026-08-26 에 철회했다 — §4.1.**

⚠임무 지시대로 *"희소 층의 채점 격자가 다르면 dk 도 달라진다"* 를 **먼저 확인했다.**

```
python3 - <<'PY'   # 런 0회, 자료만 읽는다
import h5py, numpy as np, glob, os
rows = {}
for p in sorted(glob.glob('tmp/HOSGATE_2026-08-13/data_hos/*.h5')):
    with h5py.File(p, 'r') as h:
        gx = h['frames/gt_grid_x'][:]; gy = h['frames/gt_grid_y'][:]
    rows.setdefault((gx[0], gx[-1], len(gx), gy[0], gy[-1], len(gy)), []).append(p)
for k, v in rows.items(): print(k, len(v))
PY
```
**출력: 격자가 단 하나다 — `(10.0, 250.0, 80, −100.0, 100.0, 60)`, 64/64 에피소드.**
⟹ 희소 16개와 혼잡 48개가 **완전히 같은 채점 격자**를 쓴다.

`Δk = 2π/L` ⟹ **Δk_x = 2π/240 = 0.0261799…** · **Δk_y = 2π/200 = 0.0314159…**
- `DK1` = **0.02618** (= `gates_b16.DK1`, 두 축 중 **더 고운** 쪽)
- `DK2` = **0.05236** (= `gates_b16.DK2`, 2배)

### 4.1 ⚠**`DK1`/`DK2` 는 반올림된 손복사 리터럴이다** (2026-08-26 정정)

⛔**초판이 *"`gates_b16` 에서 import 한다(손복사 0)"* 라 적은 것은 거짓이었다.**
`gates_b16.py:48-49` 가 `DK1 = 0.02618  # = 2π/240` 이라는 **손으로 반올림한 리터럴**이고,
**남의 손복사를 import 하는 것은 손복사 0 이 아니다.**

★**그럼에도 도출식(`2*math.pi/240`)으로 바꾸지 않는다. 사유 둘**:
1. `DK1` 은 문서용 상수가 아니라 **개입값 그 자체**다. `B-16` 은 이미 `0.02618` 로 **돌았다**.
   값을 바꾸면 §3 이 선언한 *"개입은 `B-16` 과 **동일**"* 이 깨지고 두 층의 절제가 서로 다른
   격자가 된다.
2. `gates_b16.py` 는 **이미 돌아간 배치의 동결 파일**이다. 고치면 그 배치의 팔 정의가 실제로
   돌아간 것과 달라진다(= 재현 불가). ⟹ **그 파일은 건드리지 않았고 `B-16` 판정은 무손상**이다.

⟹ **대신 정직하게 계측한다.** `G-10` 이 16 에피소드 각각에서 `2π/Lx` 를 **자료에서 재도출**해
대조하고 **반올림 편차의 실측값을 게이트 상세에 적는다**. 런 전 실측:

| | 값 |
|---|---|
| `DK1` (리터럴) | 0.02618 |
| `2π/240` (재도출) | 0.026179938779914945 |
| 절대 편차 | **6.122e-08** |
| 상대 편차 | **2.338e-06** |
| G-10 허용오차 `1e-5` 대비 | **0.0061배** (= 허용오차의 1/163) |
| 이 배치가 재는 상대 섭동 `Δk₁/\|k\|` ≈ 0.142 대비 | **약 1.6e-05 배** |

⟹ **수치적으로 무해**하다. ⚠단 이것은 *"손복사가 없다"* 가 아니라
***"손복사가 있고, 그 크기를 쟀으며, 재도출로 대조한다"*** 는 뜻이다. λ 3중 기재와 같은
결함 부류이므로 **그렇게 적어 둔다.**

★**등방 스냅의 비대칭이 희소에서도 같은 방향인가 — 확인했다.**
격자가 동일하므로 **y 축에는 실제 기준선(0.03142)보다 고운 격자를 주는 것**이 그대로 성립한다
⟹ **우리 팔에 유리한 조건**이고, 그래도 해치면 주장이 강해진다. 그리고 §2.1 의 `|k|` 분포가
두 층에서 사실상 같으므로 **상대 섭동의 크기도 같은 자리**에 있다. 도출:

```
python3 - <<'PY'
```

## 6. 판정 (결과 전 확정, n=16, 단측 부호검정, `math.comb` 로 **코드가** 계산)

⛔**`B-16` 의 48-표본 문턱(31/34/17)을 쓰지 않는다.** `gates_b19.thresholds(n)` 이
`n` 에서 직접 낸다(형제 규약: `NOMINAL` = p≤0.05 최소 · `CONFIRM` = p≤가족단위 α 최소 ·
`NOT_EARN` = `n − NOMINAL`, `B-12` §판정의 *"WEAK = n − NOMINAL"* 을 상속).

`n=16`: `12/16 → p=0.038406` · `13/16 → p=0.010635` · `4/16 → 반대 꼬리 대칭`

- **PRIMARY** = `SHIP-NOW < KGRID1` 인 에피소드 수 `w`
  - `w ≥ 13` ⟹ ★**`CONTINUOUS-K-EARNS-SPARSE`** (가족단위 α = 0.05/2 = 0.025 통과)
  - `w = 12` ⟹ ⚠`CONTINUOUS-K-EARNS-SPARSE-NOMINAL` (명목만, 탐색적)
  - `5 ≤ w ≤ 11` ⟹ `ATTRIBUTION-UNDECIDED-SPARSE`
  - `w ≤ 4` ⟹ ⛔**`CONTINUOUS-K-DOES-NOT-EARN-SPARSE`**
- **SECONDARY(용량-반응)** = `KGRID1 < KGRID2` 인 수 `≥ 12` ⟹ `DOSE-RESPONSE` (아니면 `NO-DOSE-RESPONSE`)

**가족단위 α = 0.05 / 2 = 0.025** — 주장은 둘(PRIMARY·DOSE)이다. **음성 대조는 게이트이지
주장이 아니므로 세지 않는다**(`B-15`·`B-16` 규약 상속).

⚠**표본 손실 규칙(결과 전)**: 라우팅 오염·개입 미발화로 제외되는 에피소드가 생기면
PRIMARY 는 남은 `n_used` 에서 계산하고 문턱을 `thresholds(n_used)` 로 **다시 낸다**.
`n_used < 14` 이면 판정은 **`SAMPLE-LOSS-UNDECIDED`** 다(문턱 재계산으로 결론을 사지 않는다).

### 6.1 ★동점 규칙 (결과 전) — **희소 층에서만 생기는 문제**

원자가 **1–5개**뿐이면 `dk` 격자와 `2dk` 격자가 **같은 점으로 반올림**될 수 있다

⚠이 규칙은 **양성 주장을 쉽게 만들지 않는다** — 동점은 `NO-DOSE-RESPONSE` 를
`UNDECIDABLE` 로 바꿀 수 있을 뿐 `DOSE-RESPONSE` 로 바꾸지 못한다.
