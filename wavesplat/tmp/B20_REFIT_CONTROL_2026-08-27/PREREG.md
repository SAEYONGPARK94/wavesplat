### 3.1 팔 (`gates_b20.ARMS` — ⛔빈 dict 로 정의하지 않는다)

★**`SHIP-NOW` 를 팔 순서 맨 앞에 둔다** — 러너의 온라인 드리프트 검사가 **첫 런**에서 발화하도록.

★**배포 상수는 명시한다**(런타임 스냅샷 아님): `varpro_steps=400` · `learned_init_iters=0` ·

읽어(`gates_b19.deploy_constants()`) 설정에 넣고, `G-5d` 가 그 값을 이 배치의 핀과 대조한다.

### 3.2 ★`DK0` — **손으로 고르지 않았다** (임무 지시의 `1e-6` 을 4 자릿수 개선했다)

임무 지시는 `k_snap_dk = 1e-6` 을 제안하며 *"그 값이 정말 no-op 인지 코드에서 확인하라 …
부적절하면 **더 나은 값을 도출하고 사유를 적어라(손으로 고르지 말 것)**"* 라 적었다.
**확인한 결과 `1e-6` 은 부적절하다.** 실측(런 0회, 단위 수준 탐침, 무작위 현실적 파수 12개):

| `dk` | `shift_max` | float32 파라미터에서 **비트 동일한 원자** |
|---|---|---|
| 1e-5 | 5.80e-06 | 0/12 |
| **1e-6 (제안값)** | 5.99e-07 | **0/12** |
| 1e-7 | 5.34e-08 | 0/12 |
| 1e-8 | 4.95e-09 | 7/12 |
| **1e-9** | 6.78e-10 | **12/12** |
| 1e-10 | 5.89e-11 | 12/12 |

⟹ `1e-6` 에서는 **모든 원자의 파수가 실제로 움직인다**(|k|≈0.18 에서 약 **27 float32 ulp**).
그러면 `NOOP-REFIT` 은 *"재적합만"* 이 아니라 *"재적합 + 아주 작은 파수 섭동"* 이 되고,
심사가 지목한 바로 그 결함(**두 가지가 동시에 바뀐다**)을 규모만 줄여 되풀이한다.

★**대신 물리적 기준을 세워 도출한다** (`gates_b20.derive_dk0()`, 런 0회 · 자료에서 계산):

> **요구**: 파수 섭동이 **렌더된 파랑장을 float32 정밀도에서조차 바꿀 수 없어야 한다.**

장은 η = Σ w·cos(kx·x + ky·y − ω·t + φ), ω = √(g|k|tanh(|k|d)) 이므로 격자 반올림
(성분마다 |δk| ≤ dk/2, 벡터로 |δ**k**| ≤ dk/√2)이 만드는 **최대 위상 오차**는

```
Δψ_max ≤ (dk/2)·L ,   L = (|x|max + |y|max) + √2·max|dω/dk|·t_max
```

자료에서 재도출한 값(희소 16 에피소드 **전부** 동일):

| | 값 | 출처 |
|---|---|---|
| `|x|max`, `|y|max` | **250.0**, **100.0** m | `frames/gt_grid_x`, `gt_grid_y` |
| `t_max` | **30.0** s | `frames/timestamps` |
| `depth` | **50.0** m | `config.attrs['depth']` |
| `max dω/dk` (\|k\|≥0.01) | **19.7035** m/s | `dispersion.G` 단일출처로 수치 미분 |
| **L** | **1185.9504** | 위 식 |
| 상한 = 2·2⁻²³/L | **2.0104e-10** | |
| ★**그 아래 최대 10의 거듭제곱 = `DK0`** | **1e-10** | |

- `DK0 = 1e-10` ⟹ **Δψ_max = 5.93e-08 rad = 0.497 × float32 eps** ⟹ ★**렌더 장의 마지막
  비트도 못 바꾼다.**
- 제안값 `1e-6` ⟹ Δψ_max = **4974 × float32 eps** (장에서 검출 가능).
- 대조군 `DK1 = 0.02618` ⟹ Δψ_max = **15.52 rad = 2.47 주기** (완전한 위상 교란). 비 **2.6e8**.
- **10의 거듭제곱으로 내리는 이유**: 상한 바로 밑의 임의 실수보다 재현·기술이 쉽고, 아래쪽
  수치 하한(`round(k/dk)` 가 2⁵³ 근처로 가는 것)에서 **10¹⁰ 배 이상** 떨어져 있다.
  (`|k|/DK0 ≈ 2e9 ≪ 2⁵³ ≈ 9e15`.)
- ⚠`max dω/dk` 의 `|k|` 하한을 0.01 → 0.005 → 0.001 로 바꿔도 **거듭제곱은 1e-10 으로
  불변**이다(상한 2.010e-10 → 1.891e-10 → 1.851e-10). ⟹ 그 선택이 결과를 사지 않는다.

★**`G-17` 이 이 도출을 자료에서 **다시** 해 핀과 대조한다** — 코퍼스가 바뀌면 배치가 멈춘다.
★**그리고 게이트가 추론을 대신한다**: `G-15` 는 위 상한이 아니라 **런에서 실제로 측정한**
원자별 Δψ_max 를 검사하고(§8), `G-15b` 는 더 강한 형태(**float32 파라미터 비트 동일**)를 잰다.

### 3.3 ⚠`NOOP-REFIT` 이 정확히 무엇을 켜는가 — 정직하게

`_snap_k_to_grid` 는 파수 반올림 외에 **셋**을 더 한다. `NOOP-REFIT` 은 그 **셋을 전부** 켠다:
1. `(w,φ)` ← `ls_fit_wphi`(무가중 · ridge 0.5) — **주 성분**
2. VARPRO 의 **가파름 클램프 결과가 `w` 에 대해 취소**된다(스냅 뒤 클램프가 없다)
3. `_build_tracking_optimizer()` 재호출 — ⚠**거동 무변화**: 그 시점의 Adam 은 스텝을 한 번도
   밟지 않았으므로 상태가 동일하고, 파라미터 텐서는 `copy_` 로 제자리 갱신돼 참조가 유지된다.

⟹ ★**이 배치가 "재적합" 이라 부르는 것은 정확히 1+2 다.** 그것이 `B-16`/`B-19` 의 절제 팔이
파수 양자화와 **함께** 받은 처치의 전부이므로, 통제로서 옳다.
⛔*"오직 ridge 0.5 만"* 이라고 쓰지 마라.

### 3.4 난수 소비
`_snap_k_to_grid` 는 난수를 **소비하지 않는다**(`np.round` · `np.linalg.solve` · `torch.copy_`).
`_build_tracking_optimizer` 도 마찬가지다. 성장/가지치기의 난수 위상(`:1193`)은 스냅 **앞**이다.
⟹ **세 팔의 난수 소비가 동수**다. ★그리고 그것은 추론이 아니라 **측정된다**:
`G-11`·`G-11b` 가 `SHIP-NOW`(스냅 미발화)와 `KGRID1`(스냅 발화)이 **둘 다** `B-19` 동결 행과
비트 동일임을 요구한다 — 스냅이 공유 난수열을 건드렸다면 그것이 깨진다.

## 5. 판정 — **주장 둘** (문턱은 `gates_b20.thresholds(n)` 이 `math.comb` 로 직접 낸다)

n=16 단측 부호검정: `12/16 → p=0.0384063720703125` · `13/16 → p=0.010635…` · `4/16` = 반대꼬리 대칭.
⟹ **`(NOMINAL, CONFIRM, NOT_EARN) = (12, 13, 4)`**. `G-18` 이 이 핀과 형제 배치(`B-19`)를 대조.

- **PRIMARY-A** — `w_A` = `SHIP-NOW < NOOP-REFIT` 인 에피소드 수.
  ***재적합 단독이 해치는가*** = **교락 검출**.
- **PRIMARY-B** — `w_B` = `NOOP-REFIT < KGRID1` 인 에피소드 수.
  ***적합 절차를 고정한 채 파수 양자화가 해치는가*** = **교락 없는 절제**.
- **T**(재현 확인, **주장 아님**) — `SHIP-NOW < KGRID1`. `B-19` 와 같아야 한다(§4.1).

**가족단위 α = 0.05/2 = 0.025.** 주장은 둘이다. 음성대조는 게이트이지 주장이 아니다.

### 5.1 ★**A 의 검출 문턱은 보정하지 않는다** (결과 전, 사유)
A 의 *"좋은 소식"* 가지는 **널**(교락 없음)이다. 널은 검정으로 증명되지 않으므로,
**보정으로 문턱을 올리면 널 주장을 *쉽게* 만드는 방향**이 된다. ⟹ A 의 **검출**은
**무보정 α=0.05(NOMINAL=12)** 로 한다 — 즉 *"교락이 있다"* 를 **가능한 한 쉽게** 잡는다.
가족단위 보정(CONFIRM=13)은 **양성 주장 둘** — A 의 `HELPS` 가지(`w_A ≤ n−13 = 3`)와
PRIMARY-B — 에만 건다. ★이 비대칭은 **일부러 보수적**이고, 결과 전에 코드에 박혀 있다.

### 5.2 ⚠표본 손실 규칙
라우팅 오염·개입 미발화로 제외되는 에피소드가 생기면 `n_used` 에서 문턱을 **다시 낸다**.
`n_used < 14` 이면 판정은 **`SAMPLE-LOSS-UNDECIDED`** 다(문턱 재계산으로 결론을 사지 않는다).

### 5.3 ⚠동점 규칙
strict `<` — 동점은 승리로 세지 않는다(`B-16`·`B-19` 상속). 동점 때문에 문턱이 **산술적으로
도달 불가**해지면(`n − n_tie < NOMINAL`) 라벨은 `UNDECIDABLE-TIES` / `QUANT-UNDECIDABLE-TIES`
이고 ⛔**널을 "효과 없음" 으로 읽지 않는다.**
★특수 분기: `n_tie_A == n`(= `NOOP-REFIT` 이 `SHIP-NOW` 와 전건 비트 동일)이면
`REFIT-IS-EXACTLY-A-NOOP` — 단 그 상태는 `G-16` 이 **FAIL 로 잡으므로 먼저 배선을 의심하라.**

## 6. 음성 대조 둘 — 그리고 **왜 하나만 무효화하는가**

`ZERO` = **참 제로필드 기준**. 채점 창(`t > 2·Tp`) 프레임마다 `nRMSE(0, gt, Hs_true)` 를
계산해 평균한다(`gates_b19.zero_nrmse` 를 **그대로** import).
⛔**상수 `1.0` 을 쓰지 않는다** — 2026-08-23 실측에서 계수 전건이 철회된 부류다.

| | 검정 | 문턱 | 실패 시 |
|---|---|---|---|
| **N-1** | `SHIP-NOW < ZERO` | ≥ 12/16 | ⛔**A·B 모두 무효** → `ARM-NO-SKILL-HERE` |
| **N-2** | `NOOP-REFIT < ZERO` | ≥ 12/16 | ⚠**무효 아님 — B 의 라벨에 `-NO-SKILL-BASE` 접미** |

**N-1 이 하드 무효화인 이유**: 절제·통제는 *"작동하는 시스템에서 성질 하나를 빼면 얼마를
잃는가"* 를 잰다. 원 팔이 무기술이면 **뺄 것이 없다**.

**N-2 를 하드 무효화로 하지 않는 이유**(`B-19` §7 상속): `NOOP-REFIT` 은 독립 방법이 아니라
**우리 팔의 처치본**이다. 그것이 무기술로 떨어지는 것은 *처치가 강했다*는 뜻이므로,
무효화 조건으로 걸면 **효과가 클수록 판정이 무효가 되는 단조 역전 게이트**가 된다.
⟹ 대신 라벨을 갈라, 그 경우 ⛔**B 의 상대 중앙 %를 margin 으로 인용 금지**로 표시한다.
(보고용으로 `KGRID1 < ZERO` 도 싣는다 — 판정에 쓰지 않는다.)

### 7.6 ★서술로만 싣는 것 (검정 아님)
1. **로그 분해** — 에피소드마다 **정확히 가법**이다: `ln(K/S) = ln(N/S) + ln(K/N)`.
   중앙값 셋과 **담지자 몫** `median(d_refit)/median(d_total)` 을 싣는다
   (분모 가드 `|d_total| ≥ ln 1.05`; 가드에 걸린 에피소드 수도 싣는다).
2. **`NOOP-REFIT` 이 `KGRID1` 에 얼마나 가까운가** — 위 몫이 그 답이다.
   ★몫이 **1 에 가까우면 손해의 담지자가 재적합**이라는 강한 증거이고, **0 에 가까우면
   담지자는 파수 양자화**다. ⛔이 몫에 p 를 붙이지 않는다.
3. 재적합의 크기 자체 — `|Δw|max` · `|Δφ|max` 중앙값(훅 2 가 파라미터에서 직접 잰다).

### 7.7 ★**어느 쪽이든 논문이 좋아진다** — 이 배치의 정당성
- **A 가 널이면** `B-16`/`B-19` 의 **크기가 인용 가능해진다**(지금은 방어가 논증뿐이다).
- **A 가 교락을 잡으면** ⛔옛 크기는 죽지만, **PRIMARY-B 가 교락 없는 새 크기를 준다.**
- ⟹ ★***이 배치는 빈손으로 돌아올 수 없다*** — 인용 가능한 절제 크기가 **항상 하나 남는다.**
  단 하나의 예외가 `QUANTIZATION-DOES-NOT-EARN` 이고, 그것은 **기여 ①이 틀렸다는 발견**이라
  그 자체로 이 배치의 최대 산출이다.
