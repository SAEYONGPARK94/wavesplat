# B-2d — **모델 차수는 최악의 실패를 구하되 균일하게 돕지 않는다** (36런, 2026-08-23) · `PARTIAL`

가설(러너 독스트링에 **결과 전** 기재): *"실측 한계는 모델 차수가 자료에 비해 과하기 때문이다."*
근거: `B-2c` 가 λ 를 후보에서 지웠고, 코드 확인상 **`PROP` 경로에는 잡음 모형이 없다**
(신뢰도 전부 1, 벌점 무효) ⟹ **가중 없는 최소제곱**이므로 자유도가 남으면 잡음을 적합한다.
실측 소형 박스는 질의점이 **16–25개**인데 원자를 **16–30개** 세운다.

## 2. ★★이것이 오늘 아크에서 갖는 자리

| 후보 | 판정 |
|---|---|
| 개구/λ | ⛔**널**(`APERTURE_AXIS`) |
| 파장 λp | ⛔**교락**(`B-2b`: 잡음만 낮춰도 회복) |
| 벌점 λ | ⛔**매개 안 함**(`B-2c`: 없애도 동일) |
| **관측 잡음** | ✅**원인**(`B-2b`: 7→10/12, p=0.039) |
| **모델 차수** | ⚠**부분** — 최악을 구하되 균일하지 않음(본 배치) |

⟹ ★**두 후보가 남았고 둘은 같은 것의 두 얼굴이다**: *"자유도가 자료에 비해 많다."*
잡음을 줄이면 적합할 잡음이 줄고, 차수를 줄이면 적합할 자유도가 준다. **둘 다 듣는다.**

## 3. ★★처방과, 그 처방이 왜 지금까지 안 보였는가

처방 = **자료에 맞춘 적응적 차수**. 저장소에 `adaptive_n` 이 **이미 있다.**
⛔**그런데 그것은 2026-08-03 에 합성에서 `NULL` 로 측정됐다.**
★***이유가 이제 보인다 — 합성 코퍼스에는 "자료가 얇은 레짐" 이 없었다.***
합성 질의 격자는 수백~수천 점인데 실측 소형 박스는 **16–25점**이다.
⟹ ★**죽은 축이 실측에서 되살아난다.** 단 **이 배치는 적응적 차수를 시험하지 않았다**(고정 상한만).
