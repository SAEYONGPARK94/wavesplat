## 4. 집계 규약 (동결 — 결과를 본 뒤 **변경 금지**)

1. **시드 → 에피소드**: 중앙(median-of-3).
2. **수준값**: 에피소드 중앙들의 중앙 (medOfMed).
3. **효과**: **짝지은** 에피소드별 `Δ(ep) = median_seeds[cell](ep) − median_seeds[AUTO](ep)`
   의 **중앙**. 즉 **개입 − 대조**.
4. **방향 (명시적으로 못 박음)**
   - `nRMSE`: **Δ < 0 = 개입이 더 좋다**. `k/n` = Δ<0 인 에피소드 수 ("승").
   - `Pearson_rho`: **Δ > 0 = 개입이 더 좋다**.
   - `|VR−1|`(프레임별로 형성 후 평균, `absVR_framewise`): **Δ < 0 = 개입이 더 좋다**.
   - `m_mean`, `decorr_mean`, `shrink_mean`: **Δ < 0 = 개입이 더 좋다**.
5. **검정**: 짝지은 **부호검정, 양측**. 동점(Δ=0 정확히)은 **불리하게** 처리한다(승으로 세지 않고 n 에는 남긴다).
6. **상대 효과**(층 간 오차 규모가 25배 차이나므로 **병기 의무**):
   `Δrel(ep) = Δ(ep) / median_seeds[AUTO](ep)` 의 중앙. 서술 전용.
7. 벽시계는 기록하되 **성능 주장에 쓰지 않는다**.

### 평평한 바다 널 — 병기 의무 + 배제 규칙
널 = `tmp/B2_g1p1_ext_2026-08-06/nulls12.json` 의 `zero_null_tracking_nRMSE_mean` (12/12 커버, 재사용).

  **미배제 전체 블록도 병기**한다(투명성). 배제는 대조 셀로만 결정한다(개입 셀로 결정하면 선택 편향).

  그 셀은 그 블록에서 **NULL-FAILING** 으로 표시하고 **결과로 보고하지 않는다**.

## 7. 합격선 (결과 보기 **전** 확정)

표적 대조 = **`AUTO-NOTRACK` vs `AUTO`** (추적기 완전 정지 vs 출하).

### PRIMARY — 전체 12 (§4(a) 배제 적용 후)
- **MATTERS** iff \|짝 Δ 중앙\| **≥ 0.0134** **그리고** k ≥ 11/n (또는 ≤ n−11, 즉 반대 방향).
- **NULL** iff \|짝 Δ 중앙\| **< 0.0134** **그리고** k 가 **동전던지기 밴드** (n=12 기준 4 ≤ k ≤ 8).
- 그 사이는 **INCONCLUSIVE**. 승격하지 않는다.

### CO-PRIMARY — 혼잡 층 (ncomp 15–30, §4(a) 배제 적용 후)
- **MATTERS** iff \|짝 Δ 중앙\| **≥ 0.0329** **그리고** 부호가 **만장일치**(k = n 또는 0).
- **NULL** iff \|짝 Δ 중앙\| **< 0.0329** **그리고** k 가 만장일치가 아니다.
- 그 사이는 **INCONCLUSIVE**. ⛔이 블록에 "유의" 금지.

### 판정이 갈리면
PRIMARY 와 CO-PRIMARY 가 다르면 **갈린 대로 보고**한다. 한쪽을 골라 헤드라인으로 쓰지 않는다.
