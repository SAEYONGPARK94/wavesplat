`RESULT_G3.md`(커밋 `67166fd`)가 **런 0회로** 확정했다. 요지만:

- 조우주파수를 실제로 만들면 도출대로 작동한다(정지 대조 통과, 예측 0.0310 / 측정 0.0314).
- ★**선언된 작동점(U=11.3 m/s · BF4 · following)에서 조우주기 202.7 s** ⟹ 30 초 에피소드가
  사이클의 **0.15** 만 덮는다. head 는 **8.72** 사이클 = **58배**. 그리고 **BF4 는 BF2–BF5 중
  유일한 최소점**이고 퇴화점(`Tp=7.24 s`)에서 **3% 안**이다.
⟹ **아직 모르는 것은 성능이다.** 이 배치가 그것을 잰다.

## §1 PRIMARY — 단 1개
> **PRIMARY**: 설계 선속 **`U = 11.3 m/s` · following (`direction_deg=0`)**, 즉 **선언된 작동점**에서
> **`SHIP < ZERO`** 인가.
- 짝(에피소드) 단위 **정확 이항 부호검정, 단측**, `H1: SHIP < ZERO`, **α = 0.025**.
- **혼잡 층 n = 16**, 문턱 **13/16**(`p = 0.010635 < 0.025`). 동점은 `n` 에서 제외.
- 자: `avg_nRMSE`, 추정기 시드 **median-of-3**(`reference` 규율: CV 53%).
- ⛔**PRIMARY 는 1개다.** 다중성 보정 없음.

### §1.1 왜 이 질문인가 (그리고 왜 VARPRO 가 아닌가)
- 심사 위험질문 1번은 **범위**다: *"조우를 한 번이라도 쟀는가."* `SHIP<ZERO` 가 그 질문의 최소 단위다.
- ⛔**VARPRO 를 PRIMARY 로 두지 않는다** — 미출하이고, 조우 기하 × 미출하 처치는 **미지수를 곱한다**.
- ★**이 PRIMARY 는 죽을 수 있다**(§1.2). 통과가 확실한 PRIMARY 는 정보가 없다.

### §1.2 ★사전 선언한 대안설명 — `V2K` 팔이 **선택이 아니라 필수**
체크포인트는 **정지 센서 자료로만** 학습됐다. 따라서 `SHIP` 이 조우 기하에서 실패해도 그것이
**기하 탓인지 분포이탈(OOD) 탓인지** 구분되지 않는다.
⟹ **`V2K`(`init_method='v2_konly'`, 학습 없음) 팔을 같은 셀에 둔다.**
- `SHIP` 실패 **&&** `V2K` 통과 ⟹ **OOD**(체크포인트 문제).
- `SHIP`·`V2K` 동반 실패 ⟹ **기하**(방법 문제).
- 이 분해는 **결과 전에 기재**했으므로 사후 선택이 아니다.

## §3 코퍼스 — 2×2 요인, 짝
| | following (`dir 0`) | head (`dir 180`) |
|---|---|---|
| **`U = 0`** (정지 = 기존 전 배치의 기하) | 셀 A | 셀 B |
| **`U = 11.3`** (설계 선속) | ★**셀 C = PRIMARY** | 셀 D |
- **같은 시드·같은 성분**을 네 셀에 쓴다 ⟹ 짝지음이 성립하고 `U` 와 방향이 분리된다.
- ⚠**`U` 만 바꾸면 개구가 쓸고 지나간 면적도 바뀐다**(교락). ⟹ **같은 `U` 안에서
  following↔head 대조가 조우주파수의 유일한 비교락 추정치**다. 셀 간 절대값 비교는 §6 에서 금지한다.
- 혼잡 층 **n = 16**, `BF4`, 15성분, 30.0 s / 0.1 s, depth 50, `n_pts=50`, `uniform` raydrop,
  `direction_spread_deg=30`, `random_amplitudes/frequencies/decorrelate_stream` 전부 True (=배치 표준).
- 시드: 에피소드 **1598–1613**, 추정기 **1614–1616**(median-of-3) ⟹ 원장 잔여 **[1617–1818]**.
