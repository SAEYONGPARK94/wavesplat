## 2. Q-A — Golub–Pereyra 킬이 척추까지 삼키는가

### 2.1 결론: **삼키지 않는다. 그런데 그게 좋은 소식이 아니다.**

P2 의 킬은 **"VARPRO 가 배포 팔보다 낫다"** 라는 **결과**를 겨눈다:

> *"…results in a **better-conditioned problem**. **The same optimization method applied to the original
> and reduced problems will always converge faster for the latter.**"*
> — Golub & Pereyra, *Inverse Problems* **19** (2003) R1, 초록 (**내가 WebFetch 로 독립 재확인, `VERIFIED`**)

척추는 다른 문장이다: **"벽이 어디 있는가"** 라는 **진단**이다. GP 초록은 어느 하위공간이 벽인지 말하지 않는다.
⟹ `ARGUED`: **논리적으로 두 문장은 독립이다. P2 의 킬은 척추를 삼키지 못한다.**

### 2.2 ⛔그러나 척추는 **다른 데서** 죽는다 — 그리고 사인은 더 무겁다

P2 의 킬은 *"당신 결과는 1973년에 예측됐다"* 다 — **결과가 참임을 전제**한다.
내 킬은 *"당신 진단의 두 단어가 자기 자료와 자기 코드에 의해 반증된다"* 다.
**심사위원 입장에서 두 번째가 훨씬 나쁘다** — 전자는 기여의 크기를 깎고, 후자는 **저자의 문제 이해를 의심하게 만든다.**

⟹ ★**우선순위 판정: 척추를 그 이름으로 쓰는 것은 GP 인용보다 위험하다.**

## 3. ★★★Q-B·Q-C — 척추는 "위상"도 "비볼록성"도 살 수 없다

### 3.1 전방모델이 그렇게 생겼다 (`MEASURED`, 코드)

`wavesplat/model/spectral_gaussian.py:5`·`:118-127` (forward):

```
z(x,y,t) = Σᵢ wᵢ · cos(kxᵢ·x + kyᵢ·y − ωᵢ·t + φᵢ),    ωᵢ = √(g|kᵢ|·tanh(|kᵢ|d))
```

`θᵢ := kxᵢx + kyᵢy − ωᵢt` 로 두고 `aᵢ := wᵢcos φᵢ`, `bᵢ := −wᵢ sin φᵢ` 라 하면

```
wᵢcos(θᵢ+φᵢ) = aᵢ cos θᵢ + bᵢ sin θᵢ
```

⟹ ★**`k` 를 고정하면 잔차는 `(a,b)` 의 아핀함수이고 제곱손실은 볼록(정확히는 볼록 이차식)이다.**
`ARGUED`(초등 대수, 아래 §3.2 가 코드로 확인).

**벌점도 볼록이다** (`MEASURED`, `sequential_update.py:350-358`):
`λ_l1 Σ|wᵢ| = λ_l1 Σ‖(aᵢ,bᵢ)‖₂` = **group-lasso(ℓ2,1) 노름** ⟹ 볼록.
⟹ **데이터항 + ℓ1 벌점은 `k` 고정 시 전체가 볼록 문제다.**

⚠**정직한 예외 하나**: `lambda_smooth Σ(w_sorted[i+1]−w_sorted[i])²`(`:361-368`)는
`w=√(a²+b²)` 를 통해 들어가므로 `(a,b)` 에서 **볼록이 아니다.**
그러나 S5 가 그 몫을 쟀다 — 혼잡 `AUTO-NT-NOREG − AUTO-NT` 총 −0.02399 중 smooth 몫은 **−0.00155(6.5%)**
(`MEASURED`, S5 원자료 재집계). ⟹ **볼록성 논증을 흔들 크기가 아니다.**

★**최적화 이론의 문장으로**: 진실 `θ*` 에서 출발해 하강이 떠나면 `∇L_train(θ*) ≠ 0` 이다.
이는 **`θ*` 가 훈련 목적함수의 정류점이 아니라는 진술**이고, **지형이 볼록인지와 무관**하다.

⟹ ⛔**"진실보다 나쁜 곳에서 멈춘다" 로부터 "비볼록"을 연역할 수 없다.** `ARGUED`, 그리고 §3.7 이 실측으로 뒷받침.

## 4. Q-D — W6 의 포락선 정리 검증

### 4.1 증명은 **옳다** (`MEASURED`, 내 독립 재도출)

W6 `RESULT.md` §2.1 의 논증:
`f(k) = min_c ‖Φ(k)c − z‖²`, `c* = argmin` ⟹ `∂f/∂c|_{c*} = 0` ⟹
`df/dk = ∂f/∂k|_{c=c*} + (∂f/∂c)|_{c*}·dc*/dk = ∂f/∂k|_{c=c*}`.

**나는 이것을 잔차 형태로 독립 재도출했다**: `r = Φc* − z`, 정규방정식 `Φᵀ r = 0` ⟹ `r ⊥ range(Φ)` ⟹
`2rᵀΦ·(dc*/dk) = 0`. ✅**동일 결론. 증명 옳다.**

**그리고 검사는 공허하지 않다** (`MEASURED`, `als_patch.py`·`RESULT.md` 표):
ridge 를 키우면 `c*` 가 참 최소점에서 밀려나고 차이가 **정확히 비례해서** 나타난다
(1e-8 → 3.7e-11, 1e-4 → 3.7e-07, 1 → 3.7e-03, 100 → 1.9e-01). ⟹ **시험의 민감도가 입증됐다.**

### 4.2 ★그러나 **범위를 정확히 적어야 한다** (`ARGUED`, 내 정정)

W6 `RESULT.md` §3 은 *"VARPRO 의 이득 중 '문헌이 예측하지 않은 부분'은 **없다**"* 라고 적는다.
⚠**이 문장은 증명보다 넓다.** 포락선 정리가 지우는 것은 **정확히 하나** — *"`c` 를 detach 하면 다른 방법이 된다"*.
그것은 **1차 하강의 기울기**에 대한 진술이다. **Kaufman 근사가 겨누는 것은 그 기울기가 아니라

⟹ ⛔**"W6 이 VARPRO 의 모든 novelty 를 수학으로 닫았다" 는 과장.** 정확히 닫힌 것은
