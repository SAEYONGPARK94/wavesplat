# 1. ★★★`KILL` — `decorr` 가 절반이 되는 것은 **동어반복이다**

## 1.1 정의 — `decorr` 는 **주 종점의 대수적 성분**이다 `[M]`

`tmp/W4_SOLVER_2026-08-19/run_w4.py:380-384` (W5 가 **같은 함수를 재사용**한다):

```python
rho = np.array([f['Pearson_rho'] ...])
vr  = np.array([f['Variance_Ratio'] ...])
decorr = 1.0 - rho ** 2
shrink = (np.sqrt(np.clip(vr, 0, None)) - rho) ** 2
```

`Pearson_rho`·`Variance_Ratio`·`nRMSE` 는 **같은 `compute_all_metrics(pred_field, gt_field, ...)` 호출**이
같은 두 배열에서 만든다(`evaluation/metrics.py:422, 450, 451`). 그리고 `nRMSE = RMSE/Hs`(`metrics.py:51`).

정규화 MSE 의 항등식
```
m = MSE/Var(gt) = 1 + VR − 2ρ√VR = (1−ρ²) + (√VR − ρ)² = decorr + shrink
```
이고 해수면은 `Hs ≈ 4σ` 이므로 **`decorr + shrink ≈ 16 · nRMSE²`**.

⟹ `decorr` 는 **위상 오차를 독립적으로 잰 양이 아니다.** 그것은 **주 종점 `avg_nRMSE` 를
제곱해서 두 조각으로 나눈 것 중 큰 조각**이다.

   **"참해가 모델류 안에 있는 분리형 NLLS"** 다.
2. ⛔**희소 0행.** 그리고 희소의 −93% 는 **표현 아티팩트로 확정**(HOSGATE: 비선형화 시
   `SHIP` 희소 0.0195→0.0700 = **3.6배**, 기준선은 ±0.5% 무감).
3. ⛔**비선형(HOS) 팔 0개.** 상시지시 *"검증에 비선형 필수"* 미충족.
4. ⛔**실측 전이 = LOSS.**
5. ⛔**외부 기준선 행 0개.** S17 이 768런 쓰고 **최강 기준선이 움직이지 않았고**,
   `med(rel) −24.4%` 는 **효과 크기 인용 금지** 상태다.

⟹ ★**"격자없는 다성분 파랑 재구성의 벽" 은 이 자료의 5배쯤 넓은 문장이다.**
게다가 *"벽"* 이라는 단어가 1번 각도에서 죽었다 — 벽의 정체를 잰 적이 없다.

# 7. ★처방 검증 — 내 처방이 틀릴 수 있는 지점

저장소에서 *"감사가 옳은 결함 + 틀린 수정"* 을 낸 사고가 있었으므로, 내 처방을 스스로 검사한다.

| 내 처방 | 이것이 틀릴 수 있는 경우 |
|---|---|
| *"decorr 를 인쇄하지 마라"* | ⚠**과잉이다.** `decorr/shrink` 는 `L-ITER0` 에서 **비중이 −4.95 pp 움직였다**(§1.4) ⟹ **자 자체는 죽지 않았다.** 죽은 것은 **"VARPRO 가 decorr 를 절반으로 만들었다"** 는 문장이다. **처방을 좁힌다: 비(ratio)가 아니라 비중(share) 만 보고하고, 비중이 안 움직였다는 사실을 함께 적어라.** |
| *"추적 개입 팔을 추가하라"* | ⛔**하지 마라.** `tracking_lr=0` 축은 이미 6회 재현·독립 처치 0건으로 닫혔다. 추가하면 **7번째 재탕**이다. 필요한 것은 팔이 아니라 **`init_nrmse` 를 추적 프레임 t 에서도 다시 재는 자**(현재 없음). |
| *"CVX 를 HOS 에서 재측정하라"* | ⚠비용이 크다(HOS ~115 s/에피소드). `W4k_prekill §8.5` 의 처방이지만 **미이행 이유가 기록되지 않았다** — 승인 전에 예산을 먼저 적을 것. |
| *"−17.5% 를 쓰라"* | ⚠그것도 `S-2c`(가중 유의) 때문에 **단일요인이 아니다.** 완전히 안전한 것은 **`L-VP` vs `L-STEP400`(예산 동수) −17.3%** 뿐이다. |

**내가 확인하지 않은 것** `[A]`:
① `analyze_w5.py` 의 Wilcoxon/Holm 구현 · ② `ORA-K-CVX` 6요인의 내역 · ③ arXiv 원문 ·
④ `G-4` 재사용 비트동일성(RESULT 의 `max|Δ|=0` 주장) · ⑤ `direction_deg` (에피소드 attrs 에
`direction_spread_deg=30` 은 있으나 `direction_deg` 필드 자체가 없다 — **반인과 기하 경고는
재확인하지 못했다**).
