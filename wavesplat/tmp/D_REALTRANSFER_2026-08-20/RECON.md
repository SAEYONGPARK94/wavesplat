## 1. `bank_mmse` 추정 구조 — 수식 `MEASURED`

### 1.1 무엇을 후보로 두는가 (은행의 원소)

`bank_mmse.py:154-163`

```
dk_c = kp/10                                    (:154-155, 기본)
ax   = arange(-2.5·kp, +2.5·kp, dk_c)           (:157, band=(0.35, 2.5))
(KX,KY) = meshgrid(ax,ax);  kk = |k|            (:158-159)
sel  = (0.35·kp < kk < 2.5·kp)                  (:160)   ← 환형(annulus) 선택
(kxb, kyb) = KX[sel], KY[sel]                   (:161)   ← B 개
om   = √(g·|k|·tanh(|k|·d) + 1e-12)             (:162, :44-46)
```

⟹ **은행의 원소 = 분산관계 위에 놓인 고정 격자점 (kx_j, ky_j, ω_j), j=1..B.**
격자 간격 `dk_c = kp/10`, 반경대역 `[0.35 kp, 2.5 kp]`.
격자점 개수 B ≈ π(2.5²−0.35²)kp² / dk_c² ≈ **π·6.13·100 ≈ 1,900** (`ARGUED`, 산술).

### 1.2 무엇이 선형이고 무엇이 비선형인가

관측 `z_i` 는 점 `P_i = (x_i, y_i, t_i)`. `ψ_ij = kx_j x_i + ky_j y_i − ω_j t_i` (`:166-167`).

```
z_i  =  Σ_j [ a_j cos ψ_ij  +  b_j sin ψ_ij ]  +  ε_i
Φ    =  [ cos Ψ | sin Ψ ]   ∈ R^{n × 2B}                      (:168)
w    =  (a_1..a_B, b_1..b_B) ∈ R^{2B}
```

- **선형**: `(a_j, b_j)` — 즉 **진폭과 위상 전부**.
  극좌표 역사상 `A_j = √(a_j²+b_j²)`, `φ_j = atan2(−b_j, a_j)`.
  ⟹ ★**`bank_mmse` 는 위상을 파라미터로 두지 않는다.** 위상은 직교 성분쌍으로 흡수된다.
- **비선형**: `(kx_j, ky_j)` — 그런데 **자유변수가 아니다**. `:157-161` 에서 **격자로 고정**된다.
  자유롭게 남는 비선형 스칼라는 `kp` 하나이고, 그것은 **격자 argmax** 로 정해진다(§1.4).

### 1.3 MMSE 결합이 최소화하는 것

`:187-190`, `:216-218`

```
사전       w ~ N(0, Γ),  Γ = diag(gam),  gam = [g; g]·Var(z),  g = pw^pexp / Σ pw^pexp   (:184-187)
잡음       ε ~ N(0, s² I),  s² = (smult·sigma0)²                                          (:189)
K          = Φ Γ Φᵀ + s² I                                                                (:190, :216)
alpha      = K⁻¹ z                                                                        (:217)
w_pred     = Φᵀ alpha                                                                     (:218)
예측       f(Q) = Φ(Q) · Γ · w_pred = Φ(Q) Γ Φᵀ (ΦΓΦᵀ + s²I)⁻¹ z                          (:117)
```

⟹ **정확히 사후평균 = MAP = 가중 Tikhonov 해**:

```
ŵ = argmin_w  ‖z − Φw‖²  +  s² Σ_j w_j² / gam_j
```

**`ARGUED`(표준 GP/ridge 쌍대성) — 그러나 §2.3 에서 수치로 확인했다.**

### 1.4 `kp` 는 어떻게 정해지는가

`:145-153` → `_beamform_top` (`:49-74`).
**2단계 빔포밍 줌**, 둘 다 **격자 argmax**(하강 아님):

| 단계 | klim | n | 격자 | 판정 |
|---|---|---|---|---|
| 1 | 2.0 | 120 | 14,400 | `argmax` periodogram power `(Σ r cosψ)² + (Σ r sinψ)²` (`:71-73`) |
| 2 | 3.5·kp₁ | 120 | 14,400 | 동일 |

전력은 **분산관계 위에서만** 평가된다(`:65` 가 ω 를 k 에서 유도) ⟹ 3차원 (kx,ky,ω) 탐색이

## 2. VARPRO 와의 대조 — **직접 유사물이 있고, 이미 그 자리에 있다**

### 2.1 오늘의 처방 `L-VP` 가 하는 일 (`varpro.py:1-70`, `recon/C2_varpro.md:§1`)

```
Φ(K) = [cos Θ | sin Θ]                                  (M × 2N)
c(K) = (Φ_wᵀΦ_w + εI)⁻¹ Φ_wᵀ z_w                        ← 선형 소거 (닫힌형)
f(K) = ‖Φ_w c(K) − z_w‖² / M                            ← 축소 목적함수
K ← K − η ∇_K f(K)   (autograd, 400스텝, Golub–Pereyra 전체 기울기)
```

### 2.2 `bank_mmse` 의 대응

| VARPRO 단계 | `bank_mmse` 의 대응 | 상태 |
|---|---|---|
| **극좌표 매개화** `w cos(θ+φ) → a cosθ + b sinθ` | `:168` `concatenate([cos ψ, sin ψ])` | ✅ **동일** |
| **선형 소거** `c(K) = (ΦᵀΦ+εI)⁻¹Φᵀz` | `:216-218` `w_pred=Φᵀ(ΦΓΦᵀ+s²I)⁻¹z`, 예측 `ΦΓw_pred` | ✅ **동일, 단 ε 이 열별 Γ** |
| **축소 목적함수 f(K)** | 존재하나 **미분되지 않는다** | ⛔ |
| **K 에서 하강** | **없음** — K 는 `:157-161` 고정 격자 | ⛔ **대상 부재** |

### 2.3 "동일" 을 수치로 확인 `MEASURED` (넘파이, 추정기 런 0회)

Woodbury 항등식으로, `bank_mmse` 의 선형 계수 사후평균은 `varpro.py` 의 `c(K)` 와
**열별 ridge `ε_j = s²/γ_j`** 하에서 같아야 한다:

```
Γ Φᵀ (ΦΓΦᵀ + s²I)⁻¹ z   ≡   (ΦᵀΦ + s²Γ⁻¹)⁻¹ Φᵀ z
```

난수 `n=60, B=25, s²=0.37, γ~|N|+0.1` 로 양변 계산:

```
max|c_bank − c_varpro(per-column eps)| = 1.382e-14      ← 부동소수 한계
max|c_bank − c_varpro(scalar eps=1e-8)| = 1.382e-01     ← 시험이 공허하지 않다는 증거
```

⟹ ★**`bank_mmse` 의 선형해는 VARPRO 의 선형 소거 그 자체이고, 스칼라 ε 대신
데이터가 고른 열별 ε_j 를 쓴다는 점에서 엄격히 더 강하다.**

### 2.4 그리고 VARPRO 패턴이 **두 번** 쓰였다 `ARGUED`

1. **w 소거** → 사후평균(`:216-218`) — 위 §2.3.
2. **w 주변화** → 증거(evidence) → `gam` 최적화(`:199-213` SBL-EM).
   SBL-EM 은 type-II ML 이고, 그 정의가 *"선형 계수를 해석적으로 주변화한 뒤 남은
   비선형 하이퍼파라미터만 최적화"* 다 ⟹ **VARPRO 와 동형**.
   여기서도 각 EM 스텝은 닫힌형(`:201-206`)이고 하강이 아니다.

### 2.5 ★그러면 VARPRO 가 고치려던 벽은 실측 경로에 **존재하지 않는다** `ARGUED`

08-15 척추: *"벽은 정보가 아니라 위상의 비볼록성이다"*.
`A cos(kx+ky−ωt+φ)` 에서 φ 가 비볼록성의 원천이다.
`bank_mmse` 는 **φ 를 파라미터로 두지 않는다**(§1.2) ⟹

  (`X3_audit_and_next_2026-08-11/AUDIT_NEUTRAL.md` §6 도 `default_rng(seed)` 외 전역 RNG 의존
  0건으로 확인).

⟹ ★**실측 경로는 그 벽의 반대편에 이미 서 있다.**
`bank_mmse.py:7-12` 자신이 그 이동의 크기를 적어 놓았다: 동결 실측 3창 nowcast nRMSE

## 5. 처방 (제안이며, 결정은 사용자)

**닫는다**: VARPRO-on-real 축. `bank_mmse` 가 이미 그 처치의 상위집합이다(§2.3, 1.38e-14).
`varpro.py` 를 실측 경로에 이식하려는 어떤 시도도 **런 전에 죽여야 한다** — 대상 코드가 없다.

**만약 실측 축을 계속한다면**, 유일하게 사전등록을 통과한 것은 **재적합 주기**다:
1. `run.py` `DEFAULT_CONFIG` + `configs/estimation.yaml` 에 `bank_refit_every_s` 노출 (키 한 줄).
2. 배포 기본값 변경은 **런 0회 사안이 아니다** — 신선 창(레코드당 미소비 창 3개 = w0/w2/w4)에서
   `PROTOCOL_ROLLING_REFIT.md` 의 동일 기준으로 재확인 후 사용자 결정.
3. ⚠**그 재확인조차 α=0.05 에 도달할 수 없다**(레코드 3개). 사전등록에 **MDE 대신 "탐색적 확인"
   이라고 적을 것** — `S13` 이 여기서 이탈했다.

**하지 말 것**: `kp` 정밀화 · 은행 세밀화 · 앙상블 확대 · `vr` 기반 선택.
네 축 전부 **이미 실측 음성**이고, 특히 `kp` 는 **오라클을 줘도 나빠진다**.
