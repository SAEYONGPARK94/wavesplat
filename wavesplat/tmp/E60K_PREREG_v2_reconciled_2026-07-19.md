## 3. 재조정 설계 (제안 — 동결 전, fable red-team 대기)

### 3.1 ★핵심 변경: 주 아레나를 HOS로, 실측을 확증 다리로

fable 초안은 **실측을 주 아레나**로 놓았다. R3가 그것을 위태롭게 한다. 재조정:

- **주 아레나 = 합성 HOS** — 바다를 얼마든지 만들 수 있어 **군집이 싸다**(E-15 캐시 32바다).
  kp_floor 감사가 세 번 반복해 내린 처방("군집을 늘리는 것 외에 약이 없다, 그리고 **HOS가 가장 싸다**")과 정합.
  게다가 상시지시([[feedback_validation_nonlinearity]])가 **헤드라인은 HOS에서 재현**을 요구하므로,
  HOS는 어차피 통과해야 하는 관문이다. **현재 HOS는 ~null(+0.010, 5/8)이고 이게 B의 최대 약점**이므로
  주 아레나로 두는 것이 정직하다(약한 쪽을 주 판정에).
- **확증 다리 = 실측 k=6** (현행 5 + BS11a). BS11b 이하는 **사전 명기 탐색 층**으로만 보고, 주 판정 제외.

### 3.2 팔 (3개, 그 외 전부 동일: 아키텍처·init·셔드·12k step·시드 {0,1,2})
- **T** — `task_loss_one` (기존 ckpt 6개 재사용)
- **L** — 창-안 20% heldout z-잔차 (기존 ckpt 재사용)
- **NLL(신규)** — 진짜 marginal likelihood(ML-II). **"우도" 문구의 측정 공백을 닫는 팔.**
  (fable litcheck: 현 L은 CV류지 ML-II가 아니며, **Bachoc CSDA 2013**이 "오지정 하 ML 오선택·CV 강건"을
  정리급으로 선점 ⟹ NLL 팔이 없으면 "우도" 단어를 쓸 수 없다.)

### 3.3 주 통계 (동결 후보)
- 단위 = 창-짝지음 Δcorr(T−L), **시드 3개는 창 안에서 평균**(반복측정, 군집 아님)
- **군집 = HOS 바다 / 실측 site-day** (⛔파일 아님 — R2)
- 실패창 정의 = hand < 0.5 (07-12 동결본), **전창 대비 병기 의무**
- 검정 = record/sea-mean, t(k−1), **단측**(방향은 07-12 독립 데이터로 고정 ⟹ 단측 정당) +
  Webb 6점 null-imposed wild cluster bootstrap-t, 전수열거(6^k ≤ 4e6이면)
- 지표 키 = `corr_bl` 고정

### 3.4 PASS / FAIL / VOID (동결 후보)
- **PASS** = ①HOS: 바다-군집 k≥15에서 Δ(T−L) > +0.02 AND wild p<0.05
  AND ②실측 k=6: Δ ≥ +0.05 AND ≥4/6 양수 AND ③전창 대비 ≥ −0.01(무해)
- **FAIL** = HOS Δ ≤ 0 **또는** HOS wild p ≥ 0.10 ⟹ **B 헤드라인 자격 영구 상실**,
  "선택-수준 병리(H5)는 확정 + 훈련-수준은 방향-시사" 스코프로 A의 §7 잔류
- **PARTIAL** = HOS 통과·실측 미달 ⟹ 합성-스코프 각주로 챕터 잔류(헤드라인 불가)
- **VOID(FAIL 아님)** = L 또는 NLL의 수렴 smult가 2.5 초과(팔이 분리 안 됨) —
  manipulation check 실패
- **검정력 캐비엇 사전 명기**: 실측 k=6 검정력 0.55 ⟹ **미달은 "미성립"이지 "반증"이 아니다**
  (E-59 교훈: 비관 오류도 실재)

### 3.5 대칭감사 함정 (사전 명기)
**가짜-양성**: 실패창 정의가 hand를 씀(동결본 사용·전창 병기) · kp_hint/σ₀ 오라클 유출
(**E-12g 센서-실현 프로토콜 강제**, 600점 빔포밍) · L 허수아비(NLL 팔이 감사 겸함) ·
레코드 선택 편향(명단을 결과 보기 **전에** 동결) · HOS 추출잡음의 바다-신호 위장(바다당 ≥5추출)
**가짜-음성**: 검정력(위) · smult 미분리 → VOID · AA15a형 이질성(전체 미달 시 레짐-분할은
**탐색으로만**, 구제 금지) · HOS 메시 아티팩트(E-1b, 미세 메시 dx≤λ/6 강제)
