⛔ 논문·판정문에서 실측 다리를 **독립 확증으로 인용 금지**. 본 설계는 사실상 **HOS 단일-아레나**이며,
전향적 실측 정보는 **BS11a 1건뿐**이다. (그게 진실이다 — 실측 데이터는 이미 소진됐다.)

## 3. 팔 (3개, 손실 외 전부 동일)
아키텍처 PriorNet+SmultHead · init v7fan · 데이터 bwtask 8,000 · 12,000 step(auto-extend) · 시드 {0,1,2}

- **T** — `task_loss_one` (창-밖 질의 과제오차). ckpt 재사용 `b2deep_T_s{0,1,2}.pt`
- **L** — 창-안 20% heldout z-잔차 (**CV류**, ML-II 아님). ckpt 재사용 `b2deep_L_s{0,1,2}.pt`
- **NLL(신규)** — 진짜 ML-II: `−log p(z) = ½[zᵀK⁻¹z + logdet K + n log2π]`, **관측당** 정규화.
  ckpt `b2deep_N_s{0,1,2}.pt`
  - **공정성 증명 완료**: 뱅크 구성을 `_build_bank`로 공유해 **손실만이 유일한 차이**.
    T/L 경로 **bit-identical**(값·γ-net 기울기·log_smult 기울기 전부 d=0.00e+00,
    `tmp/e60k_verify_refactor.py`). NLL vs naive slogdet rel 2e-7.
  - **(Hs/4)² 재척도 미적용이 정당한 이유**: 모델이 scale-equivariant(z→cz ⟹ gam→c²gam, σ₀→cσ₀)
    라 NLL/n은 **파라미터 무관 상수 log c**만 이동 ⟹ 기울기 불변. 재척도하면 오히려 우도이기를 그만둔다.

## 4. 주 통계 (동결)
- 단위 = 창-짝지음 Δcorr(T−L) [부차: Δ(T−NLL), Δ(L−NLL)], 지표 키 **`corr_bl`**
- **시드 3개는 창 안에서 평균**(반복측정, 군집 아님)
- **군집 = HOS 바다 / 실측 site-day** (⛔파일 아님)
- 실패창 = **hand < 0.5** (07-12 동결 정의), **전창 대비 병기 의무**
- 검정 = 군집-평균 t(k−1) **AND** Webb 6점 null-imposed wild cluster bootstrap-t **양쪽 수렴 요구**(수정⑥-③)
- 단측(방향은 07-12 독립 데이터로 고정). ⚠실측 다리의 단측성은 **부분 순환**(같은 5레코드가 방향을 정함) —
  실측 다리는 어차피 확증 아님(§1)이므로 수용, 단 명기.
- 입력 = **E-12g 센서-실현 프로토콜**(600점 빔포밍 kp_hint, 희소-Hs σ₀). **오라클 0개.**

## 5. 판정 (동결)

**PASS** = ① **AND** ② **AND** ③:
1. **[주] HOS**: 바다-군집 k=32에서 실패창 Δ(T−L) **> +0.02** AND cluster-t p<0.05 **AND** wild p<0.05
2. **[보조] 실측 k=6**: mean ≥ +0.05 AND ≥4/6 양수 — ⚠**이 조건은 기지 데이터로 사전-충족 상태이며,
   실질 시험은 BS11a의 비-모순뿐**(§1)
3. **[무해] 전창** Δ(T−L) ≥ −0.01

**FAIL (헤드라인 자격 영구 상실 → A의 §7 잔류, "선택-수준 병리는 확정 / 훈련-수준은 방향-시사" 스코프)**
- HOS Δ ≤ 0 **또는** HOS wild p ≥ 0.10
- **또는** 실측 전체 mean < 0
- **또는 ★NLL 동률 분기 (수정③, T−L 결과와 무관)**: 실패창 Δ(T−NLL) < +0.02 **AND**
  NLL 건전 수렴 smult ∈ [2.5, 4.0] (시드 간 std < 0.5)
  ⟹ ML-II 무죄 ⟹ B의 **비-우도 정체성 소멸** ⟹ 헤드라인 자격 상실.
  챕터는 **"검증-축 오정렬(창-안 CV형) pitfall"** 서사로 재프레임. 축소 문장 = fable 심사 §5 동결본.

**PASS 봉쇄 (최대 PARTIAL) — 실측 반증자 복원 (수정②)**: **BS11a Δ(T−L) ≤ −0.05**
⟹ 실측 다리를 "혼재"로 라벨, 방향-일관 주장 불가, PASS 인가 불가.

**PARTIAL** = HOS 통과·실측 미달(또는 BS11a 봉쇄) ⟹ 합성-스코프 각주로 챕터 잔류, **헤드라인 불가**.

**VOID (수정③으로 교체)** = **훈련 진단 퇴행에 한정**: 발산·NaN·시드 간 smult std > 0.5.
⛔ 구 조항("L 또는 NLL smult > 2.5 ⟹ VOID")은 **폐기** — NLL이 smult≥2.5로 건전 수렴하는 것은
조작 실패가 아니라 **이 실험이 낼 수 있는 가장 결정적인 발견**이며, 위 FAIL 분기로 처리한다.

### 5.1 PASS 인가 시 헤드라인 스코프 문장 (동결, 수정④)
> "훈련-수준 loss-choice 병리는 **비선형 HOS 합성(32바다 군집)에서 확립**되었고, 실측 스테레오
> (6 site-day)에서 **방향-일관**(기관측 5 + 전향 1)이다."

⛔ PASS를 "실측에서 확립"으로 마케팅하는 경로 차단.
