## ⚠**내 앞선 진술 1건 정정** — `AA15b = Wang 2025 의 AA 03` 은 **미검증**이었다
조사 에이전트가 그렇게 보고했고 내가 그대로 옮겼다. **직접 대조한 결과는 「강한 정황, 증명 아님」**:

| | Wang 2025 (원문 축자) | 우리 레코드 |
|---|---|---|
| 범위 | `x −25..25 m` · **`y 30..80 m`** | `AA15b` `gx −80..−25` · `gy −40..40` |
| | | `AA14` `gx −75..−5` · `AA15a` `gx −70..−5` |

★**축 이름과 부호가 다르다.** 크기로 맞추면 Wang 의 **`y 30..80`** 이 우리 `AA15b` 의
**`|gx| 25..80`** 과 맞고, **다른 AA 레코드 둘은 맞지 않는다**(5..75 · 5..70).
교차축은 저들이 ±25, 우리가 ±40 ⟹ **자른 것**으로 보인다.
⛔**그리고 Wang 은 원영상에서 WASS 를 자기 파라미터로 다시 돌렸다**(*"processed all sequences
using WASS with the recommended parameters"*) ⟹ 저들 격자는 공개 `Surfaces_*.nc` 와 **같지 않다**.
⟹ 허용 진술: ***"범위가 `AA15b` 하나와만 맞는다"*** 까지. ⛔*"같은 레코드"* 는 아직 쓰지 마라.

## ⛔배치 설계에 결과 전 박을 것
- **관측 밀도 사다리**. 배포 실측 장면은 프레임당 **12점**(`scene_station.py` 기본 `m_scan=12`)이고
  256² 격자 기준 dense ratio ≈ **1.8e−4** = Wang 이 *"extremely sparse"* 라 부른 **0.005 의 약 27배
  희소**. ⟹ 자기검정(`G-8` 형 제로필드 게이트)을 그냥 걸면 **세 번째 `NO-VALID-COMPETITOR`**
  가 나올 사전확률이 높다. 밀도 사다리를 넣으면 **어느 쪽이 나와도 판정이 남는다**:
  *"제3자 재구성기가 기술을 얻는 밀도 문턱은 X 이고 우리 관측 기하는 12 를 공급한다."*
- ⛔**우리 코드는 한 줄도 안 고친다**(정지규칙이 금지한 것은 *세 번째 사내 기준선 수리*이고,
  이것은 제3자 코드·제3자 가중치다).
- ⚠**분포 겹침 미확인**: 학습 자료가 `synthetic/matlab/wafo_generate_sequence.m`(WAFO
  Torsethaugen, 256², du 0.46 m, 7 fps)로 **보이나** MDPI 본문을 못 읽었다(403) ⟹ **추론**이다.
- ⚠3-프레임(t−1,t,t+1) 입력이라 **비인과적** ⟹ 기준선에 유리한 방향, 그대로 공시.
- 스모크 = 저들 공식 시험자료 `https://www.dais.unive.it/wass/wassfast_testdata_256.7z`
  (**122,583,502 B**, HTTP 200 확인)로 환경·가중치 로딩부터.
