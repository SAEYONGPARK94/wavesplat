     W1  = exact 1-Wasserstein between normalised ENERGY measures on the k-plane [rad/m]
     COV = energy-weighted mean distance from each TRUE atom to nearest PLACED atom
     PREC= energy-weighted mean distance from each PLACED atom to nearest TRUE atom
     nulls: STACK = every atom at the energy centroid of the true set

  READ 1: ORACLE-K STARTS at W1=COV=PREC=0 exactly (its k IS the truth) and its k is
          TRAINABLE. The numbers above are FINAL k. So they measure how far the optimizer
          walks the atoms away from the truth over 900 steps. On CROWDED4 that walk is
          W1=0.0370 rad/m against a true NN spacing of 0.026-0.084 rad/m -- i.e. of the
          same order as the spacing it is supposed to resolve. ORACLE-K is therefore NOT
          "the field error you get with correct k"; it is "the field error you get if you
          are HANDED correct k and then allowed to lose it".
  READ 2: NULL-PRIOR is far from every arm on all three -> the metric has dynamic range
          (detection_rate did not).
  READ 3: ★ on CROWDED4 the shipped fallback X-BASE does NOT beat the one-point STACK null
          on W1 (0.0648 vs 0.0548) or on PREC (0.0371 vs 0.0192). It beats it only on COV
          (0.0268 vs 0.0548). Block medians only -- NOT a test. Flagged for the prereg as
          the first thing the next experiment must settle at cluster level.

  episode -> cluster   : MEDIAN of episodes sharing a bit-identical truth field

  test                 : exact two-sided sign test on CLUSTERS (not episodes)
