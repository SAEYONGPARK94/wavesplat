## 2. `G-15` 가 재는 것과 FAIL 사유 — 전역 RNG 결합

```
gates_m4.py:521-526
    inl  = {(unit, seed): r for r in ok if r['arm'] == 'SHIP-K-INL'}   # pc 필터 없음 ⟹ 12개
    base = {(unit, seed): r for r in ok if r['arm'] == BASE}           # SHIP-K
    same = [k for k in inl if k in base
            and repr(inl[k]['nowcast']) == repr(base[k]['nowcast'])]
```

즉 `G-15` 는 **원자를 비교하지 않는다.** 두 팔의 **최종 nowcast 부동소수 repr** 을 비교한다.
(그래서 `G-13` 0/12 와 `G-15` 2/12 가 다른 수인 것이다 — `G-13` 은 `pc` 를 거르고 `G-15` 는
안 거른다. 자료는 하나다.)

`PREREG.md:175` 의 의도는 *"**캐시가 값을 바꾸지 않았다**의 증명"* 이다. 게이트는 그 의도를
**끝단 nowcast 의 비트동일**로 구현했다. 원자는 바뀌지 않았는데(§3.1) nowcast 는 바뀐다.

### 2.1 기제 — 코드로 특정했다

```
scripts/d3_beamform_cond_diffusion.py:160   torch.manual_seed(seed)      # ★전역 시드를 다시 박는다
                                            (+ 확산 체인이 전역 스트림을 소모)
   ← learned_init.py:152  cd.sample(model, Bmap, abar, betas, n=nsamp, seed=int(diffusion_seed))
   ← learned_init.py:355  propose_atoms(...)          # 인라인 팔만 여기를 탄다
   ← sequential_update.py:877  learned_init_params(...)

sequential_update.py:1617   _init_phi = torch.rand(n_actual, device=device) * 2 * np.pi
   ← _adaptive_prune_grow 의 **성장 가지**. 전역 torch RNG 에서 뽑는다.
```

⟹ 인라인 팔은 `set_seed(42)` 뒤 **확산 체인을 통째로 소모한 상태**로 `_adaptive_prune_grow`
에 도착하고, 캐시 팔은 `set_seed(42)` 직후 상태로 도착한다. **성장 가지가 발화하는 셀에서는
두 팔이 서로 다른 난수 위상을 새 원자에 넣는다** ⟹ 최종 장이 달라진다.

★**즉 추정기 초기화는 `(원자, 시드)` 의 순수함수가 아니다.**
그러므로 *"같은 원자를 주입하면 인라인과 비트동일"* 은 **성장 가지가 발화하는 한 성립할 수 없다.**

### 2.2 ⛔패키지 독스트링이 이 전제를 잘못 보증하고 있다

```
learned_init.py:129-130
    "Selection/dedup happens later in ``pool_and_select`` so the inline and cached paths
     are byte-identical."
```
**원자에 대해서는 참이고(내가 12/12 로 확인), 추정치에 대해서는 거짓이다.**
`G-15` 는 이 문장을 끝단까지 확장해 읽고 설계됐다.
⟹ 저장소의 반복 결함 부류 **"문서가 측정보다 넓게 말한다"** 의 재발.

더 강하게**(원자 배열 자체를 12/12 비트 비교) 확인했다. 결함은 게이트 두 개의 명세에 있다.

### 5.3 ★해야 할 것 = **AMENDMENT 사전등록** (판정 코드 수정은 그 문서 안에서만)

다음 셋을 **결과를 다시 집계하기 전에** 적고 동결할 것. ⛔여기서는 적기만 하고 적용하지 않는다.

  0행 가드만 본다(`:591-593`, `:616-617`) ⟹ **`M2 G-13` 교훈이 런타임 게이트에 미적용**.

### 5.4 저장소 수준으로 올릴 것 (이 배치 밖, ⛔지금 고치지 않는다)

- ★**`learned_init.py:129-130` 독스트링이 거짓을 보증한다** — *"the inline and cached paths
  are byte-identical"*. 원자에 한정해야 한다. `sequential_update.py:1617` 이 전역 RNG 를 쓰는
  한 끝단은 비트동일하지 않다.
- ★**추정기 초기화가 전역 RNG 에 결합돼 있다.** 성장 가지의 위상을 `self.seed` 로 파생한
  전용 `Generator` 에서 뽑으면 `(원자, 시드)` 의 순수함수가 된다. **이 배치는 그것을 제안만
  하고 재지 않았다** — 배포 거동 변경이므로 별도 사전등록 사항이다.
- ⚠**실측 nowcast 는 성장 위상 난수에 매우 민감하다** — 한 draw 로 `BS11c` 0.645 → 3.412
  (+429%), `BS11a` 3.103 → 1.608 (−48%). 실측 층의 **레코드 단위 절대값**을 인용할 때는
  이 산포를 병기해야 한다. (⛔이 배치의 짝 판정은 §4.3 에 의해 영향받지 않는다.
  ⛔다른 배치로 일반화하지 않는다 — 열지 않았다.)
- ⚠`G-15` 의 `base` 는 `stratum` 을 거르지 않는다(`:522`). 이 배치에서는 실측 레코드명과
  합성 에피소드명이 겹치지 않아 무해했지만, 이름공간이 겹치면 조용히 틀린다. **잠재 결함.**
- (기존 항목, `VOID_phaseA_skipped/README.md` 가 이미 적었다) `gates_m4.py:203 thresholds(n)`
  이 소표본에서 `min()` 빈 iterable 로 죽는다.
