  남은 예산 `m_cap − k` 만 나머지에서 `default_rng(0)` 으로 균등추첨한다."***

  ```python
  if len(z) > m_cap:
      if cap_mode == 'end_anchored':
          last = np.flatnonzero(P[:, 2] >= P[:, 2].max() - 1e-9)   # 최신 스캔 통째로
          rest = np.setdiff1d(np.arange(len(z)), last)
          ii = np.concatenate([last,
                               np.random.default_rng(0).choice(
                                   rest, m_cap - len(last), replace=False)])
      else:                                                        # 'uniform' = 현행

      P, z = P[ii], z[ii]
  ```

그러면 이 배치는 *"창 길이"* 가 아니라 *"관측 예산"* 을 재게 된다 — 그 축은
**`B-18`(밀도 25배)이 이미 쟀고 `NEITHER-SUFFICIENT`** 였다. **교락으로 축이 사라진다.**

### 안 C — 끝점 고정 + **균등 시간 간격 솎기** (⛔이 배치에서는 기각, 후속 설계로 보관)

600점을 `W` 에 **고르게** 깔면 `G-1b`·`G-2` 가 둘 다 성립하고 **§3.1 의 밀도 기울기까지
제거**된다 — 개구와 밀도를 **분리하는** 유일한 안이다. 그러나 관측 모형 자체(*"매 프레임 12점
→ 전체에서 600 무작위"*)를 바꾸므로 `ANCHOR` 가 **지금까지 측정된 어떤 구성과도 닮지 않게**
되고, 조건자(`beamform`)가 보는 프레임 수까지 바뀐다. **소거 배치가 감당할 변경 폭이 아니다.**
⟹ ★***개구 vs 밀도 분리는 별도 사전등록의 몫***이라고 적어 둔다.

### ⛔검토조차 하지 않은 길 (전부 사후 자유도)

`G-1b` 를 SCOPING 으로 재분류 · 허용오차(예: `≤ 3·dt`) 도입 · `BS11a`/`LJ18a` 사후 배제

**결과가 디스크에 있는 상태에서의 게이트 완화는 전부 탈락이다.**
