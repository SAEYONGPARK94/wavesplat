## 0. 질문

***"넷이 실측에서 자신 있게 틀리는 것은 학습 *분포* 때문인가, 학습 *손실* 때문인가?"***

사용자 제안은 **분포**(*"실측과 유사하게 뾰족하고 어렵게 만들어서 학습"*)이고,

`loss = F.mse_loss(pred, eps)` ⟹ 배포 제안망은 **「파도장을 잘 맞추도록」 학습되지 않는다.
「참 원자 집합의 분포를 재현하도록」 학습된다.** 장 오차도 관측 잔차도 손실에 없다.
⟹ **2×2 로 둘을 분리한다.**

## 2. 팔 — 2×2 + ★음성대조 (감당 가능성 판정: **가능**)

### 2.1 2×2 를 유지한다 (축소하지 않는다)

|  | 손실 = 원자 분포(현행) | 손실 = 장 오차 포함 |
|---|---|---|
| 학습 분포 = 현행 | **`BASE`** | **`LOSS`** |
| 학습 분포 = 어렵게 | **`DATA`** | **`BOTH`** |

★**감당 가능한 이유는 사전학습을 공유하기 때문이다**: 손실 요인은 **미세조정 단계에서만**
갈리므로 사전학습은 **분포당 1회**면 된다(4회가 아니라 2회). 실측 비용은 §7.

### 2.2 학습 절차 — 네 칸에서 **완전히 동일**, 다른 것은 두 요인뿐

* **Phase A (사전학습, 분포당 1회)**: 40,000 스텝 · ε-MSE · AdamW lr 2e-4 wd 1e-4 · cosine ·
  bsz 32 · **from scratch** — `mixed_retrain` PREREG §4 의 동결 레시피 그대로.
* **Phase B (미세조정, 칸마다 1회)**: 4,000 스텝 · lr 5e-5 cosine · bsz 32 ·
  `loss = ε-MSE(전 t) + λ_field · field-MSE(x̂₀, t < T/4, 배치 절반)` · grad clip 5.0 ·
  `NGRID=20` — `wp_e2e` `CONFIGS['A']` 그대로. **λ_field ∈ {0.0, 1.0}**.
  ★**λ_field=0.0 팔도 4,000 스텝을 돈다** ⟹ 대비가 *"추가 학습 4k 스텝"* 이 아니라
  **정확히 λ_field** 다(`G-11`).
* ⛔**하이퍼파라미터 탐색 0건.** λ=4.0 은 wp_e2e 가 이미 **앵커를 망가뜨린다**고 측정했다.
* ⛔**from-scratch 장 손실은 선택하지 않는다** — 초기 x̂₀ 가 잡음이라 앵커를 압도할 위험이
  측정된 적이 없고, wp_e2e 가 검증한 것은 **미세조정 경로**다. 이 선택은 *"측정된 구성을 쓴다"* 다.

### 2.3 ★음성대조 `BASE-B` — 이 설계의 가장 중요한 추가

저장소에 **이 넷의 사전학습 시드 잡음 추정치가 없다**(v1/v2/v3 는 시드가 아니라 `target_mode`
가 다르다 — `mixed_retrain/RESULT.md:62`). 그런데 `DATA` 축은 **서로 다른 사전학습 2개**를
비교한다 ⟹ 요인 효과와 시드 잡음이 교락할 수 있다.
⟹ `BASE-B` = **분포·손실은 `BASE` 와 같고 사전학습 시드만 다른** 다섯 번째 칸.
★**중단 규칙**: `BASE` vs `BASE-B` 가 12 레코드 중 **어느 방향으로든 10개 이상**으로 갈리면
E1 의 모든 요인 귀속은 **DESCRIPTIVE 로 강등**된다(`gates_m7.NEG_CONTROL_ABORT=10`).

### 2.4 참조 팔 (학습 0회)

`SHIPPED`(배포 체크포인트, 강제-learned) · `BANK`(실측 배포 경로 `bank_mmse`, 체크포인트 무관,

## 4. 검정 · 가족 · ★MDE

레코드가 독립 단위다(n=12). 세 대비를 레코드 단위로 만든다(`gates_m7.contrasts`):

| | 정의 | H1 |
|---|---|---|
| **T-1 손실 주효과** | 레코드별 median{ `LOSS−BASE`, `BOTH−DATA` } | < 0 (단측) |
| **T-2 분포 주효과** | 레코드별 median{ `DATA−BASE`, `BOTH−LOSS` } | < 0 (단측) |
| **T-3 교호** | `(BOTH−DATA) − (LOSS−BASE)` | ≠ 0 (양측) |

부호검정 · **Holm(가족 3)** · α=0.05.
★**MDE (결과 전 명시)**: Holm 첫 문턱은 **0.016667** 이고 n=12 단측에서
**11/12 = p 0.003174 (통과)** · **10/12 = p 0.019287 (실패)**
⟹ ***이 설계는 "12개 중 11개에서 같은 부호" 보다 약한 것은 검출하지 못한다.***
크기는 별도로 **짝 상대 중앙값 + 부트스트랩 CI** 로 보고한다(기술).
⛔**참 제로필드 이김 계수는 기술(DESCRIPTIVE)** — 귀무가 0.5 라는 근거가 없다.

⚠**전역 RNG 결합**(`sequential_update.py:1617` 성장 위상 `torch.rand`): 팔마다 원자 수가 다르면
소모 draw 수가 달라진다. 완화 = ①레코드별 확산 시드 3개 중앙값 ②런마다 격리 워커 +
추정 직전 `torch.manual_seed(SEED)` ③`add_calls`·`final_n` 행별 기록(`G-12`).

## 6. ★결과 전 해석 규칙 (`gates_m7.label()`, 코드가 권위)

0. **중단** — 음성대조가 10/12 이상 갈리면 `SEED-NOISE-DOMINATES`: E1 전부 DESCRIPTIVE,
   요인 귀속 금지.
1. **손실만** ⟹ `SUPERVISION-EARNS` — ★*"문제는 분포가 아니라 **감독**이었다"*. 강한 양성.
   다음 = 배포 후보 배치(별도 사전등록). 그리고 wp_e2e 의 널이 **기저 조건부**였음이 확인된다.
2. **분포만** ⟹ `DISTRIBUTION-EARNS` — 사용자 제안이 맞다. 다음 = **분포 묶음 분해(M7b)**:
   (해상상태) vs (2차 비선형 관측) 중 무엇이 지불했는지. ⚠**M7 의 DATA 요인은 둘의 묶음**이고,
   양성이어도 **어느 쪽인지 말할 수 없다** — 이것을 결과 전에 못 박는다.
3. **둘 다 / 교호** ⟹ `BOTH-ADDITIVE` 또는 `INTERACTION`(교호가 유의하면 *"감독의 값은 학습
   분포에 의존한다"*). 후속 후보는 **실측 기술 계수가 가장 큰 칸**, 동점이면 E2 바 여유로
   **동결 tie-break**(⛔이것은 **결정 규칙**이지 우월성의 증거가 아니다).
4. **둘 다 널** ⟹ `NEITHER-MOVES-REAL`.
   ⛔***"재학습이 무익" 으로 쓰지 마라.*** 정확한 문장 =
   **"이 두 개입(실측 앵커 분포, λ_field=1.0 감독)으로는 실측 경계가 움직이지 않았고,
   이 설계의 MDE 는 12개 중 11개 일치다."**
   ★그리고 그것은 **소거표의 한 줄**이다 — `B-26`(해상상태 배제) · `B-18`(밀도·잡음 둘 다 불충분)
   옆에 **"학습 레시피(분포·감독)"** 가 붙는다. 나아가 논문 기여 ②(**제안 표현의 실측 음성**)가
   *"쉬운 학습 분포나 대리 손실의 산물이 아니다"* 로 **강해진다**.
   ⚠**단 이 읽기는 E2 바를 통과했을 때만 허용된다** — 못 통과하면 `UNINTERPRETABLE-NULL`
   (*"넷을 망가뜨려서 생긴 널"* 과 구별 불가).
5. **실측 이득 + E2 바 위반** ⟹ `TRADE`(거래이지 개선이 아니다). 배포 권고 없음.

⛔**어떤 가지도 배포 기본값을 바꾸지 않는다.** 기본값 전환은 별도 사전등록이다.

## 8. 공시 · 교란 · 한계 (결과 전)

1. ★**누출 공시** — HARD 앵커는 **E1 이 평가하는 바로 그 12 레코드**에서 유도됐다
   (레코드당 스칼라 2개: 중앙 `Hs`, `Tp_disp`). 창 자료·표면 자료는 학습에 **일절** 들어가지
   않는다. 완화 측정(학습 0회·CPU): **사이트 제외 재계산**(AA/BS/YS/LJ 4사이트)으로 앵커 상자가
   얼마나 움직이는지 보고한다. ⟹ 누출에서 자유로운 검사는 **E2**(BF4/BF5 코퍼스)다.
2. ★**DATA 요인은 묶음**(해상상태 + 2차 비선형 관측). 물리적으로는 함께 가야 맞지만
   (그 가파름이면 속박 조화가 실린다), **양성이어도 분해되지 않는다**. 분해는 `M7b`.
3. ⚠**조건자 대역 상한** — HARD 장면 10%는 목표 에너지의 40%가 빔포밍 대역(`|k|≤0.6`) 밖이다.
4. ⚠**`SHIPPED` 는 시드 1개짜리 표본**이다(v1 은 tie-break 로 뽑혔고 *"v1 이 v3 보다 낫다"* 는
   쓸 수 없다 — `learned_init.py:50-53` 축자). 그래서 요인 판정은 **`BASE` 대비**로 하고
   `SHIPPED` 는 기록 정합용 참조로만 둔다.
5. ⚠**실측 4 사이트** — 사이트 수준 일반화 금지. `LJ18a` 는 평가에 남지만 물리적으로 이상하다.
6. ⛔**외부 기준선 0개** — `B-5`·`B2_WANGFIX` 가 실측에서 두 번 닫았다. 이 배치도 열지 않는다.
7. ⚠**wp_e2e 의 선례가 널이었다** — M7 의 사전 기대는 낮다. 그렇게 적어 둔다.
