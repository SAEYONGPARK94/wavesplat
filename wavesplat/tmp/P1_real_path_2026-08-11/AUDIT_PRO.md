## 3. ★P-3 [BLOCKER · MEASURED] — `sigma0` 계수 팔은 죽었다 (본 감사가 직접 측정)

BRIEF §1 Q-A 의 핵심 주장은 *"`sequential_update.py:840`(현재 **848**) 의 `sigma0 = 0.05*Hs_obs`
가 하드코딩, 이것이 bank 경로의 사전 잡음 규모 = λ 의 구조적 대응물"* 이다.
**두 부분 다 정정이 필요하다.**

### 3.1 구조: λ 의 대응물은 `sigma0` 가 아니다

`bank_mmse.py:184-196` — 수축(shrinkage)을 결정하는 것은 **σ²/γ 비**다.
- `gam = (pw^pexp 정규화) * np.var(z)` (line 187) — 사전 분산, **var(z) 에 비례**
- `s2 = (smult*sigma0)**2`, `sigma0 = 0.05*Hs_obs = 0.05*4*std(z) = 0.2*std(z)`
  (`bank_mmse.py:189`, `sequential_update.py:847-848`)
- ⟹ **σ²/Σγ = (4c·smult)²** 로 **해상상태에 완전 무관**(c = sigma0 계수). 즉 c 는 수축 손잡이가 맞다.
- 그러나 **λ 의 진짜 구조적 대응물은 `gam` 의 모양**(`pexp`)과 그 위의 **SBL-EM 정련**
  (line 199-213 = ARD/자동 관련성 결정 = **적응형 희소화**)이다.
  ⟹ ★**bank 경로에는 λ 가 없는 게 아니라, 고정 λ 대신 자동 조정되는 ARD 사전이 이미 있다.**

### 3.2 결정적 결함: `smult ∈ {1,3,10}` 이 **val 로 선택**되므로 base 변화를 흡수한다

`bank_mmse.py:188` 의 이중 그리드(`pexp∈{0.5,1,2}` × `smult∈{1,3,10}`)는 held-out val misfit
argmin 으로 뽑힌다. ⟹ c 를 바꾸면 val 이 `smult` 를 **반대로 움직여 되돌린다**. 직접 측정:

**MEASURED** — 3개 **이미 소비된** 창(AA15a w5 · AA15b w3 · YS17 w0 = 07-29 port 창),
median-of-3 필드, 스테레오 채점. 로컬 재구현이 출하 `fit_bank_mmse` 와 **bit-identical**
(`gam`·`w_pred` max|Δ| = **0.000e+00**, 3/3 창).

1. **음성 대조 PASS** — 15개를 **동시에**, 출하값에서 크게 벗어나게 흔들어도 예측면이
   바이트 동일하다. ⟹ §8.1 의 "전면 단절"은 **연역이 아니라 측정**이다.
   ⛔이제 "λ 는 실측에 도달하지 않는다"가 아니라 **"합성 튜닝 우주 전체가 도달하지 않는다"**
   라고 써야 한다.
2. ★**양성 대조 FAIL** — 양성 대조로 넣은 `bank_memory_s` **40→20 조차 바이트 동일**이었다.
   ⟹ **P-5 가 코드 읽기가 아니라 실행으로 확증됐다**: 출하 기본값(`bank_refit_every_s=None`)에서
   `bank_memory_s` 는 **완전한 no-op** 이다. 08-01 의 최강 저가대조 arm D 는 출하 config 로
   재현 불가능하다.
   ⟹ **P1 이 recency 축을 돌리려면 §4.2 의 2줄 수정이 선행돼야 하며, 그 전에는 이 배치에
   "양성 대조"로 쓸 수 있는 실측 손잡이가 `bank_refit_every_s` 하나뿐이다.**

## 11. 본 감사의 한계 (자기 고지)

- M-1~M-4 는 **이미 소비된 3창(+AA15a/AA15b 6창의 GT-free 값)** 에서만 쟀다. 신선 창을 소비하지
  않기 위한 의도적 선택이며, ⟹ **`sigma0` 축 사망 판정의 범위는 "이 3창"** 이다. 다만 기제
  (val 이 base 를 흡수한다)는 코드에서 연역 가능하고 3/3 창에서 방향이 일치한다.

  ⟹ 정밀한 예측이 아니라 **설계 결정을 가르는 크기의 계산**으로만 쓸 것. **결과 전 동결 필수.**
