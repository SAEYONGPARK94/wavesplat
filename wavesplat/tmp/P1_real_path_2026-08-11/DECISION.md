## 1. ★★★배치의 **동기 문장이 정규화 인공물**이었다 (B-2, 결정적)

초안 §0.3 과 내가 사용자에게 **두 번** 보고한 문장: *"합성 0.016/0.158 vs 실측 0.49 = 자릿수 격차."*

**분모가 다르다** (코드로 확인):
- 합성 `nRMSE = RMSE / Hs` (`wavesplat/evaluation/metrics.py:32-34`)
- 실측 `nRMSE = RMSE / σ` (`tmp/bankmmse_port_2026-07-29/measure_blind_vs_frozen.py:31-55`)
- 가우시안 바다에서 **Hs ≈ 4σ**. 실측 측정된 Hs/σ = **3.045–4.278**.

**같은 분모로 맞추면**: 실측 nowcast = **0.171 Hs 단위** vs 합성 혼잡 **0.178** ⟹ **0.96배 = 사실상 동등.**
(희소 대비로는 8.5배 — 그건 희소가 유난히 쉬운 것이다.)

⟹ ⛔**"실측이 자릿수만큼 뒤처진다"는 인용 중단.** P1 의 존재 이유가 여기서 사라진다.
★**이 아크의 상시 함정 재발**: 서로 다른 규약의 수를 나란히 놓고 결론을 냈다.

## 4. 표본 수 — 내 초안 판단이 **양방향으로** 틀렸다

- ⛔초안 "창 6개가 상한이고 서로 겹친다" → **둘 다 거짓**. 인접 간격 77.9–347.9 s > 창 스팬 54–60 s
  ⟹ **프레임 공유 0**. 창 우주는 100 안팎(⚠**에이전트 간 불일치: 136 / 101 / 51@60s gap** —
  인용 전 직접 유도 필요).
- ⛔초안 "레코드 내 상관 때문에 n=5" → **ICC(1)=+0.077**, 인접창 lag-1 자기상관 **−0.25**
  ⟹ 유효 n ≈ **21.7**(m=6).
- ★**그러나 군집은 5개가 진짜 상한이다**: 디스크 13개 .nc 전수 스캔 결과 BS 7개는 패치
  **13.5–19 m** 로 팬 기하 불가, LJ Grid1 은 Grid2 와 **동일 시각**.
  ⟹ ⛔**내가 사용자에게 보고한 "미등록 8개가 표본 돌파구"는 거짓.**
  E-12(07-14)의 "레코드 5→9/12" 처방은 **현 데이터로 실행 불가**.
- 5군집 **정확검정** 바닥 양측 p = **0.0625** (부호·Wilcoxon·순열 전부). 단측이면 0.03125.
  근사(클러스터-강건 t(4), CR1)로는 α=0.05 도달 가능 — 저장소에 전례 있음
