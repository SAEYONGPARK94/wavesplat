# 논문 로직 구조 — "파를 어떻게 추정하고, 그 결과를 어떻게 논문으로 쓰는가" (2026-07-18)

> 사용자 질문: 지금 논문의 주제가 되는 로직 구조 + 어떤 방식으로 파를 추정한 결과를 논문으로 쓰는지.
> 프레임 v2([[THESIS_FRAMING_v2]]) + E-42~E-56 아크의 통합 설명.

## Part A — 파를 어떻게 추정하는가 (방법/기계)

**물리 상황**: 배가 파도 속을 이동하며 센서(LiDAR/스테레오)로 수면 표고 η를 측정. 짧은 창(window)마다
흩어진 (x,y,t)에서 **~400개 잡음 섞인 점-샘플 z**. **희소**(수면의 극소부분만 봄) + **이동**(센서가 병진).

**파 모델**: 수면 = 자유파 중첩. η(x,t) = Σ_m A_m cos(k_m·x − ω_m t + φ_m).
**★분산관계 하드제약**: ω = √(g|k|·tanh(|k|d)) — 주파수가 파수로 결정됨(자유 아님). ⟹ 추정할 미지는
**2D 파수 스펙트럼 γ(k)** (독립 (k,ω) 아님). 이 제약이 희소 관측을 풀리게 만드는 핵심.

**추정기 (dispersion-constrained spectral GP)**:
1. 모드 진폭에 **스펙트럴 prior** γ(k) (파수별 에너지 = "gamma map").
2. 관측이 모드 계수에 선형: z = Φ w + noise (Φ = 설계행렬, 각 열 = 한 k-원자를 관측점서 평가, ω는 분산관계로 고정).
3. **사후평균 장** = Φ_q diag(γ) Φᵀ (Φ diag(γ) Φᵀ + σ²I)⁻¹ z = 분산제약 선형 MMSE / 스펙트럴 GP.
4. **핵심 미지 = γ(k)**. 데이터서 추정: 빔포밍 파워맵 → **학습망(amortized)** 또는 hand 앙상블 prior.

⟹ **"파 추정" = 분산제약 스펙트럴 GP; 장은 prior γ(k) 주어지면 선형 solve; prior는 희소 데이터서 추론
(빔포밍+학습).** — **이건 확립된 기계**(그래서 방법 novelty = 0).

**언제 잘 맞고 언제 틀리나(기제)**: 분산제약+스펙트럴 prior가 희소 관측으로 장을 결정 —
- **잘 맞음**: 관측이 스펙트럼을 **잘 결정**할 때(개구 충분·우세방향 식별). 바닥→수축→위상 보존.
- **자신있게 틀림**: 관측이 장을 **미결정**할 때(좁은 개구·2차 파티션). ⟹ 논문의 정직함 = **그 경계를 정확히 보임.**

## Part B — 그 결과가 어떻게 "논문"이 되는가 (논증 구조)

**결과 = 상관수치**(추정장이 진실과 얼마나 맞나, corr), 바다·추정기·정보조건별.

**★논문의 논지는 "우리 추정기가 최고다"가 아니다** (그 헤드라인은 죽음: 방법 표준·고전법 대등·선행 소유).
대신 **진단**:

> **"이 희소-이동 관측 레짐에서 성능을 정하는 것은 알고리즘이 아니라 관측의 정보 내용이다. 우리는 임의의
> 보조-정보 채널에 대해 (1)가치 (2)blind 추론가능성 (3)외부공급 등급/환율 (4)공급 달성성 (5)CRB로 회수실패가
> 정보벽인지 추정기한계인지를 회계하는 프로토콜을 제시하고, 그것이 채널마다 다른 사망요인을 판별함을 보인다."**

**왜 이게 논리인가**: **모든 corr 수치가 한 채널의 5요소 중 하나의 *측정*이 된다.** 수치는 "우리가 이겼다"가
아니라 증거다 —
- "참 파티션 공급 = +0.072 (가치)" · "blind 추론 = net 못 넘음 (회수 닫힘)" · "CRB = 정보는 실은 있음,
  추정기 한계지 정보벽 아님 (판별)" · "필요 부이급 = 부재 (달성 실패)".
- 이 사슬이, 채널마다, **곧 논문**이다.

**살아남는 novelty = 프로토콜 + 정직한·검증된 판정.** 새 알고리즘 아님.

## Part C — 논문 구조 (절별 로직)

1. **문제 + 정직한 스코프**: 분산제약 스펙트럴 GP를 희소 이동 관측서. 스코프 = **시뮬 센서 연산자**(실물 LiDAR
   미관측; "실측"=스테레오). 처음부터 명시.
2. **방법(스펙트럴 GP)**: 신규성 아니라 **수단(vehicle)**으로 제시. difference-first(AHGP가 못 하는 4가지).
3. **★정보-채널 회계 프로토콜 (5요소 + CRB 판별)** = 기여.
4. **채널 1 — regime(파티션)**: 5요소 완전 회계 → **achievability서 사망**(부이급 부재). 가치 +0.072/조우
   +0.043(n=957)·blind≈net(open 재현)·CRB 결과 B(추정기 한계+작은 정보잔여 +0.040)·공급 사산.
5. **채널 2 — current(Uc)**: 회계 → **VALUE서 사망**(kp 고치면 됨, radar급 Uc 무가치; base-robust). **다른
   요인서 죽음** ⟹ 프로토콜이 판별함을 실증(2채널 판정완료).
6. **CRB 백본(aperture/Direction-I)**: 채널 아니라 **정보벽을 세우는 기하 축** — 채널들이 그것에 대해 측정됨.
7. **정직한 음성 + 방법론**: 사전등록·대칭 검증·탈-극화 규율([[feedback_direction_flip_discipline]]) →
   음성을 **믿을 수 있게** 만드는 rigor. (심사자 "결과 믿을 수 있나"에 대한 답.)
8. **결론**: 성능은 정보-속박. **주어진 센서+채널마다 "추정기를 만들지 vs 외부정보를 공급할지"를 정하는
   결정 규칙**을 제공 = 실용 기여.

## 한 줄 요약 (사용자에게)
파는 **분산관계로 묶인 스펙트럴 GP**로 추정한다(희소 점 → 스펙트럼 prior → 선형 장복원). 논문은 그 **추정
성능이 알고리즘이 아니라 관측 정보에 속박**됨을 보이고, **채널별 5요소 회계 + CRB**로 "어디서·왜 잘/못
맞는지"를 판별한다 — corr 수치들은 "승리"가 아니라 그 회계의 *측정값*으로 쓰인다.

## 학위 vs 논문 (현 상태)
- **논문(OE/JOE) 성립**: 채널 1 완전 + 프로토콜 + 정직한 음성. 지금 골격화 가능.
- **학위(일반 프로토콜)**: 2채널 판정완료(regime achievability / current value, E-54~E-56)로 **다채널 일반성
  실증** — 단 스코프 병기(current은 radar급·deep-swell·nowcast 한정). 완성엔 forecast/tidal·실측 anchor가 남음.
