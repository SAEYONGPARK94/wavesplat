# 3. `KILL` — 각도 3b: **VARPRO 는 원리적으로 진폭 붕괴를 못 고친다**

(§1 이 붕괴 자체를 인공물로 판정했지만, 진짜 붕괴가 나타나도 처방이 답이 아니라는 것을 코드로 보인다.)

## 3.1 MEASURED — VARPRO 의 자유변수는 `k` 뿐이고, (a,b) 는 **벌점 없는 LS** 다

`tmp/W4_SOLVER_2026-08-19/varpro.py:174-184`:

```python
A = Phi_w.T @ Phi_w + ridge * torch.eye(2*n, ...)      # VP_RIDGE_DEFAULT = 1e-8
c = torch.linalg.solve(A, Phi_w.T @ z_w)
```
`Phi = [cos Θ(K) | sin Θ(K)]`, `Θ_j = kx_j x + ky_j y − ω_j t`, `a = w cosφ, b = −w sinφ`.
자유변수는 **`K=(kx,ky)` 뿐**(파일 헤더가 *"the ONLY free variables"* 라고 적었다).

## 3.2 ARGUED (코드가 강제하는 기하) — ‖c‖→0 은 **버그가 아니라 LS 정답**이다

`c = (Φᵀ Φ + 1e-8 I)⁻¹ Φᵀ z`. **제안된 기저 `Φ(K)` 가 자료 `z` 와 상관이 없으면 `Φᵀz → 0` 이고
따라서 `c → 0`, 즉 `w = hypot(a,b) → 0`.** 진폭 수축은 *"K 가 틀렸다"* 의 **닫힌형 서명**이다.

⟹ ★**"파수 제안이 쓰레기면 닫힌형도 쓰레기다"** 는 정확하다. 더 나아가 —
**VARPRO 는 붕괴를 고치기는커녕, 결합 적합보다 더 정확하게 붕괴를 재현한다**
(결합 적합은 L1(λ=1e-4)과 Adam 유한스텝 때문에 0 에 *덜* 정확히 수렴한다).

## 3.3 MEASURED — VARPRO 가 남기는 것은 정확히 **풀지 못한 k 부분문제**다

- W3: `ORA-K-CVX`(오라클 k, 닫힌형, 경사하강 0스텝) 혼잡 **0.00139** vs 최선 경사하강 0.138 = **×95.4**.
- W5: `L-VP-ONLY` **0.105761** vs `ORA-K-CVX` 0.001298 = ★**×81** — W5 자신이 §6.2 에
  *"상한 대비 여전히 ×81"* 이라 적었다.

⟹ VARPRO 는 (a,b) 부분문제를 닫았고 **k 부분문제는 그대로 열려 있다**(95배 → 81배, 대부분 잔존).
VARPRO 의 `k` 하강 출발점은 **`_initialize_learned` 의 출력**이다(`varpro.py` 가 그 메서드를
monkeypatch 한다).

## 3.4 ★그런데 실측에서 **그 출발점이 분포 밖(OOD)** 이라고 저장소가 스스로 적었다

- `d3_falcon_real_operator.py:15` — *"hand-MMSE only (**net is OOD for this operator until retrained**)"*
- `real_estimate.py:19` — *"⚠ The learned initialiser is out of distribution here (trained on the
  synthetic corpus). That is not a bug in this script; it is the finding..."*
- 메모리 — ★**"담지자는 프레임워크가 아니라 체크포인트"**, **분포 이동 2회 모두 패배**.

5. `r_fan` 축척(**실척 2 / 축소 3**)으로 층화 인쇄 + **VARPRO 호출 원자 카운터**를 스모크에서 확인.

## 8.3 ★대안 — 이 배치가 답할 수 있는 질문으로 갈아타라

n=5 는 **"얼마나"** 를 못 판정한다. 그러나 **런 0회 게이트**는 아직 안 쓴 자원이 있다:

> **`R-VP-ORA-K`(§3.6)를 넣고, PRIMARY 를 *"실측에서 벽이 `k` 냐 `(a,b)` 냐"* 로 바꿔라.**
> 이건 **부호 하나**만 필요하고, W3 의 `ORA-K-CVX ×95` 를 **실측에서 처음 재현/반증**하며,
> 척추(*"벽은 정보가 아니라 위상의 비볼록성이다"*)를 **합성 밖에서** 시험하는 유일한 실측 설계다.
> 그리고 이 질문은 §6.2.3 의 레짐 미판정에 **영향받지 않는다**(팔 내부 대조이므로).

⚠단 그 경우에도 ⛔**`SUPPORT-TRADEOFF` 를 "우리 이득은 먼바다에 있다" 로 읽지 마라** —
그건 전부 내부 노브 대조였다(08-15 전수 감사, 외부 기준선 행 0개).
