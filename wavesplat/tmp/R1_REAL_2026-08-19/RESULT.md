# RESULT — `R1 · REAL` = ★**`STRUCTURALLY-UNMEASURABLE`** (런 0회)

**이 배치는 사전등록 동결 전에 죽었다.** 사인은 통계도 표본도 아니라 **구조**다.
오늘 저장소에서 **네 번째** 런 0회 사망이고, 사유는 저장소가 반복해서 대가를 치른 그것이다 —
*"안 돌아가는 코드를 연구하지 마라."*

---

## 1. 물으려던 질문
정정을 세 번 거친 끝에 확정된 질문:
> *"실측에서 **실제로 쓰이는 경로**(`bank_mmse`)에 VARPRO 를 얹으면 되는가."*

## 2. 답 — **얹을 수 없다. 얹을 자리가 없다.**

`varpro.py` 는 **`SequentialUpdater._initialize_learned` 를 패치**한다(유일 대상, 실측).
그런데 실측 입력에서 배포 라우터는 `REAL-DOMAIN GATE`(`sequential_update.py:434-470`)를 통과해
**`_initialize_bank` 로 직행**하고(`:497` `return self._initialize_bank(frames, verbose)`),
**`_initialize_learned` 를 한 번도 부르지 않는다.**

`_initialize_bank` 본문 실측(정규식 계수):
| 패턴 | 횟수 |
|---|---|
| `.backward(` | **0** |
| `.step(` | **0** |
| `for iteration` | **0** |
| `range(max_iters` | **0** |
| `_initialize_learned` | **0** |

그리고 반환 계약이 스스로 말한다: **`'n_iters': 0`** · **`'final_n': 0`**
— 주석이 축자로 *"no Gaussian components on this route"*.

⟹ ★**실측 경로에는 경사하강 단계도, 가우시안 성분도 없다.**
VARPRO 의 전제(*"진폭·위상을 해석적으로 소거하고 파수에서만 하강한다"*)는 **소거할 선형 파라미터도,
하강할 비선형 파라미터도 없는 곳**에 붙일 수 없다. **개입률이 낮은 게 아니라 0 이고, 그것은 구조적이다.**

## 3. 세 갈래뿐이고 셋 다 이 배치가 아니다
| 길 | 왜 이 배치가 아닌가 |
|---|---|
| (a) `real_domain_gate=False` 로 게이트를 끈다 | 라우터가 실측 창 **30/30 을 OOD `learned`** 로 보낸다. **오늘 실제로 해봤고 무너졌다**(배포 0.272 · VARPRO **0.420** · 항등 기준선 0.250). ★게다가 이건 **저장소가 승인하지 않은 정책을 실측에 적용하는 것**이다(게이트 주석이 그렇게 적었다). |
| (b) 실측 경로를 가우시안+경사하강으로 다시 짠다 | **연구 프로그램이지 배치가 아니다.** |
| (c) `bank_mmse` **안에서** VARPRO 를 쓴다 | bank 는 **후보 은행 + MMSE** 라 매개화가 다르다 ⟹ 같은 이름의 다른 처치가 된다. 하려면 **새 사전등록**이 필요하다. |

## 4. ★이 사망이 실제로 산 것 — 학위논문 범위 절에 들어갈 문장
> **"배포 시스템은 두 개의 구조적으로 다른 추정기를 돌린다. 합성 입력에는 가우시안 성분 + 경사하강
> 경로를, 실측 입력에는 `REAL-DOMAIN GATE` 를 통해 비-경사 은행 추정기를 쓴다. 2026-08-19 의 개선
> (−25.3%, 2.04배)은 **전자에만** 적용되며, 후자로 이전하려면 후자를 다시 짜야 한다."**

★**이건 추측이 아니라 코드가 스스로 적어놓은 사실이다** — 게이트 주석이 *"the deployment authorisation
covers SYNTHETIC inputs only"* 라고 축자로 쓴다. ⟹ **"실측 전이" 는 미측정이 아니라 설계상 분리돼 있다.**

## 5. ⛔ 이 문서가 주장하지 않는 것
1. ⛔**"실측에서 우리 시스템이 안 된다" 금지** — 배포 경로는 2026-07-29 에 실측 3레코드에서
   **제로필드를 3/3 이겼다**(4σ 규약 0.122 · 0.162 · 0.181 vs 0.250).
2. ⛔**"VARPRO 가 실측에서 나쁘다" 금지** — 오늘 잰 0.420 은 **게이트를 무력화한 비승인 경로**의 수다.
3. ⛔**"bank_mmse 가 더 낫다" 금지** — 두 경로는 **다른 입력에서** 잰 것이고 짝지어진 적이 없다.
4. **범위**: 이 판정은 **코드 구조**에 대한 것이지 성능에 대한 것이 아니다.
