## §0 왜 이 배치가 있는가 — **더 잴 것을 사기 전에 자를 고친다**

실측 채점 규약에 **두 가지 구조적 결함**이 있다. 둘 다 **어느 팔의 수치도 보지 않고**
진술할 수 있다.

### 결함 A — 참 장이 0 점을 못 받는다
`scene_station.py:121-122` 가 관측창 `Zmem`(40 s)과 채점창 `Zfut`를 **따로** 만들고,
`scripts/d3_sa_multirecord.py:144` 가 `Z -= np.nanmean(Z, axis=0, keepdims=True)` 로
**창별·픽셀별** 시간평균을 뺀다. 두 창의 자기평균이 다르므로 같은 물리 시각의 참 장이
두 규약에서 **다른 값**을 갖는다.

관측은 `Zmem` 규약을 표집하고 채점은 `Zfut` 규약으로 한다 ⟹
***관측을 완벽히 재현하는 추정기도 0 점을 못 받는다.***
그리고 모형은 그 차를 만들 수 없다 — `model/spectral_gaussian.py` 의 전방식
`z = Σ wᵢ cos(kxᵢx + kyᵢy − ωᵢt + φᵢ)` 에 DC 항이 없고, 하드 제약
`ω = √(g|k|tanh(|k|d))` 가 정적장(ω=0, |k|>0)을 금지한다.

⚠**비대칭이 핵심이다**: 제로 예측자는 `zero_ref.py:44-52` 가 `Z ≡ 0` 을 같은 식에 통과시킨
값이라 **기준면을 갖지 않는다** ⟹ *팔 대 제로* 비교가 **팔에게 불리**하다.

### 결함 B — 채점 목표가 **배치가 고른 lead 격자**에 의존한다 (★내가 재측정했다)
`i0` 를 **고정**하고 `Zfut` 길이만 바꾸면 `maps_gt[0]` 의 제로 기준이 움직인다:

| | n_lead=20 | 50 | 80 | 140 | spread |
|---|---|---|---|---|---|
| `BS13a` | 0.7231 | 0.7277 | 0.7235 | 0.7017 | 1.037× |
| `LJ18a` | 0.5251 | 0.4117 | 0.3691 | 0.3375 | **1.556×** |
| **12 레코드** | | | | | **1.037–1.556× · 불변 0/12** |

⟹ ***lead 0 의 채점 목표는 바다의 성질이 아니라 「얼마나 멀리까지 채점하기로 했는가」의
성질이다.***

⚠**잠재 결함이지 실현된 오염이 아니다**: 동결 배치 전건이 `lead_max=14.0` 이고
자동 단축 분기(`scene_station.py:110-113`)는 12 레코드 어디서도 발화하지 않는다.
⛔따라서 *"기존 배치가 오염됐다"* 로 쓰지 않는다.

★**부수 발견(내 측정)**: `lead_max` 를 바꾸면 `scene_station.py:114-118` 이 `i0` 를
다시 계산해 **창 위치까지 움직인다**. 위 표는 그것을 **분리**한 값이다
(고정하지 않고 재면 1.093–2.456× 로 **두 효과가 섞인다**). ⚠이 사실 자체가 별도의 함정이다.

## §1 후보와 선택 — **어느 팔의 수치도 보지 않고 고른다**

| | 후보 | 참 장 0점? | 인과 실현? | `Zmem` 불변? |
|---|---|---|---|---|
| **①** | **`Zfut` 를 `mu_mem` 으로 demean** | ✅ | ✅ | ✅ |
| ② | demean 안 함 | ⛔(정적 편향 전체가 바닥) | ✅ | ✅ |
| ③ | 공통(합집합) 창으로 둘 다 demean | ✅ | ⛔**미래 자료로 보정 정의** | ⛔`Zmem` 이 바뀐다 |
| ④ | 채점에서 DC 제거 | ⛔부분만 | — | ✅ |

**선택 = ①.** 두 선택 기준은 **GT 의 정의에만** 걸려 있다:

- **`G-ORACLE`** — *"추정기가 적합한 그 장을 예측하라고 요구받는다"* ⟹ **참 장의 점수는 0**.
  ①·③ 만 통과.
- **`G-INVAR`** — *"lead 0 의 목표는 배치의 lead 격자에 의존하면 안 된다"*.
  ① 은 `mu_mem` 이 `lead_max` 와 무관하므로 **구조적으로** 통과.

**① vs ③ 은 수치가 아니라 두 사유로 갈린다**: ③ 은 (a) 미래 자료로 보정을 정의해
**배포 불가**이고, (b) `Zmem` 을 바꿔 **동결 장면과의 비트동일성을 파괴**한다.

★**① 의 결정적 성질**: `Zmem` 이 불변이므로 `P`·`z`·`Pq`·`sg`·`Hs`·`kp` 가 **비트 동일**하고
따라서 **추정기 출력이 비트 동일**하다 ⟹ ***한 번의 런에서 두 규약을 동시에 채점***할 수 있고,
**옛 규약이 동결 결과를 재현하는지**가 게이트가 된다(`G-FROZEN`).

## §6 ★검정력 — **내 자신의 예측 하에서**

**내 예측**: *"판정 불변, 10/12"*.
감사가 Cauchy–Schwarz 로 결과 전에 확정한 범위 = **8승 확정 + 4 가변**(도달 8–12).
가변 4를 동전던지기로 보면 `≥10` = **11/16 = 68.8%** · `9` = 25% · `8` = 6.3%.

⟹ ★★**이 설계는 자기 예측 하에서 `CONFIRMATORY`(가족 α=0.025 ⟹ 11/12 필요)에
도달할 수 없다.** 그래서 **단일 검정 α = 0.05 로 등록하고 등급을 올리지 않는다.**
⛔결과를 보고 가족을 재정의하지 않는다.
