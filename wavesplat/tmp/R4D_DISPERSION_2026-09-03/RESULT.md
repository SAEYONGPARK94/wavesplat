# `R4d-DISPERSION` 결과 — **`DEEPWATER-EQUIVALENT`** (게이트 11/11 · 런 0회) · 예측 적중

> 등급 **`EXPLORATORY`**. ⛔**발견이 아니다** — 기능은 **도구 확장의 무해성 증명**이다.

## 1. PRIMARY

⟹ ★***자를 유한 수심으로 넓혔고, 기존 판정은 한 비트도 움직이지 않는다.***
`R4b`·`R4c` 의 `DISPERSION-REGIME-DIFFERS` / `-HOLDS` 는 **그대로 유효**하다.

## 2. 개입은 **한 줄**이었다

```
jl = round(√(9.81·k)         / dω)     # R4c — 심해 근사
jl = round(√(9.81·k·tanh(kd)) / dω)     # R4d — 유한 수심
```

수심은 **레코드가 선언한 값**(`scene_station.RECORDS_12`)에서 오고 행에 기록된다.
그 밖 모든 규약(창·`NT`·링·서브샘플·귀무·시드·`B`·`PCTL`·문턱)은 `gates_r4c` 에서 **임포트**한다
⟹ *"바꾼 것은 하나뿐"* 이 **주장이 아니라 코드**다.

## 3. ★이 배치가 사는 것

이제 입회검정을 **얕은 물 후보에 적용할 수 있다.** 그전까지는 `kd ≲ 3` 자료(실험실 수조·
천수역)를 넣으면 참 분산면이 심해면 아래에 있는데 자가 심해면에서 세므로
⛔***"파랑 구조가 없다" 는 틀린 사유로 기각***했을 것이다.

⚠**그러나 이 배치는 그쪽에서 옳게 작동함을 보이지 않는다** — 심해에서 **무해**함만 보인다.
★확장이 얕은 물에서 옳은지는 **그런 자료를 실제로 넣어 보는 후속**이 판정한다.

## 4. ⛔범위와 금지

- ⛔**발견 아님** · ⛔`R4b`·`R4c` 계수 갱신 아님 · ⛔`blind` 아님(모든 값을 알고 동결).
- ⛔*"DesignSafe 8/8 탈락은 수심 때문이었다"* 로 **읽지 마라** — 그 배치는 별도 측정이고
  `R4b/PREREG §6` 이 기제 지목을 금지한다. 이 배치는 **그 재검을 하지 않았다**.
- ⛔*"남극 자료가 나쁘다"* 아님 · 사이트 일반화 금지.
- ⚠남극 수심은 자료에 없어 **선언값 1000 m** 를 썼다(심해라 `tanh → 1`; 행에 기록).
