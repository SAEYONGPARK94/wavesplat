## 1. PRIMARY — 배포 신뢰가중은 이 코퍼스에서 **상수다**

`observation_weights(θ, r; d_ref) = clamp(cos θ / (r/d_ref), 0, 1)`, `d_ref = 125 m`(코드 되읽기).

| | 값 |
|---|---|
| 포화(모든 점에서 미클램프 ≥ 1) 레코드 | **7/7** |
| 미클램프 conf **최소** | **1.232** |
| 미클램프 conf 중앙 범위 | **2.07 – 2.77** |
| 실제 사거리 중앙 | 23.6 – 27.3 m |

★기제: `d_ref = 125 m` 는 **선박 LiDAR 규모**의 기준거리이고 고정 관측소 스테레오는
**23–27 m** 다 ⟹ 비가 `r/d_ref ≈ 0.19` 라 `cos θ` 가 0.45 여도 몫이 **2 를 넘는다**
⟹ `clamp` 가 전부를 **1** 로 만든다.

⟹ ★***원장의 「`A7` 신뢰가중 = 실측에서 구조적 무연산」에는 두 번째, 독립적인 이유가 있다.***
하네스가 `confidence=1` 을 박아 넣은 것(`make_gif_bank_deployed.py:78`)뿐 아니라,
**공식 자체가 이 사거리에서 상수**다. 하네스를 고쳐도 값은 안 바뀐다.

⚠부호검정이 아니다 — 포화 비율은 **자료의 성질**이지 표본추출이 아니다. p 를 붙이지 않는다.

## 4. ⛔범위와 금지

- ⛔**배포 기본값 변경 아님** — 하네스의 **입력**만 바꿨다.
- ⛔*"신뢰가중이 쓸모없다"* 로 넓히지 마라. 잰 것은 둘뿐이다:
  (a) **이 사거리에서 공식이 상수**라는 것, (b) **어느 경로가 그 필드를 읽는가**.
- ⛔`CVAR` 는 **계측기**다 — 배포 후보가 아니고 정확도 근거도 아니다.
- ⛔**BS 7 · 1 사이트** — 사이트 일반화 금지 · 실측 12 판정의 재채점 아님 ·
  `B-2`·`R1b`·`B-25` 계수 갱신 아님.
- ⚠**평면 근사 법선**(0,0,1)을 썼다 — 참 경사를 쓰면 값이 달라지지만 그것은 **GT 누출**이라
  쓰지 않는다(`B-25` 가 다룬 축).
- ★**후속이 물을 수 있는 것**: `d_ref` 를 사거리 규모로 다시 잡으면 가중이 변동한다.
  ⛔그것은 **새 상수를 고르는 일**이므로 별도 사전등록이 필요하다.
