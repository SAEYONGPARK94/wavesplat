> **동결 시점: 결과 0행.** 사용자 상시지시(2026-09-03, 축자): *"실측과 비교가능한 데이터나
> 방법이나 아니면 이를 보충 할 수 있는 방법을 메가 메시브하게 검토해줘"*.
> ⛔`wavesim/**` 무수정 · ⛔동결 배치 재실행 없음 · ⛔`scene_station.py` **무수정**(임포트만).

## §0 왜 — 실측 절의 **모든** 수치에 붙어 있는 반론

`M-10` 이 12 레코드 전건에서 잰 값: **질의점 → 최근접 관측점 간격 = 0.0223–0.0485 λ**.
⟹ ***현행 실측 채점은 사실상 보간이다.*** `R1b` 의 `11/12` 도, `B-2` 계열의 판정도
**관측 지지집합 안**에서 나왔다. **지지집합 밖 성능은 한 번도 측정된 적이 없다.**

⚠소거표에서 *"✅도달 가능, 미착수"* 로 남아 있는 축이 정확히 **관측 기하** 하나다.
이 배치가 그것을 **합성이 아니라 실측 쪽에서** 처음 잰다.

## §1 개입 — **단일요인, 개구는 구조적으로 동일**

`scene_heldout(record, win, region)` 을 이 배치 안에 새로 쓴다.
`scene_station` 과 **한 줄만 다르다**: 프레임별 관측 선택 마스크에 **영역 마스크**를 AND 한다.

| 팔 | 관측 영역 | 채점 영역 |
|---|---|---|
| `IN` | `x ≤ x_split` | **`x ≤ x_split`** (지지집합 **안**) |
| `OUT` | `x ≤ x_split` | **`x > x_split`** (지지집합 **밖**) |

★★**`IN` 과 `OUT` 은 같은 런이다.** 추정기를 **한 번** 돌리고 **질의점 부분집합 둘**로
채점한다 ⟹ **개구·관측수·시드·초기화가 비트 동일**이고 **바뀌는 것은 채점 영역 하나뿐**이다.
⛔*"개구가 줄어서 나빠졌다"* 는 반론이 **구조적으로 성립하지 않는다.**

- `x_split` = `median(rec.gx)` (결과 전 고정, 코드가 계산해 행에 기록)
- `region='ALL'` 이면 `scene_station` 과 **비트 동일**해야 한다 ⟹ `G-BIT`
- 채점 규약은 `R1b` 의 **수리된** 것(`g_new = g_old + (mu_fut − mu_mem)`)을 상속
- **lead 0(나우캐스트)만** 잰다 — 예보 축과 섞지 않는다

## §2 PRIMARY — 결과 전 고정

`ratio_R(rec)` = `RMSE_SHIP(R) / RMSE_zero(R)` (R ∈ {IN, OUT}) — **1 미만이 기술**.

**가설(방향 고정)**: `ratio_OUT > ratio_IN` — **지지집합 밖에서 기술을 잃는다.**

- 통계: **단측 부호검정**, n = **12** 레코드, α = 0.05
- 문턱: **10/12**(p = 0.0193) = 명목 · **11/12**(p = 0.0032) = 확증
- ⚠**자기 예측 하의 검정력**(동결 전): 내 예측은 *"거의 전건에서 밖이 나쁘다"* = 11–12/12.
  그 예측이 참이면 라벨을 낼 확률이 높다. ⚠단 예측이 **틀릴** 경우 — 즉 밖에서도
  기술이 유지될 경우 — `w ≤ 7` 이면 **반대 방향**이 되고 그것도 판정이다(아래 표).

### 결과 전 동결 판정표

| `w` | 라벨 |
|---|---|
| **≥ 11** | **`SUPPORT-BOUND-CONFIRMED`** — 실측 기술은 **관측 지지집합 안에 갇혀 있다** |
| 10 | **`SUPPORT-BOUND-NOMINAL`** — 명목만(⛔확증 아님) |
| 8–9 | **`SUPPORT-UNDECIDED`** |
| **≤ 7** | **`SUPPORT-GENERALISES`** — ★예측 반증. 밖에서도 기술이 유지된다 |

## §3 대조 (⛔결과 전 고정)

| # | 대조 | 왜 |
|---|---|---|
| ★`C-IN` | `ratio_IN < 1` 이 **10/12 이상** | **양성 대조.** 지지집합 **안**에서조차 기술이 없으면 PRIMARY 는 해석 불가 ⟹ **판정 없음** |
| ★`C-ZERO` | 두 영역의 `zero` 절대값을 행에 기록하고, `zero_OUT/zero_IN` 의 범위를 병기 | 두 영역은 **다른 자료**다. 비를 쓰는 이유가 이것이고, ⛔절대오차 비교 금지 |
| `C-GAP` | 두 영역의 **질의→최근접관측 간격**을 `λ_p` 단위로 행에 기록 | 개입이 실제로 걸렸는지의 **원자 카운터**. `gap_OUT` 이 `gap_IN` 보다 크지 않으면 개입 실패 |
| `C-PROP` | 같은 대조를 `PROP`(제안 표현)에 대해 별도 보고 | ⛔`PROP` 은 실측 무기술이므로 **PRIMARY 에 넣지 않는다** |

## §4 차단 게이트 (⛔사후 완화 금지)

| # | 게이트 |
|---|---|
| ★`G-BIT` | `region='ALL'` 이 `scene_station` 과 **비트 동일**(관측 해시·질의 해시) — ⛔실패 시 판정 없음 |
| ★`G-NOBS` | `n_obs` 가 `IN`/`OUT` 에서 **같다**(같은 런이므로 구조적) **그리고** `ALL` 팔과 같다(=`m_cap`) |
| ★`G-GAP` | 전 레코드에서 `gap_OUT > gap_IN` — **개입이 실제로 걸렸다는 원자 확인** |

| `G-ARM` | 팔 구성 **객체 되읽기**(⛔의도표 아님) + 출하 삼종 대조 |
| `G-SEED` | 추정기 시드 = `42`(`B-2` 상속), 장면 시드 = `700+win` |

| `G-BLOCK` | `blocked_by()` **자가진단** — 합성 실패행으로 이름을 실제로 잡는지 확인 |

## §4b `SEC-LARGE` — **검정력을 지는 사전등록 층** (결과 전 고정)

★결과 전 장면 점검(⛔추정기 0회)에서 확인: 질의점 수가 레코드마다 **8–1,262** 로 두 자릿수
갈린다(BS 격자는 박스가 12–16 m 라 4 m 질의격자에 8–15 점밖에 안 들어간다).
⟹ **박스 ≥ 40 m 인 5 레코드**(`AA14`·`AA15a`·`AA15b`·`LJ18a`·`YS17`, npx ≥ 55)에서
같은 PRIMARY 를 **따로** 집계한다. 문턱 **5/5**(p = 0.03125) — ⚠**전승만 유의**.
⛔이것은 PRIMARY 를 대체하지 않는다. 둘이 갈리면 **갈렸다고 적는다.**

⚠`G-SPLIT` 의 문턱을 **20 → 5** 로 내렸다(결과 0행, 추정기 0회). 사유는 성능이 아니라
**질의격자 해상도**이고, 그 결과 ***이 게이트는 현 코퍼스에서 발화하지 않는다*** —
기능은 「퇴화 분할 탐지」이지 「검정력 보증」이 아니다. 검정력은 `SEC-LARGE` 가 진다.
