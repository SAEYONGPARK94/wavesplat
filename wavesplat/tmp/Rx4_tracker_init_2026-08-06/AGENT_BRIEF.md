## 절대 규칙 (역할 무관, 위반 시 그 보고는 폐기된다)
1. **원자료에서 직접 재도출하라.** 남이 계산해 준 수치를 그대로 옮기지 마라.
   `analyze_rx4.py` / `rederive_rx4.py` 의 출력은 **대조용으로만** 보고, 최소 한 번은
   `results.jsonl` 에서 네 손으로 다시 계산하라 (네가 쓴 코드로).
2. **사전등록을 이긴다.** `PREREG.md` §4(집계 규약) §5(합격선) §6(무결성) 은 결과를 보기 전에 동결됐다.
   규약을 결과에 맞춰 바꾸지 마라. 다른 규약을 쓰고 싶으면 **"사전등록 규약 = X, 내 대안 = Y"** 로 병기하라.
3. **널 병기 의무.** 모든 nRMSE 는 그 에피소드의 평평한바다 널(`nulls_full.json`)과 함께 보고한다.
   널 미달 셀/블록의 수치는 결과로 인용 금지.
4. **n=4(설정 단위)에 "유의" 금지** (부호검정 바닥 p=0.125).
5. **`AUTO` 는 단일 추정기가 아니라 라우터다** (에피소드/시드마다 learned 또는 v2_konly).
   "AUTO 가 ~한다" 대신 "AUTO 라우팅 하에서 ~"로 쓰고, `auto_selected` 분포를 확인하라.
6. **묶음 개입에 단일 원인 이름 금지.** (본 실험은 셀당 노브 1개라 해당 없어야 한다 — 확인하라.)
7. 벽시계로 성능 주장 금지.
8. **모르면 모른다고 하라.** 검정력 부족과 효과 없음을 구별하라 (MDE 대비 관측 효과크기를 계산).

## 배경 (전제 — 이미 측정으로 확인됨, 재확인 환영)
- `spectral_gaussian.py:38` — **`w` 는 진폭(amplitude, [m])이지 각주파수가 아니다.**
  따라서 출하 `tracking_mode='w_phi'` 는 **"진폭+위상"** 추적이다.
- 추적 중 **kx,ky 는 동결**, `omega` 는 파라미터가 아니라 매 forward 마다 분산관계로 재계산된다.
  측정된 분산관계 위반량 = **4.8e-07** (float32 잡음) ⟹ "추적기가 물리제약을 깬다" 가설은 **사망**.
- B3(선행): 혼잡에서 **추적기를 끄면 −0.0391 (4/4, −16.9%)**. 기제 = Phase 2 가 초기화를 **+0.0354** 망친다.
- Rx-4 진단(`diag_analysis.txt`, 서술적): 손상은 **단조 누적**, 채널은 **탈상관** 지배,
  반사실 분해가 손상의 대부분을 **진폭(w)** 에 놓았다 (`dmg_w` +0.0278 vs `dmg_phi` +0.0054).
  ⚠ 이 분해는 **실현된 joint 궤적 위의 분해**이며 한 채널을 얼려 다시 돌린 결과의 예측이 아니다.

## 판정해야 할 것
- **PRIMARY**: `T-PHIONLY`, 블록 C(혼잡16, 널 배제 후), `nRMSE`.
  - A조건: `median Δ(T-PHIONLY − AUTO) < 0` **그리고** 승 ≥ 13/16
  - B조건: `Δ(T-PHIONLY − AUTO-NOTRACK)` 가 NOTRACK 편으로 13/16 에 도달 **못함**
  - STRONG PASS / PASS / PARTIAL / FAIL / VOID — §5 정의 그대로
- **D1 (진단 반증 시험)**: |Δ(T-PHIONLY−AUTO)| > |Δ(T-WONLY−AUTO)| 이면 진단 지지, 아니면 **진단 반증**.
  ★**반증이면 "반사실 분해가 개입을 예측하지 못했다"고 그대로 보고하라.** 이건 실패가 아니라 결과다.
- **D2**: `T-EARLY20` 이 AUTO(0) 와 바닥 사이에 있는가.
- **블록 S(희소8)**: 해 끼치지 않기 점검 전용. PRIMARY 를 뒤집지 않는다.
- **무결성 §6.2 Phase-1 불변 / §6.3 워커누출** — 통과 못 하면 해당 셀 VOID.
