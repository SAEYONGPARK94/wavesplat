## 4. 집계 규약 (동결 — 결과를 본 뒤 **변경 금지**)

1. **시드 → 에피소드**: 중앙(median-of-3).
2. **수준값**: 에피소드 중앙들의 중앙 (medOfMed).
3. **효과**: **짝지은** 에피소드별 `Δ(ep) = median_seeds[cell](ep) − median_seeds[REF](ep)` 의 **중앙**.
   기준 셀 `REF` 는 **두 개를 다 보고한다**: `REF=AUTO`(개입−출하) 와 `REF=AUTO-NOTRACK`(개입−바닥).
4. **방향 (명시적으로 못 박음)**
   - `nRMSE`: **Δ < 0 = 개입이 더 좋다**. `k/n` = Δ<0 인 에피소드 수 ("승").
   - `Pearson_rho`: **Δ > 0 = 개입이 더 좋다**.
   - `|VR−1|`(프레임별로 형성 후 평균, `absVR_framewise`): **Δ < 0 = 개입이 더 좋다**.
   - `m_mean`, `decorr_mean`, `shrink_mean`: **Δ < 0 = 개입이 더 좋다**.
5. **검정**: 짝지은 **부호검정, 양측**. 동점(Δ=0 정확히)은 **불리하게** 처리한다(승으로 세지 않고 n 에는 남긴다).
6. **회복률** `R = median(Δ_cell−AUTO) / median(Δ_NOTRACK−AUTO)` — **서술 전용**.
   판정에는 쓰지 않는다(작은 수의 비는 불안정). 판정 통계량은 §5 의 짝 부호검정이다.
7. **상대 효과** `Δrel(ep) = Δ(ep) / median_seeds[AUTO](ep)` 의 중앙 — 서술 전용, 층 간 오차규모 차이 때문에 병기 의무.
8. 벽시계는 기록하되 **성능 주장에 쓰지 않는다**.

## 5. 합격선 / 실패조건 (결과 보기 **전** 동결)

★**기준은 "AUTO 보다 낫다"가 아니라 "끄는 것(`AUTO-NOTRACK`)에 얼마나 근접/초과하는가"다.**
끄는 것보다 못한 개입은 무의미하다 — 배포자는 그냥 끄면 되기 때문이다.

**PRIMARY = `T-PHIONLY`, 블록 C(CROWDED16, 널 배제 적용 후), 지표 `nRMSE`.**

- **A조건 (출하 추적기를 이긴다)**: `median Δ(T-PHIONLY − AUTO) < 0` **그리고** 승 ≥ 13/16.
- **B조건 (바닥에 도달한다)**: `Δ(T-PHIONLY − AUTO-NOTRACK)` 의 부호검정이
  **NOTRACK 편으로 13/16 에 도달하지 못한다**.
- **판정**
  - **STRONG PASS** = A조건 ∧ (T-PHIONLY 가 NOTRACK 을 **이긴다**: 승 ≥ 13/16) — 즉 **끄는 것보다 낫다**.
  - **PASS** = A조건 ∧ B조건 — 즉 **끄는 것과 구별되지 않으면서 출하 추적기보다는 낫다**.
  - **PARTIAL** = A조건은 만족하나 NOTRACK 이 13/16 으로 이긴다 — **끄는 것이 여전히 낫다** ⟹ 개입은 무의미.
  - **FAIL** = A조건 불만족.
  - **VOID** = §6 무결성 검사 실패 또는 NULL-FAILING.
- 같은 규칙을 `T-WONLY`·`T-EARLY20`·`T-K4REF` 에 **서술적으로** 적용한다(PRIMARY 는 `T-PHIONLY` 하나뿐).
