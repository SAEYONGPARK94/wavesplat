## 0. 왜 다시 하는가

### A (Rx-5): Rx-4 의 채널 질문은 **답이 없었던 게 아니라 물어진 적이 없다**
Rx-4 는 `tracking_mode` 를 `phi_only`/`w_only` 로 바꿔 "손상이 어느 채널에 사는가"를 물었다.
3검토자 + 내 원자료 확인이 그 대조를 무효화했다: Adam 은 **≈lr 크기의 절대 스텝**을 밟는데
두 채널의 자연 스케일이 다르다.

| 채널 | 자연 스케일 | 공유 `lr=0.005` 의 **상대 스텝** |
|---|---|---|
| 진폭 `w` | 추적 시작 시점 median\|w\| = **0.044095 m** (§3 측정) | **11.3 %** |
| 위상 `phi` | 2π rad | **0.080 %** |

⟹ **142배 비대칭** (초기 GT 진폭 기반 추정 ~100배보다 크다). `tracking_mode` 는 config 키 1개지만 **묶음**이었다.
★그리고 동결 판정식 `|Δ(PHI)|` vs `|Δ(WONLY)|` 는 **두 Δ 가 모두 양수**로 착지해
**"더 크게 망친 팔이 이기는 검정"**으로 퇴화했다 ⟹ Rx-4 의 D1 은 **반증이 아니라 UNDECIDED**.

### B (E-스윕): Rx-4 의 `T-EARLY20` 은 **한 점**이라 기제를 잃었다
−0.0123(13/14) 로 유일하게 사전등록 문턱을 넘었으나 §7 이 미리 금지한 대로
**20 은 스윕이 아닌 사전선택 1점**이었고, 회수율 60.1% 가 **자명한 프레임비율 모델과 구별되지 않았다**
(짝검정 9/14, p=0.42). 곡선을 재야 기제가 산다.

## 3. `RX5_LR_W_MATCHED` 확정 (결과 보기 **전** 측정, `measure_wscale.py`)

정합 정의: 상대 스텝 = `lr / 파라미터의 자연 스케일`.
- 위상: `0.005 / 2π` = **7.9577e-4**
- 진폭: **추적 시작 시점(Phase 1 종료 직후) 모델의 `median|w|`** — GT 진폭이 아니라 **모델 파라미터**를
  잰다(GT 를 lr 에 넣으면 누수). 출하 작동점으로 16ep × 3시드 = 48회 측정 후 **블록 중앙으로 동결**.

⟹ `RX5_LR_W_MATCHED = 7.9577e-4 × median|w|`. **런마다 바꾸지 않는다**(데이터 의존이 되면 셀이 묶음이 된다).

### ★측정 완료 (48회 = 16ep × 3시드, `wscale.json` / `wscale.log`, 결과 채점 **전**)
| 항목 | 값 |
|---|---|

| 위상 상대 스텝 `0.005 / 2π` | 7.957747e-04 |

## 4. 집계 · 방향 · 검정 (오늘 물린 것 **전부** 미리 박음)

| 지표 | 열화 방향 | 집계 |
|---|---|---|
| `nRMSE` | 클수록 나쁨 | 시드중앙 → **짝별 부호 있는 Δ** → Δ 의 중앙 |
| `init_nrmse` | 클수록 나쁨 | 〃 (Phase-1 불변 검사용) |
| `Pearson_rho` | **작을수록** 나쁨 | 〃 |
| `absVR_framewise` · `m_mean` · `decorr_mean` · `shrink_mean` | 클수록 나쁨 | 〃 |

1. **검정** = 짝지은 **정확 양측 부호검정**. **동점(Δ=0)은 n 에서 제외**하고 건수를 보고한다.
2. ★**절댓값 판정식 금지.** 두 셀 비교는 항상 **부호 있는 짝 차이**로 정의한다
   (Rx-4 D1 이 여기서 퇴화했다).
3. ★**"블록 중앙의 차" 금지, 항상 "짝별 Δ 의 중앙".**
   (K6 에서 `ORACLE-K − AUTO` 가 블록중앙 차 **+0.0067** vs 짝 중앙 Δ **−0.0046** 로 **부호가 반대**였다.)
4. ★**n 별 합격 승수 사전 동결** (널 배제로 n 이 줄어도 사후에 채우지 않는다):

| n | 필요 승수 | 전승 바닥 p |
|---|---|---|
| 16 | **13** | 3.05e-05 |
| 15 | 12 | 6.10e-05 |
| 14 | **12** | 1.22e-04 |
| 13 | 11 | 2.44e-04 |
| 12 | 10 | 4.88e-04 |

5. **널 병기 의무** (`nulls_k6.json` 재사용, 같은 에피소드). 대조 셀 `AUTO` 가 널 미달인 에피소드는
   PRIMARY 에서 배제하되 **미배제 결과를 반드시 병기**한다.
   ★**배제의 방향성도 보고한다** — K6 에서 배제된 2개가 하필 개입이 가장 크게 이기는 에피소드였고
   효과크기 추정이 12배 달라졌다.
6. **널 미달 셀은 결과로 인용 금지** (K6 의 `K6-NSCHED` 사고).
7. **설정 폴드(n=4) 병기하되 "유의" 금지**(바닥 p=0.125). ★**효과크기 인용도 금지**
   (K6 에서 폴드가 PRIMARY 를 살아난 것처럼 보이게 했다: 폴드 −0.0095, 4/4 vs 에피소드 −0.0007, 8/14).
8. **검정력**: 각 헤드라인에 관측/MDE 를 병기하고, **남은 여유 대비 MDE 비**도 적는다.

## 5. 합격선 (결과 보기 전 동결)

### PRIMARY-A = **`W-MATCH` vs `PHI-5e3`**, 블록 = 독립 혼잡16(널 배제 후), 지표 `nRMSE`
판정량 = `median[ Δ(W-MATCH − AUTO) − Δ(PHI-5e3 − AUTO) ]` (**부호 있음**).
- **CHANNEL-REAL** = 중앙 > 0 **그리고** 승 ≥ 문턱 ⟹ **상대 구동을 맞춰도 진폭이 더 취약**.
- **INVERTED** = 중앙 < 0 그리고 승 ≥ 문턱 ⟹ **위상이 더 취약. 진단은 방향까지 틀렸다.**
- **NO-DIFFERENCE** = 어느 쪽도 문턱 미달 ⟹ **Rx-4 의 채널 비대칭은 스텝크기 산물이었다.**
  ⛔이 경우 **"두 채널은 동등하다" 금지** → "이 표본에서 구별되지 않는다".

### PRIMARY-B = **E-스윕의 단조성**, 지표 `nRMSE`, 기준 `AUTO`
★**사전 선언한 귀무 모델**: 손상이 시간에 균일하게 누적된다면 회수율은
`R(E) = 1 − E/160` 이어야 한다 ⟹ 예측 **98.8 / 96.9 / 93.8 / 87.5 / 75.0 / 50.0 %**.
- **UNIFORM-DAMAGE** = 관측 R(E) 가 그 예측과 **에피소드별 짝검정에서 구별되지 않음**
  ⟹ `T-EARLY20` 은 **"끄기의 부분 용량"**일 뿐이고 기제 주장 불가(Rx-4 결론 확정).
- **FRONT-LOADED** = 관측 R(E) 가 예측보다 **유의하게 낮음**(작은 E 에서 이미 많이 회수)
  ⟹ **손상이 초기에 집중** = 새 기제, 조기 동결에 근거가 생긴다.
- **BACK-LOADED** = 유의하게 높음 ⟹ 손상이 후기 집중.
- 각 E 셀에 `AUTO` 대비 짝 판정을 **서술적으로** 병기.

## 7. 사전 선언 — 인용하지 않을 것
- 혼잡16 전용. **희소/전 레짐 일반화 금지.**
- ⛔`W-*` 셀 결과를 **"진폭이 원인이다"** 로 승격 금지 — 이 설계가 답하는 것은
  **"상대 구동을 맞췄을 때도 채널 차이가 남는가"** 하나뿐이다.
- ⛔E-스윕의 특정 E 값을 **"최적"** 으로 인용 금지 — 스윕이지 최적화가 아니다.
- ⛔`lr_w → 0` 이 손상을 줄이는 것을 **발견으로** 인용 금지(정의상 `AUTO-NOTRACK` 수렴).
- ⛔**배치 지표(`detection_rate`, 매칭 조건부 `k_mag_rel_error`)를 필드 주장으로 승격 금지.**
- ⛔**블록 중앙의 차**를 효과로 인용 금지(§4.3).
- ⛔이 배치 결과를 **과거 표본(draw 4–8)과 풀링·합산 금지** — 게이트 등급이 다르다.
- 벽시계 성능 주장 금지.
- **널 결과도 그대로 보고한다.** "채널 차이는 스텝크기였다" 도 값진 판정이다.
