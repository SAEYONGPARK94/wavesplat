## 0. Rx-5 가 남긴 것 — **한 점 비교로는 원리적으로 답이 안 나온다**

Rx-5 는 두 채널을 **정합점 한 점**에서 비교했고 세 검토자가 그 설계를 무효화했다:

1. ⛔**정합 상수가 종류 불일치**였다 — 위상을 **주기(2π)** 로, 진폭을 **크기(median|w|)** 로 나눴다.
2. ⛔**정합 셀이 퇴화**했다 — `W-MATCH` 는 총손상의 **6.6%** 만 남아 `AUTO-NOTRACK` 과 구별되지 않았고,
   반대편 `PHI-5e3` 는 `AUTO` 와 구별되지 않았다(p=1.000).
   ⟹ PRIMARY-A 는 채널 대조가 아니라 **on/off 대조**였다(바닥으로 대리치환 시 **r=0.9921**).
3. ⛔**진폭은 4점, 위상은 1점**에서만 쟀다 ⟹ *"진폭 손상이 구동의 함수"* 는 보였지만
   *"위상도 같은 함수를 따른다"* 는 **미측정**. 두 곡선이 그 점에서 **우연히 교차**했을 가능성을 배제 못 한다.
4. ★**부가법성 파탄**: 바닥 기준 φ만 +0.0222 + w만 +0.0321 = 합 +0.0544 vs 실측 양채널 **+0.0202 (합의 37%)**.

⟹ **한 점을 아무리 잘 골라도 이 질문에는 답할 수 없다. 두 채널의 손상-구동 곡선을 통째로 재야 한다.**

## 1. ★"정합"의 정의 — **비순환적으로, 결과 보기 전에 못 박는다**

NEUTRAL 이 지적한 순환 위험: **"손상이 같아지는 lr" 로 정합을 정의하면 손상 검정이 순환논법**이 된다.
그래서 정합을 **모델의 1차 장민감도에서 직접 유도**한다 — 오차·손상을 전혀 참조하지 않는다.

모델 (`spectral_gaussian.py:127`): `z = Σᵢ wᵢ cos(kᵢ·x − ωᵢt + φᵢ)`
- `∂z/∂wᵢ = cos(·)` ⟹ 진폭 장이득 = **1**
- `∂z/∂φᵢ = −wᵢ sin(·)` ⟹ 위상 장이득 = **|wᵢ|**

**정의 (동결)**: 한 스텝의 **장 등가 스텝** `S = lr × (장이득)`
```
S_w   = lr_w                     S_φ = lr_φ × median|w|
```
`median|w| = 0.044095 m` (Rx-5 `wscale.json`, 48회 측정, **모델 파라미터**, GT 아님).

⟹ **같은 S 를 두 채널로 실현**한 쌍이 "정합 쌍"이다.
★참고: 출하 lr 0.005 를 이 척도로 재면 **진폭 5.000e-03 vs 위상 2.205e-04 = 22.7배 비대칭**
(⛔Rx-5 가 보고한 "142배"는 2π 관례의 산물이며 **철회**한다).

### 1.1 ★정합이 실제로 성립했는지 **사후 검증**한다 (순환 방지의 두 번째 층)
`AUTO-NOTRACK` 은 `tracking_lr=0` 이라 그 최종 파라미터 = Phase-1 파라미터(Rx-5 §6.2 로 확인).
따라서 각 셀의 **실현 장변위**를 GT 없이 잴 수 있다:
```
D_w = rms( Δw )                    (Δw = w_cell − w_NOTRACK)
D_φ = rms( w_NOTRACK ⊙ Δφ )        (Δφ 는 wrap 해서 (−π, π])
```
둘 다 **필드 단위 [m]** 이므로 직접 비교 가능하다.
⟹ **PRIMARY 판정 전에 `D` 를 보고한다.** 정합 쌍의 `D` 가 크게 어긋나면 그 쌍은 **정합 실패**로 표기하고
판정에서 제외하되 **제외 사실과 수치를 반드시 보고**한다. (D 는 오차가 아니라 **궤적의 성질**이므로 비순환.)

| S (장 등가 스텝) | 진폭 셀 `lr_w` | 위상 셀 `lr_φ` |
|---|---|---|
| 5.000e-03 | `W-S1` = 5.000e-03 | `P-S1` = 1.1339e-01 |
| 5.000e-04 | `W-S2` = 5.000e-04 | `P-S2` = 1.1339e-02 |

| 5.000e-05 | `W-S4` = 5.000e-05 | `P-S4` = 1.1339e-03 |
| 5.000e-06 | `W-S5` = 5.000e-06 | `P-S5` = 1.1339e-04 |

- `W-*` = `tracking_mode='w_only'` + `tracking_lr`. `P-*` = `tracking_mode='phi_only'` + `tracking_lr`.
- ★**`W-S3` 가 Rx-5 의 두 검토자가 동시에 요구한 "빠진 셀"**(필드 정합점)이다.

  §5 의 판정량은 **같은 S 안에서의 채널 차이**다.

**공통 대조**: `AUTO`(출하 `w_phi`) · `AUTO-DUP`(워커누출) · `AUTO-NOTRACK`(**바닥**, `tracking_lr=0`).

## 5. 합격선 (결과 보기 전 동결)

### PRIMARY = **두 채널의 손상-구동 곡선이 일치하는가**
각 S 에서 채널 차이 `C(S) = median[ Δ(W-S − AUTO) − Δ(P-S − AUTO) ]` (**부호 있음**, 양수 = 진폭이 더 나쁨).

- **CHANNEL-REAL** = **5개 S 중 3개 이상**에서 `C(S)` 가 **같은 부호로** 문턱을 넘는다
  ⟹ 장 등가 스텝을 맞춰도 채널 차이가 **곡선 전체에 걸쳐** 남는다.
- **NO-DIFFERENCE** = 문턱을 넘는 S 가 **1개 이하**
  ⟹ **Rx-4/Rx-5 의 채널 비대칭은 전부 구동 크기였다.**
  ⛔이 경우 **"두 채널은 동등하다" 금지** → "이 표본에서 구별되지 않는다".
- **CROSSOVER** = 문턱을 넘는 S 가 2개 이상이나 **부호가 엇갈린다**
  ⟹ 채널 차이가 구동 크기에 의존한다 = **단일 답이 없다**. 그대로 보고한다.
- **VOID** = §6 무결성 실패 · 게이트 실패 · `AUTO` 널 미달.

### 부차 (서술)
- **곡선 형태**: 각 채널의 `nRMSE` vs `D`(실현 장변위) 관계. 두 곡선이 **같은 함수**인가.
- **퇴화 점검**: 각 셀이 `AUTO` 또는 `AUTO-NOTRACK` 과 구별되는가. **양 끝이 퇴화한 S 는
  채널 판정에서 정보가 없다**고 명시한다(Rx-5 PRIMARY-A 가 그래서 무의미했다).
- `AUTO-NOTRACK − AUTO` 재측정(Rx-5 −0.0202, 14/16 이 n=32 에서 어떻게 되는가).

## 7. 사전 선언 — 인용하지 않을 것
- ⛔**"두 채널은 동등하다"** — 등가 검정이 아니다.
- ⛔**"위상/진폭이 더 취약하다"를 문턱 미달 S 에서** — S 별로 판정하고 S 별로 인용한다.
- ⛔**`lr→0` 셀(`W-S5`·`P-S5`)이 좋은 것을 발견으로** — 정의상 `AUTO-NOTRACK` 수렴.
- ⛔**퇴화한 셀**(바닥 또는 AUTO 와 구별 불가)의 차이를 채널 주장으로.
- ⛔**"정합했다"를 `D` 검증 없이** — §1.1 을 통과한 쌍에만 쓴다.
- ⛔**과거 표본(draw 4–8·16)과 풀링·합산** · **혼잡 밖 일반화** · **벽시계 성능 주장**.
- ⛔**배치 지표를 필드 주장으로 승격**.
- **널 결과도 그대로 보고한다.** "채널 차이는 전부 구동 크기였다" 도 값진 판정이다.
- ★**질문이 ill-posed 로 판명될 가능성을 미리 인정한다**: 만약 `D` 정합이 성립한 쌍이 2개 미만이거나
  모든 정합 쌍이 퇴화하면, **"이 설계로는 채널 질문에 답할 수 없다"** 로 보고하고 축을 닫는다.
