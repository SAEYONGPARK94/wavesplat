## 부록 A — 재도출 규약 (재현용)

- 에피소드 값 = 추정 3시드 `statistics.median`. 짝 Δ 는 같은 에피소드 안에서만.
- 부호검정 = 양측 정확 이항 `min(1, 2·P(X ≥ max(개선,악화)))`, **동점 제외**(수 병기).
- 이항 확률은 **로그공간**(`lgamma`)으로 계산 — `math.comb` 는 N>1000 에서 오버플로한다.
- 상대 Δ = `(처치 − 기준)/기준 × 100`. **중앙(전체)·중앙(동점제외)·짝평균·최악**을 항상 함께 출력.
- Wilcoxon = 동점보정 정규근사, **상대 Δ** 에 적용(BRIEF 규약과 부호만 반대).
- Fisher = 2×2 정확 단측(초기하 꼬리합).
- CP 하한 = 단측 95% Clopper–Pearson(이분탐색 200회).
- 검정력 = `n_eff ~ Bin(N, q)`, 개선수 `~ Bin(n_eff, p)`, 문턱 `primary_k(n_eff)` 로 **정확 이중합**.
- 비모수 MDE = 무처치 널의 **실측 짝 log-비 분포** `L` 에 대해 `r(ρ) = #{x ∈ L : x < −log ρ}/|L|`,
  검정력 = 정확 이항. **처치 자료를 보지 않는다.**
- 부트스트랩 = 20,000 회 복원추출(`random.seed(20260812)`).
