## 0. 순위 집계

| 페르소나 | 1위 | 2위 | 3위 | 비고 |
|---|---|---|---|---|
| P1 ML | **A** | B | C | "C 는 비용이 아니라 원리로 3위" |
| P2 OE | **B**(B-3 → B-1 lean) | A | C | "C 는 산술로 사망" |

| P4 문헌 | **B**(B-1) | C(= B-1 파일럿일 때만) | A | 원안 C 고정이면 B>A>C |
| P5 지도교수 | **B**(집필 재개 + B-3) | C | A | |

- **C 는 3/5 가 꼴찌, 1위 0표 ⟹ 죽었다.** P2 의 산술이 결정적: 축소하면 N=48 → 검정력 **0.623**

- **A vs B = 2 : 3.** 단 "B" 가 셋 다 다른 뜻이었다(§3).
- ★**공통분모: `B-3`(런 0회, 실측의 레짐 위치 측정)을 오늘 하라 — 3인이 지지, 반대 0.**
  P3 의 표현: *"B-3 는 A 의 경쟁자가 아니라 동반자"*.

## 1. ⛔내 브리핑 팩의 오류 (P2·P3 가 적발, 메인 세션 재확인) — **전부 정정**

### ★1b. A 의 실제 비용 — 메인 세션이 **S9 생성 로그를 직접 측정**
`S9_lr_x_l1_2026-08-11/gen.log`·`gen_crowded.log`:
- 희소 64ep: **08:27:48 → 12:34:12 = 4 h 06 m** (에피소드당 ~165 s)
- 혼잡 32ep: **08:42:03 → 11:18:59 = 2 h 37 m** (에피소드당 ~290 s)
- **두 프로세스가 병렬로 돌았다** ⟹ 96ep 생성 **벽시계 = 4 h 06 m**(프로세스 합 6.7 h 아님).

A(128ep = 희소 64 + 혼잡 64 가정) 외삽: 희소 2.9 h ∥ 혼잡 5.2 h ⟹ 생성 벽시계 **≈5.2 h**,
런 1584 × ~35 s ÷ 8워커 **≈1.9 h** ⟹ **A ≈ 7.1–7.4 h 벽시계.**
⟹ **P3 가 맞다.** ⛔내 "11.5 h" 와 P2 의 "16.3 h" 둘 다 인용 중단.
⚠단 128ep 의 레짐 구성이 혼잡 쪽으로 치우치면 늘어난다 — **사전등록에 구성을 못 박을 것.**

## 2. ★★★A 의 운명을 가르는 쟁점 — P1 과 P4 는 **사실이 같고 함의가 반대다**

**둘 다 동의하는 사실**: A 의 질문은 **선점됐다.**
- **Katende arXiv 2606.07153**(2026-06) — GT 없이 잔차로 팔을 고르는 no-harm 선택층 + 오차 상한.
  (⚠07-26 메모리에 이미 "라우터를 기여로 주장 금지" 근거로 등재돼 있었다 = **자체 확인됨**)
- **Sprunck·Pereyra·Liaudat arXiv 2510.27663** — 관측 분할로 GT 없이 모델 선택
  = **오늘 내가 배선한 held-out 신호와 정면으로 같은 것.**
- **Gomes & Selman, AIJ 126:43–62 (2001)** — restart 포트폴리오 vs 혼합 포트폴리오(⚠P4 2차 확인, 원문 403).
- 널의 정체("두 번 뽑아 좋은 쪽")는 seed-hacking·benchmark-variance 문헌의 **표준 지식**.

**함의가 갈린다**:
- **P1**: *"남들이 양성인 곳에서 우리만 음성"* ⟹ **반례로서 값이 오른다**. 처음으로 ML 산출물
  1개를 인정 — "물리 역문제 GT-free 선택 규칙의 **시드-널 대조 음성 벤치마크**"(ML4PS 워크숍 4p).
  ⚠단 현 자산은 **비신선**이라 그대로는 못 낸다 ⟹ **A 가 그 조건**. 그리고 **팔 창에 시한이 있다.**
- **P4**: 3중 선점 ⟹ **novelty ≒ 0**. A 는 실패해야만 값이 있고 **그 값은 S10 이 이미 부분 구매**했다.

**판정**: 둘 다 옳다. **A 는 novelty 배치가 아니라 "독립 표본 0→1" 배치다.**
P3 의 정식화가 정확하다 — *"A 의 정당화는 배포가 아니라 **독립 표본 0개 → 1개 + 축 종결 + 널 대조
규약**이며, 사전등록서를 그렇게 다시 써야만 성립한다."*
⟹ ⛔**"선택기가 이긴다"를 목표로 A 를 돌리면 안 된다.** 돌린다면 목표는 **반례의 신선 표본**이다.

## 3. "B" 가 무엇인가 — 셋이 서로 다른 것을 가리켰다
- **P5 = 집필 재개 + B-3.** **P2 = B-3 먼저, 그다음 B-1 을 재설계.** **P4 = B-1.**
- ★**B-1 은 브리핑이 말한 "속도 축"이 아니다**(P2). 출하 기하가 **전 배치 `direction_deg=0`
  following seas** 인데 BF4 에서 **U/c_p = 11.3/10.93 = 1.034 = 서프라이딩 임계**,
  피크 조우주기 **209 s** ⟹ 14 s 초기화 창에서 위상이 **0.42 rad** 밖에 안 돈다.
  ⟹ **설계속도 직진은 d74 가 잰 최악 조건**(field-CRB 6.9배 악화). **`B-1` 은 조우기하 축으로
  다시 써야 한다**(2×2 필수, `MIN_DK=0.15` 를 `D_eff` 에서 유도).
- **B-1 실행가능성(P2, 프로브 포함)**: 추정기 **변경 0줄**, 생성기 **≈40줄**, `generate_rays` 는
  이미 `ship_x/y/heading` 을 받는다. 확장 도메인 비용 **2.2×**. lean 설계(혼잡 15comp 전용, 64ep)
  **≈11 h**. **사전 예언 동결**: 15comp 개선 / 30comp·희소 널.
- ⛔**단 §1 오류 #1 을 반영하면 B-1 은 "새 축"이 아니라 "한 번 죽은 축의 재설계"다.**
  되살리려면 **왜 지난번이 실패했는지에 대한 기제**가 사전에 있어야 한다 —
  P2 의 조우기하 논증이 바로 그것이므로 **성립은 한다.** 그러나 novelty 주장은 그만큼 약해진다.

⟹ *"08-07 이전은 검정력 없는 반복, 이후는 정직한 음성"* — **기계는 이제 작동한다.**

## 6. 판정
1. ⛔**C 는 기각**(1위 0표, 3/5 꼴찌, 검정력 0.623 = 죽은 자리 재방문).
2. ✅**B-3(런 0회, 실측의 레짐 위치)를 오늘 하라** — 3인 지지·반대 0, 비용 반나절 이하,
   그리고 **X1/X2 의 "실측 = 혼잡형" 전제(X3 가 미측정으로 판정)를 실제로 결정한다.**
3. **A 와 B-1 은 배타적이지 않다** — A ≈7.4 h, B-1 lean ≈11 h. 다만 **둘 다 하면 이번 주가 끝난다.**
   - **A 를 돌린다면**: 목표를 **"독립 표본 0→1 + 반례의 신선화"** 로 사전등록서에 다시 쓰고,
     P1 의 **`/DEPLOY-CONDITION` 거부권**(배포는 시드 1개, PRIMARY 는 3시드 중앙 — 배포 조건으로
     재도출하면 희소가 30/64 로 뒤집힌다)과 P3 의 **수정 4건**(배포 어휘 제거 · `n_eff≥48`
     커버리지 하한 · 널 10분할 분포 의무 · **"이 축은 A 로 종결" 선언**)을 반드시 넣을 것.
   - **B-1 을 돌린다면**: **조우기하 축**으로 다시 쓰고(2×2), 사전 예언(15comp 개선 / 30comp·희소 널)을
     동결하고, **지난번 FAIL 의 기제**를 사전등록에 명시할 것.
4. ★★★**그러나 5인 중 3인(P1·P2·P5)이 "진짜 질문은 A/B/C 가 아니다"에 도달했다.**
   - P1: *"양성으로 끝나는 학위를 원하면 A 도 하지 말고 B-1 로 가라. 진짜 질문은 **음성-지도로
     방어할 것인가**다."*
   - P5: **08-04 편집 금지의 부분 해제 건의** — thesis 제1장·제5장·금지 수치 수정은 **다듬기가
     아니라 거짓 주장의 철회**이고, 철회는 **어떤 미래 결과에도 되돌아오지 않는다**.
     `paper/wavesplat.tex` 의 수치·표는 유지.
   ⟹ **이 두 건은 사용자 결정 사항이다.** (⚠지시는 지켜졌다 — 어떤 tex 도 편집되지 않았다.)
