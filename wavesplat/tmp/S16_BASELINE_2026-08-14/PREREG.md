> **출하 팔 `SHIP`(median-of-3) 이 *수리된 최강 기준선* 상대로도 사전등록 문턱을 넘는가.**

### 1.1 ★"최강 기준선" 선택 규칙 — **결과를 보기 전에 못 박는다**

- 후보 풀 `P = {SPEC25, SPEC50, SPEC100}` (세 국소화 반경 × 스펙트럼 배경).
- 각 팔 `a` 에 대해 `W_a = #{혼잡 에피소드 : SHIP_med3 < a}` (= **출하 팔이 이긴 수**).
- **선택: `r* = argmin_a W_a`** — 즉 **출하 팔이 가장 적게 이기는 팔** = 가장 강한 기준선.
  - 동점 1차: `med((SHIP−a)/a)` 가 **큰**(= 출하 팔의 이득이 작은) 쪽.
  - 동점 2차: `loc_radius` 가 **작은** 쪽.
- **PRIMARY 통계량 = `W_{r*}`**, 문턱 41/64.

⚠**이 선택은 우리에게 불리하다 — 그게 요점이다.** 세 팔 중 우리에게 가장 유리한 것을 고르는 것이
아니라 **가장 불리한 것**을 고른다. 따라서 다중비교 보정은 **필요하지 않다**(최소값을 취하는 것은
보수적 방향이다). ⛔**결과를 본 뒤 다른 팔로 갈아타는 것은 금지**한다.

**보조 comparator(동시 사전등록, PRIMARY 에 미기여)**: `P_all = P ∪ {WHITE50, WHITER50}` 에 대해
같은 규칙으로 `r*_all` 을 골라 `W_{r*_all}` 도 인쇄한다. `r*_all ∉ P` 이면 **수리가 기준선을 강화하지
못했다는 뜻**이고 §7 R-2 가 발동한다.

## 4. 수리의 정확한 사양 (`letkf_spec.py`) — **가장 작은 개입**

**개입은 개념 하나뿐**: *배경오차공분산 모형을 "공간 백색 · 0.1 m" 에서 **"JONSWAP 스펙트럼 · 참 Hs"** 로
바꾼다.* 예보 연산자·관측 연산자·동화 수식·팽창 계수 크기·`max_obs`·`obs_noise`·`n_ensemble` 은 **불변**.

### 4.1 수식

LETKF 격자(`nx=40, ny=30`, `dx≈6.15 m, dy≈6.90 m`)의 `rfft2` 모드
`kx = 2π·fftfreq(nx,dx)[:nx//2+1]`, `ky = 2π·fftfreq(ny,dy)` 에 대해 (예보 연산자 `letkf_grid.py:76-80` 과 **동일한 모드 집합**):

1. `|k| = √(kx²+ky²)`, `ω(k) = √(g|k|·tanh(|k|d))` — **필터가 쓰는 것과 같은 분산관계**.
2. **JONSWAP** (γ=3.3, `ω_p = 2π/Tp`):
   `S_J(ω) = ω⁻⁵ exp(−1.25 (ω_p/ω)⁴) · γ^{exp(−(ω−ω_p)²/(2σ²ω_p²))}`, `σ = 0.07 (ω≤ω_p) / 0.09 (ω>ω_p)`.
   (앞의 상수 `αg²` 는 §4.1-5 의 재척도에서 **소거**되므로 1 로 둔다.)
3. **방향 분포는 등방**(`D(θ) = 1/2π`). ⟹ **방향 오라클을 주지 않는다.**
   야코비안: `S_k(kx,ky) = S_J(ω)·D(θ)·c_g/|k|`, `c_g = dω/dk` (해석적으로 계산).
   모드 분산 `σ²_k = S_k · Δkx · Δky`, `Δkx = 2π/(nx·dx)`, `Δky = 2π/(ny·dy)`. `|k|=0` 모드는 0.
4. 멤버 `m` 의 복소 계수 `Ĥ_m(k) = σ_k · e^{iφ}` , `φ ~ U(0,2π)` (전용 RNG).
   `η_m = irfft2(Ĥ_m)`, `η̇_m = irfft2(−i·ω·Ĥ_m)` — **η 과 η̇ 의 교차공분산이 분산관계와 정합**
   (`η = Re Σ ĉ e^{i(k·x−ωt)}` ⟹ `∂η/∂t = Re Σ (−iω)ĉ e^{i(k·x−ωt)}`).
5. **재척도**: `s = (Hs_bg/4)/std(η_m)` 를 `η_m` 과 `η̇_m` 에 **같이** 곱한다.
   ⟹ FFT 정규화 규약과 무관하게 **배경 스프레드 = Hs/4** 가 보장된다(= 참 장의 rms).
6. **중심화**: 앙상블 평균을 뺀다 ⟹ **배경 평균 = 제로필드**(정보 없음의 정직한 사전분포),
   스프레드는 `√(1−1/Ne)` 만큼만 준다(Ne=600 ⟹ 0.08%).
7. **가산 팽창도 같은 스펙트럼에서 뽑는다** (`add_inflation=0.005 m` 는 **크기 불변**, 구조만 스펙트럼).
   ⟹ 매 사이클 백색을 다시 주입해 수리를 되돌리는 일을 막는다. 이것이 "개념 하나" 의 일관된 적용이다.

**한 줄 요약**: *등방 JONSWAP(γ=3.3, ω_p=2π/Tp) 무작위위상 실현으로 배경 앙상블을 만들고,
`η̇ = irfft2(−iω·Ĥ)` 로 분산관계 정합을 준 뒤 `std(η)=Hs/4` 로 재척도·중심화한다. 가산 팽창도 같은 스펙트럼.*

### 4.2 ⚠ 오라클 선언 — **기준선에 유리하게 설계했다**

`Hs_bg = loader.Hs_true`, `Tp_bg = loader.Tp_true` 를 쓴다. **이는 기준선에 주는 오라클이다.**
- **의도적이다.** PRIMARY 는 *"우리에게 최대한 불리한 기준선"* 상대의 시험이고, GT 스펙트럼
  파라미터를 받은 기준선을 이긴다면 GT-free 기준선도 이긴다(`ARGUED`, 오라클이 상한).
- **방향은 주지 않는다**(등방) — 방향까지 주면 사실상 장(場) 오라클이 된다.
- **투명성**: 모든 행에 GT-free 추정치 `hs_obs4std = 4·std(첫 20프레임 관측 z 풀)` 를 함께 기록해
  오라클의 크기를 후속 배치가 정량할 수 있게 한다(본 배치 실측 예: BF4 혼잡 1.416 vs 참 1.2).
- ⚠**사망 분기의 범위 문구(§8)에 이 오라클을 반드시 달고 나간다.**

### 4.3 사전에 아는 한계 (결과 전 명시)
- BF5(Tp 9.0 s)의 첨두 파수 `k_p = 0.0497 rad/m`(λ_p ≈ 126 m)는 격자 `Δk_x = 0.0262` 로 **≈1.9 모드**
  밖에 안 되게 표본화된다 ⟹ 첨두가 거칠다. BF4 는 ≈3.1 모드. **이는 격자가 준 한계이지 수리의 결함이 아니다.**
- 격자 Nyquist `λ = 12.3 m` 밖 분산 분율은 이미 **혼잡 중앙 0.1%** 로 측정돼 있다(`P4_skeptic.md:236-237`)
  ⟹ 고파수 절단은 무해하다.
- `max_obs=40` (프레임당 관측 중앙 **49**개 ⟹ thinning 이 실제로 작동한다)는 **S13·HOSGATE 와 동일하게 유지**한다.
  thinning 을 끄는 것의 효과는 이미 **평균 −0.42%** 로 측정돼 있다(`P4_skeptic.md:238-239`) ⟹ 축이 아니다.

## 11. 이 사전등록이 스스로에게 거는 제약

1. 결과를 본 뒤 **집계 규약·문턱·층 경계·comparator 선택 규칙을 바꾸지 않는다.**
2. **크기를 헤드라인에 쓰지 않는다** — 판정은 부호. 크기는 3규약 병기로만.
3. **`SPEC` 팔의 사양(§4)을 결과를 본 뒤 조정하지 않는다.** 조정이 필요하면 **새 배치로 재사전등록**한다.
4. **팔을 사후에 추가하지 않는다.** `loc` 는 {25,50,100} 셋뿐이다.
5. ⛔**"novelty" 를 이 배치의 산출로 주장하지 않는다.**
6. **정정·반증은 짧게라도 반드시 보고한다**(§0.1 이 이미 그 첫 항목이다).
