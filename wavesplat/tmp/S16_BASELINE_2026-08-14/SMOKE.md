## 4. ⚠ 탐색적 관찰 — **n=1 셀, 스모크, 사전등록 아님. 판정 아님. 인용 금지.**

> 아래는 **에피소드 2개**의 값이다. PRIMARY 는 혼잡 **64** 에피소드 짝 부호검정이다.
> 여기서 어떤 방향도 결론으로 옮기지 마라 — 이 저장소는 **소표본 방향이 전량에서 뒤집힌 사례를 여러 번** 기록했다.

| 팔 | 혼잡 `BF4_15_s32` | vs `WHITER50` | 희소 `BF4_2_s48` | vs `WHITER50` |
|---|---|---|---|---|
| `SHIP` (med3) | **0.1131** | — | **0.0100** | — |
| `SPEC25` | 0.1970 | **−7.0%** | 0.2246 | −1.6% |
| `SPEC50` | **0.1953** | **−7.8%** | 0.2314 | +1.4% |
| `SPEC100` | 0.2347 | **+10.8%** | 0.2519 | **+10.3%** |
| `WHITER50` | 0.2118 | 0.0% | 0.2283 | 0.0% |
| `WHITE50` | 0.2128 | +0.5% | 0.2279 | −0.2% |
| `ZERO` | 0.2470 | | 0.2500 | |

관찰 4가지 (**전부 탐색적**):
1. **수리가 혼잡에서 기준선을 강화했다** — `SPEC50` 이 짝지어진 백색 대조를 **−7.8%** 이긴다.
   P2 의 외삽 기울기(기준선 1% 개선당 마진 ≈0.76p)를 적용하면 마진 −28.8% → **약 −23%** 가 된다.
   ⟹ **R-2(수리 유효성) 게이트가 통과할 가능성이 보인다.** 단 n=1.
2. ★**`SPEC100` 은 두 층 모두에서 기준선을 약화시켰다**(+10.3%, +10.8%).
   ⟹ 국소화 컷오프를 200 m 로 넓히면 **가짜 원거리 상관**이 들어와 손해다.
   §0-4 의 "먼바다 구조적 0" 은 **국소화 반경으로는 못 고친다**는 첫 신호.
   ⟹ 선택 규칙(`argmin` = 최강 기준선)은 **`SPEC100` 을 고르지 않을 것**이다 — 규칙이 의도대로 작동한다.
3. ★**`WHITER50` vs `WHITE50` = −0.2% / +0.5%** ⟹ **RNG 스트림 분리 + 가산팽창 적용 지점의 총 교락이 ±0.5%**.
   재구현이 재고 클래스와 사실상 동일함을 확인 (E-3 이 전량에서 다시 잰다).
4. ★**먼바다 `obs:150_inf`(면적 20.4%)**: 기준선은 수리 후에도 제로필드보다 **나쁘다**
   (혼잡 `SPEC50` 0.2982 vs `ZERO` 0.2928; `SPEC100` 0.3386). `SHIP` 은 **0.1728**.
   ⟹ **S-1a 가 FAIL 할 가능성이 높고**, 그 경우 PREREG §8-5 가 발동한다:
   *"§0-4 결함은 국소화 반경으로 고쳐지지 않는다 — 원인은 관측 발자국 자체다"*.

**부수 관찰 (규율 3 의 값어치)**: 희소 스모크 에피소드에서 `SHIP` 시드별 값이
**0.0100 / 0.0064 / 0.0952** 였다 — 시드 44 가 **10배 이상치**다. median-of-3 이 이것을 흡수한다.
⟹ S13b 교훈(단일 시드 금지)이 이 표본에서 **다시 확인**된다.

**GT-free Hs 추정치**(오라클 크기 감사용): `hs_obs4std` = 혼잡 **1.416** · 희소 **1.137** vs 참 **1.2**
⟹ 관측만으로 얻는 Hs 는 **−5% ~ +18%** 안에 있다 ⟹ §4.2 오라클은 **작다**(후속 배치가 정량 가능).
