### 5.1 ★`gc_zero_frac` 은 어떻게 계산되어야 하는가 — GC 구현으로 특정

`wavesplat/baselines/letkf_grid.py:18-38` `gaspari_cohn(r, c)`:
- `z = r/c`, `c = loc_radius`
- `z ∈ [0,1]` · `z ∈ (1,2]` 두 분기, **`z > 2` 는 초기값 `np.zeros_like(r)` 그대로 = 정확히 0**
- `z = 2` 에서 2분기 다항식이 해석적으로 0 (검산: `4 −10 +20/3 +5 −8 +32/12 −1/3 = 0`)
- `np.clip(result, 0, 1)` 이 수치 잔차를 제거

증분 경로: `:211` `L = gaspari_cohn(dists, self.loc_radius)` → `:238` `W_local = Kd @ L.T` →
`:241-242` `delta_eta = sum(X_pert_eta * W_local)`.

> ⟹ **격자점 `gp` 의 해석 증분이 항등 0 ⟺ `L[gp,m] = 0 ∀m` ⟺ `min_m dist(gp, obs_m) > 2·loc_radius`.**
> **`gc_zero_frac` = "가장 가까운 동화 관측점까지의 거리가 `2·loc_radius` 를 넘는 격자점의 비율".**

**반드시 함께 동결해야 할 4가지** (전부 현재 미명시):
1. **어느 격자인가** — GC 는 **필터 격자 40×30 = `n_grid` 1200**(`run_s16.py:203-204`) 위에서 돈다.
   그런데 §3 `D-3`(`:200`)은 *"**채점** 격자 비율"* 이라 적었다. 채점은 GT 격자 `gx,gy` 이고
   그 바깥은 `RegularGridInterpolator(..., bounds_error=False, fill_value=0.0)`(`run_s16.py:231-233`)로
   **다른 이유(외삽 채움)로 0 이 된다.** ⟹ **두 기제가 섞인다. 필터 격자로 정의할 것을 권고.**
2. **어느 관측점 집합인가** — `letkf_grid.py:118-120` 이 `M > max_obs(=40)` 이면
   `np.random.choice(M, 40, replace=False)` 로 **솎아낸다**. S16 의 `n_obs_median ≈ 49–50` `MEASURED` ⟹ **솎기가 실제로 작동한다.**
   ⟹ **"전 관측점" 과 "동화된 40점" 의 답이 다르다.** (전역 스트림은 `run_s16.py:199` `np.random.seed(filter_seed)` 로 고정되므로 결정적이지만 **시드 의존**이다.)
3. **시간 집계** — 관측 기하가 프레임마다 바뀐다. `shell_frac` 과 같은 규약(`sel = t > 2·Tp` 창의 `nanmean`, `run_s16.py:258-266`)을 명시할 것.
4. **`런 0회 계산 가능`(`:200`) 과 `필수 기록 필드`(`:232`) 의 충돌** — 전자는 에피소드만 로드하면 된다는 뜻이고
   후자는 러너가 행마다 적어야 한다는 뜻이다. **둘 중 하나로 정하라.**
