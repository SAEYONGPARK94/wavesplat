# `S1-SHELL` 사전등록 — **앙상블 이득은 근거리를 팔아 먼바다를 사는가**

> **동결 시점: 결과 0행.** ⛔**신규 런 0회** — `S_ENS`(2026-09-01) 동결 행의 재집계.
> ⛔`S-ENS` 판정 갱신 아님. ★**진짜 `blind`** — 셸 **값**을 아직 보지 않았다(점유율만 셌다).

---

## §0 왜 — 살아 있는 확증 판정에 저장소 상시규율이 **미적용**이다

`S-ENS` 가 **`SYNTH-ENSEMBLE-EARNS (CONFIRMATORY)`**(혼잡 55/64, p=1.77e−09)를 냈다.
그런데 저장소 상시규율은 이렇게 적는다:

> **"전역 승리는 근/원 셸로 분해할 것"**(`SUPPORT-TRADEOFF`).

⚠**그 규율이 이 판정에 적용된 적이 없다.** `S_ENS` 의 256행 **전부**에
`avg_shell_rmse`(셸 9개)와 `avg_RMSE_near` 가 기록돼 있는데,
그 배치의 `analyze_sens.py`·`gates_sens.py`·`verdict_sens.json` 에 두 키가
**0회** 등장한다(2026-09-03 grep 으로 확인: 0 · 0 · 0).

그리고 이 질문에는 **선행 신호**가 있다 — 결정 `D3`(2026-09-01)이 관련 팔에서
*"NEAR 8/36 악화(최악 +40.56%) vs FAR 1/36"* 을 관찰했다.

⟹ ***같은 무늬가 이 확증 판정 안에도 있는가.***

## §1 자료와 팔 (⛔`S_ENS` 에서 그대로 상속)

| | |
|---|---|
| 행 | 256 = 2 팔 × 2 층 × 64 에피소드 (시드 **1626** 하나) |
| 팔 | `LEARN-M1`(`ensemble_k = 1`, 배포) vs `LEARN-M3`(`k = 3`) |
| 층 | `crowded` 64 · `sparse` 64 |
| 셸 | `0_5 · 5_10 · 10_20 · 20_30 · 30_50 · 50_75 · 75_100 · 100_150 · 150_inf` (전건 비-널) |

**근/원 정의(결과 전 고정)**: **근 = `0_5` + `5_10`**, **원 = `75_100` + `100_150` + `150_inf`**.
셸 결합은 **에피소드별 RMS 합성**(⛔단순 평균 아님):
`rms_group = sqrt(mean(rms_shell²))` — 셸 간 표본수 가중은 자료에 없으므로 **동일 가중**이고
그 사실을 판정문에 병기한다.

---

## §2 PRIMARY — 결과 전 고정 (혼잡 층, 확증이 사는 곳)

**가설**: 앙상블(`M3`)이 **먼 셸에서 이기고 근 셸에서 진다**(교환).

- 통계: 짝 단측 부호검정, n = **64**, α = 0.05.
- 문턱: `α=0.05` 최소 정수 = **40/64**. ⚠**초판이 그 `p` 를 틀리게 적었다**(0.0192 라
  썼다) — 코드가 전수 계산한 실측은 **`p = 0.02997`** 이고 39 는 **0.05171** 로 미달이다.
  ⟹ **문턱 40 은 맞고 `p` 만 정정**했다(결과 0행). ★`G-THRESH` 가 그것을 잡으려고 있다.
  ⛔**오늘 사전등록에 손으로 적은 `p` 가 틀린 것이 세 번째다**(`R7` 0.6786 · `E2` 0.0303 · 여기).
  ⟹ ★***사전등록의 수는 코드가 재계산해 대조해야 한다.***

### 결과 전 동결 판정표

| 조건 | 라벨 |
|---|---|
| **먼 셸 승 ≥ 문턱** 그리고 **근 셸 승 ≤ (n − 문턱)** | **`ENSEMBLE-BUYS-FAR-SELLS-NEAR`** — ★교환이다 |
| 먼 ≥ 문턱, 근도 ≥ 문턱 | **`ENSEMBLE-GAINS-EVERYWHERE`** — 교환이 아니다 |
| 먼 < 문턱, 근 ≥ 문턱 | **`ENSEMBLE-BUYS-NEAR`** — ⛔예상과 반대 |
| 그 밖 | **`SHELL-UNDECIDED`** |

**SECONDARY(보고 전용)**: 희소 층 같은 대조 · 셸 9개 전건의 승수 곡선 ·
`avg_RMSE_near` 단독 대조.

## §3 ★결과 전 예측

**`ENSEMBLE-BUYS-FAR-SELLS-NEAR`**, 확률 **0.45**
(`GAINS-EVERYWHERE` 0.35 · `SHELL-UNDECIDED` 0.15 · `BUYS-NEAR` 0.05).
⚠★**오늘 내 예측이 두 번 틀렸고 두 번 다 「효과를 과대평가」했다**(`E1b`·`C2`).
⟹ 그 편향을 감안해 **교환 가설의 확률을 0.45 로 낮춰 적는다**(직관은 0.6 이었다).

## §5 ⛔범위와 금지

- ⛔**`S-ENS` 판정 갱신 아님** — 전역 승리(55/64)는 그대로다.
- ⛔**배포 권고 아님** — `S-ENS/PREREG §5` 가 결과 전에 *"필요조건 하나"* 로 고정했고
  남은 셋(희소 미결·단가 2.6배·**학습 경로 프레임 예산 미측정**)은 그대로다.
- ⛔**`D3` 의 NEAR 8/36 과 직접 비교 금지** — 다른 배치·다른 팔·다른 자다.
- ⛔**기제 지목 금지** — 교환이 나와도 *"왜"* 는 이 자료로 분리 불가.
- ⚠**시드 하나(1626)** · ⚠셸 결합이 **동일 가중**(표본수 가중 자료 없음).
- ⛔**실측으로 옮기지 마라** — 합성 코퍼스의 성질이다.
