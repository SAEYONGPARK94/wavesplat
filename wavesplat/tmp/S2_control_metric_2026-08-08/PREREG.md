## 1. 실행 전에 원자료에서 측정한 기하 (전부 오늘 확인)

1. **포일 위치**: 전방 **+2.0 m**, 후방 **−2.5 m** (CG 기준) — `hydrofoil/config.py:67,79`.
2. **FF 프리뷰 점** = `x_foil + V·Δt` — `hydrofoil/controller.py:12`. 설계 선속 **11.3 m/s**,
   Δt = 0.2 s ⟹ **+2.26 m** ⟹ 제어가 보는 곳은 **배에서 4~5 m 이내**다.
3. ★**저장된 GT 격자는 `x ∈ [10, 250] m`** 인데 **포일은 x ≈ 0** 이다
   ⟹ **제어 평가점은 저장 격자 밖에 있다.** ⟹ GT α_wave 는 격자가 아니라
   `config/wave_components` 에서 **해석적으로** 계산해야 한다(저장돼 있으므로 가능).
4. ★**LiDAR 반환 중심은 x ≈ 20.8 m** (프레임 0·300 모두, 좌표계는 배 고정)
   ⟹ **제어 평가점(x≈4 m)은 관측 중심에서 약 16 m 떨어져 있다.**
   ⛔따라서 **"제어점 = 관측점"이 아니다.** E-D 의 `0_5` 셸(−0.1417)은
   **관측점까지의 거리** 기준이지 **배까지의 거리**가 아니다. 두 개를 혼동하면 안 된다.
   해당 거리대는 E-D 셸로는 `10_20`(−0.0428, 43/46) 근처다.
5. **그래서 결과가 정해져 있지 않다**: 추적기는 (w, φ) 를 움직이고, α_wave 는
   **공간·시간 미분량**이라 위상 오차를 **증폭**한다. 센서 근처 η 를 좋게 만들면서
   slope 를 나쁘게 만드는 것이 물리적으로 가능하다. **양쪽 분기 모두 도달 가능하다.**

## 2. 가설

- **H1 (PRIMARY).** 요구 지평 0.2 s · 요구 물리량 α_wave 에서 `AUTO − AUTO-NOTRACK` 의
  짝 Δ 중앙 < 0 (= **추적기가 제어 물리량을 개선한다**). H0: 중앙 = 0.
  혼잡·희소 각각 하나씩, **Holm-2** 로 묶는다.
- **H2 (같은 런의 레거시 지표).** 같은 런에서 전역 격자 η nRMSE 를 함께 낸다.
  기존 3회 독립 재현(`AUTO-NOTRACK − AUTO` −0.0202 / −0.0220 / B3)이 재현되는지 본다.
- **H3 (지평 의존).** 리드 0.1 / 0.2 / 0.3 / 0.5 s 에서 Δ 가 어떻게 변하는가.

### 2.1 판정 규칙 (사전 확정, 양쪽 분기 도달 가능)

| M2(전역 η) | M1(α_wave @0.2 s) | 판정 |
|---|---|---|
| 추적기 **불리** 재현 | 추적기 **유리**(≥13/16, Δ<0) | ★**METRIC-ARTIFACT** — "추적기가 해롭다"는 **제품이 쓰지 않는 양을 채점한 결과**였다 |
| 추적기 불리 재현 | 추적기 불리 또는 널 | **ROBUST** — 추적기는 제어 지표에서도 이롭지 않다. **재프레이밍은 죽는다. 그렇게 보고한다.** |
| M2 미재현 | — | **INVALID** — 이 배치로는 비교 불가. 그렇게 보고하고 원인을 찾는다. |

⛔**"METRIC-ARTIFACT" 가 나와도 그것은 "추적기가 좋다"가 아니라
"지금까지의 채점 대상이 제품과 다르다"이다.** 성능 주장으로 승격 금지.

## 3. 설계

**데이터** = S1 의 **신선 독립 32 에피소드**(`data_indep_crowded_2026-08-08` 16 +
`data_indep_sparse_2026-08-08` 16). 게이트 통과 기록 = `tmp/S1_indep_sparse_2026-08-08/gate.txt`
(5축 전부 16종, 바닥 p = 3.05e-05). **α_wave 목적으로는 한 번도 쓰이지 않았다.**

**셀** (노브 1개):
| 셀 | 내용 |
|---|---|
| `AUTO` | 출하 기본값 (`init_method='auto'`, `analytic_ensemble_k=3`) |
| `AUTO-NOTRACK` | 위와 동일 + `tracking_lr = 0` — **노브 1개** |
| `AUTO-DUP` | `AUTO` 바이트 복제 — 워커 누출 프로브 |

3 셀 × 32 ep × 3 시드 = **288 런**. 시드 = **1551, 1552, 1553** (원장 [1551–1818]).

**α_wave 계산 규약 (동결)**
- 평가점 = 프레임 t 에서 `x = x_foil + U·L`, `y = 0`, 포일 2개(+2.0, −2.5), U = 11.3 m/s,
  L ∈ {0.1, 0.2, 0.3, 0.5} s. **PRIMARY 는 L = 0.2 s**(STUDY_GUIDE 튜닝값), 나머지는 부.
- `α_wave = −slope − w/U`, slope = 진행방향 ∂η/∂x, w = ∂η/∂t.
- ★**GT 와 추정 모두에 동일한 중심차분 스텐실**을 쓴다(공간 ±2.0 m, 시간 ±0.05 s).
  2026-07-09 캐비엇이 지적한 **평활화 비대칭을 원천 차단**하기 위해서다.
  GT η 는 `config/wave_components` 에서 해석적으로, 추정 η 는 살아있는 모델에서.
- 정규화 = **에피소드별 GT α_wave 의 표준편차**(전 프레임·양 포일 풀). ⛔창 안 자기정규화 금지.
- 프레임 집계 = 에피소드·리드별 **RMSE / std** = nRMSE(무차원).

**집계·검정 (S1 규약 승계, 동결)**
1. 에피소드당 값 = 3 시드의 **중앙**. 2. 짝 Δ = `AUTO − AUTO-NOTRACK`, 같은 에피소드 안에서.
3. 집계 = 레짐 안에서 **짝 Δ 의 중앙**. ⛔중앙들의 차 금지. ⛔mean 금지.
4. **양측 정확 부호검정**, 레짐당 n=16, 바닥 p = 3.05e-05. **PRIMARY 문턱 = 13/16**(Holm-2, α=0.025).
5. 동점 제외·제외 수 병기. 6. **널 배제 없음.**
7. **절대·상대 Δ 둘 다 출력**(S1 에서 절대 규약이 희소 피해를 은폐한 전례).
8. **MDE**: η 는 S1 의 레짐별 값 승계. **α_wave 는 사전 추정치가 존재하지 않으므로
   본 배치 `AUTO-NOTRACK` 팔의 시드분산에서 산출하고 "배치 내 산출(사전 동결 아님)"이라고
   명시해 병기한다.** ⛔사전 동결된 척 인용 금지.

## 5. ⛔이 실험이 말할 수 **없는** 것 (사전 선언)
- ⛔**"추적기가 좋다/나쁘다"는 성능 주장** — 이건 **지표 간 비교**다.
- ⛔**E-B/E-C/E-D/Rx-7 과 풀링** — 저쪽은 전역 η, 이쪽은 α_wave. 같은 축이 아니다.
- ⛔**"제어점 = 관측점"** — 측정 결과 약 16 m 떨어져 있다(§1.4).
- ⛔**0.1–0.5 s 지평의 일반화** — 이 지평은 **FF 제어 산출물** 기준이다.
  상황인지·조종 판단 산출물이면 지평이 길어지고 **E-D 의 먼바다 손상이 다시 지배한다**
  (2026-07-09 캐비엇 마지막 항). **제품 정의가 바뀌면 이 결과는 적용되지 않는다.**
- ⛔실측 일반화 · ⛔지연·벽시계(`elapsed_ms` 오염) · ⛔LETKF 대비 주장(이 배치에 없음).
