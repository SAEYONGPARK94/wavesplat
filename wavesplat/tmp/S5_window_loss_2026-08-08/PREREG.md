# S5 — 최적화 실패인가 창-과적합인가, 그리고 **정규화항이 범인인가**

작성 2026-08-08, **채점 전·해당 수치 미존재** 상태에서 동결. 논문·`configs/`·출하 기본값 **무수정**.

--------------------------------------------------------------------------------
## 0. S4 가 남긴 정확한 질문
S4: 혼잡에서 **진실 파라미터로 출발시켜도** 최적화 후 관측손실이 **14.6배** 나빠진다(0/16).
그런데 그 손실은 **추적 프레임 전체 평균**이고 Phase-1 은 **`init_frames` 창 하나**만 적합한다
⟹ **(1) 최소화 자체 실패** 와 **(2) 창은 잘 맞추고 일반화 실패** 를 구별할 수 없었다.

## 0.1 ⚠사전 공개 — 구현 검증 스모크 (n=1, 배치 아님). **숨기지 않는다.**
`S5_WINDOW=1` 게이트를 배선하고 에피소드 1개(BF4_15comp_seed20, 시드 1560)를 돌려 아래를 봤다.
**이 사전등록은 이걸 본 뒤에 쓰였다.** 그래서 §1 의 문턱은 전부 **수치로 미리 못 박는다.**

| 셀 | **학습창 잔차** | 전 프레임 잔차 | nRMSE |
|---|---|---|---|
| `ORA-WPHI-0STEP`(진실) | 0.00601 | 0.00637 | 0.0000 |
| `ORA-WPHI-NT` | 0.01528 | 0.08760 | 0.1106 |
| ★`ORA-WPHI-NOREG`(λ=0) | **0.00552** | **0.00884** | **0.0139** |
| `AUTO-NT` | 0.03723 | 0.13432 | 0.1408 |

⟹ n=1 에서 **정규화항을 끄자 nRMSE 가 0.1106 → 0.0139 (8배)** 로 떨어졌고,
학습창 잔차는 **진실보다도 낮아졌다**(0.00552 < 0.00601 — 적합 중이므로 당연).
⟹ 스모크는 **REGULARISER** 분기를 가리킨다. n=1 이라 판정력 0.

## 0.3 ★그래서 이 배치의 진짜 질문은 하나 더 있다 — **출하 팔에서도 되는가**
위 스모크는 전부 **오라클 초기화** 위에서 나왔다. 정규화항은 **초기화가 나쁠 때** 존재 이유가
있을 수 있고, 출하 팔에서 끄면 오히려 나빠질 수 있다.
⟹ S1 에서 **출하 안 되는 팔 위의 개선이 배포에서 무효**였던 전례가 있다(`G1P1`).
⟹ **`AUTO-NT-NOREG` 를 반드시 같이 잰다.** 그게 없으면 이 발견은 배포에 대해 아무 말도 못 한다.
⟹ 어느 항이 범인인지 가르기 위해 **`AUTO-NT-NOL1`**(λ_l1 만 0)도 넣는다.

## 0.2 ★그래서 대조를 하나 더 넣는다 — 정규화항
옵티마이저가 최소화하는 것은 **무가중 잔차가 아니다**: 신뢰도 가중 데이터항 +
`lambda_l1`(0.001) + `lambda_smooth`(0.0001) 이다(`run.py:DEFAULT_CONFIG`).
⟹ "진실보다 창 잔차가 나쁘다"가 곧 **"자기 목적함수를 못 내렸다"는 아니다** —
정규화항이 **의도적으로** 진실에서 밀어냈을 수 있다.
⟹ **`ORA-WPHI-NOREG`**(`lambda_l1 = lambda_smooth = 0`) 를 추가해 그 가설을 직접 시험한다.

## 1. 가설과 분기 (전부 도달 가능)

**PRIMARY (H1)** = 혼잡에서 짝 Δ `window_resid(ORA-WPHI-NT) − window_resid(ORA-WPHI-0STEP)`.
H0: 중앙 = 0. **문턱 = 부호 13/16**(양측 정확 부호검정).

| H1 | H2(`NOREG` vs `NT`) | 판정 |
|---|---|---|
| Δ > 0 (창에서도 나쁨), ≥13/16 | `NOREG` 가 진실 수준으로 회복 | ★**REGULARISER** — 정규화항이 진실에서 밀어낸다 |
| Δ > 0, ≥13/16 | `NOREG` 도 회복 못 함 | ★**OPTIMISER-CANNOT-FIT** — 데이터항조차 못 내린다 |
| Δ ≤ 0 또는 문턱 미달 | — | ★**WINDOW-OVERFIT** — 창은 잘 맞추고 밖에서 무너진다 |

**H3 (일반화 몫).** `전프레임 잔차 − 창 잔차` 를 셀별로 보고. 창에서의 열화와 창 밖 열화의 분해.
**H4 (희소 대조).** 같은 것을 희소에서. S4 에서 희소는 실패하지 않았으므로 **음성 대조**다.

### ★H5 (PRIMARY-2, 배포 질문) — `AUTO-NT-NOREG − AUTO-NT`, 혼잡 `nRMSE`
**사전 확정 판정**:
- Δ < 0 이고 부호 **≥13/16** ⟹ ★**DEPLOYABLE** — 출하 팔에서도 정규화 제거가 이긴다.
- Δ > 0 이고 부호 ≥13/16 ⟹ **ORACLE-ONLY-HARMFUL** — 오라클에서만 좋고 배포에선 해롭다.
- 문턱 미달 ⟹ **ORACLE-ONLY-NULL** — 배포에 대해선 아무것도 말하지 못한다.
⛔**H1 이 REGULARISER 로 나와도 H5 가 없으면 배포 주장 금지.** (S1 `G1P1` 전례.)

**H6 (어느 항인가).** `AUTO-NT-NOL1 − AUTO-NT` 와 `AUTO-NT-NOREG − AUTO-NT-NOL1` 로
`lambda_l1` 과 `lambda_smooth` 의 몫을 분리. ⛔둘 다 끈 팔에 **단일 원인 이름 금지**.

⛔`NOREG` 회복 판정 기준(사전 확정): `window_resid(NOREG) − window_resid(0STEP)` 의
짝 Δ 중앙이 **`NT` 의 그것의 절반 미만**일 것.

## 2. 설계
**데이터** = S1 신선 독립 32ep. **PRIMARY = 혼잡 16ep.** 시드 **1560, 1561, 1562**.

| 셀 | 초기화 | 정규화 | 최적화 | 추적기 |
|---|---|---|---|---|
| `ORA-WPHI-0STEP` | 오라클 `(kx,ky,w,φ)` | — | **0 스텝** | off |
| `ORA-WPHI-NT` | 오라클 `(kx,ky,w,φ)` | 기본 | 정상 | off |
| **`ORA-WPHI-NOREG`** | 오라클 `(kx,ky,w,φ)` | **λ_l1 = λ_smooth = 0** | 정상 | off |
| `AUTO-NT` | 출하 | 기본 | 정상 | off |
| ★**`AUTO-NT-NOREG`** | **출하** | **λ_l1 = λ_smooth = 0** | 정상 | off |
| **`AUTO-NT-NOL1`** | 출하 | **λ_l1 = 0** (smooth 유지) | 정상 | off |

7 × 32 × 3 = **672 런**(단일 실행 — S4 와 달리 한 번에 전 지표를 뽑는다).

**신규 계측** = `run.py` 에 `S5_WINDOW=1` **opt-in 게이트**: `initialize()` 직후·첫 `update()` 전에
`init_frames` 전체 관측점에서 모델 잔차 RMS 를 잰다(`window_resid`, `window_n_obs`).
게이트 off 면 실행되지 않는다. ⚠**무가중**이다 — 학습 목적함수와 같지 않다(§0.2).

## 3. 집계 (S1–S4 규약 승계, 동결)
에피소드당 3시드 **중앙** → 짝 Δ → 레짐 안 **Δ 중앙** → **양측 정확 부호검정**, 문턱 13/16.
⛔중앙들의 차·mean 금지. 동점 제외·수 병기. **널 배제 없음.** 절대·상대 Δ **둘 다**.
⚠**오라클 팔은 시드 무관**(S4 에서 확인) ⟹ 그 팔들의 MDE 는 정의되지 않는다.
근거는 **에피소드 부호 일치**이며 ⛔`|Δ|/MDE` 인용 금지. 부대조는 Holm-3.

## 5. ⛔말할 수 없는 것
- ⛔**"옵티마이저가 자기 목적함수를 못 내린다"** — `window_resid` 는 **무가중**이다.
  허용: **"학습창의 무가중 데이터 적합에서도 진실보다 나쁘다"**. 목적함수 자체 값은 안 쟀다.
- ⛔`0STEP` 의 nRMSE=0 을 **표현 충분**으로(동어반복) · ⛔`ORA-*` 를 배포 성능으로(묶음·출하 불가)
- ⛔혼잡 판정을 희소로 일반화 · ⛔S1–S4 와 풀링(짝비교만) · ⛔지연·벽시계 · ⛔실측 일반화
- ⛔**처방 주장** — 이 배치는 **원인 지목**까지다. `λ` 를 바꾸는 것이 배포에 좋다는 뜻이 아니다.
