## 3. 승계되는 규약 (S1–S8, 동결)

1. 에피소드당 값 = 3 추정기 시드의 **중앙**.
2. **짝 Δ** = (처치 − 기준선), **같은 에피소드 안**.
3. 검정 통계량 = 에피소드별 짝 Δ 의 **부호**. ⛔(에피소드×시드) 를 쓰지 않는다.
4. Δ 중앙은 크기 보고용, 검정 통계량 아님. ⛔"중앙들의 차"·mean 금지(mean 은 꼬리 진단만).
5. **판정은 절대 규약**, 상대 의무 병기. 두 규약이 갈리면 **불일치 자체가 결과**.
6. 동점 제외·수 병기. 널 배제 없음.
7. MDE 는 **결과 관측 전**에 S8 `results.jsonl` 에서 σ 와 기준선 수준만 읽어 산출(효과 크기 미열람).

8. 실행 전 게이트(G-1 독립성 5축 · G-2 메시 ADEQUATE · G-3 손잡이 3종 · G-4 시드 충돌 0 ·
