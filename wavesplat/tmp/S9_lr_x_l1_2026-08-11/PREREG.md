## 3. 집계 (S1–S8 승계, 동결)

1. 에피소드당 값 = 3 추정기 시드의 **중앙**.
2. **짝 Δ** = (처치 − 기준선), **같은 에피소드 안**.
3. 검정 통계량 = 에피소드별 짝 Δ 의 **부호**. ⛔(에피소드×시드) 를 쓰지 않는다.
4. "부호 x/n" = Δ<0(개선) 에피소드 수. 반대 방향 족에서는 Δ>0 인 수.
5. Δ 중앙은 **크기 보고용**이며 검정 통계량이 아니다. ⛔"중앙들의 차"·mean 금지
   (mean 은 §6 꼬리 진단에서만).
6. ★**판정은 절대 규약**, 상대 의무 병기. 두 규약이 갈리면 **불일치 자체가 결과**.
7. 동점 제외·수 병기. **널 배제 없음.**

## 4. ★근거리 — **부재 증명을 존재 증명으로 바꾼다**

초안은 PRIMARY 통과 조건을 *"근거리 악화가 MDE 미만"* 으로 걸었다. **위음성을 통과로 바꾸는
규칙**이다(CON B-4). NEUTRAL M5 / PRO P-7 의 처방을 채택한다:

**이동 널 부호검정.** 셸 s 에서 상대 Δ 가 사전 동결된 등가한계 **δ_s** 보다 작은 에피소드 수
`#{rel_Δ_s < δ_s}` 를 **같은 부호검정 문턱표**로 검정한다. ⟹ 문턱·Holm 구조를 **하나도 안 바꾸고**
재사용하며, 결론이 **"손상이 δ 보다 작다"는 적극적 주장**이 된다.

- δ_s 는 `mde_prespec_s9.py` 가 **결과 관측 전에** S8 `results.jsonl` 에서 **산포와 기준선 수준만**
  읽어 산출·동결한다(효과 크기 미열람). δ = `mde_sign80_c(n, k) × σ_Δ,robust / baseline`.
- 대상 = 근거리 3셸 `0_5` · `5_10` · `10_20`.
- ★**전 셸 규칙은 무처치 널로 보정한다**(S8 A2 를 셸에 확장): 널 셀의 같은 통계량을 병기하고,
  **처치의 악화가 널의 악화를 넘지 못하면 `TAIL-UNCALIBRATED`** 를 붙이고 손상 주장을 하지 않는다.
  ⚠S8 이 이걸 안 해서 "0.25× 면 사라진다"를 잘못 말했다(§0). **같은 실수를 두 번 하지 않는다.**
- ⛔통과해도 **"무해하다"** 금지. 허용 = **"δ_s 이상의 근거리 손상은 검출되지 않았다"** + δ_s 병기.
- 9셸 전부를 보고하되 **판정은 근거리 3셸만** 쓴다. 9셸 위양성 여유는 §6 에 병기.

## 5. SECONDARY (전부 탐색적, ⛔판정 미기여 — 단 (a) 는 배포 문장의 **거부권**을 갖는다)

**(a) ★`all_resid` 게이트 — S8 A5 승계, 초안이 빠뜨렸던 것.**
`all_resid`(무가중 GT-free 센서 잔차)는 **S7 의 묶음을 죽인 지표**이자 S8 헤드라인이
*"거래가 없다"* 라고 말할 수 있었던 근거다. PRIMARY 가 통과해도 **처치의 `all_resid` 가
어느 레짐에서든 `harm_k(n)` 이상 악화하면 `/SUPPORT-TRADEOFF` 를 붙이고 ⛔배포 문장을 금지**한다.
⛔`avg_obs_loss` 는 λ·Σ|w| 를 포함하므로 관측 적합 근거로 인용 금지(A5).

**(b) ★lr 축 폐쇄 (이 배치의 두 번째 목적).**
`AUTO-QTR − AUTO` 와 `AUTO-QTR-L1 − AUTO-L1` 를 **`all_resid` · 전역 nRMSE · 근거리 3셸**
세 지표에서 본다. ★**기준선이 `AUTO-L1` 인 대조를 반드시 포함한다**(CON B-5):
기준선을 `AUTO` 로만 두면 두 팔이 다 "개선"으로 찍혀 **거래를 구조적으로 못 본다**.
- **사전 예측**(S8 자료 기반, 결과 전 기록): 혼잡에서 `all_resid` 악화가 재현되고,
  `AUTO-QTR-L1` 이 `AUTO-L1` 에 전역·근거리 모두 진다.
- 예측이 맞으면 → **lr 축 폐쇄**(`LR-AXIS-CLOSED`). 틀리면 → S8 해석이 틀렸다는 뜻이므로
  **그 자체를 결과로** 적는다. ⛔어느 쪽도 기제 이름이 아니다.

**(c) lr 사다리**: `AUTO-NT`(0) · `AUTO-QTR`(0.25×) · `AUTO`(1×) 의 `0_5` 와 `all_resid`.
⚠**널 보정 필수**(§4). ⛔S8 의 `DOSE-MONOTONE` 문장은 널 보정 없이 쓰였으므로 **재인용 금지**.

**(d) 기제 계측**: `window_resid` · `decorr_mean` · `shrink_mean` · `N` · `init_iters` · `final_n`.
⛔`ΔN ≠ 0` 이면 "정규화 효과" 대신 **"정규화+용량 묶음"**.

**(e) 혼잡 n=32 복제**: `AUTO-L1 − AUTO`. ⚠**사전 통과확률이 높다**(S8 27/32) ⟹
통과해도 **신규 정보가 아니라 복제**다. ⛔"두 번 독립 재현" 은 쓸 수 있으나 **p 결합 금지**.

**(f) 라우트 층화**: `auto_selected` · `ensemble_k`. ⛔"희소 전용" 대신 **"(희소 ∧ 라우트)"**.

**(g) ⛔2-loci 는 이 배치의 범위 밖이다.** 필요 n ≈ **405**(PRO P-14). **결과 전에 이렇게 적어
두므로**, `/TWO-LOCI` 가 남는 것은 실패가 아니라 **알려진 미해결**이다.
