## 2. 왜 비었나 — 코드가 막았다 (B-21 이 3단계로 실측)

1. **노드 세분은 Δk 를 세분하지 않는다** — `letkf_spec.py:177 dkx = 2π/(nx·dx)` 는
   **정의역이 정한다**(노드 ×2 는 Δk +1.3%). Δk/2 의 유일 구성 = **정의역 ×2**(79×59, dx 유지).
2. **그런데 도달 불가** — `run_s16.run_letkf` 가 해석 격자를 **지역 변수로 박고**(`:203-204`
   `egx=linspace(...,40)`·`egy=linspace(...,30)`) **같은 지역 변수로 채점 보간기를 만든다**(`:232`).
   필터만 세분하면 실측 `ValueError: There are 30 points and 59 values in dimension 0`.
3. **두 우회로가 다 금지 부류** — ①동결 파일 수정(`S16`·`B-11b`·`B-12`·`B-15` 가 그 함수로
   돌았다) ②함수 복제(*"같은 기능이 두 파일에 구현돼 한쪽만 계측"* = 반복 결함 3부류).

⚠`M2`(08-28)가 같은 벽을 독립 재확인했다: `G-L4` 가 소스 파싱으로 **격자 40×30 도달 불가**를
확인하고 `loc` 축만 닫았다(`M2/RESULT.md:341,366-368`). ⟹ **F2 는 `loc` 축에서만 측정으로
닫혔고, 격자 축은 여전히 이 공백이다** — `C8` 의 "M2 결론의 방향 비대칭"은 이 뜻이다.
