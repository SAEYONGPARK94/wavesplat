- 실측 참값 패널의 흰 영역은 **스테레오 재구성이 없는 곳**(NaN)이고 채점에서 제외된다.
  추정 패널은 그 영역에도 값을 낸다 — ⚠**보이는 것보다 채점 영역이 좁다.**
