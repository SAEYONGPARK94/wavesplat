# `S-ENS` 사전등록 — 합성에서의 앙상블 대칭 (배포 코드 경로)

> **동결 시점 = 결과 0행 · 추정기 0회.** 모든 수는 `gates_sens.py` 가 재도출한다(손복사 0).
> 선행 = `T3-NOW`(나우캐스트 확증) · `T5-ENS`(예보 확증 + `AMENDMENT_1` 서술 정정) ·
> 결정 `D3`(2026-09-01, 다중 에이전트 토론 — 경로 구현, 기본값 OFF 유지).

---

## §0 질문 — 한 문장

> ***"실측에서 확증된 앙상블 이득이 **합성에서도**, 그리고 **배포 코드 경로 자체에서도**
> 나타나는가?"***

★**왜 이것이 남은 질문인가**: `D3` 토론에서 찬성 측이 스스로 자백한 공백이다 —
***기본값이 실제로 바꾸는 트래픽은 합성인데 개입 확증은 실측뿐이다.***
그리고 반대 측의 최강 논거는 ***측정된 연산자가 패키지에 없다*** 였다.
⟹ 이 배치는 **둘을 동시에** 해소한다: 합성에서, 그리고 **패키지가 소유한 경로**로 잰다.

## §2 이미 잰 것 (중복 방지) · 노출 공시

| | |
|---|---|
| 실측 나우캐스트 | `T3` 29/36 · −8.65% (확증) |
| 실측 예보 | `T5` NEAR 28/36 −8.53% · FAR 35/36 −11.10% (확증) ⚠NEAR 는 노출 r=0.836 |

★**노출**: 나는 **실측 방향과 크기를 안다**(위 표). ⛔그러나 **합성에서의 방향·크기는

⟹ 이 배치의 PRIMARY 는 **노출되지 않았다.** ⚠단 실측 결과가 사전 기대를 만들었다는 것은
공시한다(§3 이 그것을 예측으로 적는다).

## §3 ★결과 전 예측 + **그 예측 하의 검정력 표**

⛔**규율**(`T5` v1 이 이것을 안 해서 폐기됐다): 예측만 적는 것은 설계를 검증하지 않는다.

**예측**: 합성에서도 이득이 나타나되 **실측보다 작다**. 사유 — 실측에서 학습 경로의 시드
분산이 크고(시드 CV 중앙 13.57%) 합성은 그보다 안정적일 것이다. 예측 구간 **q ≈ 0.62–0.72**.

**검정력** (n=64, Holm 첫 문턱 **41**):

| 참 승률 | P(확증) |
|---|---|
| q = 0.806 (실측 나우캐스트 수준) | 0.9994 |
| q = 0.75 | 0.9819 |
| q = 0.70 | **0.8785** |
| q = 0.65 | **0.6179** |
| q = 0.60 | 0.2983 |
| q = 0.50 (효과 없음) | 0.0164 |

⟹ **내 예측 구간(0.62–0.72)의 중앙에서 확증 확률 ≈ 0.62–0.88.**
⛔`T5` v1(0.07%)과 비교하라. ★그리고 **음성도 값이 있다**(§5).

⛔결과를 보고 표본을 늘리지 않는다. n=64 × 2 층 고정.

## §4 설계

### 4.1 처치는 단일 요인
**`learned_ensemble_k` 1↔3** 하나뿐. 두 팔 모두 **배포 라우터를 그대로 탄다**
(`init_method='auto'` + `auto_switch_thresh=0` ⟹ 라우터가 학습으로 해소).

### 4.2 팔 — ⛔전 키 명시 · 빈 dict 0개

```
_BASE = dict(init_method='auto', auto_switch_thresh=0,
             varpro_steps=400, learned_init_iters=0, lambda_l1=1e-4,
             k_snap_dk=None, adaptive_n=True, max_n=30,
             tracking_mode='w_phi', tracking_steps=10, tracking_lr=0.005,
             tracking_window=3, use_confidence=True,
             analytic_ensemble_k=3,          # 배포값 — 이 배치에서는 무연산(라우터가 학습으로 간다)
             real_domain_gate=True, seed=SEED)
```

| 팔 | config | 기대 `ensemble_k` | 앵커 |
|---|---|---|---|
| `LEARN-M1` | `dict(_BASE, learned_ensemble_k=1)` | **1** | ★동결 `W-15 POST` 와 **비트 동일** |
| `LEARN-M3` | `dict(_BASE, learned_ensemble_k=3)` | **3** | 없음(신규 팔) |

★**`LEARN-M1` 이 곧 배포 기본값이다** — `learned_ensemble_k` 를 명시했지만 그 값이 기본값과
같으므로 동작이 같다. ⟹ **앵커가 「기본값 불변」을 비트로 증명한다**(`P5` 의 실행 확인).

### 4.3 셀 · 표본
- 코퍼스 = 동결 `W-15 corpus.json` — **혼잡 64 · 희소 64** (⛔재선언하지 않고 임포트)
- 추정기 시드 **고정**(`W-15` 의 세 시드 중 첫 값). ⟹ ★**새 시드 청구 0**
- 셀 = 에피소드. **PRIMARY = 혼잡 64** · **SEC-A = 희소 64**

### 4.4 문턱 (코드 재도출)
| | 값 |
|---|---|
| n | 64 |
| N_FAMILY | **2** (PRIMARY 혼잡 · SEC-A 희소) |
| **Holm 사다리** | **[41, 40]** |
| NOMINAL | 40 |
| **NOT_EARN** | **23** (= n − 41, 대칭) |
| ★**MDE q80** | **0.682** |

### 4.5 판정 · 라벨 (결과 전 고정 · 공역 전건)
등급은 `T5 gates_t5.grade` 규약 — **Holm 생존이 등급을 정한다.**

| 조건 | 라벨 (PRIMARY) |
|---|---|
| Holm 생존 | ★`S-ENS :: SYNTH-ENSEMBLE-EARNS (CONFIRMATORY)` |
| ≥40, Holm 탈락 | `S-ENS :: SYNTH-ENSEMBLE-EARNS [EXPLORATORY]` |
| 23 < w < 40 | `S-ENS :: SYNTH-ENSEMBLE-UNDECIDED` |
| ≤23 | `S-ENS :: SYNTH-ENSEMBLE-REVERSED [EXPLORATORY]` ⚠역방향 꼬리, ⛔확증 승격 금지 |
| 차단 게이트 FAIL | ⛔라벨 없음 |

SEC-A 는 같은 4갈래(주어만 희소).

**⛔확증 가족 밖 (`EXPLORATORY` 고정)**: `EX-1` 단가 비교(`wall_s`) · `EX-2` `final_n` 분포 ·
`EX-3` 층 간 대비(⛔`B-17` 교훈 — 층 대비에 `p` 를 붙이지 않는다).

### 4.6 앵커 불일치 시 (`T5 §4.6b` 상속)
계수를 열지 않고 진단만 한다 → 장치로 특정되면 `H-ANCHOR` 강등 + 공시, 아니면 라벨 없이
닫고 승계 배치로. ⛔게이트 수정·재실행 금지.

## §5 널이면 무엇을 쓰는가

- **PRIMARY 널** ⟹ ***"실측에서 확증된 앙상블 이득이 합성에서는 검출되지 않았다
  (n=64, MDE q80=0.682)"*** ⟹ ★**그것이 큰 결과다**: 이득이 **실측 특이**임이 측정되고,
  `D3` 의 배포 축이 **닫힌다**(기본값을 켤 근거가 소멸). ⛔*"차이 없다"* 금지.
- **PRIMARY 확증** ⟹ 배포 기본값 전환의 **필요조건 하나**가 충족된다.
  ⛔**충분조건이 아니다** — 단가 3배와 프레임 예산은 별도 측정이고, 전환은 **별도 사전등록**이다.
- ⛔어느 결과도 **실측 판정을 바꾸지 않는다**(다른 층·다른 코퍼스).
