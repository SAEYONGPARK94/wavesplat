## 1. ⛔사전등록 위반 — PREREG §6 의무 공시 3건이 삭제됐다 (V2 / MAJOR)

`PREREG.md:121` 이 **의무**로 건 문장을 개정문 2 의 분석기 재작성이 **떨어뜨렸다**:
```

```
그리고 `AMENDMENT_1 §6.4` 가 *"예산 비대칭 공시를 **정정**하라"* 한 것을 나는 **삭제**로

## 2. `G-ENV` 항진 잔존 — 3개 중 **2개만** 고쳤다 (V1 / MAJOR)

개정문 2 §7 이 `G-ENV` 의 항진을 셋으로 지목했는데(*"러너 리터럴 == 분석기 리터럴,
**시드는 같은 상수 왕복**, `code_md5` 는 `bool()`"*) 수리는 둘만 했다:
```python
run_t11.py:356      seed=G.SEED
analyze_t11.py:217  meta.get('seed') == G.SEED      # ← 같은 모듈 상수 왕복. 실패 불가.
```
게다가 **런에 실제로 들어간 시드는 `G.SEED + fi`**(`run_t11.py:297,301`)인데 어떤 게이트도
그것을 보지 않았다. ⟹ 행의 `seed` 열을 되읽어 **집합 대조**한다:
`{r['seed']} == {G.SEED+1 … G.SEED+24}` (팔별). 이것은 러너가 **블록마다 다르게** 쓴 값이라
상수 왕복이 아니다.

**그리고 동결 대조를 「측정면 / 분석면」으로 가른다** — 개정문 3 이 `gates_t11.py`·
`analyze_t11.py` 를 고치므로 `meta['code_md5']`(런 시점 기록)와 어긋나는 것이 **정상**이다:
| 면 | 파일 | 대조 |
|---|---|---|
| **측정면** | `run_t11.py` · 임포트 8 · ckpt · `sample_t11.json` · `PREREG` · `AMENDMENT_1/2` · `NOTE` | 현재 == `meta['code_md5']` == **원래 `FROZEN_md5.txt`** (3중) |
| **분석면** | `gates_t11.py` · `analyze_t11.py` · `AMENDMENT_3_POSTRESULT.md` | 현재 == `FROZEN_md5_A3.txt` |
★**측정면 3중 대조가 통과하면 「개정문 3 은 측정을 건드리지 않았다」가 기계로 증명된다.**
⛔원래 `FROZEN_md5.txt` 는 **수정하지 않는다** — 결과 0행 동결의 증거물이다.

## 3. `G-DENSITY` 소실, 대체 없음 (V2 / MAJOR) — **사후 점검으로 복원**

초판 분석기는 `|n_obs − density·WIN_S| ≤ density` 를 단언했다. `AMENDMENT_1` 이 그것을
`G-CAP` 의 「소비 == min(제공, 캡)」 항으로 대체했고, **개정문 2 가 그 항을 항진이라며 뺐다**
⟹ 남은 게 0. 실측: 개정 분석기가 `density`·`n_frames`·`dt`·`tq`·`e_shape` 를 **한 번도 읽지
않는다**. 개정문 2 §7 이 *"`dt`·`tq`·`E.shape` 를 추가해 「창 40 s」가 결과 파일에서 검증
가능하다"* 라 적었는데 **기록만 하고 검증은 안 했다.**

**사후 점검 `G-DENSITY` (식을 여기서 먼저 고정한다 — 결과를 보고 정하지 않는다)**
```
모든 행:  n_offered == DENSITY * int(WIN_S)          (= 200 * 40 = 8000)
SHIP/RESCALE 행:  n_frames == int(WIN_S)             (= 40, 프레임에서 되읽은 값)
모든 행:  e_shape[0] >= J0 + int(WIN_S)              (창이 자료 안에 들어간다)
모든 행:  |tq - (int(WIN_S) - 1) * dt| <= 1e-9       ("창 40 s" 의 실제 검증)
```
⚠`n_offered` 는 러너가 **만들어진 프레임에서 되읽은** 값이고(`readback_frames`) 우변은
사전등록 상수다 ⟹ **항진이 아니다.**

## 5. `label_probs` 가 음성 라벨 둘을 하나로 뭉갠다 (V1 / MAJOR) — **공시로만 처리**

## 6. 라벨 인쇄 벨트 (V3 / MAJOR)

`lab = label(...) if not blocked else None` — 라벨 인쇄가 `blocked_by()` **하나**에만 매달려
있다. V3 가 합성으로 `blocked_by` 를 무력화하니 **`G-BLOCK` 이 FAIL 인데 라벨이 인쇄됐다**.
⟹ `if not blocked and all(ok for _, ok, _ in A)` 로 좁힌다. **막을 수만 있는 변경**이다.
(현 코드에 그 경로는 없다 — V3 가 15/15 매칭·39회 종단 실행으로 **장식 게이트 0건**을 확인했다.)
