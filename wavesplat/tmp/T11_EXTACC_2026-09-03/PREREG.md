# `T11-EXTACC` 사전등록 **v2** — **실패가 우리 것인가 자료 것인가**

> ⛔**v1 은 러너를 쓰기 전에 폐기됐다** — `AMENDMENT_1_PREDATA.md` 를 먼저 읽어라.
> 원문 = `PREREG_v1_DISCARDED.md`. 폐기 사유: 밀도 사다리가 내부 캡으로 뭉개졌고(BLOCKER-1),
> `config` 재사용이 원자 캐시를 흘리며(BLOCKER-2), 표본이 각도 교락이었다.
>
> **v2 동결 시점: 결과 0행.** ⚠단 **완전 blind 가 아니다** — 사전감사가 `mixed_data2`
> 8파일에서 스모크를 돌려 **`SHIP` 이 기술을 못 얻는다**는 것을 이미 보았다(§2 가 그것을
> 설계에 반영한다). 그 8파일은 **PRIMARY 표본에서 제외**한다.

---

## §0 왜 질문이 바뀌었나

v1 은 *"우리 방법이 저들 자료에서 잘 되는가"* 를 물었다. 사전감사가 **답을 이미 보여 줬고**
(스모크 8파일에서 `SHIP<ZERO` **1/8**, 중앙 비 1.009), 더 중요하게 **사유를 진단했다**:

| 사실 | 근거 |
|---|---|
| 저들 첨두 파수 `k_p ≈ 0.030–0.040` rad/m (`λ` 156–208 m, `Tp ≈ 10 s`) | 내가 직접 확인 |
| 우리 해석적 초기화가 `dk = 0.10` 격자에서 **`\|kx\|,\|ky\| ≤ 0.10` 블록을 0 으로 지운다** | `initializer.py:456,509` |
| `MIN_DK = 0.15` 가 저들 **에너지 대역 전체보다 크다** | `initializer.py:63` |
| 학습 제안의 원자가 참값의 **16배** 파수에 놓인다 | 감사 실측 |
| ★**오라클**(참 파수에서 `A,φ` 만 LS)은 **같은 희소 관측으로 기술을 얻는다**(비 0.726) | 감사 실측 |
| ★**분산관계 보존 재척도**로 저들 바다를 우리 대역에 옮기면 **기술이 나타난다**(비 0.606, ρ +0.80) | 감사 실측 |

⟹ ***"안 된다" 는 이미 알고 있다. 물을 값이 있는 것은 「그것이 누구 탓인가」다.***
그리고 그 질문은 **귀속 가능**하다 — 오라클과 재척도가 각각 한 방향을 닫는다.

## §1 팔 (전부 **같은 희소 관측**을 쓴다 — 이것이 설계의 핵심)

| 팔 | 정의 | 무엇을 닫는가 |
|---|---|---|
| `SHIP` | 출하 기본값(`make_updater`, 상수 `gt_field`) | *"우리 방법이 되는가"* |
| ★`RESCALE` | **분산관계 보존 재라벨** `x'=x/s`, `t'=t/√s` (`s=2`) 후 같은 `SHIP` | ★*"우리 대역에 넣으면 되는가"* |
| `ORACLE` | 참 FFT 파수에서 `A,φ` 만 LS(⛔추정기 아님) | *"정보가 관측에 있는가"* |
| `ZERO` | 창별 제로필드 | 무기술 기준 |

⛔`RESCALE` 은 **자료를 바꾸지 않는다** — 같은 표본을 다른 단위로 라벨링할 뿐이고
`ω=√(gk)` 가 보존된다. ⟹ **처치는 「우리 대역과의 정렬」 하나**다.
⚠`s=2` 는 **결과 전 고정**(감사가 s=1/2/3 를 보았고 2·3 이 비슷했다 ⟹ **작은 쪽**을 택한다).

## §2 결정표 (결과 전 고정) — **귀속 사다리**

**PRIMARY**: `RESCALE < ZERO` 짝 부호검정, `n = 24`. **≥17** 이면 유의(α=0.05, 전수 계산).

| `RESCALE` | `SHIP` | 라벨 |
|---|---|---|
| ≥17 | ≤12 | ★**`BAND-MISMATCH`** — 실패는 **우리 대역**이고 자료가 아니다 |
| ≥17 | ≥17 | **`BOTH-WORK`** — v1 의 예상(⛔가능성 낮다) |
| ≤12 | ≤12 | **`BEYOND-REACH`** — 재척도로도 안 된다 ⟹ 대역 말고 다른 것 |
| 그 밖 | | **`UNDECIDED`** |

**SEC-A** `SHIP<ZERO`(정직한 음성 보고) · **SEC-B** `ORACLE<ZERO`(정보 존재) ·
**SEC-C** `Hs` 두 층. ⛔**층별 라벨 없음**(다중성).

## §3 ★결과 전 예측과 검정력

**`BAND-MISMATCH`**, 확률 **0.65** (`BEYOND-REACH` 0.20 · `UNDECIDED` 0.10 · `BOTH-WORK` 0.05).
**사유**: 감사가 **1파일에서** 재척도 이득을 보였다(비 0.941 → 0.606, ρ +0.35 → +0.80).
⚠**그것은 한 파일이고 PRIMARY 표본 밖이다** — 24파일로 일반화될지는 모른다.

|---|---|
| 0.6 | 0.192 |
| 0.7 | 0.565 |
| 0.8 | **0.911** |
| 0.9 | 0.998 |

## §4 표본·규약 (전부 결과 전 고정)

- **표본**: `mixed_data2` 에서 **각도 6종 × 4개 = 24파일**, `Hs` **12/12 균형**.
  ⛔감사 스모크 8파일(인덱스 60,63,65,68,71,74,77,80)은 **제외**한다.
  ⚠`angle<A>` 는 **방향 퍼짐 폭**이지 입사방향이 아니다(감사 실측: 방향집중도 R² 0.98→0.77).
  ⚠**`Tp` 는 전 파일 10.0 s** ⟹ 변하는 해상 파라미터는 **`Hs` 하나뿐**이다.
- ★**시간 원점**: 창마다 `t` 를 **0 으로 옮긴다**. ⚠감사가 원점만 바꿔 비가
  0.941/1.011/0.939 로 흔들리는 것을 보였다 — **재는 효과만 한 자유도**다. 행에 기록한다.
- **채점**: 저들 `eta` 전 격자, 마지막 관측 프레임. **정규화는 `4σ`** 로 못 박는다
  (⚠파일명 `Hs` 와 최대 **7%** 어긋난다 · `metrics.py:35` 의 σ-vs-`Hs` 4배 함정).
- **관측**: 프레임당 **200점** 균등 무작위 · 창 **40 s**(=40프레임).
  ⛔**밀도 사다리를 쓰지 않는다** — `M_OBS_CAP=400`·`bank_max_obs=600` 때문에 사다리가
  거의 뭉개진다(v1 BLOCKER-1). 대신 **제공·소비를 행에 둘 다 기록**한다.
- **`confidence`**: 전부 `ones` (⚠**live 하다** — 손실 가중 `:647` · VARPRO 가중 `:1006`).
- **`depth`**: **400 m**(`T10` 의 `NOT-SHALLOW` 와 정합). ⚠감사 실측으로 **추정에 무영향**
  (50/100/400/1085 에서 비가 1.011–1.016) · ⚠`d3_beamform_net.py:31` 이 `DEPTH=50` 을
  하드코딩해 **config 의 depth 가 학습 경로 전체에 닿지 않는다** — 공시한다.
- **좌표**: 창마다 **재중심화**(감사: 절대/재중심/축교환 차이 무의미, 그래도 규약을 고정).

## §6 ⛔범위와 금지

- ⛔**`BAND-MISMATCH` 를 *"우리 방법이 낫다/못하다"* 로 읽지 않는다.** 그것은 **귀속**이다.
- ⛔**`RESCALE` 을 실제 성능으로 인용 금지** — 단위를 바꾼 사고실험이지 배포 가능한 구성이 아니다.
- ⛔**`ORACLE` 은 추정기가 아니다**(참 파수를 받는다) — **정보 존재의 상한**일 뿐이다.
- ⛔`E2` 와 대각선 비교 금지 · 저들 논문 수치와 비교 금지 · solver 미명시.
- ⚠**완전 blind 아님**: 감사 스모크가 8파일에서 `SHIP` 무기술을 보였고 1파일에서 재척도
  이득을 보았다. 그 9파일은 표본에서 **제외**했으나 **설계가 그 관찰에 영향받았다**.
- ⚠`Tp` 가 전 파일 10 s 이므로 이 배치는 **한 주기 조건**의 진술이다.
