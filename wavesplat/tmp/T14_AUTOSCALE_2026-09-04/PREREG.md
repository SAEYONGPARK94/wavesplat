## §0 왜 이 배치인가 · PRIMARY 한 문장

`T11-EXTACC`(`BAND-MISMATCH`, 17/17 게이트)가 남긴 것:

| 사실 | 값 |
|---|---|
| 배포 팔 `SHIP` 이 제3자 참값 위에서 | **8/24, p=0.968 = 무기술** |
| 좌표 단위만 재라벨한 `RESCALE`(**`s=2.0` 고정**) | **24/24, p=5.96e-08** |
| 참 파수 오라클(정보 존재의 상한) | **24/24** |

⛔`RESCALE` 은 배포 구성이 **아니다** — `T11 PREREG §6` 이 *"단위를 바꾼 사고실험"* 이라 못박았고
**`s` 를 고르는 규칙이 없었다.**

### ★PRIMARY 질문 (한 문장)
> ***관측만으로(참값 없이) 고른 `s` 로 좌표를 정규화하면, 배포 학습 경로가 제3자 참값 위에서
> 제로필드를 이기는가 — 그리고 그 이득은 고정 `s=2.0` 이 낸 것의 얼마를 회수하는가?***

★**앵커 두 개로 읽는다**: `SHIP`(s=1) = **하한**, `FIX2`(s=2.0, = `T11` 의 `RESCALE`) = **상한**.
회수율 `R` 은 §4.4 에 정의된 **기술통계**이고 ⛔검정이 아니다.

### ⚠이 배치가 **재지 못하는 것** (결과 전에 못박는다)
이 코퍼스는 격자가 **전 파일 동일**(128×128, `L`=619.64 m)이고 `Tp` 도 **전 파일 10 s** 다
⟹ 두 규칙 모두 파일마다 **거의 같은 `s`** 를 낸다(`SCALE_ESTIMATORS.md §4`).
⟹ ⛔***`T14` 로 "규칙이 자료에 적응한다" 를 주장하지 마라.*** `T14` 는 **착지점**을 잰다.
**적응성(등변성)은 런 0회의 `G-EQUIVAR` 가 따로 증명**한다. **둘은 다른 진술이다.**

## §1 팔 (⛔`{}` 로 팔을 정의하지 않는다 — `T11` 개정문 2 의 처방)

모든 팔이 **같은 물리 관측점**을 본다(관측 추첨은 팔 분기 **전에** 파일 시드로 한 번).
팔 사이의 차이는 **좌표 재라벨 `s` 하나뿐**이고, `z`(고도)는 **절대 건드리지 않는다**.


| 팔 | `s` | 층 | 역할 |
|---|---|---|---|
| `ZERO` | — | 1·3 | 무기술 기준(창별 제로필드) |
| `SHIP` | **1.0**(항등) | 1·3 | ★**하한 앵커** = 출하 기본값. ⚠`x/1.0` 은 IEEE 항등이라 `T11 SHIP` 과 **비트 동일**이어야 한다(`G-SHIPID`) |
| `FIX2` | **2.0** 고정 | 1·3 | ★**상한 앵커** = `T11 RESCALE` |
| ★`AUTO-AP` | `s_ap(obs)` | 1·3 | 규칙 ① 개구/픽셀 비를 학습 범위로 |
| ★`AUTO-BAND` | `s_band(obs)` | 1·3 | 규칙 ② 첨두 파수를 사전 밴드로 |
| `SW-1.414` · `SW-2.828` · `SW-4.000` | 고정 | 2 | s-응답 곡선(√2 격자). **기술통계 전용** |

**재라벨 정의**(`T11` 규약 축자 계승, 분산관계 보존):
```
x' = x/s ,  y' = y/s ,  t' = t/√s ,  z' = z          ⟹  k' = s·k ,  ω' = √s·ω ,  ω' = √(g k') 보존
```
`s` 를 만드는 규칙 두 개의 정의·동결 상수·유래는 **`SCALE_ESTIMATORS.md §2`** 가 정본이다:
- `s_ap  = clip(max(ptp(x), ptp(y)) / L_TRAIN, 0.25, 4.0)`, `L_TRAIN = 220.55` m (`pool_xy()` 재생성 대조)
- `s_band= clip(K_TRAIN / k̂_p, 0.25, 4.0)`, `K_TRAIN = 0.06779` rad/m (사전 생성기 재생성 대조),
  `k̂_p` = 2단 빔포머 줌(`bank_mmse.py:158-165` 절차)
- **결과 전 예상값**: `s_ap ≈ 2.81`(코퍼스 상수) · `s_band ≈ 1.50–1.58` · 앵커 **2.0 이 그 사이**에 놓인다.

⛔**규칙은 이 시점에 동결된다.** 결과를 본 뒤 `K_TRAIN` 의 중심 통계(기하평균)나 `L_TRAIN` 의
정의(최대 변)를 바꾸는 것은 **금지**다. 새 규칙은 **새 사전등록으로만**.

⚠`SW-2.828` 이 `s_ap = 2.8095` 와 **0.7% 차**로 우연히 겹친다. √2 격자는 스케일-자유라는 이유로
골랐고 규칙에서 유도하지 않았다 — **공시하고, ⛔ 스윕을 규칙의 증거로 쓰지 않는다.**

### §4.1–4.3 SEC (전부 **무보정 · 라벨 없음**, `disclosures` 에 무보정임을 기계로 적는다)

★**`SEC-G` 의 허용된 용도는 정확히 둘이다**: (i) 경험적 최적 `s` 가 **격자 내부**인가 **가장자리**인가
(가장자리면 두 규칙 다 **부족 도달**), (ii) 각 규칙의 `s` 와 경험적 argmin 의 거리(**기술**).
⛔**이 곡선으로 새 규칙을 만들거나 기존 규칙을 다시 고르는 것은 금지**다(*"질 때까지 조율"* 회피).
새 규칙은 **새 사전등록으로만**.

### §4.4 ★회수율 `R` — **기술통계** (사용자가 요청한 앵커 읽기)
```
파일 i 에 대해   R_i = ( ln r_AUTO,i − ln r_SHIP,i ) / ( ln r_FIX2,i − ln r_SHIP,i )
포함 조건(결과 전 고정):  ln r_FIX2,i − ln r_SHIP,i  <=  −ln(1.05)     # 분모가 유의미하게 음수
보고:  median(R) , IQR , n_used , n_excluded
```
`R = 0` 은 *"자동이 하한과 같다"*, `R = 1` 은 *"상한을 전부 회수했다"*, `R > 1` 은 *"고정값을 넘었다"*.
⛔**검정이 아니다 · CI 없음 · `n_used` 와 §4 의 MDE 를 병기하지 않고 인용 금지.**
⛔**`R` 을 라벨로 승격하지 않는다.** ⚠분모가 파일마다 다르므로 `R` 은 **비의 비**다 — 평균 금지, **중앙값만**.

## §5 ★역변환 — 어디서 원 단위로 되돌리는가

재라벨은 **좌표에만** 작용하고 `z`(고도)는 불변이다. 따라서:

| 양 | 재라벨 좌표계 | 원 단위로 |
|---|---|---|
| 파수 | `k'` | **`k = k'/s`** |
| 각주파수 | `ω'` | **`ω = ω'/√s`** |
| 진폭 `w`(=A) | `A'` | **`A = A'` (불변)** |
| 위상 `φ` | `φ'` | **`φ = φ'` (불변)** |

**두 경로를 다 계산하고 일치를 강제한다 (`G-INVERT`)**:
- **P-implicit** (`T11` 경로): 원 격자의 **상(image)** 에서 질의 — `predict_field(gx/s, gy/s, tq/√s)`.
  반환 고도가 이미 원 단위다. ⟹ 역변환이 **암묵적**.
- ★**P-explicit** (배포 가능 경로): `initialize()` 뒤 모델에서 `kx',ky',w,phi` 를 **되읽어**
  `kx = kx'/s, ky = ky'/s` 로 매핑하고, `model/tnse.py:221 render_wave_field(kx, ky, A, phi, depth, gx, gy, t_abs)`
  로 **원 격자·원 시각**에 렌더. ⟹ **원 단위 원자**가 실제로 나온다 = 배포 시스템이 쓸 형태.
- 허용 오차(결과 전 고정): `max|P_implicit − P_explicit| <= 1e-4 · σ4`.
  ⛔비트 동일을 요구하지 않는다 — 두 렌더 경로가 다르고 `ω` 를 서로 다른 `k` 에서 `tanh` 로 다시 만든다.

⚠**전제 두 개, 게이트로 강제**:
- `G-PURE`: `model.use_stokes2 is False` ∧ `model.use_neural_corrector is False`
  (`model/spectral_gaussian.py:45-52` 기본 False · `:130,136` 분기 — 켜져 있으면 모델이 원자 합이 아니라 **명시 역변환이 무효**).
- `G-DEEP`: 엄밀히는 `d' = d/s` 여야 `ω=√(g k tanh(kd))` 가 정확히 보존된다. 이 배치는 `T11`
  앵커를 지키려고 **`depth = 400` 을 두 팔 다 고정**한다. ⟹ 게이트가 `k̂_p · d >= π`(⟹ `tanh >= 0.9963`)
  를 **모든 행에서** 확인하고 행에 `kd_min` 을 적어, 생략이 수치적으로 무해함을 **판정 자료 위에서** 보인다.
  ⚠`T11` 개정문 3 의 교훈 그대로: **값이 들어가는 양이 아니라 판정에서 재라** — 그래서 `G-INVERT`
  가 **필드 차이**로 잰다(분산관계 상대오차로 재지 않는다).

   규칙은 *"장면을 우리 사전이 학습된 곳으로 옮긴다"* 이고, ⛔*"제3자 자료가 규칙을 정했다"* 는 거짓이다.
9. ⚠`k̂_p` 는 FFT 첨두 대비 **+7–13% 높다**(자격검사 2파일). ⛔보정하지 않는다.
10. ⚠`proposal_device` 는 `config` 가 정하지 않는다(`propose_atoms` 가 `cuda if available`).
11. ⚠`torch.set_num_threads(1)` 은 numpy/BLAS 를 제약하지 않는다 ⟹ ⛔`wall_s` 팔간 비교 금지.
12. ⚠`G-WRAPPER` 는 배포 상수상 **구조적으로 참**이다(⛔`gates_pass` 를 오독하지 마라).

## §10 ★실측 경로(`bank_mmse` 라우팅)와의 관계 — ⛔`W-12`·`D3` 재발 방지

- **이 배치는 라우팅을 건드리지 않는다.** `real_domain_gate=False` 를 **쓰지 않고**,
  `init_method` 기본값을 바꾸지 않으며, `real_estimator` 도 건드리지 않는다.
  ⛔`D3` 의 BLOCKER(*"「인가된 켜는 길」이 실측 게이트를 껐다"*)가 정확히 그 부류였다.
- **재라벨은 `initialize()` 상류의 좌표 변환**이다 — `FrameData` 의 `x_obs,y_obs,t` 를 바꿀 뿐이고
  `_frames_have_gt`(`sequential_update.py:411`)가 보는 `gt_field` 와 **무관**하다.
  ⟹ 라우터에게 **보이지 않는다** ⟹ 게이트 거동 불변.
- 입력에 **상수 `gt_field`** 를 붙이므로(`T11 NOTE §1-2` 의 누출 불가 설계) 라우터는 `learned` 로 간다.
  `G-ARM` 이 `resolved_init_method=='learned'` ∧ `real_domain_gate_fired is False` 를 **되읽어** 증명한다.
  ⟹ ⚠***`T14` 가 재는 것은 배포 「합성 경로」다. 실측 경로에 대해 아무 말도 하지 않는다.***
- ★**진짜 실측 입력(`gt_field=None`)에서는** 게이트가 `bank_mmse` 로 보내고, `bank_mmse` 는
  **자기 `k̂_p` 에 상대적인 뱅크를 이미 만든다**(`bank_mmse.py:158-168` 두 단계 줌,
  `:183-186` `ax = arange(−b_hi·kp, …, dk_c = kp/10)`) ⟹ **자동 정규화는 거기서 거의 no-op 일 것**이다.
  ⛔**이 배치에서 재지 않는다**(사용자 결정 2026-08-30: *연구는 학습 위주, bank 는 눈금*).
  ⛔그리고 이 예상을 **결과로 인용하지 마라** — 측정하지 않았다.
- ★**팔 정체는 「의도」가 아니라 「되읽기」로 적는다**: 모든 행이 `upd.arm_provenance()` 전체를
  담는다(`requested_init_method` ≠ `resolved_init_method` 일 수 있다는 것이 요점).
