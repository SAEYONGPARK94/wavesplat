## §2 채택된 두 규칙 (**경쟁 후보** — 어느 쪽이 맞는지는 측정이 답한다)

### 규칙 `BAND` — *"첨두 파수를 사전의 학습 밴드로"*
```
k̂_p  = 2단 빔포머 줌 (bank_mmse.py:158-165 와 축자 동일한 절차)
         1단: _beamform_top(P, z, depth, klim=2.0,      n=120)
         2단: _beamform_top(P, z, depth, klim=3.5·k̂₁,  n=120)
s_band = clip( K_TRAIN / k̂_p ,  S_MIN, S_MAX )
```
`K_TRAIN` = 사전이 학습된 **첨두 파수의 기하평균**.
동결값 = **0.06779 rad/m** (λ 92.7 m). ⛔손복사 금지 — 분석기가 `d3_setdiff_prior.py:39,42`
의 밴드(`Tp ~ U(5.0, 11.0)`, `depth=50.0`)를 그대로 써서 `wavesim.wave_generator.jonswap_components`
로 **재생성해 대조**한다(`G-KTRAIN`). 재생성 표본 2,000: mean 0.07502 · **geomean 0.06779** ·
median 0.06286 · p05 0.03734 · p95 0.14771.
⚠**기하평균을 고른 이유**(결과 전 고정): `s` 는 **곱셈량**이라 log 축에서 중심을 잡는다.
⛔산술평균(0.07502)을 쓰면 `s` 가 약 11% 커진다 — 이 선택은 **하중을 진다**(§4).

### 규칙 `AP` — *"관측 개구를 학습 개구로"* (= 조건화 지도의 개구/픽셀 비 정합)
```
L_obs  = max( ptp(x_obs), ptp(y_obs) )
s_ap   = clip( L_obs / L_TRAIN , S_MIN, S_MAX )
```
`L_TRAIN` = 학습 풀의 최대 변 = **220.55 m**(`pool_xy()` 실측, n=49,969, Lx 220.55 · Ly 197.16).
⛔손복사 금지 — 분석기가 `pool_xy()` 를 다시 불러 대조한다(`G-LTRAIN`).

**왜 이것이 「개구/픽셀 비」인가**: 조건화 지도의 칸은 `2·KLIM/(NK−1) = 2(0.6)/63 = 0.019048`
(`d3_beamform_net.py:31`). 빔포머 PSF 폭 ≈ `2π/L` ⟹ **PSF 칸수 = (2π/L)/0.019048**.
`x' = x/s` ⟹ `L' = L/s` ⟹ `L' = L_TRAIN` 로 맞추면 PSF 칸수가 학습 코퍼스와 같아진다.

| | `L` [m] | PSF [칸] |
|---|---|---|
| 학습 풀 (`pool_xy`) | 220.55 (x) / 197.16 (y) | **1.496 / 1.673** |
| 제3자 코퍼스 (`SHIP`, s=1) | 619.64 | **0.532** ← 언더샘플 |
| 제3자 코퍼스, s=2 (`T11 RESCALE`) | 309.82 | 1.064 |
| 제3자 코퍼스, s=2.81 (`AP`) | 220.55 | **1.496** (정의상 일치) |

✅이 세 값은 `T11` `AMENDMENT_2 §6(a)` 가 적은 **0.53 / 1.06 / 1.37–1.65** 와 정합한다
(내 재계산 1.496–1.673, 감사 표기 1.37–1.65 — 학습 풀 변의 정의 차이로 보인다. ⚠이 배치는
**내가 재계산한 값과 그 정의**를 정본으로 쓴다).

### 공통 안전 레일
`S_MIN = 0.25`, `S_MAX = 4.0` (log₂ 로 ±2). **판정이 아니라 레일**이다 —
어느 행이든 레일에 닿으면 `G-SCLIP` 이 **기록**하고 공시한다(⛔막지 않는다: 레일 발화는
「규칙이 자유롭지 않았다」는 공시 사항이지 측정 타당성의 게이트가 아니다 — `T11`
`AMENDMENT_2 §9.1` 의 `G-CLAMP` 선례).
