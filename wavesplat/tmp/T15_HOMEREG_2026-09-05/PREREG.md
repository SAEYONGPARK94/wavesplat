## §0 PRIMARY 질문 (한 문장)

***제안 서브시스템의 절대 파수 스케일을 배포값에서 옮기면, 우리 자국 코퍼스에서 무엇을 지불하는가.***

⛔이것은 *"우리 방법이 좋다/나쁘다"* 가 아니다. **배포 결정에 필요한 비용**이다.
`T12` 가 제3자 자료에서 *"그 스케일을 절반으로 내리면 24/24"* 를 냈다. 남의 자료에 맞춘 이동이
**우리 자료를 해치면 배포 불가**다. ⟹ **무해성 시험**이되, 심사 지적대로 *"해치는가"* 하나가
아니라 ***"얼마나 옮기면 얼마를 잃는가"*** 의 **곡선**을 잰다.

## §2 팔 (⛔`{}` 빈 dict 금지 · 처치는 `T12` 에서 **임포트**한다)

**처치 정의의 단일출처**: `wavesplat/tmp/T12_ISOLATE_2026-09-04/consts_t12.py:57`
`TREAT['A-MAPSCALE'] = {'KLIM': 0.3, 'K_LIM': 0.55}` = 배포값(`KLIM 0.6`·`K_LIM 1.1`)의 **1/2**.
⛔러너는 그 리터럴을 **다시 적지 않는다** — 임포트하고 `assert` 로 핀한다(`G-TREATPIN`).
스케일 인자 `f` 를 일반화하면 `KLIM = 0.6/f`, `K_LIM = 1.1/f`. `f=2` 가 곧 `A-MAPSCALE` 이다.

| 팔 | `f` | 층 | 역할 |
|---|---|---|---|
| `ZERO` | — | 전층 | 무기술 기준 — **산술**(`RMS(gt)/Hs_true`, 런 0회) |
| `SHIP` | **1.0** | **128** | 배포 기본값 · **앵커** |
| `F2` | **2.0** | **128** | ★`T12` 의 `A-MAPSCALE` **그 자체** |
| ★`FLOOR-VPLR` | — | **128** | ★**처치정합 잡음 바닥** — `T12` 의 `D-VPLR`(VARPRO lr 2e-3→1e-3). `T12` 에서 **8/24 널**이면서 노브 되읽기가 **개입 발화를 증명**한 축이다 ⟹ *"같은 부류의 개입이 걸렸는데 아무 일도 없을 때의 크기"* |
| `F1.414` · `F2.828` · `F4` | √2 · 2√2 · 4 | **64** | ★**비용 곡선** |
| `A-MAPCELL` · `A-BAND` | 2(반쪽씩) | **64** | `f=2` 의 **분해**(맵 칸만 / 사전 밴드만) — `T12` 에서 19/24 vs 15/24 로 갈렸다 |

### 2.1 ⛔`f` 는 **자료가 아니라 노브**를 옮긴다
`T11`·`T14` 의 `RESCALE`/`AUTO-*` 는 **좌표를 재라벨**했다. 이 배치는 **자료를 건드리지 않고**
제안 서브시스템의 상수만 옮긴다 ⟹ ⛔**`T11`·`T14` 의 `s` 와 같은 기호로 쓰지 마라.**
정본 표기 = **`f`(노브 스케일 인자)**.

### 2.2 ★잡음 바닥의 정당성 (v1 이 여기서 기각됐다)
`FLOOR-VPLR` 은 **같은 종류의 개입**(모듈 상수 몽키패치, 제안·정련 경로)이고,
`T12` 가 그것이 **발화하지만 효과가 없음**을 측정했다(`vp_lr` 노브 차이 되읽기 + 8/24).
⟹ ***"개입이 걸렸는데 아무 일도 없을 때의 크기"*** = 이 파이프라인의 **개입 잡음 바닥**.
⛔추정기 시드 변동(분산)을 바닥으로 쓰지 않는다 — 처치는 **편향**이라 범주가 다르다.

### 2.3 ⛔`ORACLE` 을 넣지 않는 사유
심사가 *"미검출이 정보 없음인지 바닥 효과인지 구분 불가"* 라며 요구했다. 그러나 **자국 코퍼스에서는
`SHIP` 이 작동한다** — 그것이 이 코퍼스의 정의다(`W16` 동결: 혼잡 **0.1275** · 희소 **0.0202**
vs `ZERO` ≈ 0.25). ⟹ *"정보가 있는가"* 는 **양성대조 `SHIP < ZERO`** 가 층별로 답한다.
⛔`ORACLE` 은 비용만 늘리고 새 정보를 주지 않는다. **이 판단을 결과 전에 적는다.**

## §5 판정 (결과 전 고정) — **층별 · 이김 다리만 검정 · 음성은 이름이 「미검출」**

```
층 = crowded(64) · sparse(64)         짝 부호검정, 단측
PRIMARY 가족 = 2층 × 해침 다리 (통계량 W[F2 < SHIP], n=64 짝, **낮을수록 나쁘다**),
               Holm 첫 단계 α/2 = 0.025
   해침  W[F2 < SHIP] <= 23   (n=64, p = 0.016380)
   이김  W[F2 < SHIP] >= 41   (n=64, p = 0.016380)   ← 같은 문턱의 반대편(기술통계)
양성대조(층별)  W[SHIP < ZERO] >= 41           ⟹ 실패한 층은 처치 판정에서 **제외**하고 인쇄
전역 128        ⛔**기술통계로만** (상시지시: 전역 nRMSE 헤드라인 금지)
셀 8개(n=16)    ⛔**기술통계로만** — MDE q<=0.0975 로 사실상 검정력 없음(결과 전 계산)
```

**등가(크기) 판정 — 처치정합 바닥 대비**
```
floor_L  = median|relΔ|( FLOOR-VPLR vs SHIP )   층 L 에서
effect_L = median  relΔ( F2         vs SHIP )   층 L 에서
|effect_L| <= floor_L  ⟹ 그 층에 접미 (WITHIN-INTERVENTION-FLOOR)
```
⛔바닥을 **사후에 고르지 않는다** — `FLOOR-VPLR` 은 배치 안에서 측정된다.

### 5.1 라벨 (5개가 전 조합을 덮는다 · `UNDECIDED` 없음)
```python
hurt_L = (W_L <= 23) ; help_L = (W_L >= 41)   for L in (crowded, sparse)
ctrl_L = (W[SHIP<ZERO]_L >= 41)

not (ctrl_crowded or ctrl_sparse)  -> 'ANCHOR-DID-NOT-REPLICATE'   ⛔다른 라벨 인쇄 금지
any hurt_L (검정 가능한 층에서)     -> 'HOME-REGRESSION'            ⟹ ★배포 불가
all help_L                          -> 'HOME-ALSO-IMPROVES'
else and all |effect_L| <= floor_L  -> 'NO-HARM-WITHIN-INTERVENTION-FLOOR'
else                                -> 'CHANGE-UNDETECTED'          ⛔"무해하다" 아님
```
⛔`CHANGE-UNDETECTED`·`NO-HARM-*` 를 *"안전하다"* 로 읽는 것을 **금지**한다 — **검정력의 진술**이다.

### 5.2 라벨 다섯과 **각각의** 등록 예측 확률 (⛔코드 출력 · 손계산 아님)
⚠양성대조도 **모형 안에** 있다(`PRED_Q_CTRL = 0.95`, 근거 `W16` 동결 중앙 nRMSE 혼잡 0.1275 ·
희소 0.0202 대 `ZERO` ≈ 0.25) — ⛔*"통과한다고 가정"* 은 `ANCHOR-DID-NOT-REPLICATE` 를
**확률 없는 라벨**로 남기고 그것이 `A3 §5` 가 이름 붙인 **음성 라벨 뭉개기** 부류다.
⚠`NO-HARM-WITHIN-INTERVENTION-FLOOR` 와 `CHANGE-UNDETECTED` 의 **분할은 `q` 가 모형하지 않는다**
(크기 비교다) ⟹ 둘 다 같은 버킷의 **상한**으로 적는다. 그 사실을 결과 전에 적는다.

| `q(F2<SHIP)` | `ANCHOR-DID-NOT-REPLICATE` | `HOME-REGRESSION` | `HOME-ALSO-IMPROVES` | `NO-HARM-WITHIN-INTERVENTION-FLOOR` / `CHANGE-UNDETECTED` (버킷 **상한**, 둘의 분할은 미모형) |
|---|---|---|---|---|
| 0.20 | 4.45e-30 | 1.0000 | 5.783e-28 | 0.0000 |
| 0.25 | 4.45e-30 | 0.9997 | 2.451e-21 | 0.0003 |
| 0.30 ★등록 | 4.45e-30 | 0.9852 | 3.62e-16 | 0.0148 |
| 0.35 | 4.45e-30 | 0.8540 | 4.314e-12 | 0.1460 |
| 0.40 | 4.45e-30 | 0.5077 | 7.497e-09 | 0.4923 |
| 0.50 ⛔귀무 | 4.45e-30 | 0.0325 | 0.0002684 | 0.9672 |

★버킷을 **라벨 이름으로** 다시 적는다(⛔표의 한 칸에 둘을 묶어두면 그것이 「뭉개기」다):
- `NO-HARM-WITHIN-INTERVENTION-FLOOR` — 등록 예측 상한 0.0148 · 귀무 상한 0.9672
- `CHANGE-UNDETECTED` — 등록 예측 상한 0.0148 · 귀무 상한 0.9672
  ⚠둘의 **합**이 그 값이고 분할은 등가 판정(크기 비교)이 가른다. ⛔각각을 그 값으로 인용하지 마라.

⟹ ★등록 예측 = **`HOME-REGRESSION` 0.9852**, 귀무 아래 오경보 **0.0325**.

## §6 사전등록 예측과 MDE (⛔믿음 선언 아님 — 계산)

**근거**(`PLUMBING.md`, 생성기 재계산): 자국 참 파수는 제3자보다 **4–6배 높다**
(자국 중앙 `|k|` 0.2515 · `_ra_rf_ds` 0.197 vs 제3자 `k_p` 0.0415).
그리고 배포 사전의 학습 앵커가 **자국 BF2–BF5 의 (Hs,Tp) 그 자체**이며
`gen_mixed.py:58` 이 `K_LIM_HARD = 1.1` 을 못박는다 ⟹ `K_LIM 1.1→0.55` 는
**학습 인코딩과 어긋난 디코딩**이다. ⟹ ★**예측: `HOME-REGRESSION`**.

```
등록 예측  q(F2 < SHIP) = 0.30   (혼잡·희소 공통, ⛔층별로 다르게 걸지 않는다)
⚠**초안의 손계산이 틀렸다** — `P(W<=23|64,0.30)` 을 0.8113 이라 적었으나 실제는 **0.8785**.
  ⛔동결 전에 **계산해서** 고쳤다(⟹ 이 표는 전부 코드가 낸다: `gates_t15.label_probs`).
   P(W <= 23 | 64, 0.30) = **0.8785**    ⟹ 층 하나가 해침을 낼 확률
   P(적어도 한 층)       = **0.9852**    ⟹ 예측 라벨 `HOME-REGRESSION` 확률
```

## §7 ⛔범위·금지 (분석기가 `disclosures` 에 **기계로** 넣는다)

1. ⛔**`f` 를 `T11`·`T14` 의 `s` 와 같은 기호로 쓰지 마라** — 저건 자료 재라벨, 이건 노브 이동이다.
2. ⛔**어떤 팔도 배포 구성이 아니다.** 이겨도 **배포 권고가 아니다** — 배포는 별도 사전등록.
3. ⚠★**자국 코퍼스는 배포 체크포인트의 학습 봉투다** — `gen_mixed.py:78` 의 학습 장면 앵커가
   `pipeline.py:35 SEA_STATE` 와 **완전 동일**하고 `nc ∈ {1,2,5,15,30}` 도 같다.
   ⟹ ⛔***"out-of-sample"·"held-out"·"blind" 자구 금지.*** 그리고 결과는
   *"자국은 사전의 학습 분포다"* 와 **분리되지 않는다**.
   ⚠공여자 14파일(`gen_mixed.py DONOR_FILES`)의 **관측 기하가 학습에 들어갔다**(파랑장은 아니다).
4. ⛔**전역 128 수치를 헤드라인으로 쓰지 마라**(상시지시). 층별로만.
5. ⛔음성 라벨을 *"안전하다/무해하다"* 로 → **MDE q80=0.3185 병기 의무**.
6. ⛔`T12` 의 회수율 `ρ` 나 `T14` 의 `R` 과 **병치 금지**(정의가 다르다).
7. ⚠**스윕은 64 부분층**에서만 잰다 — 전 128 이 아니다. 곡선을 128 에 외삽하지 마라.
8. ⛔`wall_s` 팔 간 비교 금지 · `proposal_device` 는 config 가 정하지 않는다(되읽기를 볼 것).
9. ⚠`FLOOR-VPLR` 은 **`T12` 에서 측정된 널**이다 — 이 코퍼스에서 다시 널이라는 보장은 없다.
   널이 아니면 `verdict['floor_moved']=True` 로 공시하고 **등가 판정을 인쇄하지 않는다**.
