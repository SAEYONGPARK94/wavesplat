## §0 왜 이 배치인가 · PRIMARY 한 문장

`T14-AUTOSCALE` 은 **`BLOCKED`** 로 끝났다(`blocked_by = ['G-EQUIVAR']`, 게이트 31/32).
차단의 정체는 성능이 아니라 **규칙의 well-posedness** 였다:

| 사실 (`T14 AMENDMENT_2 §1`, 동결 자료) | 값 |
|---|---|
| `AUTO-AP` 등변 편차 `\|c=0.5\|` · `\|c=2.0\|` | **0.000e+00 · 0.000e+00** (정확히 등변) |
| `AUTO-BAND` 등변 편차 `\|c=2.0\|` | 중앙 0.0217 · 최대 **0.0721** · 초과 **1/34** (허용 0.0588) |
| `AUTO-BAND` 등변 편차 `\|c=0.5\|` | **~0.99** (규칙이 무너진다) |
| 1단 격자 여유 `k_p/Δk₁` (`Δk₁ = 2·2.0/119 = 0.033613`) | 중앙 **1.16** · 최소 **0.88** |

**기제(코드 유래)**: 2단 줌의 **1단이 절대 격자**다 — `wavesplat/optimizer/bank_mmse.py:159-160` 이
`_beamform_top(..., klim=2.0, n=120)` 으로 돈다. 장면의 `k_p` 가 그 격자 간격보다 작으면 1단이 첨두를
못 잡고, 2단의 `klim = 3.5·k̂₁`(`:162-163`)이 통째로 틀어진다.

⛔`T14` 의 규칙은 **동결**됐다(`scale_rules_t14.py`). 고친 규칙은 **다른 규칙**이므로 새 사전등록이
필요하다 — 그것이 이 배치다.

### ★고친 것 (한 줄, `REACHABILITY.md §3` 이 정본)
> **1단 `klim` 을 관측 개구에서 유도한다: `klim₁ = (n−1)/2 · 2π/L_obs` ⟹ `Δk₁ = 2π/L_obs`.**
> 자유 파라미터 **0개** — `n = 120` 은 `bank_mmse.py:160`, `2π/L_obs` 는 개구의 Rayleigh 한계다.
> 2단(`klim = 3.5·k̂₁`)은 **손대지 않는다**(이미 상대적이다). ⟹ **단일요인 개입 1건.**

### ★PRIMARY 질문 (한 문장)
> ***1단 격자를 관측 개구에 상대적으로 고쳐 등변으로 만든 밴드 규칙(`AUTO-BANDR`)이, 참값을 전혀
> 보지 않고 고른 `s` 로, 제3자 참값 위에서 배포 학습 경로가 제로필드를 이기게 하는가 — 그리고
> 그 수리가 옛 규칙(`AUTO-BAND`)의 착지점을 실제로 바꾸는가?***

**PRIMARY 통계량 · 방향 · 집계 · n (이름으로 못박는다)**
- 통계량 = **파일 단위 짝 부호검정**. 집계 함수 = **「팔 A 의 `nRMSE` 가 팔 B 보다 작은 파일의 수」**
  (⛔짝별 차의 중앙값이 아니다 · ⛔중앙값의 차도 아니다 — 그 둘은 기술통계로만 보고한다).
- 방향 = `nRMSE` **작을수록 좋다**.
- `n` = **60** (Tier-P 전수).
- ★**축 두 개**: `S`(제로필드 대비 이김, 단측) · `D`(옛 규칙 대비 짝 = **착지 축**, 양측). §3 이 정본.
  ⛔**옛 판(하나의 `BANDFIX-*` 라벨)은 폐기**됐다 — `S` 는 처치를 판별하지 못하고 `D` 의 처치는
  이 코퍼스에서 배제 문턱보다 작다(아래 4·5 · §3 · §14 개정 R-2/R-3).

### ⚠이 배치가 **재지 못하는 것** (결과 전에 못박는다)
1. ⛔**규칙의 적응성(장면마다 다른 `s`)을 재지 못한다.** 이 코퍼스는 격자가 전 파일 동일
   (`[502,128,128]`, `dx = dy = 4.879 m`, `L_obs ≈ 619.63 m` — `T1`·`T10` 동결 행에서 확인)
   ⟹ `s_ap` 도 `klim₁` 도 **코퍼스 상수**다(`s_ap = 2.8095`, `klim₁ ≈ 0.6033`).
   ⟹ ★**적응성이 아니라 (i) 착지점과 (ii) 등변성(런 0회 게이트)을 잰다. 둘은 다른 진술이다.**
2. ⛔**"우리가 저들보다 낫다" 를 재지 못한다** — 외부 기준선 행이 **0개**다. 라벨은 **귀속**이다.
3. ⛔**`AUTO-BAND`(옛 규칙)의 착지점을 「규칙의 성능」으로 읽지 못한다** — 그 규칙은 **ill-posed** 다
   (`T14` 가 그것으로 차단됐다). `D` 축은 *"수리가 착지점을 바꾸는가"* 이지 *"옛 규칙이 나쁘다"* 가 아니다.
4. ★⛔**1단 격자를 「개구에서 유도한 것」과 「적당한 상수로 박은 것」을 구별하지 못한다.**
   축퇴는 §9.3-2 가 처음 적은 *"0.56% 차"* 보다 **훨씬 넓다** — 이 코퍼스에서 `klim₁` 을
   **0.6033 → 2.0 으로 3.3배** 움직여도 최종 `k̂_p` 는 **약 1%** 밖에 안 변한다(2단 줌이 흡수한다;
   측정 = `REACHABILITY §4.4` 의 옛/새 대조). ⟹ 자료는 상수 `KLIM = 0.6` 뿐 아니라
   **`[k_p, 2.0]` 구간의 어떤 상수와도** 이 규칙을 구별하지 못한다.
   ★구별은 **`G-KLIM1-LIVE`(코드 행동 검사)** 가 하고 ⛔**자료는 하지 않는다.**
   (⚠`REACHABILITY.md:13`·`:104` 의 *"자유 파라미터 0개"* 는 **설계 미덕**이지 측정 결과가 아니다.)
5. ★⛔**`D` 축의 처치는 이 코퍼스에서 이 배치 자신의 자보다 작다.**
   동결 프로브(`REACHABILITY §4.4`, 코드 출력): `median |Δ ln s| = 0.912%` · 최대 **2.511%** ·
   `|Δ ln s| < ln(1.05)` 인 셀 **4/4** · 부호 **+3 / −1**.
   ⟹ `D` 축의 널은 *"차이가 없다"* 가 **아니라** `D-TREATMENT-BELOW-SCALE` 이라는 **구조적 사실**이다(§3.3).
   ⟹ `D` 축의 **양성**도 *"1단 격자 수리 덕분"* 으로 귀속되지 않는다(§9.3-3 · 부호가 섞인다).

## §1 팔 (⛔`{}` 로 팔을 정의하지 않는다 — `T11` 개정문 2 · `gates_b7.py:46` 선례)

모든 팔이 **같은 물리 관측점**을 본다(관측 추첨은 팔 분기 **전에** 파일 시드로 한 번).
팔 사이의 차이는 **좌표 재라벨 `s` 하나뿐**이고, `z`(고도)는 **절대 건드리지 않는다**.

```python

BASE.update(depth=DEPTH, seed=SEED16+fi, device='cpu', init_method='auto')
# ⛔BASE 를 팔 사이에 재사용하지 않는다 — 파일·팔마다 새로 만든다(T11 v1 BLOCKER-2: learned_atoms 캐시 누출)
upd = make_updater(cfg)                     # ★출하 진입점. ⛔맨 SequentialUpdater 금지
```

| 팔 | `s` | 역할 | 지위 |
|---|---|---|---|
| `ZERO` | — | 창별 제로필드 = **무기술 기준** | 자 (런 0) |
| `SHIP` | **1.0**(항등) | ★**하한 앵커** = 출하 기본값 | 앵커 |
| `FIX2` | **2.0** 고정 | ★**상한 앵커** = `T11 RESCALE` | ★**양성대조 `F`** |
| `AUTO-AP` | `SR14.s_ap(obs)` ★**임포트** | 개구/픽셀 비를 학습 범위로 (**정확히 등변**) | SEC |
| `AUTO-BAND` | `SR14.s_band(obs)` ★**임포트** | ⚠**옛 규칙 = 비교자**(1단 절대 격자, ill-posed) | `D` 의 비교자 |
| ★`AUTO-BANDR` | `SR16.s_bandr(obs)` | ★**처치** — 1단 격자를 개구에서 유도 | **PRIMARY** |

★**`AUTO-AP`·`AUTO-BAND` 는 손복사하지 않는다** — `scale_rules_t16.py` 가 `scale_rules_t14` 를
**임포트**하고 `G-RULEID` 가 `SR16.s_ap is SR14.s_ap` · `SR16.s_band is SR14.s_band` 를 **객체 동일성**으로
단언한다(체크리스트 B8 단일출처).

**재라벨 정의**(`T11`·`T14` 규약 축자 계승, 분산관계 보존):
```
x' = x/s ,  y' = y/s ,  t' = t/√s ,  z' = z        ⟹  k' = s·k ,  ω' = √s·ω ,  ω' = √(g k') 보존
```

**규칙 정의 (⛔결과 전 동결)** — 정본은 `REACHABILITY.md §3`:
```

s_band_raw = K_TRAIN / kp_hat_ABS(obs)               K_TRAIN = 0.06779     (SR14, 재생성 대조 G-KTRAIN)
★s_bandr_raw= K_TRAIN / kp_hat_REL(obs)              ← 이 배치가 새로 등록하는 유일한 규칙

                k̂₁ = |argmax beamform(klim₁, N1)| ,  k̂₂ = |argmax beamform(3.5·k̂₁, N1)|
   L_obs = max(ptp(x), ptp(y))                       (SR14 의 s_ap 와 **같은 양**)
안전 레일:  s = clip(s_raw, S_MIN=0.25, S_MAX=4.0)   (SR14 에서 임포트)
```

- ★**등변성은 `*_raw`(비클리핑)로 잰다** — 레일이 등변성을 깬다(`T14 AMENDMENT_1 §2`, 교훈 9).
- ⛔`(x or 기본값)` 을 쓰지 않는다 — `0.0` 은 falsy 다(`T14 AMENDMENT_1 §1`, 교훈 8). `is None` 으로 가른다.
- ⛔**결과를 본 뒤 `K_TRAIN`·`L_TRAIN`·`N1`·`3.5`·레일을 바꾸는 것은 금지.** 새 규칙은 새 사전등록으로만.

★**결과 전 예상값**(`REACHABILITY.md §4` 합성 프로브, ⛔프리즌 표본 미접촉):
`klim₁ ≈ 0.6033`(합성 프로브 실측 0.603340; 파일의 `x` 배열에 따라 0.6033 근방) · `Δk₁ ≈ 0.010140` · `k̂_p ≈ 0.034–0.055` ⟹ `s_bandr ≈ 1.2–2.0` ·

## §3 판정 사다리 — ★**2축**(결과 전 고정 · 이김 다리만 검정 · 널은 이름이 「미검출」 또는 「구조」)

> ⛔**2026-09-05 개정 R-2(결과 0행).** 옛 사다리는 `F × S × D` 를 **하나의 `BANDFIX-*` 라벨**로 접었다.
> 두 심사가 같은 자리를 각각 찔렀다:
> (i) **`S` 는 처치와 무관하게 발화하는데 이름이 *"밴드 수리가 이긴다"* 로 읽힌다**(A `B-2`) ·
> (ii) **`D` 의 처치 크기가 이 코퍼스에서 배제 문턱 `ln(1.05)` 안이라 어떤 결과가 나와도 귀속이 안 된다**(A `B-1`).
> ⟹ ★**축을 둘로 갈랐고 `BANDFIX-` 접두어를 전부 없앴다.** ⛔**문턱은 완화하지 않았다**(§3.6).

### §3.1 두 축과 문턱 (⛔결과 전 고정)

```
Tier-P, n = 60. 전부 **파일 단위 짝 부호검정**. 방향 `<` (nRMSE 가 작을수록 좋다).

양성대조 F (가족 밖 · 무보정 · 단측) — ⛔거짓이면 다른 라벨을 인쇄하지 않는다
    F      = W[ FIX2 < ZERO ] >= 37                      P(W>=37|60,.5) = 0.046230

PRIMARY 가족 = **2 축** · n = 60 · Bonferroni α/2 = 0.025
  ★축 S (기술 축, 단측) : W[ AUTO-BANDR < ZERO ]      >= 39   P(W>=39|60,.5) = 0.013670
  ★축 D (착지 축, 양측) : W[ AUTO-BANDR < AUTO-BAND ] >= k⁺(n_eff)  또는  <= n_eff − k⁺(n_eff)
                          k⁺(n) = min{k : P(W>=k|n,.5) <= 0.0125}   ⟹ k⁺(60) = 40
                          (한 꼬리 0.006745 · 양측 0.013489 <= 0.025)

동반 통계 — ⛔확증 등급이 아니다(무보정) · ★그러나 **사다리 안에 있다**
  SEC-E   = W[ AUTO-BAND < ZERO ] >= 37                 P(W>=37|60,.5) = 0.046230
            ⟹ **S 축의 라벨을 가른다**(§3.2)
  D_drive = { median_i |Δ ln s_i| , sign(Δ ln s_i) 분포 }
            Δ ln s_i = ln s_bandr_raw,i − ln s_band_raw,i     (⛔**클리핑 전** 값으로 잰다)
            ⟹ **D 축의 널을 가른다**(§3.3)
```

⚠**동점 처리(결과 전 고정)** — ★심사 A `B-1` 의 처방으로 정의를 **넓혔다**(개정 R-4):
`n_tied` = `|nRMSE_BANDR − nRMSE_BAND| / max(nRMSE_BAND, 1e-12) < 1e-6` 인 파일 수.
⛔**옛 정의(비트 동일)는 1e-12 차이를 「신호」로 셌다.** 동점은 제외하고 `n_eff = 60 − n_tied` 로 검정하며,
문턱은 `gates_t16.k_two_sided(n_eff)` 가 **계산한다**(⛔리터럴 금지). `n_tied` 는 `verdict` 에 반드시 인쇄한다.

### §3.2 축 S 라벨 — ⛔`SEC-E` 없이 인쇄 금지

| 조건 | 라벨 | 읽는 법 |
|---|---|---|
| `S` 참 ∧ `SEC-E` 참 | ★**`AUTOSCALE-BEATS-ZERO-BOTH-RULES`** | *"GT-free 자동 스케일이 제3자 blind 코퍼스에서 제로필드를 이긴다 — **옛 규칙도 이긴다**."* ⛔밴드 수리의 공로가 아니다 |
| `S` 참 ∧ `SEC-E` 거짓 | ★**`AUTOSCALE-BEATS-ZERO-BANDR-ONLY`** | *"새 규칙만 이긴다."* ⚠`SEC-E` 는 **무보정**이므로 이 라벨은 **EXPLORATORY** 다 |
| `S` 거짓 | ★**`NO-AUTOSCALE-SKILL-DETECTED`** | 이름이 「미검출」이다. MDE `q80 = 0.6915` 병기 의무 |

★**이 갈래가 존재하는 이유**(A `B-2`): `S` = `AUTO-BANDR < ZERO` 는 **처치를 판별하지 못한다**.
옛 규칙의 `s_band` 는 새 규칙과 **1% 차**(§0-5)라 `SEC-E` 도 거의 확실히 발화하고, 손으로 고른
`FIX2`(`s = 2.0`)도 발화한다. ⟹ ***`S` 가 말하는 것은 「`s ∈ [1.2, 2.2]` 면 제로필드를 이긴다」이지
「밴드 수리가 이긴다」가 아니다.*** 라벨 이름이 그 사실을 담아야 한다.

### §3.3 축 D 라벨 — ★**널을 구조적 사실로 이름 붙인다**

```
사전등록 발화 순서 (⛔결과를 보고 순서·문턱을 바꾸지 않는다)
  0.  n_eff <= 6                 → D-UNPOWERED                     ★k⁺(n) 이 존재하지 않는 유일한 대역
  1.  W >= k⁺(n_eff)             → D-STAGE1-GRID-CHANGES-LANDING
  2.  W <= n_eff − k⁺(n_eff)     → D-STAGE1-GRID-WORSENS-LANDING
  3.  널 ∧ T1                    → D-TREATMENT-BELOW-SCALE
  4.  널 ∧ ¬T1 ∧ T2              → D-DIRECTION-MIXED
  5.  널 ∧ ¬T1 ∧ ¬T2             → D-NO-DIFFERENCE-DETECTED

사전등록 수치 발화 조건 (⛔결과 전 고정 · `gates_t16` 상수)
  T1  «처치가 자보다 작다» :  median_i |Δ ln s_i|  <  ln(1.05) = 0.048790
        (`ln(1.05)` 는 §4.2 회수율의 **배제 문턱**과 **같은 수**다 — `T14 §4.4` 에서 계승했다.
         ⟹ 이 배치가 스스로 *"채점 불가"* 라 등록한 크기 안에 처치가 들어간다는 뜻이다.)
  T2  «방향이 섞였다»       :  max( #{Δ ln s_i > 0}, #{Δ ln s_i < 0} )  <  55 / 60
        (55/60 = 91.7%. 그 아래면 짝 부호검정 W[BANDR<BAND] 는
         *"s 가 오른 셀"* 과 *"s 가 내린 셀"* 의 **혼합을 세는 통계량**이 된다.)
```

| 라벨 | 지위 | 읽는 법 |
|---|---|---|
| ★**`D-STAGE1-GRID-CHANGES-LANDING`** | 확증(Bonferroni) | *"1단 격자 선택이 착지점을 유의하게 바꾼다(좋은 쪽)."* ⛔`D_drive` 병기 없이 인용 금지 |
| ★**`D-STAGE1-GRID-WORSENS-LANDING`** | 확증(Bonferroni) | *"바꾼다 — 나쁜 쪽으로."* (`T11 RESCALE-HURTS` 선례) ⛔`D_drive` 병기 의무 |
| ★★**`D-TREATMENT-BELOW-SCALE`** | **구조** | ★*"이 코퍼스에서 두 규칙의 착지점 차이가 이 배치의 배제 문턱보다 작다."* **널이 아니라 측정된 구조적 사실**이다 — ⛔*"차이가 없다"* 로 읽지 마라 |
| ★**`D-DIRECTION-MIXED`** | **구조** | *"처치 방향이 파일마다 뒤집힌다 ⟹ 부호검정이 혼합을 센다."* ⛔귀속 불가 |
| **`D-NO-DIFFERENCE-DETECTED`** | 미검출 | 처치가 자보다 크고 방향도 일치하는데 부호검정이 문턱에 못 닿았다 = **진짜 측정된 널**. MDE `q80 = 0.7074` 병기 의무 |
| **`D-UNPOWERED`** | 미검출 | 동점이 많아 `k⁺(n_eff)` 가 없다. ⛔*"차이가 없다"* 금지 |

⛔**`D-TREATMENT-BELOW-SCALE` 를 `D-NO-DIFFERENCE-DETECTED` 로 접지 마라** — `M8b` 가 대가를 치른 부류다
(`GAP-NOT-FACTORIZABLE` → `NO-SINGLE-LINK-DETECTED` 개명). **왜 널인지가 라벨의 내용이다.**

```python
# ⛔`gates_t16.label_probs()` 가 이 값을 **재생산**해야 한다(§12-3).
from math import comb, log
def ge(k, n, q): return sum(comb(n,i)*q**i*(1-q)**(n-i) for i in range(k, n+1))
def le(k, n, q): return sum(comb(n,i)*q**i*(1-q)**(n-i) for i in range(0, k+1))
def k_one(n, a): return min(k for k in range(n+1) if ge(k, n, .5) <= a)
def k_two(n, a): return min(k for k in range(n+1) if ge(k, n, .5) <= a/2)
N = 60
K_F, K_S, K_E, K_D = k_one(N,.05), k_one(N,.025), k_one(N,.05), k_two(N,.025)   # 37 · 39 · 37 · 40
qF, qS, qE, qD = 0.95, 0.92, 0.92, 0.50      # ★등록 예측 (q_D 는 0.60 에서 내렸다)
pT1, pT2 = 0.95, 0.80                        # T1·T2 의 발화 예측 (결정적 통계량에 대한 예측 — 이항 아님)
PF, PS, PE = ge(K_F,N,qF), ge(K_S,N,qS), ge(K_E,N,qE)
PDup, PDdn = ge(K_D,N,qD), le(N-K_D,N,qD); PDnull = 1 - PDup - PDdn
S_AX = {'AUTOSCALE-BEATS-ZERO-BOTH-RULES': PS*PE,
        'AUTOSCALE-BEATS-ZERO-BANDR-ONLY': PS*(1-PE),
        'NO-AUTOSCALE-SKILL-DETECTED':     1-PS}
D_AX = {'D-STAGE1-GRID-CHANGES-LANDING': PDup, 'D-STAGE1-GRID-WORSENS-LANDING': PDdn,
        'D-TREATMENT-BELOW-SCALE': PDnull*pT1, 'D-DIRECTION-MIXED': PDnull*(1-pT1)*pT2,
        'D-NO-DIFFERENCE-DETECTED': PDnull*(1-pT1)*(1-pT2), 'D-UNPOWERED': 0.0}
```

독립 가정이 준 `9.660e-12` 는 **상한**이다 ⟹ ★***설계는 「새 규칙만 이긴다」가 나오리라 예측하지 않는다.***

### §3.6 ★★이 설계가 **못 하는 일을 예측표가 스스로 말한다** (⛔결과 뒤에 재서술 금지)

1. ★**`S` 축은 등록 예측 아래 사실상 결정적이다**(`1 − P(S) = 5.1e-10`).
   ⟹ `S` 축이 인쇄할 라벨은 **거의 확실히 `AUTOSCALE-BEATS-ZERO-BOTH-RULES`** 이고,
   그것은 ***밴드 수리의 공로가 아니라는 라벨***이다. ⛔이 사실을 결과 뒤에 재서술하지 마라.
2. ★**`D` 축의 최빈 결과는 `D-TREATMENT-BELOW-SCALE`(0.937)** 이다.
   ⟹ ***이 배치는 「1단 격자 수리가 착지점을 바꾸는가」에 「처치가 자보다 작다」로 답할 것이다.***
   그것은 **정보다** — *"수리는 well-posedness 수리이지 이 코퍼스에서 정확도 수리가 아니다"* 라는 측정이다.
   ⛔그러나 **정확도 주장으로 승격 금지**이고, ⛔*"차이가 없다"* 로도 접지 마라.
3. ⟹ ★**확증 내용은 셋뿐이다**:
   (a) **`G-EQUIVAR`** — 판정 자료 위에서, 추정기 런 0회로, 새 규칙이 등변임을 보인다(`T14` 가 못 낸 것).
   (b) **`S` 축** — GT-free 자동 스케일이 **제3자 blind 코퍼스**에서 제로필드를 이기는가
       (`T14` 는 `BLOCKED` 로 이 질문에 답하지 못했다). ⚠단 (a)(b) 어느 것도 **밴드 수리에 귀속되지 않는다**.
   (c) **`D-TREATMENT-BELOW-SCALE`** — 착지 축의 **구조적 측정**(널이 아니다).
4. ⛔**`q_D = 0.50` 은 「정직한 동전던지기」가 아니라 「자보다 작은 처치」의 결과다.**

## §5 ★역변환 — 어디서 원 단위로 되돌리는가 (`T14 §5` 축자 계승)

재라벨은 **좌표에만** 작용하고 `z` 는 불변이다: `k = k'/s` · `ω = ω'/√s` · `A = A'` · `φ = φ'`.

**두 경로를 다 계산하고 일치를 강제한다 (`G-INVERT`)**

- ★**P-explicit**(배포 가능 경로): `initialize()` 뒤 모델에서 `kx',ky',w,phi` 를 **되읽어**
  `kx = kx'/s` 로 매핑하고 `wavesplat/model/tnse.py:221 render_wave_field(...)` 로 **원 격자·원 시각**에 렌더.

**전제 두 개, 게이트로 강제**: `G-PURE`(`use_stokes2 is False` ∧ `use_neural_corrector is False`) ·
| `G-DEEP`(모든 행 `k̂_p · depth >= π`, `kd_min` 기록 — 수심 미재척도가 수치적으로 무해함을 **판정 자료 위에서**.
