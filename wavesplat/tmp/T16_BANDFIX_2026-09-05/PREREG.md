## §0 왜 이 배치인가 · PRIMARY 한 문장

`T14-AUTOSCALE` 은 **`BLOCKED`** 로 끝났다(`blocked_by = ['G-EQUIVAR']`, 게이트 31/32).
차단의 정체는 성능이 아니라 **규칙의 well-posedness** 였다:

| 사실 (`T14 AMENDMENT_2 §1`, 동결 자료) | 값 |
|---|---|
| `AUTO-AP` 등변 편차 `\|c=0.5\|` · `\|c=2.0\|` | **0.000e+00 · 0.000e+00** (정확히 등변) |
| `AUTO-BAND` 등변 편차 `\|c=2.0\|` | 중앙 0.0217 · 최대 **0.0721** · 초과 **1/34** (허용 0.0588) |
| `AUTO-BAND` 등변 편차 `\|c=0.5\|` | **~0.99** (규칙이 무너진다) |
| 1단 격자 여유 `k_p/Δk₁` (`Δk₁ = 2·2.0/119 = 0.033613`) | 중앙 **1.16** · 최소 **0.88** |

**기제(코드 유래)**: 2단 줌의 **1단이 절대 격자**다 — `wavesplat/optimizer/bank_mmse.py:159-160` 이
`_beamform_top(..., klim=2.0, n=120)` 으로 돈다. 장면의 `k_p` 가 그 격자 간격보다 작으면 1단이 첨두를
못 잡고, 2단의 `klim = 3.5·k̂₁`(`:162-163`)이 통째로 틀어진다.

⛔`T14` 의 규칙은 **동결**됐다(`scale_rules_t14.py`). 고친 규칙은 **다른 규칙**이므로 새 사전등록이
필요하다 — 그것이 이 배치다.

### ★고친 것 (한 줄, `REACHABILITY.md §3` 이 정본)
> **1단 `klim` 을 관측 개구에서 유도한다: `klim₁ = (n−1)/2 · 2π/L_obs` ⟹ `Δk₁ = 2π/L_obs`.**
> 자유 파라미터 **0개** — `n = 120` 은 `bank_mmse.py:160`, `2π/L_obs` 는 개구의 Rayleigh 한계다.
> 2단(`klim = 3.5·k̂₁`)은 **손대지 않는다**(이미 상대적이다). ⟹ **단일요인 개입 1건.**

### ★PRIMARY 질문 (한 문장)
> ***1단 격자를 관측 개구에 상대적으로 고쳐 등변으로 만든 밴드 규칙(`AUTO-BANDR`)이, 참값을 전혀
> 보지 않고 고른 `s` 로, 제3자 참값 위에서 배포 학습 경로가 제로필드를 이기게 하는가 — 그리고
> 그 수리가 옛 규칙(`AUTO-BAND`)의 착지점을 실제로 바꾸는가?***

**PRIMARY 통계량 · 방향 · 집계 · n (이름으로 못박는다)**
- 통계량 = **파일 단위 짝 부호검정**. 집계 함수 = **「팔 A 의 `nRMSE` 가 팔 B 보다 작은 파일의 수」**
  (⛔짝별 차의 중앙값이 아니다 · ⛔중앙값의 차도 아니다 — 그 둘은 기술통계로만 보고한다).
- 방향 = `nRMSE` **작을수록 좋다**.
- `n` = **60** (Tier-P 전수).
- 다리 두 개: `S`(제로필드 대비 이김, 단측) · `D`(옛 규칙 대비 짝, 양측). §3 이 정본.

### ⚠이 배치가 **재지 못하는 것** (결과 전에 못박는다)
1. ⛔**규칙의 적응성(장면마다 다른 `s`)을 재지 못한다.** 이 코퍼스는 격자가 전 파일 동일
   (`[502,128,128]`, `dx = dy = 4.879 m`, `L_obs ≈ 619.63 m` — `T1`·`T10` 동결 행에서 확인)
   ⟹ `s_ap` 도 `klim₁` 도 **코퍼스 상수**다(`s_ap = 2.8095`, `klim₁ ≈ 0.6033`).
   ⟹ ★**적응성이 아니라 (i) 착지점과 (ii) 등변성(런 0회 게이트)을 잰다. 둘은 다른 진술이다.**
2. ⛔**"우리가 저들보다 낫다" 를 재지 못한다** — 외부 기준선 행이 **0개**다. 라벨은 **귀속**이다.
3. ⛔**`AUTO-BAND`(옛 규칙)의 착지점을 「규칙의 성능」으로 읽지 못한다** — 그 규칙은 **ill-posed** 다
   (`T14` 가 그것으로 차단됐다). `D` 다리는 *"수리가 착지점을 바꾸는가"* 이지 *"옛 규칙이 나쁘다"* 가 아니다.

## §3 판정 사다리 (결과 전 고정 · **이김 다리만 검정** · 음성 라벨은 이름이 「미검출」)

Tier-P, n=60. 전부 **파일 단위 짝 부호검정**.

```
양성대조 F (가족 밖, 무보정, 단측)
    F = W[ FIX2 < ZERO ] >= 37                          P(W>=37|60,.5) = 0.046230

PRIMARY 가족 = 2 다리 · n = 60 · 방향 `<` (nRMSE 가 작을수록 좋다) · Bonferroni α/2 = 0.025
    S (단측 이김 다리) : W[ AUTO-BANDR < ZERO ]  >= 39   P(W>=39|60,.5) = 0.013670
    D (양측 짝 비교)   : W[ AUTO-BANDR < AUTO-BAND ] >= k⁺(n_eff)  또는  <= n_eff − k⁺(n_eff)
                         k⁺(n) = min{k : P(W>=k|n,.5) <= 0.0125}   ⟹ k⁺(60) = 40
                         (한 꼬리 0.006745 · 양측 0.013489 <= 0.025)
```
- ⚠**`D` 의 동점 처리(결과 전 고정)**: 두 팔의 `s` 가 **비트 동일**하면 런도 비트 동일해 `nRMSE` 가
  같다. **동점은 제외하고 `n_eff = 60 − n_tied`** 로 검정하며, **문턱은 `gates.k_two_sided(n_eff)` 가
  계산한다**(⛔리터럴 금지). `n_tied` 는 `verdict` 에 반드시 인쇄한다.
  ★`n_eff <= 11` 이면 `k⁺` 가 존재하지 않는다 ⟹ `D` 는 **`D-UNPOWERED`** 로 기록되고

## §5 ★역변환 — 어디서 원 단위로 되돌리는가 (`T14 §5` 축자 계승)

재라벨은 **좌표에만** 작용하고 `z` 는 불변이다: `k = k'/s` · `ω = ω'/√s` · `A = A'` · `φ = φ'`.

**두 경로를 다 계산하고 일치를 강제한다 (`G-INVERT`)**
- **P-implicit**(`T11` 경로): `predict_field(gx/s, gy/s, tq/√s)` — 역변환이 암묵적.
- ★**P-explicit**(배포 가능 경로): `initialize()` 뒤 모델에서 `kx',ky',w,phi` 를 **되읽어**
  `kx = kx'/s` 로 매핑하고 `wavesplat/model/tnse.py:221 render_wave_field(...)` 로 **원 격자·원 시각**에 렌더.
- 허용 오차(결과 전 고정): `max|P_implicit − P_explicit| <= 1e-4 · σ4`. ⛔비트 동일 요구 아님.

**전제 두 개, 게이트로 강제**: `G-PURE`(`use_stokes2 is False` ∧ `use_neural_corrector is False`) ·
`G-DEEP`(모든 행 `k̂_p · depth >= π`, `kd_min` 기록 — 수심 미재척도가 수치적으로 무해함을 **판정 자료 위에서**).

### ★6.0 되읽기 지점의 선택 — ⛔**효과가 죽는 곳에 두지 않는다**
`T12 AMENDMENT_1 §2` 가 대가를 치렀다: 조건화 맵 상태의 되읽기로 `OM_G[0,0]` 한 칸을 지정했는데

⟹ 처치가 실제로 발화했는데 게이트가 *"안 바뀌었다"* 로 읽었다. 처방은 **전체 텐서 지문**이었다.

이 배치의 되읽기 지점은 그 기준으로 골랐다 — **팔 사이에서 값이 반드시 갈리는 자리**여야 한다:

## §7 스모크 (⛔본실행 전 필수 — 상시지시)

앵커 2파일(**이미 노출**)에서 **6팔 전부**를 돌린다. ⛔프리즌 표본(Tier-P 60)은 **건드리지 않는다**.
★스모크가 **결정해야 하는 것**(결과 0행 시점에 개정문으로 못박는다):
1. ★`G-ANCHOR-T11` 의 **등급**(T1 비트 동일 / T2 1e-9). `T14` 가 T1 으로 통과했으므로 기대값은 T1.

3. **가장 비싼 팔의 단가**(`AUTO-BANDR` = 2단 줌 + 등변 4회 + blind 1회 + 추정).
4. ★**게이트가 발화할 수 있는 셀**: `G-EDGE`(`edge_margin`) · `G-FLOOR`(`floor_margin`) ·
   `G-DEEP`(`kd_min`) · `G-INVERT`(허용오차) · `G-KLIM1-LIVE`(`c` 배 정확성)가 실제 자료에서 내는 값.
   ⛔**통과를 보고 허용오차를 넓히지 않는다.** 넓혀야 한다면 사유를 축자로 적고 **결과 0행에서** 한다.

6. ⚠**`Tp` 는 이 코퍼스에서 미확인**이다(§2.2). `T14` 의 *"전 파일 10 s"* 는 `mixed_data2` 의 진술이다.
   `G-TP` 가 `Tp̂` 를 행마다 적는다.

   Holm/Bonferroni 는 PRIMARY 가족(2다리)에만 적용한다.
8. ⚠**규칙의 목표 상수는 우리 학습 분포에서 나온다**(`L_TRAIN`·`K_TRAIN`). 규칙은

10. ⚠`proposal_device` 는 `config` 가 정하지 않는다(`propose_atoms` 가 `cuda if available`) ⟹ 되읽어 적는다.
11. ⚠`torch.set_num_threads(1)` 은 numpy/BLAS 를 제약하지 않는다 ⟹ ⛔`wall_s` 팔간 비교 금지.

## §10 ★실측 경로(`bank_mmse` 라우팅)와의 관계 — ⛔`W-12`·`D3` 재발 방지

- **이 배치는 라우팅을 건드리지 않는다.** `real_domain_gate=False` 를 **쓰지 않고**,
  `init_method` 기본값을 바꾸지 않으며, `real_estimator` 도 건드리지 않는다.
- **재라벨은 `initialize()` 상류의 좌표 변환**이다 — `FrameData` 의 `x_obs,y_obs,t` 를 바꿀 뿐이고
  `_frames_have_gt`(`sequential_update.py:411`)가 보는 `gt_field` 와 무관하다 ⟹ 라우터에게 보이지 않는다.
- 입력에 **상수 `gt_field`** 를 붙이므로 라우터는 `learned` 로 간다(`:794-795` 의 실측 게이트 미발화).
  `G-ARM` 이 되읽어 증명한다 ⟹ ⚠***이 배치가 재는 것은 배포 「합성 경로」다. 실측 경로에 대해 아무 말도 하지 않는다.***
- ★**규칙이 빌려 쓰는 `bank_mmse._beamform_top` 은 배포 경로에서 실행되지 않는다** —
  패키지 안의 호출자는 `fit_bank_mmse` 의 `:159`·`:162` **둘뿐**이고 그것은 **실측 게이트 뒤**의 경로다
  (`REACHABILITY §2`, `grep` 전수). ⟹ ★**규칙을 고쳐도 출하 팔은 한 비트도 바뀌지 않는다.**
- ★**팔 정체는 「의도」가 아니라 「되읽기」로 적는다**: 모든 행이 `upd.arm_provenance()` 전체를 담는다
  (`requested_init_method` ≠ `resolved_init_method` 일 수 있다는 것이 요점 — `E1-EXTBASE` 사고).
