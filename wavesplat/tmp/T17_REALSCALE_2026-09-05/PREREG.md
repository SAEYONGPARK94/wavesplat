## §0 왜 이 배치인가 · PRIMARY 한 문장

### §0.0 배치의 이유 (외부 시선의 질문)

이 저장소는 3주 동안 실측 음성의 **물리 축**을 하나씩 죽였고(잡음 형태 · 센서 모형 · 희소성 ·
파랑 조건 · 창 길이 · 표현 용량 — `MEMORY.md §소거표`), 결론은 *"우리는 축을 지목하지 않는다"* 였다.
그런데 **`T11`·`T12` 가 이틀 만에 축을 하나 찾았다** — **절대 파수 스케일**이다
(`T11 BAND-MISMATCH`: 제3자 참값 위에서 `RESCALE`(s=2) 24/24 vs `SHIP` 8/24 ·
`T12 MULTIPLE-AXES-CARRY`: `A-MAPSCALE` 24/24). 그리고 **`T14`→`T16` 이 그 축을
관측만으로 고르는 규칙**을 만들었다(`T16` `AUTOSCALE-BEATS-ZERO-BOTH-RULES`, `S` 59/60,
`SEC-A AUTO-BANDR < SHIP` 58/60).

그 규칙을 시험할 자료는 **학위논문의 주제인 실측 12 레코드**다. 그런데 `T11`–`T16` 은 전부
**제3자 합성** 위에서만 돌았고, 논문은 그 방향이 **미측정**이라고 스스로 적는다.
⟹ ***다음 배치가 그것이 아닐 이유가 없다.*** 이 배치가 그것이다.

### §0.1 ★★★이 배치가 **확증할 수 있는 것과 없는 것** (⛔결과 뒤에 재서술 금지)

  m=2 에서는 **10/12(p = 0.019287 ≤ 0.025)** 가 기각된다. §3.1 이 계산으로 보인다.

  ⛔**그러므로 「12 레코드 단독」 설계는 채택하지 않는다.**

**(b) ✅창 축이 그것을 구한다 — 그리고 그 축이 진짜 복제임을 결과 전에 쟀다.**

⟹ **PRIMARY 는 셀 단위 n = 12 × 6 = 72**, 등록 예측 아래 **양성 라벨 확률 0.770688**.

**(c) ⛔그 대가를 숨기지 않는다 — 셀 72 는 「독립 72」가 아니다.**

**(d) ⛔이 배치가 원리적으로 답하지 못하는 것 (결과 전에 못박는다)**
1. ⛔**"우리가 경쟁자보다 낫다"** — 외부 기준선 행 **0개**. 실측 외부 기준선은 저장소에서

   이동 플랫폼·조우 기하에 대해 **아무 말도 하지 않는다**(전부 고정 관측소).
3. ⛔**사이트 수준 일반화** — 사이트 4개, 층 바닥 p 0.0625(위 (a)).

5. ★⛔**"자유 파라미터 0개의 규칙이 승리했다"** — 이 코퍼스에서 규칙은 **12셀 중 4셀에서

6. ⛔**`AUTO-BANDR` 와 `AUTO-BAND`(옛 규칙)의 차이를 이 코퍼스에서 못 가른다** —
   `|Δ ln s_raw|` 중앙 **0.009815 < ln(1.05)=0.048790**, 초과 **1/12**, 그리고 레일 클립 4셀에서는

### §0.3 ★PRIMARY 질문 (한 문장)

> 배포 학습 경로(`PROP`)의 착지점이 바뀌는가 — 그리고 그 결과가 참 제로필드를 이기는가?***

**PRIMARY 통계량 · 방향 `<` (`nRMSE` 는 작을수록 좋다) · 집계 · n = 72 (이름으로 못박는다)**

  (⛔짝별 차의 중앙값이 아니다 · ⛔중앙값의 차도 아니다 — 그 둘은 기술통계로만 보고한다).
- PRIMARY 방향 = `<` — `nRMSE` **작을수록 좋다**. 종점 = **`nowcast (τ=0)`**(`B-2` 계승),
  lead-mean 은 기술통계.
- `n` = **72** (12 레코드 × 6창 전수). **레코드 접기 n=12 병기 의무**(§3.4).
- **축 두 개**: `S`(참 제로필드 대비 기술, 단측) · `D`(항등 스케일 대비 착지, 양측). §3 이 정본.

# ⛔`gates_t17.label_probs()` 가 이 값을 **재생산**해야 한다(§12-3).
from math import comb
def ge(k,n,q=.5): return sum(comb(n,i)*q**i*(1-q)**(n-i) for i in range(k,n+1))
def le(k,n,q=.5): return sum(comb(n,i)*q**i*(1-q)**(n-i) for i in range(0,k+1))
def k_one(n,a): return min(k for k in range(n+1) if ge(k,n) <= a)
def k_two(n,a): return min(k for k in range(n+1) if ge(k,n) <= a/2)
N = 72
K_F, K_S, K_D = k_one(N,.05), k_one(N,.025), k_two(N,.025)     # 44 · 45 · 46
qS, qD = 0.60, 0.65                                            # ★등록 예측 (근거는 아래)
PS  = ge(K_S,N,qS)
PDu = ge(K_D,N,qD); PDd = le(N-K_D,N,qD); PDn = 1-PDu-PDd
S_AX = {'REAL-SKILL-WITH-AUTOSCALE': PS, 'NO-REAL-SKILL-DETECTED': 1-PS}
D_AX = {'SCALE-CHANGES-REAL-LANDING': PDu, 'SCALE-WORSENS-REAL-LANDING': PDd,

## §5 ★★재라벨과 **수심 규약** — ⛔`T11`–`T16` 을 계승하지 **않는** 유일한 지점

`T11`·`T14`·`T16` 은 재라벨에서 **`depth` 를 고정**했다. 그 코퍼스는 `depth = 400 m`,
`k·d ≈ 12–20` 로 **심해 포화**여서 두 규약이 구별되지 않았다. **이 코퍼스는 다르다**:

```
  ★ depth 고정 규약의 k'd 최소 = 1.152 (레코드 AA14) · π = 3.1416 ⟹ π 미만 8/12
  ★ depth 고정이 도입하는 |Δω/ω| 최대 = 9.457%  (중앙 1.273%)
  ★ s=1 에서도 kd < π 인 레코드 = 3/12 ⟹ ⛔심해 가정은 이 코퍼스에서 s 와 무관하게 이미 깨져 있다
```

⟹ ★**`d' = d/s` 를 등록한다.** 그러면 `k'·d' = k·d` 가 **불변**이고 분산관계가 **정확히** 보존된다
(`ω' = √(g k' tanh(k' d')) = √s·ω`, 근사 없음).

★**왜 이것이 「측정 규율」의 직접 적용인가**: `B-2` 의 수심 오류(17→30)에서 저장소는
*"Δω = 0.0000–0.0012% ⟹ 수치적으로 무해"* 라 결론했고 **분산관계에는 옳았지만 하류 판정에서
여럿이 널로 뒤집혔다**. ⟹ ***파라미터 변화의 크기로 무해를 논증하지 마라.*** 여기서는 그 변화가
**9.46%** 이므로 논증할 것도 없다. `G-DEPTH-EXACT`(차단)가 행마다 `depth_used == depth/s` 와
`k̂'·d' == k̂·d` 를 되읽어 강제한다.

⚠**이 선택의 대가(공시)**: `PROP`(s=1) 팔은 `d' = d` 이므로 **`B-14b` 앵커가 그대로 성립**하지만,
`PROP-BANDR` 등은 `T11`–`T16` 과 **다른 규약**이다 ⟹ ⛔**그 배치들의 수와 직접 비교 금지**.

**역변환** — 두 경로를 다 계산하고 일치를 강제한다(`G-INVERT`, `T14 §5` 계승):
- **P-implicit**: `predict_field(gxq/s, gyq/s, (t0+lead)/√s)`.
- **P-explicit**: `initialize()` 뒤 모델에서 `kx',ky',w,phi` 를 되읽어 `kx = kx'/s`, `ω = ω'/√s` 로
  매핑하고 `model/tnse.py render_wave_field` 로 **원 격자·원 시각**에 렌더.
- 허용 오차(결과 전 고정): `max|P_implicit − P_explicit| <= 1e-4 · sg`. ⛔비트 동일 요구 아님.
