## §0 왜 이 배치인가 · PRIMARY 한 문장

### 0.1 선점 감사가 남긴 구멍 (사실)

논문의 예비 novelty 주장은 *"서 있는 것은 **표현 성질들의 조합**"* 이다. 그런데 저장소의
절제는 **전부 일요인(one-factor-at-a-time)** 이고, 각각 **다른 성질을 두 팔 모두에서 고정**한다:

| 배치 | 절제한 것 | 다른 성질은? | 결과 (혼잡 48) |
|---|---|---|---|
| `B-16`(08-24) | **파수 연속성**(`k_snap_dk`) | 사전은 **두 팔 다 ON** | `SHIP-NOW < KGRID1` **46/48 · −38.607%** |
| `B-22`(08-27) | **학습된 사전**(원자 출처) | 파수는 **두 팔 다 연속** | `LEARN < ANA-N` **48/48 · −48.586%** |
| `B-20b`(08-27) | 위의 양자화 귀속 재분석 | 〃 | `FITSWAP < KGRID1` **48/48 · −38.840%** |
| **— (없음)** | ★**둘 다** | — | ★**저장소 전체에 0행** |

⟹ **주변효과(marginal) 둘은 측정됐고 교호작용(interaction)은 한 번도 측정된 적이 없다.**
주변효과만으로는 *"조합"* 을 검정할 수 없다 — 조합 주장은 **비가법성(non-additivity)** 의 주장이다.
저장소 자신이 결과를 보기 전에 이것을 적었다(`tmp/M8_*` 사전등록: *"다음 설계는 2요인 팔이다"*).

### 0.2 ★PRIMARY 질문 (한 문장)

> ***학습된 사전과 파수 연속성을 **동시에** 빼면, 각각을 뺐을 때 손해의 **합보다 더 잃는가**
> (= 두 성질이 초가법적으로 결합하는가)?***

**PRIMARY 통계량 · 방향 · 집계 · n (이름으로 못박는다)**
- 관측량 = 에피소드별 `avg_nRMSE` 의 **median-of-3**(추정기 시드 42·43·44) — `B-16`·`B-22` 규약 축자 계승.
- **교호작용 대비**(단일출처 정의, ⛔다른 식으로 계산하지 않는다):
  ```
  d_i = [ ln y(A-Q)_i − ln y(A-C)_i ] − [ ln y(L-Q)_i − ln y(L-C)_i ]
      = ln( y(A-Q)_i · y(L-C)_i / ( y(A-C)_i · y(L-Q)_i ) )          (비의 비)
  ```
  `d_i > 0` = **초가법**(두 절제를 겹치면 합보다 더 나빠진다) = *"조합이 합보다 크다"*.
- **통계량** = `W₊ = #{ i : d_i > 0 }` 의 **짝 부호검정**. ⛔`d_i` 의 중앙값이 아니다(그것은 기술통계).
- **방향** = 양측(두 꼬리에 서로 다른 라벨이 붙는다, §3).
- **n = 48** (`B-12`/`B-16`/`B-22` 와 **같은** 혼잡 에피소드 전수).
- `d_i` 는 **로그 척도**라 에피소드별 임의의 곱셈 재척도에 불변이다(`Hs` 정규화 규약이 바뀌어도 부호 불변).

### 0.3 ⚠이 배치가 **재지 못하는 것** (결과 전에 못박는다)

1. ⛔**외부 기준선 대비 우위를 재지 못한다.** 네 팔이 전부 **우리 팔 안의 절제**다 — 외부 기준선 행 **0개**.
   `tmp/DEBATE_novelty_2026-08-14/AUDIT_tradeoff_axis.md` 가 이름 붙인 부류 그대로다.
   ⟹ 어떤 결과도 *"우리가 남보다 낫다"* 로 읽지 마라. 이 배치가 내는 것은 **귀속**이다.
2. ⛔**합성 혼잡 층 한정.** 희소·실측·비혼잡으로 외삽 금지(`B-19` 는 희소를 따로 쟀고 크기 인용이 금지돼 있다).
3. ★⛔**「조합이 합보다 크다」의 널·음성 방향은 이 관측량에서 원리적으로 해석 불가에 가깝다.**
   가법 널이 결측 칸에 예측하는 값이 **관측 가능 범위 밖**이기 때문이다(§0.4). §3.6 이 정본.
4. ⛔**세 번째 성질(성분 수 / 표현 용량)은 이 배치가 재지 않는다.** 사유는 §5(수치로) —
   그리고 `max_n` 은 **풀링 캡과 성장 천장을 겸하므로 애초에 단일요인이 아니다**(§5.4, 코드 축자).
5. ⚠**표본을 `"HOS M=3 비선형 참값"` 으로 단일 서술하지 않는다** — `gates_b22.MESH_EXPECTED`
   가 `ADEQUATE 31 · DEGRADED 17` 로 못박았다. `DEGRADED` 셀은 사실상 2차 비선형이다.

### 0.4 ★★설계 단계에서 나온 결정적 사실 — **가법 널이 척도 밖이다**

동결 행(`B-16` ∪ `B-22`, 추정기 런 0회)에서 잰 것:

```
[2] 동결 행에서 잰 설계 상수  (n=48, B-16 + B-22, 런 0회)
==============================================================================
  q1 = ln(L-Q) - ln(L-C)   양자화 효과 | 사전 ON : median +0.4879  sd 0.3290  >0 46/48
  pr = ln(A-C) - ln(L-C)   사전 효과   | k 연속  : median +0.6655  sd 0.3615  >0 48/48
  corr(q1, pr) = 0.7138

  천장 증거 (동결 10팔 x 48 에피소드 = 528 셀)
    관측된 nRMSE/ZERO 최대 = 2.136   (에피소드별 최대의 중앙 = 1.306)
    비상관 장 논증의 연성 천장 sqrt(2) = 1.414
  ★가법 널이 결측 칸에 예측하는 값
    median 1.696 x ZERO   min 0.695  max 3.930
    그 예측이 sqrt(2)xZERO 를 넘는 에피소드      : 37/48
    그 예측이 **에피소드별 관측 최대**를 넘는 것 : 43/48
    그 예측이 전체 관측 최대(2.136)를 넘는 것      : 15/48
```

- **연성 천장의 유래(코드/물리 유래, 가정 아님)**: 참 장과 무상관이고 에너지가 맞는 예측은
  `nRMSE ≈ √2 × ZERO`(≈ 1.414). 동결 10팔 × 48 에피소드 = 528 셀에서 **관측된 최대는 2.136 × ZERO**,
  에피소드별 최대의 중앙은 **1.306**.
- ⟹ ★***가법 널은 43/48 에피소드에서 「이 저장소가 한 번도 도달한 적 없는 나쁨」을 요구한다.***
  ⟹ `d_i < 0`(아가법)은 **기제 없이도 척도만으로 거의 확정**이고,
  ⟹ `d_i > 0`(초가법)은 그 천장이 **반대 방향으로 밀기 때문에 보수적**이다.
- ★**이 비대칭이 이 설계의 전부다**: **양성(초가법)은 살아남으면 강하고, 음성(아가법)은 해석 불가**.
  그래서 음성 다리의 이름은 **구조적**이어야 하고(§3.3), 그 이름을 가르는 **판별자**가 필요하다(§3.4).

   동결 행을 빌려 쓰면 그 문장을 쓸 수 없다.
⟹ **동결 행은 「비교」가 아니라 「앵커」로만** 쓴다(§6.1, 차단 게이트).

### 2.3 규약 (⛔`B-16`·`B-22` 와 비트 동일 — 앵커가 성립하려면 필수)

(`run.py:235,272`) · `nRMSE = RMSE / Hs_true`(`metrics.py:32`) · `depth` 는 **되읽어 기록**

## §3 판정 사다리 — **축 I(검정) + 축 II(구조 판별자)** · ⛔`UNDECIDED` 구멍 없음

### 3.1 문턱 (⛔결과 전 고정 · `gates_t18` 상수 · 코드 출력, 손타이핑 0)

```
══ 1. 문턱 (n=48) ═════════════════════════════════════════════════
  축 I (PRIMARY, 교호작용, 양측 α=0.05)  W+ >= 32  또는  W+ <= 16   한꼬리 P=0.014652 · 양측 0.029305
  SEC-A / SEC-B   (무보정 단측 α=0.05)   W  >= 31               P=0.029732
  등가 밴드 ln(1.05) = 0.048790   천장 기준 median_i CEIL_i = 1.306 x ZERO
  ★k*(n) 부재 = INTERACTION-UNDER-POWERED 가 되는 n_eff : [1, 2, 3, 4, 5] ⟹ 경계는 n_eff <= 5
```
- **PRIMARY 가족 = 1주장**(교호작용). ★**주효과 둘은 가족에 넣지 않는다** — 그 둘은 `B-16`·`B-22`
  가 이미 확증했고, 이 배치에서는 **앵커/양성대조**의 지위다(§6.1). 가족을 3으로 키우면
  q80 이 0.7109 → 0.7305 로 나빠지는데 **얻는 새 정보는 0** 이다(§5 표).
- ⚠**동점 처리(결과 전 고정)**: `n_tied = #{ i : |d_i| < 1e-12 }`. 동점은 빼고 `n_eff = 48 − n_tied`
  로 검정하며, 문턱은 `gates_t18.k_two(n_eff)` 가 **계산한다**(⛔리터럴 금지). `n_tied` 는 verdict 에 인쇄.

### 3.2 축 II — **`A-Q` 의 착지 위치**(결정적 통계량 · 검정 아님 · 음성 다리의 이름을 가른다)

`T16` 의 `D_drive` 와 같은 지위다. **결과 전 고정**:
```
r_i   = y(A-Q)_i / y(A-C)_i              양자화가 사전-OFF 열에서 움직인 크기
z_i   = y(A-Q)_i / ZERO_i                무기술 대비 착지 높이
CEIL_i= max over 동결 10팔 { y(arm)_i / ZERO_i }      (에피소드별 관측 최대, 동결 값 = 핀)

T_INERT :  | median_i ln r_i |  <  ln(1.05) = 0.048790
             ⟹ "사전이 없으면 양자화가 자보다 작게 움직인다"
T_CEIL  :  median_i z_i  >=  median_i CEIL_i  ( = 1.306 )
             ⟹ "착지가 이미 관측된 최악 대역이다" = 천장 교락
```
⛔**두 문턱은 결과를 보고 바꾸지 않는다.** `ln(1.05)` 는 `T14 §4.4` → `T16 §3.3` 이 계승한
저장소의 등록된 배제 밴드이고, `CEIL` 은 §0.4 에서 **동결 행으로** 계산됐다.

### 3.3 라벨 (발화 순서 · ⛔결과를 보고 순서를 바꾸지 않는다)

```
 -1.  앵커 비트 재현 실패                 -> ANCHOR-DID-NOT-REPRODUCE      ⛔다른 라벨 인쇄 금지
 -0.  양성대조 W[L-C < ZERO] < 32         -> CONTROL-DID-NOT-REPLICATE     ⛔다른 라벨 인쇄 금지
  0.  n_eff <= 5                          -> INTERACTION-UNDER-POWERED
  1.  W+ >= k*(n_eff)                     -> COMBINATION-SUPERADDITIVE
  2.  W+ <= n_eff − k*(n_eff)  (아가법 기각)
        2a. T_INERT                       -> SUBADDITIVE-QUANT-BELOW-SCALE-WITHOUT-PRIOR
        2b. ¬T_INERT ∧ T_CEIL             -> SUBADDITIVE-AT-CEILING
        2c. 그 밖                          -> SUBADDITIVE-PARTIAL
  3.  그 밖                                -> NO-INTERACTION-DETECTED
```

| 라벨 | 지위 | 읽는 법 |
|---|---|---|
| ★**`COMBINATION-SUPERADDITIVE`** | **확증** | *"두 성질을 겹쳐 빼면 합보다 더 잃는다 = 조합이 합보다 크다."* ★**천장이 반대로 밀기 때문에 보수적**이다. ⛔`n_over_ceiling` 병기 없이 인용 금지 |
| ★★**`SUBADDITIVE-QUANT-BELOW-SCALE-WITHOUT-PRIOR`** | **구조** | *"사전이 없으면 파수 양자화는 이 배치의 자보다 작게 움직인다."* = **두 성질이 독립이 아니다**(약한 형태의 조합 주장). ⛔*"양자화가 무의미하다"* 로 읽지 마라 — `SEC-A` 의 MDE 병기 의무 |
| **`SUBADDITIVE-AT-CEILING`** | **구조** | *"아가법이 나왔으나 착지가 이미 관측 최악 대역이다."* ⛔**기제 주장 금지** — §0.4 가 예측한 그대로다 |
| **`SUBADDITIVE-PARTIAL`** | 구조 | 움직였으나 가법 예측에 못 미쳤고 천장도 아니다. ⚠**EXPLORATORY** |
| **`NO-INTERACTION-DETECTED`** | **미검출** | ⛔*"가법적이다/차이가 없다"* 금지 — **검정력의 진술**이다. MDE **q80 = 0.7109** 병기 의무 |
| **`INTERACTION-UNDER-POWERED`** | 미검출 | 동점이 많아 `k*(n_eff)` 가 없다. ⛔*"차이가 없다"* 금지 |
| **`ANCHOR-DID-NOT-REPRODUCE`** | 차단 | 오늘의 패키지가 `B-16`/`B-22` 를 재현하지 못한다 ⟹ **격자가 정합하지 않는다** ⟹ 판정 없음 |
| **`CONTROL-DID-NOT-REPLICATE`** | 차단 | 배포 팔이 무기술을 못 이긴다 ⟹ 판정 없음 |

⛔**`SUBADDITIVE-QUANT-BELOW-SCALE-WITHOUT-PRIOR` 를 `NO-INTERACTION-DETECTED` 로 접지 마라** —
`M8b` 가 대가를 치른 부류다(`GAP-NOT-FACTORIZABLE` → `NO-SINGLE-LINK-DETECTED` 개명).
**왜 그 방향인지가 라벨의 내용이다.**

### 3.6 ★★★이 설계가 **못 하는 일을 예측표가 스스로 말한다** (⛔결과 뒤에 재서술 금지)

1. ★**등록 예측 아래 `COMBINATION-SUPERADDITIVE` 의 확률은 인쇄 정밀도로 0 이다.**
   ⟹ ***이 배치는 「조합이 합보다 크다」에 「그렇다」로 답할 공산이 거의 없다.***
   그 이유는 자료가 아니라 **척도**다 — 가법 널이 43/48 에피소드에서 관측 범위 밖이다(§0.4).
2. ★**그러나 검정력은 없지 않다.** 반대 가설(반쪽 synergy, `d = +0.244`)이 참이면
   **0.9789 로 검출**한다. ⟹ *"못 잡는 설계"* 가 아니라 ***"잡을 것이 없을 것으로 예측되는 설계"*** 다.
   ⛔이 둘을 바꿔 쓰지 마라 — 전자는 MDE 의 진술, 후자는 사전 믿음의 진술이다.
3. ★**따라서 이 배치의 실질 산출물은 축 I 이 아니라 축 II 다** — ***`A-Q` 가 어디에 착지하는가.***
   최빈 예측은 `SUBADDITIVE-QUANT-BELOW-SCALE-WITHOUT-PRIOR`(0.735)이고, 그것은
   **정보다**: *"파수 연속성이라는 성질은 학습된 사전 없이는 이 코퍼스에서 잴 수 있는 값을 하지 않는다"*
   = **두 성질은 독립이 아니다** = 조합 주장의 **약한 형태의 지지**.
   ⛔단 그것은 *"합보다 크다"* 가 **아니다**. 논문 문안은 그 둘을 구별해서 써야 한다.
4. ⛔**`SUBADDITIVE-AT-CEILING`(0.147)가 나오면 이 배치는 아무것도 답하지 못한다.**
   그 경우의 처방은 **재실행이 아니라 관측량 교체**다(§11-3) — ⛔새 사전등록으로만.
5. ★**그러므로 이 문서는 「초가법을 잡는 설계」가 아니라 「초가법이 있으면 놓치지 않고,
   없으면 왜 없는지를 구조적으로 이름 붙이는 설계」로 등록된다.**
   ⛔결과가 나온 뒤에 이 문단을 다시 쓰지 마라.

## §5 ★인자 선택 — **왜 2×2 이고 2×2×2 가 아닌가** (선언이 아니라 수치)

### 5.1 후보 제3인자 = 성분 수(표현 용량): `learned_init.pool_and_select(..., max_n=30)`
동기가 된 관찰은 실재한다(설계 시점 실측):
```
[5] 카디널리티를 제3인자로 넣지 않는 근거 (전부 동결 행 실측)
==============================================================================

   자국 코퍼스 LEARN  auto_n_selected  median 19.0  ==30(포화)  23/144 =  16.0%
   자국 코퍼스 ANA-N  auto_n_selected  median 19.0  ==30(포화)  23/144 =  16.0%
   자국 코퍼스 ANA    auto_n_selected  median  3.0  ==30(포화)   0/144 =   0.0%
   제3자 코퍼스 SHIP n_sel            median 30.0  ==30(포화)  52/52 = 100.0%
   ⟹ 캡 상향(30->60) 처치는 자국에서 84% 의 런에서 구조적 no-op,

```
⚠희소 층 참고(`B-19` 동결): `auto_n_selected` median 10.0 · ==30 10/48 = 20.8%.

### 5.2 ⛔넣지 않는 사유 **셋**, 전부 수치

1. ★**모의 코퍼스가 다르다.** 포화를 푸는 처치(캡 30→60)는 **제3자에서 100% 발화하고 자국에서
   84% 의 런에서 구조적 no-op** 이다. 이 2×2 는 **앵커 때문에 자국 혼잡 48 위에 있어야 한다**
   (§2.2) ⟹ 동기가 된 관찰이 **이 코퍼스에 존재하지 않는다.**
   ⟹ ★저장소가 반복해서 물린 부류(*"개입이 걸렸는데 발화하지 않는다"*, `W3`/`W4` 처방)의 재발이 된다.
2. ★**이미 반대 방향으로 측정됐다.** `M4` 가 **`CAPACITY-HURTS`**(실측 `K-MAX < SHIP-K` 0/12
   = 반대 12/12 p=2.44e-04 · 합성 48/48 · 51/51)를 냈고, 소거표는 **표현 용량**을 *"경계가 놓인
   축이 아니다"* 로 이미 지웠다. 새 인자가 아니라 **답한 축**이다.
3. ★**검정력·비용의 대가가 계산 가능하다** — 아래.

```
══ 3. 가족 크기의 대가 (2x2 vs 2x2x2) ═══════════════════════════════
  2x2   가족 1주장 (이 설계: 주효과는 앵커, 교호만 검정)           tail α=0.025000  k*=32  q80=0.7109
  2x2   가족 3주장 (주2 + 교호1 을 전부 검정한다면)             tail α=0.008333  k*=33  q80=0.7305
  2x2x2 가족 7주장 (주3 + 2원3 + 3원1)                  tail α=0.003571  k*=34  q80=0.7500
  ⟹ 2x2x2 로 가면 q80 이 0.7109 → 0.7500 (+0.0391) 이고 PRIMARY 런이 720 → 1296 (+80%) 이다.
```
⟹ **런 +80% 를 내고 MDE 를 +0.039 나쁘게 만들면서, 발화율 16% 인 인자로, 이미 답한 축을 다시 묻는다.**
⛔한다.

### 5.3 ★★2026-09-05 추가 — **캡 축은 「다음 배치」가 아니라 「닫혔다」**

⛔**이 문서의 초안은 여기에 *"캡 상향을 별도 배치로 등록한다"* 고 적었다. 그 문장은 철회한다.**
같은 날 두 방향에서 닫혔기 때문이다:

1. **귀무가설 담당 에이전트의 실측** — 캡 포화는 **우리의 가장 좋은 자국 블록에 동반**되고,

2. **`M4_CAPACITY_2026-08-28` 의 단조 용량-반응** — 캡을 **푸는 방향이 가장 나쁘다**:
   `K-15` **−7.2%** · `K-128` **+58.5%** · `K-MAX` **+1331%**.
   ⟹ 캡 상향은 *"미측정 축"* 이 아니라 **측정된 최악 방향**이다.

### 5.4 ★★★그리고 **`max_n` 은 애초에 단일요인 노브가 아니다** (코드가 스스로 적었다)
