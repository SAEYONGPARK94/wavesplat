## 2. 읽을 수 있는 것 (PREREG §3)

- **PRIMARY** — 추적은 예산 안이다. **여덟 칸 전부 6.3% 이하**이고 장치·경로·층에
  거의 무감하다. 추적 비용이 초기화 경로에 의존하지 않는다는 것은 코드에서 이미
  예상되는 바다(추적 루프는 초기화 팔로 분기하지 않는다) — 그것을 **측정으로 확인**했다.
- **SECONDARY** — 일회성 초기화에서 **학습 경로가 해석적보다 빠르다**:
  혼잡 CPU **5.18 s vs 26.61 s**(약 5.1배), 희소 **5.89 vs 17.08 s**(약 2.9배).
  ★확산 표본기가 비싸리라는 통상적 예상과 **반대 방향**이다. 기제는 재지 않았다
  (⛔귀속 금지) — 다만 해석적 팔이 81×81 격자 스캔 + 코스투파인 staging 을 돈다는 것은
  코드에서 확인된다.
- ★**GPU 가 거의 필요 없다**: 학습 초기화가 CPU 5.18 s vs GPU 4.86 s = **1.07배**.
  희소에서는 CPU 5.89 vs GPU 4.30 = 1.37배. ⟹ **배포에 GPU 가 필수가 아니다.**

## 3. ⛔읽을 수 없는 것 (결과 전 고정, 전건 유지)

1. ⛔**정확도 주장 0건.** 이 배치는 정확도를 재지 않았다.
2. ⛔**철회된 프로세스간 수치(13.4 / 132.6 ms)와 비교 금지** — 다른 양이다.
3. ⛔**기준선(LETKF/ETKF) 지연과 비교 금지** — 이 배치는 기준선을 **돌리지 않았다**.
4. ⛔*"실시간이다"* 금지. 쓸 수 있는 것은 **측정된 비율**이고 그것은 **초기화를 포함하지
   않는다**. 초기화 5.18 s 는 10 Hz 프레임의 **약 52배**다 — 일회성이지만 작지 않다.
5. ⛔**렌더 단가(`B-6b` 137 µs/점)와 합산 금지** — 질의 쪽이고 팔이 다르다.
6. ⛔**실측 전이 금지** — 실측은 다른 경로(`bank_mmse`)로 간다.
7. ⛔**층 합산 금지**.
