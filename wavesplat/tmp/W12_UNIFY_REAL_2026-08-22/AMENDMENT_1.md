# W12 개정 1 — 게이트 2개 실패는 **내 계측 키 오류**다 (판정 불변)

## `G-1` (FORCE-LEARNED 가 learned 로 갔나) — 오설계
`_auto_selected` 는 **`init_method=='auto'` 일 때만** 채워진다. 나는 `init_method='learned'` 를
**명시**했으므로 라우터가 아예 돌지 않고 그 값은 정의상 `None` 이다.
⟹ 게이트가 *"라우터가 무엇을 골랐나"* 를 물었는데, 이 팔에는 **라우터가 없다.**

**실제로 검사했어야 할 것은 통과한다** (`MEASURED`, 별도 확인):
`AA15a` 에서 `initialize()` 반환을 직접 열어보니
`varpro_steps=400` · `n_iters=0` · **`varpro` 기록 존재** · `final_n=30`.
⟹ **학습 경로 + VARPRO = 배포 구성 그대로**이며 `bank_mmse`(성분 수 0)가 아니다.
결과 행의 `n_atoms` 도 세 팔에서 `None`(bank) / 25–30(learned) / 18–30(v2k) 로 갈린다.

## `G-3` (VARPRO 발화) — 없는 키
러너가 `getattr(upd, '_last_varpro', None)` 를 읽었는데 **그런 속성이 없다.**
옳은 출처는 `initialize()` 의 **반환 dict** (`res['varpro']`) 인데 러너가 그것을 버렸다.
직접 확인 결과 **발화했다**: 목적함수 `4.324e-2 → 1.591e-2`(−63.2%), `k_shift` 중앙 0.0416.

## ★★같은 부류가 네 배치 연속이다
W7(노브 오인) · W8(모집단 전제·없는 키) · W10(반올림 상수) · W12(없는 키·정의상 None).
★**공통 원인: 게이트가 "내가 적어 넣은 것" 또는 "있을 거라 가정한 키" 를 검사했다.**
★**처방(누적)**: ① 기준값은 원본에서 **재계산** ② 계측 키는 **실제 반환값을 열어 확인한 뒤** 사용
③ 게이트의 **모집단 전제**(전건/모두)를 먼저 검증 ④ `getattr(..., None)` 폴백을 **게이트에 쓰지 말 것**
(없는 키가 조용히 통과/실패로 둔갑한다).
