## 1. 결정 폐쇄성 — 전수 열거 `[X]`

### 1.1 방법
n=64 부호검정에서 `w1` = `P-1` 승수(0…64), `w2` = `P-2` 승수(0…64) 의 **4,225 조합 전수**에 대해
① §1 헤드라인 문턱(`P-1 ≥41`; `P-2 ≥42 또는 ≤22`)과 ② §1 세 번째 불릿의 Holm-2(족 α=0.05, 정확 이항 p, `Fraction` 정확 산술)
를 각각 적용해 기각 벡터를 비교했다. 재현:

```python
from math import comb; from fractions import Fraction
n=64; T=2**n
p1=lambda w: Fraction(sum(comb(n,i) for i in range(w,n+1)), T)
p2=lambda w: min(Fraction(2*sum(comb(n,i) for i in range(0,min(w,n-w)+1)), T), Fraction(1))
```

### 2.2 `L-VP` — ✅ 구현 가능. ⚠**명세가 부족하고 비용이 신고보다 크다**

#### A. 기울기 — **autograd 로 얻는다. 유한차분 불필요.** `[M]`
- `spectral_gaussian.py:97-103 _omega()` 는 `torch.sqrt(g·k·tanh(k·d))` 로 **전부 미분가능한 torch 연산**이다.
- `recon/probe_varpro.py:44-52 _fc()` 가 이미 그렇게 구현돼 있다:
  `Phi = cat([cos θ, sin θ]); A = ΦᵀΦ + εI; c = torch.linalg.solve(A, Φᵀz)` ⟹
