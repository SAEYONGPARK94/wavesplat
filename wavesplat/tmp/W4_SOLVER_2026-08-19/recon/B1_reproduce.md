## 1. 방법 (내가 새로 쓴 것)

### 1.1 위상 규약 — **항등식으로 검산했다** (질문 1)

전방모델은 `spectral_gaussian.py:118-124` `z = Σ w·cos(kx·x + ky·y − ω·t + φ)`.
전개하면 `w·cos(θ+φ) = (w cosφ)·cosθ + (−w sinφ)·sinθ` ⟹ 기저 `[cosθ | sinθ]` 에서
**`a = w cosφ`, `b = −w sinφ`**, 따라서 **`φ = atan2(−b, a)`** 다.

`B1_varpro_independent.py::selftest()` (N=4, M=500, 무잡음, `numpy`, seed 0) `[M]`:

```
[selftest] LS residual ||Ac-z||        = 6.184e-14
[selftest] recon RMSE, phi=atan2( b,a) = 1.360e+00   (sequential_update.py:1335)
[selftest] recon RMSE, phi=atan2(-b,a) = 1.687e-15   (model/tnse.py:216)
[selftest] max|w_hat - w_true|         = 8.882e-16
```

⟹ ✅**`model/tnse.py:216` 의 `atan2(−b, a)` 가 옳고 `sequential_update.py:1335` 의
`arctan2(b, a)` 는 부호가 뒤집혀 있다** — **W1·W2 와 독립으로 같은 줄에 도달했다**(세 번째 확인).
재구성 잔차 **1.7e-15** = 지시된 ~1e-15 수준.
⚠**내 필드 예측기는 `(a,b)` 를 그대로 쓰므로 이 버그에 노출되지 않는다** — 위 검산은
`(w,φ)` 로 라벨을 옮길 때만 필요하고, `W4 PREREG G-7` 이 요구하는 항등식과 같은 것이다.

### 1.3 VARPRO 구현 (`B1_varpro_independent.py::varpro`)

```
θ_ij(K) = kx_j·x_i + ky_j·y_i − ω_j(K)·t_i ,  ω = sqrt(g|k| tanh(|k| d))   (dispersion 하드제약)
Φ(K)    = [cos Θ | sin Θ]                                    (M × 2N)
c(K)    = solve(ΦᵀΦ + 1e-8·I, Φᵀz)                            # 닫힌형, (a,b) 소거
f(K)    = mean( (z − Φc)² )
```
`torch.float64`, Adam(lr 2e-3), 400스텝, **`kx,ky` 만 requires_grad**. 야코비안은
`torch.linalg.solve` 를 통한 autograd(= Golub–Pereyra) 로 얻는다. **GT 미사용** —
입력은 `get_init_window(2.0)` 의 `(x,y,z,t)` 뿐이다(`varpro()` 시그니처에 GT 인자가 없다) `[M]`.
채점만 `f.gt_field` 를 쓴다.

**표본**: S4 시드 **1557** 1개, 혼잡 16 + 희소 16, 셀 `AUTO-NT`·`ORA-K-NT`(+ 별도로 `ORA-WPHI-NT`).
**집계**: 에피소드 짝, 상대차 `(post−pre)/pre` 의 **중앙**, **단측 정확 부호검정**.
(부호검정이 단측임은 W2 의 p 값에서 역산된다: 14/16 → 0.00209, 15/16 → 2.59e-04, 16/16 → 1.53e-05.)
