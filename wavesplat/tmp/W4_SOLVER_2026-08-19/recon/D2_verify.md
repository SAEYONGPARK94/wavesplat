## 2. D1 과 어떻게 다른가 (독립성의 근거)

D1 코드를 못 봤으므로 "다르다"를 **구조적으로 강제**했다. 두 구현이 같은 답을 내려면
**두 개의 서로 다른 버그가 동시에 같은 방향으로 틀려야** 한다.

| 축 | D2 (`verify_w4.py`) 가 택한 길 | 왜 이게 독립인가 |
|---|---|---|
| 집계 자료구조 | **밀집 `numpy` 큐브** `[arm] → (episode, seed)` · 셸은 별도 3-D `(episode, seed, shell)`. 축은 **정렬된 에피소드 리스트 + 정렬된 시드 튜플**로 색인. dict 중첩·`pandas` 미사용 | 결측이 **NaN 으로 명시적으로 존재**한다. dict 방식의 전형적 오류(키 부재 = 조용한 누락)가 구조적으로 불가능 |
| 셸 집계 | 스칼라 경로를 **재사용하지 않고** 독립 큐브에서 한 번에 채운다 | 스칼라 med3 버그가 셸로 전파되지 않는다 |
| med3 | **손으로 쓴 3-원소 중앙 선택자**(비교 연산만, `sort` 호출 없음) + 매 셀 `numpy.median` 과 대조, 불일치 카운터를 산출에 인쇄 | 같은 라이브러리 호출을 공유하지 않는다 |
| p 값 | **경로 A** = `fractions.Fraction` + `math.comb` 정확 유리수 이항 꼬리. **경로 B** = `scipy.stats.binomtest`. 모든 검정에서 두 값의 최대 편차를 기록(`scipy_xcheck.max_abs_dev`, 1e-12 문턱) | 부동소수 누적오차·라이브러리 규약 차이가 드러난다 |
| 임계값 | **하드코딩하지 않는다.** 정확분포에서 `crit_one`/`crit_two` 를 유도한 뒤 PREREG 동결값과 **대조해 인쇄**(`threshold_selftest`) | 동결 문서의 숫자를 베끼는 대신 **재도출**한다. A-1 이 잡은 "문턱이 두 벌" 결함의 재발 방지 |
| 판정 경로 | **두 경로 병행** — ①p ≤ α ②W ≥ 임계값. 둘의 일치 여부를 `route_agreement` 로 인쇄 | 한쪽 경로의 부등호 실수를 다른 쪽이 잡는다 |
| 게이트 | 행의 `gates_pass`·`gate_fails` 필드를 **믿지 않고** 원자료에서 전부 재계산(G-7 만 `gates.log` 파싱 — 런 전 게이트라 행에 없다) | 러너의 게이트 판정과 분석기의 게이트 판정이 **독립 확인 2건**이 된다 |
| Holm-2 | 일반 Holm 절차(p 오름차순, α/(m−i))를 구현하고 **α 를 각 검정에 실제로 배정**한 뒤 그 α 에서 라벨을 정한다 | "P-2 는 항상 0.025" 같은 고정 배정 실수를 배제 |

**공유하는 것은 규칙 문서와 `results.jsonl` 스키마뿐이다.** 따라서 이 대조가 잡지 못하는 것은
**러너가 잘못된 수를 기록한 경우**다(그건 G-2/G-3/G-5/G-6 계열의 몫이고, D2 도 독립으로 재계산한다).

## 3. `compare_w4.py` — 자동 대조

형식이 다를 것을 전제로 **모양에 무관한 수확기**로 만들었다.

1. 두 JSON 을 재귀 순회해 **승수형 키와 p형 키를 동시에 가진 dict** 를 검정 노드로 본다.
2. JSON 경로 + 자기기술 필드(`label`/`name`/`test`/`id`/`contrast`)를 정규화해
   `P-1 · P-2 · IUT · S-1 · S-2 · S-2b · S-2c · S-3:obs:<셸> · D-4` 로 **정규명**을 붙인다.
3. 비교 대상은 **핵심 수치만**: `W`(정수 완전일치) · `n` · p값 · 라벨/판정 문자열 · MDE 수치.
4. 어느 한쪽에만 있는 이름은 **불일치로 세지 않되** 인쇄한다. 단 **핵심 6검정
   (`P-1·P-2·IUT·S-2·S-2b·S-2c`)이 한쪽에 없으면 불일치로 센다.**
5. 종료코드 0 = 무불일치, 1 = 불일치, 2 = 입력 문제.
   `--dump-labels` 로 양쪽 수확 결과를 인쇄해 이름을 손으로 맞출 수 있다.

**교란 시험 4종으로 검출력을 확인했다**(D1 형식을 흉내 낸 다른 모양의 JSON 사용:
`n_wins`/`n_pairs`/`pvalue`/`call`/`final_call.verdict`):

| 교란 | 결과 |
|---|---|
| 없음 | 0 불일치, exit 0 |
| `P-1` 의 W 를 +1 | **검출** (`*** MISMATCH: W ***`) |
| `P-2` 라벨 `EARNS→INERT` | **검출** |
| `S-2` 의 p 를 ×1.5 (p≈9e-13) | **검출** |

★**이 시험이 내 코드에서 실제 버그 3건을 잡았다**(전부 수정 완료):
1. `\b` 정규식이 **밑줄에서 작동하지 않아**(밑줄은 word character) `P-1`·`P-2`·`IUT`·`S-2*` 가
   **한 건도 수확되지 않았다** — 셸 9개만 잡히고 나머지는 조용히 "없음" 처리됐다.
2. p 비교 허용오차가 `rtol * max(1.0, |a|, |b|)` 라 **1e-9 절대오차**로 굳어졌다 ⟹
   PRIMARY 가 사는 **1e-6~1e-20 영역에서 모든 p 가 서로 같다고 판정**됐다(위 4번 교란 미검출).
3. MDE 비교가 `P-1` 의 MDE 블록과 `P-2` 의 MDE 블록을 **섞어서** 비교해 무교란 상태에서
   **가짜 불일치**를 냈다 ⟹ MDE 잎을 **소속 검정으로 스코프**하도록 고쳤다(PREREG 는 P-2 의 MDE 를
   요구하므로 P-2 스코프 우선, 스코프 없는 블록은 P-2 로 간주).

## 4. 규칙에서 모호했던 지점 (내가 고른 해석 + 근거)

**⛔나는 규칙을 고르지 않았다. 아래는 문서가 답하지 않은 곳이고, 선택을 전부 노출한다.**

1. ★**`결측은 리스트와이즈 제외`(§6)의 적용 층위** — 시드 층인가 에피소드 층인가.
   한 에피소드에서 시드 3개 중 2개만 있으면 (a) med-of-2 로 진행 (b) 그 에피소드를 버림.
   §6 이 *"med3 는 에피소드 수준"* 이라 못박았고 CLAUDE.md 의 처방이 **median-of-k** 이므로
   **(b) 를 기본**으로 했다(`--loose-med3` 가 (a) 민감도). 부분 시드가 하나라도 있으면
   보고서 상단에 경고를 찍고 민감도 재실행을 지시한다. **본런에서 전건 3시드면 이 선택은 무효과다.**
2. ★**`n<56` 게이트의 적용 단위** — P-1·P-2 각각인가 족 전체인가. §5 D-4 는 *"유효 짝"* 이라고만
   한다. **족의 최소값**(`min(n_P1, n_P2)`)으로 판정하고 검정별 n 도 함께 인쇄한다.
3. ★**56 ≤ n < 64 에서의 문턱** — PREREG 는 문턱을 n=64 에서만 고정했다. **p ≤ α 경로를 주(主)로**
   하고(임의 n 에서 정의된다) 임계값 경로는 대조로 병기한다. 두 경로의 일치를 인쇄한다.
4. ★**"원리적으로 평가 불가"와 "실패"의 구분** — 스모크(n=2)에서 IUT 임계값이 존재하지 않는데
   순진한 구현은 이를 **`FAIL`(D-1 사망조건)** 으로 읽어 판정을 죽인다. S6 이 죽은 형태
   (*"n=16·3대조서 13/16 은 원리적 통과 불가"*)와 같으므로 **`NOT-EVALUABLE`** 상태를 따로 두고
   D-1 을 발화시키지 않는다. **n=64 에서는 임계값 41 이 존재하므로 본런 거동은 불변이다.**
5. ★**`S-3` 9셸의 다중성** — §3 은 셸 분해에 보정을 지정하지 않았다. **원 p 를 주로 보고**하고
   Holm-9 를 **민감도로만** 병기했다(`holm9_reject`). ⛔사후에 유리한 쪽을 고르지 않도록 둘 다 인쇄한다.
6. **`S-2c`(양측)의 α** — §3 표가 *"단일 사전등록, 단측 α=0.025"* 라고 적었는데 A-4 가 S-2c 를
   **양측**으로 추가했다. 양측을 **α=0.025**(꼬리당 0.0125)로 읽었다 — 세 SECONDARY 가 같은 α 예산을
   쓰는 것이 §3 의 문면에 가장 가깝다.
7. **`L-MERGE` 의 P1 스텝 예산** — A2-1 표에 `L-MERGE` 행이 없다. G-2 의 **중단 조건에서 제외**하고
   관측값만 인쇄한다(스모크 실측 820 = `L-SHIP` 과 동일).
8. **`P-2` 의 W 방향** — "L-ITER0 이 유의하게 낮다"를 `W = #{L-ITER0 < L-SHIP}` 가 **높은 쪽**으로
   읽었다(≥42 → `OPTIMIZER-HARMS`). 반대로 ≤22 → `OPTIMIZER-EARNS`. §1.1 표의 문면 그대로다.
