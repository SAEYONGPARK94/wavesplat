# RESULT — `W6 · ALS` = ★**`CONTRAST-DOES-NOT-EXIST`** (런 0회)

**사전등록한 실험이 게이트 `G-3` 에서 죽었다.** 그런데 이 사망이 **사전등록이 물으려던 질문에 답한다** —
그리고 답은 우리에게 불리하다. 오늘 **다섯 번째** 런 0회 사망이다.

---

## 1. 물으려던 것
> `L-VP-ONLY`(VARPRO) vs `L-ALS`(= `c` 를 `.detach()` 한 교대 최소제곱).
> **이득의 원천이 "닫힌형 풀이" 인가 "소거를 통과하는 도함수" 인가.**
> `PREREG §2.1`: 후자면 **`DERIVATIVE-MATTERS`** = *"1973 종설의 문장으로는 설명 안 되는 부분이 있다"*.

## 2. 답 — ★**그 구분은 존재하지 않는다**

`G-3` 자기시험(float64, M=400, n=3): VARPRO 와 ALS 의 `k` 기울기를 **중앙 유한차분**과 대조.
| | 유한차분 대비 상대오차 |
|---|---|
| VARPRO autograd | **2.824e-09** |
| ALS autograd | **2.808e-09** |

**두 기울기가 같다.** 시험은 *"ALS 는 달라야 한다"* 를 요구했으므로 **FAIL** 이고, 그 실패가 결과다.

### 2.1 왜 같은가 — 포락선 정리(envelope theorem)
`f(k) = min_c ‖Φ(k)c − z‖²` 이고 `c*` 가 그 최소점이면 **`∂f/∂c|_{c*} = 0`** 이다. 따라서
```
df/dk = ∂f/∂k|_{c=c*}  +  (∂f/∂c)|_{c*} · dc*/dk
                            └────── = 0 ──────┘
```
⟹ ★**"소거를 통과하는 도함수" 는 최소점에서 기여가 정확히 0 이다.** `.detach()` 는 **아무것도 바꾸지 않는다.**

### 2.2 검사가 둔한 게 아니다 — ridge 스윕으로 증명
`c*` 를 참 최소점에서 밀어내는 유일한 항이 ridge 다. 그것을 키우면 차이가 **정확히 비례해서** 나타난다:
| ridge | \|g_VP − g_ALS\| / \|g_VP\| |
|---|---|
| **1e-8 (배포값)** | **3.707e-11** |
| 1e-4 | 3.707e-07 |
| 1e-2 | 3.706e-05 |
| 1 | 3.655e-03 |
| 100 | 1.935e-01 |

⟹ **시험은 민감하다.** 배포 ridge 에서 차이가 **수치적으로 0** 인 것이지, 시험이 못 잡는 게 아니다.

## 3. ⟹ 이것이 novelty 질문에 주는 답
`PREREG §7` 정지 규칙: *"`CLOSED-FORM-SUFFICES`(널)가 나오면 기제 novelty 축을 종결한다."*
**실제 결과는 널보다 강하다** — 널은 *"차이를 못 찾았다"* 이지만 이건 ***"차이가 수학적으로 존재하지 않는다"*** 다.

> ★**VARPRO 의 이득 중 "문헌이 예측하지 않은 부분" 은 없다.**
> Golub–Pereyra 2003 종설이 *"축소 문제가 항상 더 빨리 수렴한다"* 고 적은 그 문장이 **전부**다.
> ⟹ **기제 novelty 축을 종결한다.** P2 의 *"당연하다"* 논증이 문헌 근거를 넘어 **수학으로 확정**됐다.

## 4. ⛔ 이 문서가 주장하지 않는 것
1. ⛔**"VARPRO 가 쓸모없다" 금지** — W5 의 측정(−25.3%, 2.04배, 초기화 3.19배)은 **그대로 유효**하다.
   여기서 죽은 것은 **기제의 새로움**이지 **효과**가 아니다.
2. ⛔**"ALS 를 쓰면 된다" 금지** — 배포 ridge 에서 **같은 것**이므로 갈아탈 이유도 없다.
3. ⛔**ridge 를 키우면 차이가 난다는 것을 처방으로 읽지 마라** — ridge 는 정규화이지 자유 노브가 아니다.
4. **범위**: 이 판정은 **목적함수의 수학**에 대한 것이고 코퍼스·레짐과 무관하다. ⟹ **더 넓다.**

## 5. ★남는 것 (novelty 축이 닫힌 뒤)
· **배포 가치** — 더 정확(−25.3%) · 더 빠름(2.04배) · **초기화 3.19배**(26.81 → 8.47 s, 64/64) ·
  프레임 갱신 **8.90 ms**(제어 제약 100 ms 안).
· **영역 주장** — *"해양공학에서 VARPRO 가 쓰인 적이 없고, 이 문제에서 그것이 맞는 방법임을
  사전등록 개입으로 보였다"*(P1 의 논거, `Li et al. 2013 Geophysics` 가 수사적 선례).
· **음성 기록**과 **측정 체계**.
⛔**"기제가 새롭다" 는 이제 못 쓴다.**
