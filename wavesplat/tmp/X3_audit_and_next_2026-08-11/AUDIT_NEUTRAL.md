**수준(레벨)의 중앙**을 뺀 값이다. 중앙은 가법적이지 않으므로 규약을 바꾸면 값이 달라진다.

| 규약 | 희소 방법 | 희소 **학습** | 혼잡 **방법** | 혼잡 학습 |
|---|---|---|---|---|
| 수준 중앙의 차 (인용된 값) | +104.1% | **−4.1%** | **−21.2%** | +121.2% |
| **짝 Δ 의 중앙** (S9 승계 규약) | +95.5% | **−0.2%** | **−36.2%** | +136.2% |
| 짝 Δ 의 평균 | +92.5% | **+7.5%** | **−17.7%** | +117.7% |

- ★**희소 "학습 몫" 은 규약에 따라 부호가 뒤집힌다**(−4.1% → +7.5%).
- ★**혼잡 "방법 몫" 은 −17.7%~−36.2% 로 2배 움직인다** ⟹ 인용된 −21% 는 점추정이 아니다.
- ⚠짝 Δ **중앙**은 합이 100% 가 되지 않는다(희소 95.2%) — 중앙의 비가법성 때문이다.
  ⟹ **분해 자체가 이 지표에서 항등식이 아니다.**
- 이 프로젝트는 같은 결함으로 이미 네 번 물렸다(`feedback_prespecify_aggregation_and_direction`).
  ⟹ ⛔**분해 % 를 숫자로 인용 금지**. 허용 = *"희소는 거의 전부 방법, 혼잡은 거의 전부 학습"* 정도의
  **정성 진술**, 또는 규약을 사전에 못 박고 다시 계산.

## 2. ②-a 집계 공정성 — bank 의 시드 앙상블 `MEASURED` + `ARGUED`

| | 가우시안 팔 | bank 팔 |

| 배치서 쓴 시드 | 1575 / 1576 / 1577 | 42 / 1042 / 2042 |
| 결합 방법 | **스칼라 3개의 중앙** (독립 3회 실행) | **필드 3개의 점별 중앙** (1회 실행) |
| 에피소드당 표본 | 3 | **1** |

- `MEASURED` `fit_bank_mmse` 는 전역 RNG 를 쓰지 않는다(`bank_mmse.py:138` `default_rng(seed)` 하나뿐)
  ⟹ X1 은 결정적이고 재현 가능하다. 그리고 seed 42 는 `run.py:69 DEFAULT_CONFIG['seed']=42`,
  오프셋 (0,1000,2000) 는 `sequential_update.py:819` 와 **동일** ⟹ X1 = **배포 기본 구성 1회**.

  이 프로젝트는 가우시안 추정기 CV 를 **최대 53%** 로 문서화했고(`ESTIMATOR_VARIANCE_RESULT_2026-07-23.md`,
  `run.py:497-513`) 그 처방이 median-of-3 이다. **bank 의 시드 분산은 이 배치에서 측정되지 않았다.**
- `MEASURED` **가우시안 쪽 시드 잡음의 크기**(X2 원자료, 에피소드 안 3시드):
  상대범위 중앙 **희소 83.1% · 혼잡 21.9%**, CV 중앙 40.2% / 11.4% (최대 166.9% / 37.4%).
  ⟹ 혼잡에서 시드 잡음은 `V2K − bank` 상대격차(+11.3%)와 **같은 자릿수**다.
  실증: 같은 16 혼잡 에피소드를 **중앙-3시드**로 재면 `V2K − bank` = 7/16 **+0.01005**,
  **단일 시드 1575** 로 재면 9/16 **−0.00091** (§3.4).
- `MEASURED` ★**기제는 이미 코드에 적혀 있다** — `initializer.py:710-718`: `v2_konly` 는 v2 가 이미
  최소자승으로 맞춘 (w, φ) 를 **버리고 φ 를 균일 난수로 다시 뽑는다**
  (*"the measured source of the bimodal run-to-run variance (CV up to 53%)"*).
  ⟹ **`V2K` 는 이 아크에서 확률적 입력이 가장 큰 팔**이고, bank 에는 그 난수 draw 자체가 없다.
- `[UNVERIFIED]` **bank 쪽** 시드 분산의 크기. 재실행 없이는 알 수 없다.
  ⟹ **판정**: 집계는 *불공정하다고 단정할 수 없지만* **대칭이 아니며, 비대칭의 크기가 미측정**이다.

## 3. ②-b ★교락 정량화 — **가장 중요**

### 3.1 추적 유무 — S9 `AUTO-NT` 로 추가 런 0 `MEASURED`

`AUTO-NT` = `tracking_lr=0` ⟹ Phase-1 적합 후 **모델 동결, 순수 전방 예보**.
구조적으로 bank(1회 적합 후 동결 렌더)와 **같은 형태**다.

| 대조 | 희소 n=64 | 혼잡 n=32 |
|---|---|---|
| `AUTO-NT − AUTO` (추적 제거, λ 동일 1e-3) | **63/64 개선**, −0.00733 (**−40.94%**), p=7e-18 | **24/32 개선**, −0.01899 (**−11.27%**), p=0.007 |
| `AUTO-NT − bank` | **63/64 개선**, −0.13862 (−93.13%) | **29/32 개선**, −0.05160 (−19.83%), p=2.6e-06 |

★**교락의 방향이 메인 세션의 서술과 반대다.** BRIEF 는 *"bank 는 추적 없이 1회 적합, 가우시안은
매 프레임 추적"* 을 bank 에 **불리한** 조건처럼 적었으나, 이 표본에서 **추적은 가우시안을 나쁘게
만든다**. 즉 가우시안 팔은 bank 가 지지 않는 **핸디캡을 지고** 비교됐다.

**상한(추가 런 0)** `MEASURED` + `ARGUED`
- 혼잡 `V2K − bank` 격차 = **+0.02062**(V2K 가 나쁨).
- 같은 표본의 추적 제거 효과(출하 팔) = **−0.01899** ⟹ 격차의 **92.1%** 크기.
- ⚠**이것은 상한이지 점추정이 아니다.** `AUTO-NT` 는 **학습 라우팅된 팔**의 추적 제거다
  (혼잡 96런 중 87런이 `learned`). `v2_konly` 팔에서 같은 크기인지 이 자료는 말하지 않는다.
  ⟹ **§3.4 에서 직접 쟀고, 상한은 1.6–2.9배 과대였다.** (이 감사의 자기정정)
- 희소는 반대로 **교락을 제거해도 격차가 그대로**다(`AUTO-NT − bank` 63/64, −93.1%)
  ⟹ 희소의 `vs bank` 우위는 추적 교락에 **의존하지 않는다**. (⚠3.2·3.3 교락은 별개)

### 3.2 앙상블 유무 — 라우트 층화로 추가 런 0 `MEASURED`

`AUTO` 는 라우터가 `v2_konly` 를 고를 때**만** median-of-3 을 만든다(`sequential_update.py:1497`).
`V2K` 는 항상 앙상블 없음(§4). ⟹ **라우트로 층화하면 교락을 분리할 수 있다.**

| 층 | 희소 | 혼잡 |
|---|---|---|
| 3시드 전건 `learned` (앙상블 차 **없음**) | **27/45 개선**, −22.87%, p=0.233 | **0/27 개선**, +58.09%, p=1.49e-08 |
| 3시드 전건 `v2_konly` (**앙상블만 다름**) | 0/5, +40.88% | 0/1, +5.64% |
| 혼합 | 6/14, +3.10% | 0/4, +12.13% |

- **지배 층(희소 45/64, 혼잡 27/32)에서는 양쪽 다 `ensemble_k=1`** ⟹ 앙상블 교락 **없음**.
- 앙상블만 다른 층은 표본이 **5개·1개** 로 결론 불가지만 **부호는 5/5·1/1 로 앙상블 쪽 승리**
  = 문서화된 median-of-3 의 목적(나쁜 모드 제거)과 부합. 방향상 이 교락은 **V2K 를 나쁘게** 만든다
  ⟹ 희소 주장 A(널)에 대해 **보수적**이다.
- ⟹ **앙상블 교락은 A·B 의 부호를 뒤집지 않는다.** (그래도 라벨은 틀렸다 = B-1)

### 3.3 프레임 8:1 서브샘플 — 직접 측정 `MEASURED`

X1 의 `run_one` 을 그대로 재현하되 **전 프레임**을 채점했다(레짐별 8 에피소드 = 16,
결과 관측 전에 고정한 규칙: 시드 48–51 × BF4/BF5 × 희소 2comp / 혼잡 15comp).

| | 희소 n=8 | 혼잡 n=8 |
|---|---|---|
| `mean(전 160/120 프레임)` 중앙 | 0.1309 | 0.1865 |
| `mean(::8)` 중앙 | 0.1300 | 0.1868 |
| **서브샘플 편향** `(::8 − 전체)/전체` 중앙 | **+0.14%** | **−0.11%** |
| 편향 범위 (16 에피소드) | \[−1.23%, +0.77%\] | 위와 같은 범위 |
| 절대 Δ 중앙 | +0.00028 | −0.00014 |

**두 가지가 나온다.**

1. ★★**X1 을 비트 단위로 재현했다** — `max |mean(::8) − X1 값| = 0.000e+00` (16/16).
