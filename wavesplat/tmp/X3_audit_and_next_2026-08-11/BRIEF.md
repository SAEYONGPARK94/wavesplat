## 1. 검증 대상 — X1/X2 가 주장하는 것

권위 = `tmp/X1_bank_on_synth_2026-08-11/`(`probe.py`·`result.json`) ·
`tmp/X2_no_learned_2026-08-11/`(`run_x2.py`·`results.jsonl`, 288런 에러 0).
비교 기준 = `tmp/S9_lr_x_l1_2026-08-11/results.jsonl`. **같은 96 에피소드(시드 48-63).**

같은 96 에피소드, 중앙 nRMSE(÷Hs):
| | 희소 n=64 | 혼잡 n=32 |
|---|---|---|
| `bank` (운용 추정기, X1) | 0.1581 | 0.2137 |
| `V2K` (가우시안, **학습 제거**, X2) | **0.0105** | **0.2255** |
| `AUTO-L1` (가우시안, 학습 포함 = 현 출하 기본값, S9) | 0.0163 | 0.1583 |

**주장 A (희소)**: 학습 기여 ≈ 0. `V2K vs AUTO-L1` **33/64, p=0.90 = 널**.
  `V2K vs bank` **61/64, p<1e-6**. ⟹ "방법 자체가 우수".
**주장 B (혼잡)**: 학습이 전부. `V2K vs AUTO-L1` **0/32, p<1e-6, Δ +0.0776**.
  `V2K vs bank` **12/32, p=0.215 = 무승부**. ⟹ "방법 자체는 이득 없음".
**주장 C**: 실측은 혼잡형이고 학습은 실측서 실패(21/30 열세) ⟹ **bank 라우팅이 옳았다**,
  그리고 **실측의 핵심 레버 = 학습의 실측 전이**.

### 메인 세션이 **스스로 아는** 교락 (감사가 확대·추가할 것)
- `bank` 팔은 **1회 적합 후 렌더**(추적 없음)인데 가우시안은 **매 프레임 추적**.
- `bank` 팔만 프레임 **8:1 서브샘플**(렌더 비용). 나머지는 전 프레임.
- `V2K` 는 `init_method='v2_konly'` + `analytic_ensemble_k=3`(앙상블 유지) ⟹ **학습만 제거**한
  것이 맞는가? `X-BASE` 를 피한 이유는 그것이 학습+앙상블을 동시에 제거하기 때문.
- `bank` 는 **관측-전용 파라미터화**(`sigma0=0.05·4·std(z)`), 가우시안은 아니다.
- X1 의 `depth`·격자·Hs 출처가 S9 러너와 **같은지** 미확인.

## 2. 감사가 답해야 할 것 (①검증)
1. ★**주장 A·B 를 독립 코드로 재도출**하라(승계 규약: 에피소드당 3시드 중앙 / 짝 Δ / 부호).
   숫자가 틀렸으면 **재도출값 병기**.
2. ★**교락을 정량화**하라. 특히 **추적 유무**가 bank 비교를 얼마나 설명하는가?
   (힌트: S9 에 `AUTO-NT`= 추적기 off 셀이 **이미 있다** — 추가 런 0 으로 상한을 잡을 수 있다.)
3. **`V2K` 가 정말 "학습만 제거"인가?** `init_method='v2_konly'` 가 실제로 무엇을 끄는지
   코드로 확인하고, 앙상블·라우터·기타 차이가 남아 있는지 판정하라.
4. **주장 C 의 근거**(실측 21/30)를 원자료에서 확인하고, "실측=혼잡형"이라는 전제가
   **측정으로 뒷받침되는지** 판단하라(성분수·스펙트럼 폭 등으로).
5. ⛔이 결과로 **말할 수 없는 것** 목록을 만들라.

## 3. 감사가 답해야 할 것 (②다음 배치)
메인 세션의 제안: **"혼잡에서 가우시안의 이득은 전적으로 학습에서 온다"를 사전등록 확증.**
1. 이 확증이 **결정에 영향을 주는가?** (E1 이 "결정 무관"으로 죽은 전례) 무엇이 바뀌는가?
2. 사전 통과확률·필요 n·비용. **이미 0/32, p<1e-6 인데 확증이 새 정보인가?**
3. ★**더 나은 다음 질문이 있는가?** 후보:
   (a) 학습을 실측 분포로 전이(재학습/미세조정) — ⚠[[feedback-mixed-training-directive]] 준수
   (b) bank 팔에 추적/롤링 refit 을 붙여 **공정 비교** 후 라우팅 재검토
   (c) 합성에 **스웰을 넣어** 운용범위 내 혼합 바다를 만들고 재측정
   (d) 초기 적합 **21.7 s(합성) vs 1.0–1.3 s(실측) 20배 차이** 규명 — 운용 지연 여유 문제
4. **돌리지 말아야 할 이유가 있으면 1번으로.**
