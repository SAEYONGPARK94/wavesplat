## 2. 시스템 정의

**후보 C ∈ {auto_v1_m3, auto_v3_m3}**: lane별 라우터(출하값 th=8, guard 은퇴)로
`n_selected(ep, ds) ≥ 8` → learned lane(v1/v3, 1차와 동일 프로토콜·하네스) / `< 8` → v2_m3 lane.

**v2_m3 스펙 — 정본은 `run_v2m3.py`이며 본 문단은 요약이다 (레드팀 C6)**:
lane (es, ds)에서 est seed {es, es+1000, es+2000}로 표준 v2_konly 추정 3회 독립 실행,
프레임별 예측 표고장의 **원소별(pointwise) median**을 앙상블 예측으로 삼아 표준 metric
코드로 채점. `TRACK_PHASE_PREDICT=False`, `init_method='v2_konly'` 명시.
- **k=3은 07-23 median-of-k 처방의 사전값**이다. 특성화 런(소비된 confirm40) 결과로 k를
  최종 확정하며([K 기입]), 그 근거(후보 k 전체의 수치)를 §3에 공개한다. 동결 후 변경 없음.
- **err 규칙 (레드팀 C6)**: err로 기록된 lane은 **최종**이며 재실행하지 않는다(보수적 =
  P1c 위반으로 계수). 인프라 사유 재시도가 불가피하면 원본 jsonl 보존 + 사실·원인·전후 값을
  RESULT에 전량 공개. 채점기는 (episode, est_seed, diff_seed) 중복 행 발견 시 즉시 중단.

**팔 (실행 3개 + 추출 1개, 각 40ep × 5 lane [(42,0),(1,1),(2,2),(3,3),(4,4)], 대표값 median-of-5)**

| 팔 | 방법 | 용도 |
|---|---|---|
| `learned_v1`, `learned_v3` | 1차와 동일 | 후보 조립 |
| `v2_m3` | 위 스펙 | 후보 조립 폴백 + **P3 기준선** |
| `v2` (단일시드) | **v2_m3의 member[0]에서 추출** — 별도 실행 금지(I1 bit-identity 인증, 레드팀 R6) | **P0·P2·P4·P5 기준선** + 1차 연속성 |

## 3. 하드 바

**2단 기준선의 이유 (레드팀 C1)**: m3는 로버스트화가 아니라 **다른 추정기**다(특성화 프로브:
혼잡에서 모든 멤버보다 좋아짐, 기제 = 과분산 억제 VR 1.43→0.95). 무해 바(P0/P2/P4/P5)의
반사실 = "오늘 출하 중인 것"(v2 단일시드, 1차와 문자 동일 바), 가치 바(P3)의 반사실 =
"가장 강한 분석 대안"(v2_m3). 측정된 δ = mean(v2_m3) − mean(v2), 슬라이스별: [δ표 기입].

| 바 | 정의 | 기준선 |
|---|---|---|
| **P0 스펙 무해 (신설, 레드팀 R2)** | v2_m3의 슬라이스별(전체·희소·5comp·2comp·혼잡) mean이 어느 슬라이스에서도 v2 +0.005 초과 악화 없음 | v2 |
| **P1c 조립 안전 (유일 구속절)** | 후보의 희소(1·2comp 16ep) 단일-lane max ≤ 0.10 | — |
| P1a 파국 (진단 하위절) | 희소 에피소드-median > 0.10 = 0건 | — |
| P1b 학습팔 안전 (진단 하위절) | 후보가 learned로 라우팅한 희소 lane max ≤ 0.10 | — |
| **P2 비열등** | 전체 40 mean ≤ v2 +0.005 AND pairedΔmedian(C−v2) ≤ +0.002 | v2 |
| **P3 혼잡 증분 가치** | 혼잡 16 mean ≤ v2_m3 −0.03 AND 개선(vs v2_m3) ≥ 12/16 | **v2_m3** |
| **P4 5comp 무해** | 5comp mean ≤ v2 +0.005 | v2 |
| **P5 2comp 무해** | 2comp mean ≤ v2 +0.005 | v2 |

**논리 관계 (레드팀 C3)**: P1c ⟹ P1a ∧ P1b. P1a/P1b는 귀속·진단용이며 단독 FAIL 조합은
존재하지 않는다. 배포 여부는 실질적으로 P0·P1c·P2-P5가 결정한다.

**P1c 사전 실패확률 (레드팀 C2c — 알고 유지한다)**: 1차 실측(희소 불량 lane 3/80,
에피소드 클러스터형 p_e≈0.4) 기반 산출 [모델별 수치 기입: 균질/베타이항/부트스트랩,
k=3 및 채택 k]. 현행(v2 단일시드)의 동일 바 실패확률 [수치 기입]. 우리는 이 수치를 알고
이 바를 유지한다. p_e≈0.4 클러스터 에피소드에는 median-of-k가 근본 처방이 아님을 인지한다.

**P3 사전 투영 공개 (사후조작 방지)**: 임계값 −0.03은 1차에서 동결했던 수치를 그대로 쓴다
(기준선만 v2→v2_m3로 강화). 소비된 1차 데이터 기준 투영: [v1/v3 각 마진 기입 — v3가
투영상 FAIL이어도 임계값을 조정하지 않고 공개한 채 동결한다].

## 4. 판정 규칙 (동결)

1. 한 후보만 P0·P1c·P2-P5 전부 PASS → 그 후보 배포.
2. 둘 다 PASS → 혼잡 paired에서 auto_v1_m3 ≥ **11/16** 우위(동률은 v1 승리로 불계수)면 v1,
   아니면 v3. **기록(레드팀 R3)**: 1차 측정값이 정확히 11/16이었음을 알고 있으나 이 규칙은
   1차 판정에 사용되지 않았으므로(P1 FAIL로 무의미) 미사용 규칙을 값 변경 없이 재동결한다.
   검정력: H0(동등) 통과확률 0.105, 진효과 p=0.6875에서 0.618 — 이는 통계적 재현 판정이
   아니라 **결정 규칙**이며, 어느 쪽이 뽑히든 "다른 후보보다 우월" 문장을 금지한다.
3. 둘 다 FAIL → 배포 없음, 현행 유지. 하위 분기:
   - **P1c FAIL 시 귀속 우선 (레드팀 R4-i)**: 위반 lane 소속을 먼저 보고 — 학습팔 lane이면
     "후보 불량"(재학습 재개), v2_m3 폴백 lane이면 "스펙 불충분"(median-of-5를 연장 사다리
     1515/1616으로 별도 사전등록). 귀속 없이 §6 문구 발효 금지.
   - P1c·P3 동시 FAIL이면 P1c 귀속을 먼저 적용 (R4-ii).
   - P0 FAIL → 후보 판정과 무관하게 NO_DEPLOY(사유: 스펙) — m3는 배포 스펙 자격 상실.
   - P2/P4/P5만 FAIL → 혼잡 전용 스코프(th=12) 축소안을 별도 사전등록으로 (1차 규칙 유지, R4-iii).
4. **후보 간 P1c 결과가 갈리는 경우 (R4-v)**: 라우팅 차이로 한쪽만 불량 폴백 lane을 우회한
   것이면 그 차이는 정확도 근거가 아니다 — tie-break·우위 주장에 불사용, 원인 lane 명시 보고.
5. **무결성 게이트 (판정 전, 레드팀 C4·R5 반영)**:
   - I1 (하드): k=1 ≡ 표준 v2_konly bit-exact — 완료(Δ=0.000e+00, 2ep+위치독립 4건).
     커버리지 확장(R7): lane (4,4) × 희소/혼잡 각 1ep 추가 확인 [결과 기입].
   - I2 (보고 전용, 게이트 아님 — R5): 1차 불량 3 lane 수리 확인(0.195→0.015, 0.137→0.029,
     0.144→0.091) + **무해 방향**(정상 lane 각 4개 비악화 + VR 변화) [결과 기입].
     결과와 무관하게 스펙 불변.
   - I3 (분리, C4): (a) **갱신 경로 하드 게이트** — m3 프레임당 ≤ 100ms: **19.7ms 측정 PASS**
     (`--workers 1` 무부하 조건 재확인 [기입]). (b) 초기화 경로는 1회성 비용으로 예산 밖 —
     k=1 대비 배수·절대값만 보고(게이트 아님): 22s → 66s 직렬(3코어 병렬 시 ≈1회분).
     (c) 초기화 3배의 운용 수용성은 배포 결정의 별도 항목, 본 실험 미판정.
   - **I1/I3(a) FAIL 시 실험 중단, 신선 40ep 미소비** (§1 발효 시점 규칙).
6. 사후 바 변경·재실행·lane 추가 없음.

## 6. 사전공약 문구

- 전부 PASS: "P1 재정의 + median-of-3 폴백으로 {C}가 신선 표본 전 바 통과 — 배포 인가
  (실측 경로는 별도 게이트 유지). 단 tie-break로 뽑힌 후보에 '우월' 표현 금지."
- P1c FAIL(폴백 귀속): "median-of-3은 폴백 분산을 신선 표본에서 잡지 못했다 — 배포 보류,
  median-of-5를 연장 사다리로 별도 사전등록."
- P1c FAIL(학습팔 귀속) 또는 P1a FAIL: "파국/학습팔 안전 미재현 — 배포 금지, 재학습 재개."
- **P3 FAIL (레드팀 C1 교정 문구)**: "혼잡에서 학습팔의 **증분** 가치가 분석 앙상블(v2_m3)
  대비 −0.03에 미달했다(단일시드 대비 마진 [X] 병기). 이는 '혼잡 가치 미재현'이 아니라
  '분석 대안이 강해졌음'일 수 있다 — 두 기준선 마진을 병기하지 않은 인용을 금지한다."
- P0 FAIL: "m3 스펙이 무해 바를 깨뜨렸다 — 스펙 자격 상실, NO_DEPLOY(사유: 스펙)."
- 공통: pooled 단일수치 헤드라인 금지, "학습이 더 정확" 무조건형 금지 유지.
