## 3. 지표 · 열화 방향 · 집계 · MDE ★ (규율 #1 — 이 표를 못 채우면 돌리지 않는다)

### 3.1 집계 (고정)
1. 셀 × 에피소드마다 3시드의 **중앙값** → per-episode 값 (지표별 독립 중앙값)
2. **짝별 차** = (처치 − 대조 A) 를 에피소드마다
3. 보고 통계 = **짝별 차의 중앙값** (n=12). 평균은 보고하지 않는다.
4. 시드 잡음자 = 에피소드 내 3시드 range(max−min); 12에피소드 중앙값을 `seed_range_median` 으로 병기

### 3.2 검정
* **양측 정확 부호검정** (n=12). 바닥 p = 2·(1/2)¹² = 0.00049 ⟹ **α=0.05 가 이 n 에서 가능하다.**
* 유의 경계: **10/12 → p = 0.0386** (9/12 → 0.1460 = 미달, 11/12 → 0.0063, 12/12 → 0.00049)
* Wilcoxon signed-rank (n=12) 도 병기하되 판정 근거는 부호검정 + 효과크기.

### 3.3 ★ MDE 표

* **MDE(부호 축)** = **10/12 일관 부호**. 그보다 약한 것은 α=0.05 에서 구별 불가.
  이 규칙의 검정력: 참 P(+)=0.85 → 0.736, 0.90 → 0.889, 0.80 → 0.558.
* **MDE(크기 축)** = `0.8881 · σ_d` (paired-t, 80 % 검정력, α=0.05 양측, n=12).
  `σ_d` 는 **사전에** S1-A0 대조팔(혼잡 4ep × 3시드, `tmp/s1s2_2026-08-05/results.jsonl`)의

  `σ_d = √2 · 0.67 σ̂`.

### 3.4 배치 프로브의 MDE (§5)
프로브는 **결정적**이다 (RNG 는 `n_found < n_gaussians` 일 때의 패딩에만 들어가며 seed=42 고정).

0.125 · 0.0156 · 0.0625 ⟹ **혼잡 4ep 와 통제 5ep 층에서는 α=0.05 가 원리적으로 불가**. 병기한다.

## 4. 사전 확정 판정 규칙

PRIMARY = `init_nrmse`, PRIMARY 대비 = **D vs A**.

| 판정 | 조건 |
|---|---|
| **PASS** | 짝별 차 중앙값이 **개선 방향** ∧ \|중앙값\| > MDE(0.0262) ∧ 부호 ≥ 10/12 |
| **WEAK** | 개선 방향 ∧ (부호 ≥10/12 XOR 크기 > MDE) |
| **미탐지** | \|중앙값\| ≤ MDE ∧ 부호 < 10/12 — ⛔ "NULL"·"효과 없음"으로 쓰지 않는다 |
| **HARM** | **열화 방향**으로 PASS 조건 충족 |

부수 대비 (전부 **SECONDARY, 다중비교 보정 없음, 기술적**):
* **B vs A** — 요인 1 단독 (FINDING 의 맨 처방)
* **C vs A** — 요인 2 단독
* **요인 1 주효과** = median over ep of ½[(B−A)+(D−C)]
* **요인 2 주효과** = median over ep of ½[(C−A)+(D−B)]
