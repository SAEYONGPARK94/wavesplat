## 2. ★ 바꾸는 요인: **3개** (`STEP`, `RADIUS`, `MINSEP`) + 부수 대비 1개(`COVERAGE`)

⛔ **단일 원인 이름 금지.** 아래 각 요인이 **정확히 무엇을 움직이고 무엇을 고정하는지** 명시한다.

### 2.0 ★ `MIN_DK` 단위 확인 — **런 전 코드 검증 완료 (질문 (2))**

[MEASURED, 코드 독해 3 site 전부] 억제는 **격자 칸 수**로 환산된다. rad/m 절대값이 아니다:

```
wavesplat/optimizer/initializer.py:517      suppress_kx = int(min_dk / dkx) + 1
wavesplat/optimizer/coarse_to_fine.py:213   suppress    = int(min_dk / dkx) + 1
wavesplat/optimizer/sequential_update.py:1045 suppress  = int(min_dk / dkx) + 1
```
`power[iy-sup : iy+sup+1, ix-sup : ix+sup+1] = 0` ⟹ **실효 절대 반경 = `(int(MIN_DK/dk)+1) · dk`**.

| 설정 | dk | `int(0.15/dk)+1` | **실효 절대 반경** |
|---|---|---|---|
| WIDE(−4,4), n=81 | 0.1000 | 2 | **±0.200** |
| WIDE(−4,4), n=61 | 0.1333 | 2 | **±0.267** |
| WIDE(−4,4), n=401 | 0.0200 | 8 | **±0.160** |
| NARROW(−0.8,0.8), n=81 | 0.0200 | 8 | **±0.160** |

⟹ **E1 이 "격자 단위"라고 한 것은 옳다.** ⟹ 격자를 건드리면 억제 반경이 **따라 움직인다** = E1 의 교란.

★**직교화 방법 (구현상 중요)**: 실효 반경이 `c·dk` (c = 칸 수) 이므로, **원하는 절대 반경 R 을
얻으려면 `MIN_DK` 를 `(c−0.5)·dk` 로 두면 된다** (`int((c−0.5))+1 = c`).
⟹ **프로덕션 산술을 한 줄도 바꾸지 않고** 절대 반경을 고정할 수 있다.
⚠ **단 R 은 격자 스텝의 정수배로만 표현된다** ⟹ **R < dk 는 원리적으로 표현 불가**.
그래서 R 의 두 수준은 **둘 다 거친 스텝(0.100)에서도 표현 가능한 값**으로 고른다: **R ∈ {0.200, 0.100}**.
(R=0.02 는 스텝 0.100 에서 표현 불가 ⟹ 2×2 에 넣으면 직교가 깨진다. 넣지 않는다.)

⟹ ★**M 은 "간격 강제" 하나가 아니라 위 3개를 동시에 움직인다. 단일 원인 이름 금지.**

## 4. ★ 사전 확정 판정 규칙 — **두 축, 그리고 갈릴 때**

### 4.1 배치 PRIMARY
`probe detection_rate @ n_g=15`, 짝별 차 중앙 (동점 제외), 개선 방향 = 증가.

**배치 SENTINEL** `placed_nn_p10` 이 **감소(더 겹침)** 하면 배치 PASS 라도 **"겹침 대가 동반"** 을 병기한다.

### 4.2 필드 PRIMARY
`init_nrmse`, 짝별 차 중앙, 개선 방향 = 감소.
