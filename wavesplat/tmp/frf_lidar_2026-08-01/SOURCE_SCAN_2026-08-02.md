# 실측 파랑 데이터 소스 체계 스캔 (2026-08-02)

사용자 지시("놓친 게 있을 것") 후 축을 넓혀 조사. **우리 공백 = 2D 개구 + 이동 플랫폼 +
심해 레짐 + 검정력.** 각 소스를 그 4항목으로 채점했다.

## 0. 결론

**그 4항목을 동시에 만족하는 공개 데이터셋은 찾지 못했다.** 남은 최선의 후보 두 개는
모두 **다운로드가 아니라 사람에게 연락**해야 하는 것들이다. 이 스캔 자체가 논문의
data-availability 진술로 쓸 수 있는 자산이다(§4).

## 3. 남은 최선 후보 두 개 — 둘 다 "연락" 트랙

**(a) Scripps MASS** — 우리 요구를 가장 잘 만족한다.
RIEGL Q680i 스캐닝 파형 LiDAR, 수직정확도 2–3 cm, **항공 이동 플랫폼**, 심해 캠페인
(SOCAL 등), 방향 파랑 스펙트럼을 명시 목적으로 함. **다운로드 경로 없음** — Air-Sea
Interaction Lab(UCSD) 직접 연락이 유일 경로.

**(b) ERDC 플래시 LiDAR** — 센서 개념이 우리와 동일(3D 수면).
Public Release 문서이므로 데이터 요청 가능성 있음. FRF WaveShape와 같은 기관이라
접촉 창구가 하나로 묶인다.

⚠ 둘 다 **응답 보장이 없고 리드타임이 길다.** 메인 큐를 세우고 기다릴 대상이 아니라,
지금 메일을 보내놓고 **병렬로 다른 일을 하는** 대상이다.

## 4. ★ 이 스캔 자체가 자산이다

프로그램은 이미 "공개된 희소 선박탑재 LiDAR 위상분해 데이터셋은 없다"를 니치 근거로
기록해 뒀다(`ref_paper/_DATASETS` 판단). 오늘 스캔은 그 진술을 **체계적 조사로 승격**한다:
- 조사한 축: 국가 아카이브(NOAA/NASA/USACE), 해상풍력(AMETS/BrightHub), 학술 저장소
  (SEANOE/PANGAEA/Zenodo), 대체 센서(X-band 레이더), 실험시설(수조).
- 결과: **2D 개구 + 이동 플랫폼 + 심해**를 동시에 만족하는 **공개** 데이터셋 0건.

⟹ 논문 Data Availability / Related Work에 **"이 조합의 공개 데이터가 존재하지 않는다"**를
근거와 함께 쓸 수 있다. 이는 (i) 스테레오 대체 사용의 정당화이고 (ii) 수조 실험의
필요성 논거이며 (iii) 니치 주장의 뒷받침이다. **세 곳에서 동시에 값을 한다.**

## 5. 권고

1. **오늘 메일 2통**(Scripps MASS · ERDC) — 비용 0, 리드타임 김. 병렬로 진행.
2. **스캔 결과를 논문 자산으로 전환** — Data Availability 문단 초안. 이게 즉시 값이 나오는 유일한 항목.
3. **NASA ATM은 보류** — 극지 해빙 레짐이라 우리 BF2–5와 어긋난다. 단
   ATM 초기(pre-IceBridge) 대양 비행이 있는지는 미확인 — 저비용 후속 확인 항목.
4. **메인 큐 복귀** — 논문 전파 2단계·R7. 데이터 사냥은 여기서 수확 체감이다.

⛔ 이 문서는 어떤 성능 주장도 하지 않는다. §2 표의 판정은 사양·메타데이터 기준이며,
실제 사용 가능성은 데이터를 받아 검사해야 확정된다(FRF에서 두 번 정정한 교훈).
