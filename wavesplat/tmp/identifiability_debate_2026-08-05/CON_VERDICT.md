## 0. ★내 논거 2건 자진 폐기 (먼저 적는다)

### 0.1 폐기 ①: "2×2 (N∈{30,90} × M∈{1,3}) 면 within 주효과와 예산 주효과를 동시에 뽑는다"

**틀렸다. 이 2×2 는 계수 부족(rank-deficient)이다.** (`CON_design_and_power.py` §b)

설계행렬 `[절편, log N, log n_freq, within유무]`, 4셀:

| 셀 | 절편 | log N | log n_freq | within |
|---|---|---|---|---|
| (30,1) | 1 | 0 | 0 | 0 |
| (30,3) | 1 | 0 | −1 | 1 |
| (90,1) | 1 | 1 | +1 | 0 |
| (90,3) | 1 | 1 | 0 | 1 |

- **rank = 3 (열 4개 중)** · 영공간 방향 **[0, −1, +1, +1]**
- ⟹ **β_within 은 (β_nfreq − β_N) 과 정확히 별칭(aliased)**. 4셀에서 3개를 분리할 수 없다.
- 원인은 2×2 가 나빠서가 아니라 구조 제약 `n_freq = N // M` 그 자체다.
  **(N, M) 만 손잡이인 어떤 설계도 같은 특이성을 갖는다.**
- 보조 확인: n_freq=30 고정 사다리(N=30/60/90/300, M=1/2/3/10)에서
  **corr(log N, within σ₁) = +0.878** ⟹ 여기서도 교락.

⟹ **이 항목은 PRO 가 옳다.** 세 번째 손잡이 없이는 못 뽑는다.

### 0.2 폐기 ②: "빈 개수를 독립 파라미터 n_freq 로 빼는 패치가 탈출구다"

**두 번 틀렸다.**

1. **패치가 필요 없다.** HEAD 코드가 `n_freq = n_components // dirs_per_freq` 이므로
   **N=90 · M=3 이 이미 n_freq=30** 이다. 브리핑이 요구한 대조쌍은 **지금 바로 생성 가능**하다.
2. **그런데 그 대조는 깨끗하지 않다.** 아래 §1 에서 잰다 — 격자는 진짜로 같지만
   **N 이 3배, 성분당 진폭이 정확히 1/√3, 실현 총확산이 24.18°→29.29°** 로 함께 움직인다.

⟹ 진짜 탈출구는 **n_freq 축이 아니라 각도 축**이다. (§2)

### 0.3 폐기 ③: 내 첫 사다리는 오늘 S4 설계보다 **나빴다**

"생성 분산을 σ_a²+σ_w²=30² 로 고정" 하는 소박한 방식은 실현 총 σ₁ 이
**24.32° → 27.62° (+13.6 %)** 로 흘렀다. 오늘의 A→B 는 **24.18→24.41 (+0.9 %)** 로 훨씬 잘 보존했다.
내 사다리는 **에피소드별 σ_a 수치해**를 넣은 뒤에야(§2) S4 를 이긴다.

## 2. ★탈출구는 각도 축이다 — 깨끗한 대조가 **존재한다** (MEASURED)

### 2.1 구체적 패치 형태 (**구현하지 않음**)

현행(261–266행)은 사실 **1-모수 슬라이스**다: `θ_i ~ i.i.d. N(μ, σ²)` 이므로
빈내 산포 std = σ, 빈평균 산포 std = σ/√M ⟹ **σ_across = σ_within/√M 이 강제**된다.
(확인: N=90,M=3,knob 30 → within 22.96 / across 15.11, 비 1.52 ≈ √3.)

```python
def jonswap_components(..., dirs_per_freq: int = 1,
                       within_spread_deg: Optional[float] = None,   # NEW
                       across_spread_deg: Optional[float] = None):  # NEW
    ...
    # n_freq (196행) 과 per_bin (199-200행) 은 이미 존재한다.
    phases = rng.uniform(0, 2*np.pi, n_components)          # 순서 유지 = 위상 비트 동일

    if within_spread_deg is None:                            # 기본값 경로 = 무변경
        directions = rng.normal(dir_rad, spread_rad, n_components)   # 비트 동일
    else:
        if dirs_per_freq == 1:
            raise ValueError('within_spread_deg is inert at dirs_per_freq=1 '
                             '(the within term is 0 by algebraic identity); '
                             'silently accepting it would produce a dataset that '
                             'looks manipulated and is not.')        # peak_locked 가드와 같은 문체
        g = np.random.default_rng(10_000 + seed)   # ★사다리 전용 스트림: 같은 seed 면
        a_std = g.standard_normal(n_freq)          #   모든 rung 이 같은 표준정규 추출을 공유
        w_std = g.standard_normal(n_components)
        bin_idx = np.repeat(np.arange(n_freq), per_bin)
        directions = (dir_rad
                      + np.deg2rad(across_spread_deg) * a_std[bin_idx]
                      + np.deg2rad(within_spread_deg) * w_std)
```

- `within_spread_deg=None` 이 **기본값** ⟹ 프로덕션 100 ep **비트 동일**(추출 순서 무변경).
- 현행 모형은 새 모형의 **특수해**(σ_a = σ_w/√M) ⟹ 엄밀한 일반화.
- 실측 근거: depth3 이 잰 실측 D(θ,f) 는 **within 29.54° > across 21.78°** ⟹ σ_w > σ_a 영역이
  실측 레짐인데, 현행 i.i.d. 추출은 그 영역을 **표현할 수 없다**. i.i.d. 가정에 실측 대응물이 없다.
- 총확산 정합은 **생성기 밖 래퍼**로 한다(프로덕션 오염 방지): 아래 §2.2.

### 2.3 ⚠이 사다리를 무너뜨리는 사실 (필수 기재)

1. **σ_w = 0 rung 은 퇴화한다.** 빈 안 3개 원자가 ω·k 방향까지 같아지면 **결맞음 합**이 되어
   유효 자유도가 30 으로 떨어지고 빈 에너지가 Rayleigh 무작위가 된다. ⟹ **저단 rung 은 σ_w=0 이 아니라
   σ_w=4°(within 3.03°) 를 써야 한다.** 그러면 모든 rung 이 M=3 구조를 공유한다.
2. **총확산을 24.18 에 묶으면 within 은 ~16° 에서 막힌다** (σ_a=0 에서도 total 이 목표를 넘어
   σ_w≥24 는 비가용). **실측 29.28° 는 이 사다리로 도달 불가.** 실측 레짐은 총확산 목표를 ~35°
   로 올려야 하고, 그러면 arm A 와의 총확산 정합이 **다시 깨진다** ⟹ **두 개의 별도 설계**가 필요하다.
   (도달 자체는 가능: σ_w=32/σ_a=24 → within 25.01 / across 25.85 / **total 34.57** vs 실측 35.35.)
3. **에피소드별 σ_a 수치해는 생성 파라미터를 실현 추출에 조건화한다.** 성능 측정 전이므로 p-hacking 은
   아니지만 **사전등록 필수**이고, σ_w≥20 에서 **1/12 시드가 비가용** ⟹ 시드 폐기 규칙을 미리 못박아야 한다.
4. **arm A 의 "총 σ₁ = 24.18" 은 넓은 구름의 중앙값이다** — 시드별 실현값이 **20.02 / 22.19 / 24.18 /
   26.23 / 41.71°**. 중앙값에 맞추는 것은 넓은 분포의 한 점에 맞추는 것이다.
5. **`lambda_min` 보고값은 arm A(21.761 m)와 사다리(35.973 m)가 다르다.** 이건 물리 차이가 아니라
   `var ≥ 1 %` 유지집합의 인공물이다(원자 에너지가 1/3 이라 짧은 성분이 문턱 아래로 떨어짐).
   물리적으로 관련된 양(ω별 빈 에너지)은 **비트 동일**이고 `var_under_resolved` 는 양쪽 **0.0000**.
   그래도 S4 가 A/B 정합에 쓴 통계량과는 **다르게 나온다** — 정합 기준을 미리 바꿔 선언해야 한다.
6. **공짜가 아니다.** arm A 승계 불가(N 이 다름) ⟹ 전 rung 신규 생성. S4 는 10 ep / 29 분이었고
   N=90 은 성분 루프가 3배 ⟹ **2 rung × 17 시드 ≈ 34 ep ≈ 2.5 h** 규모.
7. **한 셀은 여전히 한 셀**이다(BF4·uniform·Tp 7 s). 이 사다리는 식별가능성을 사고 일반화를 사지 않는다.

**단 PRO 쪽에 절반은 돌려준다** — C 는 within=0 인데 같은 자릿수의 열화를 냈으므로

그래서 RESULT §7 의 ⛔문구("within 에 귀속되지 않는다")는 **정확하다.**
틀린 것은 본문 §4.3 의 **"귀속 실패가 측정됐다"** 다 — 귀속은 **측정된 적이 없다**.
권고 문구: *"이 설계로는 귀속을 검정할 수 없었다(B−C 검정력 7 %, 90 % CI [−0.014, +0.036])."*

## 5. ★S4 가 선언하지 않은 교락 1건 — arm C 의 **비선형성** (MEASURED, 신규)

## 6. 방어 가능한 문구 (그대로 인용 가능)

- ✅ "현행 생성기의 손잡이 집합 `(n_components, dirs_per_freq, direction_spread_deg)` 안에서는
  주파수내 확산 효과가 **식별 불가능하다** — (N, M) 만으로 만든 2×2 는 계수 3/4 로 특이하고,
  β_within 은 (β_nfreq − β_N) 과 별칭이다."
- ✅ "그 식별 불가능성은 물리가 아니라 **한 줄의 구현 선택**(전 성분 i.i.d. 방향 추출)에서 나온다.
  방향 추출을 2수준(빈평균 + 빈내)으로 바꾸면, **N·n_freq·M·성분당 진폭·실현 총확산을 고정한 채**
  within σ₁ 을 3.03° → 16.15° 로 움직이는 대조가 성립한다(12 시드, 총 σ₁ 오차 ≤ 1.3e-4°)."
- ✅ "현행 i.i.d. 추출은 σ_across = σ_within/√M 을 강제하는 1-모수 슬라이스이며,
  실측 D(θ,f) 가 사는 σ_within > σ_across 영역(depth3: 29.54° vs 21.78°)을 표현할 수 없다."
- ✅ "오늘의 PRIMARY 는 **검정력 부족**이다: 관측 중앙값 0.030 에 대해 n=5 부호검정 검정력 0.478,
  80 %에 필요한 n 은 부호검정 11 · 짝 t 7 (관측 평균 0.0175 기준이면 28 · 17)."
- ✅ "LETKF 5/5 의 귀속은 **미판정**이다: B−C 의 90 % CI 가 [−0.014, +0.036] 으로 0 과 효과 전체를
  동시에 포함하고, 격차 0.0024 를 가르는 검정력은 7 % 다.
  성립하는 것은 존재 진술뿐 — **within=0 인 arm 도 같은 자릿수의 열화를 낼 수 있다.**"
- ✅ "arm C 는 선언된 2개(N·총확산) 외에 **총 Gerstner 가파름 −28.5 %** 라는 세 번째 교락을 갖는다."

## 7. ⛔ 이 문서에서 금지되는 것

- ⛔ "2×2 (N,M) 로 within 을 분리할 수 있다" — **rank 3/4 로 반증. 내가 만들었다 폐기했다.**
- ⛔ "n_freq 를 독립 파라미터로 빼는 것이 탈출구다" — 그 대조쌍은 **패치 없이 이미 가능**하고,
  **깨끗하지 않다**(N ×3, 성분당 진폭 ×1/√3, 총확산 24.18→29.29).
- ⛔ "제안한 사다리가 **실측 레짐**을 잰다" — 총확산 24.18 에 묶으면 within 은 **16.15° 에서 막힌다**
  (실측 29.28° 미달). 실측 레짐은 **별도 설계**이고 그때는 총확산 정합이 깨진다.
- ⛔ "within 사다리를 지금 돌릴 수 있다" — **패치 + 사전등록 + 34~84 신규 에피소드**가 먼저다.
  본 문서의 어떤 수치도 **성능 측정이 아니다**(성분 대수 + 오늘 원자료 재계산뿐).
- ⛔ "S4 설계가 나빴다" — S4 의 총확산 보존(+0.9 %)은 내 소박한 사다리(+13.6 %)보다 **좋았다**.
  S4 는 **자기 손잡이 집합 안에서 최선**을 했다. 부족했던 건 설계가 아니라 **손잡이 개수**다.
