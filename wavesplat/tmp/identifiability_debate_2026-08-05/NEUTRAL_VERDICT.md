## 2. ★교락(confound) vs 처치의 일부(part of the treatment) — 정면 판정

**판정: "처치의 일부"라는 방어는 정당하다. 그러나 그것을 인정하는 순간 S4 의 성능 런은

- **N_gen** — 바다를 렌더링하는 wavelet 수 (생성기 손잡이)
- **N_est** — WaveSplat 이 지불하는 성분 수 (`final_n`, 관측 가능)

novelty 후보 (B) *"이산 성분집합은 방향확산에 성분을 지불해야 한다"* 는 **추정기의 모델 클래스**에

추정대상을 확정하면 갈린다:

| 추정대상 | n_freq↓ 의 지위 | 결과 |
|---|---|---|
| **E1** "**바다**의 주파수내 확산이 추정기에 무엇을 하는가" | N_gen 은 렌더링 잡음모수 ⟹ F↓ 는 **교락**, 제거해야 함 | S4 설계는 **교락됨** |

⟹ "교락을 제거하라"가 "가설을 측정에서 빼내는 것"이 되는가? — **E1 에서는 아니다**(제거해야 옳다).
   **E2 에서는 그렇다. 그러나 E2 는 실험이 필요 없다.**

⚠ **단 이것도 교락은 그대로다** — arm B 는 F 도 30→10 으로 바뀐다("서로 다른 주파수가 적어져서

## 3. ⓑ 코드 판정 — `wave_generator.py`

### ⓑ-1 주파수 격자는 `n_components` 에 **묶여 있지 않다**(분리 가능) ⟹ **(i) 거짓**

`n_freq`(L196)는 **함수 로컬 파생 정수**다. `omegas`(202)·`omega_centers`·`d_omega`·`S`·
`amplitudes`·`ks` 가 n_freq 크기로 만들어진 뒤 `np.repeat(..., per_bin)`(256–258)로 n_components 로
펼쳐진다. `phases`(261)·`directions`(266)는 처음부터 n_components 크기로 독립 추출된다.
함수 밖에서 `n_freq` 를 보는 코드는 **없다**(`wavesim/config.py:68` 의 `n_freq=64` 는
`compute_spectrum_1d` 용 **스펙트럼 분석 빈 수**로 무관, 이름만 충돌).
⟹ **시그니처 파라미터 1개 + 한 줄**이면 (F, M) 을 독립 손잡이로, N=F·M 을 파생값으로 만들 수 있다.
그러면 **(F, M) 요인설계**로 F 주효과와 M 주효과를 분리 추정할 수 있다.

### ⓑ-2 ★더 큰 발견 — **생성기에는 `D(θ|f)` 가 아예 없다.** arm B 는 within 을 **만들지 않았다**

```
L266:  directions = rng.normal(dir_rad, spread_rad, n_components)   # 빈 구조 없음, i.i.d.
L256:  amplitudes = np.repeat(amplitudes / np.sqrt(per_bin), per_bin)  # 빈 내부 진폭 동일
```
빈 내부 가중치가 균일(1/M)하고 방향이 빈과 무관하게 i.i.d. 이므로,
`manip_check` 의 **r1_within 은 (M, 방향분포)만의 범함수**다 — **주파수 지표가 어디에도 안 들어간다.**
(에너지 가중치는 방향 추출과 독립이므로 E[r1_within] = E[r1_bin] 이 **정확히** 성립. 시뮬 결과가 아니라 증명.)

**P1 수치 확인**: 주파수를 아예 쓰지 않고 i.i.d. 방향 30개를 3개씩 임의 분할 → within = **23.92°**.
arm B 실측 5시드 = 19.37 / 20.05 / 20.74 / 25.47 / 31.85 (평균 **23.50°**). **일치.**

⟹ ★**arm B 의 "주파수내 확산"은 i.i.d. 표본의 재라벨링(relabelling)이다.**
   A→B 의 물리적 차이는 "주파수내 확산 도입"이 아니라 **"성분 수 고정하에 주파수 격자 조대화(30→10) + 진폭 /√3 재분배"**다.

## 4. 검정력 + 귀속 실패의 **지위**

### 4.1 이 설계가 놓칠 수 있었던 것

MDE 0.0470 = **arm A 수준의 15.3 %**. 검정력: 0.131(¼MDE) / 0.336(½MDE) / 0.477(관측 크기) / 0.801(MDE).

교정용 눈금 — 이 프로그램이 실재로 다룬 효과들: 적응형-N 전체 논쟁 효과 **0.3 %** · A1 분산제약 +0.091 ·
arm C −0.132(**43 %**) · 위상수정 −42.5 %.
⟹ **이 설계는 arm C 급 효과만 볼 수 있다.** 부호검정 선택 자체도 대가가 있다(t 의 MDE 0.0365, **−22 %**) —
다만 t 로 해도 여전히 NULL 이므로 **부호검정 탓만은 아니다.**

### 4.2 ★n=5 두 개로 "귀속 실패"와 "arm C 가 우연히 같은 크기"를 가를 수 있는가 — **없다**

시드 짝을 맞춘 LETKF nRMSE **B−C** = (B−A) − (C−A):

| | 값 |
|---|---|
| 짝별 | +0.0562, +0.0035, +0.0024, +0.0077, **−0.0131** |
| 중앙 / 평균 | +0.0035 / +0.0113 · **4/5 양수** |
| 부호검정 일측 p | **0.1875** · t p₂ = **0.39** |
| **평균 B−C 의 90 % CI** | **[−0.0137, +0.0364]** |

★**상한 +0.0364 는 B−A 중앙값(+0.0097) 전체의 3.8 배**다. 즉 데이터는
**"C 가 B 를 전부 설명한다"와 "B 의 효과가 C 의 4배다"에 똑같이 부합**한다.
"C 가 같은 크기를 재현했다"는 **동등성(equivalence) 주장**인데 **동등성 검정은 수행된 적이 없고,
n=5 에서는 수행할 수도 없다.**

⟹ **지위 정정: 측정된 것은 "귀속 실패"가 아니라 "귀속의 근거 부재"다.**
   `MEASURED` 태그가 잘못 붙었다. (허용 문장: *"이 데이터는 B 의 LETKF 이동을 within 에 귀속할
   근거를 주지 않는다"* / ⛔ *"귀속 실패가 측정됐다"*)

### 4.3 ★내부 모순 — 같은 뺄셈이 한 문단에서 금지되고 다른 문단에서 판결로 쓰인다

- RESULT §4.4: *"`B−A = (C−A) + within효과` 같은 뺄셈을 **하지 말 것**"*
- RESULT §4.3: 바로 그 뺄셈을 **말로 수행**해서 귀속을 죽인다 (*"C 가 거의 같은 크기를 재현 ⟹ 귀속 불가"*)

금지가 옳다(C 는 N 30→10, F 30→10, total 24.2→16.7° 를 **함께** 바꾼다). 그렇다면 §4.3 도 성립하지 않는다.
⟹ **통제되지 않은 변수를 가로지르는 비교를 기제 주장으로 승격** — 이 프로그램의 4회 재발 오류의 **언어판**.
   (⭘ 공정 기록: RESULT §5 는 같은 종의 오류를 **스스로 잡아 철회**했다 — "중앙값의 중앙값 아티팩트",
   `k_mag 3배 악화` 철회. 규율은 작동하고 있고, §4.3 만 통과했다.)

### 4.4 SECONDARY 5/5 자체의 취약성

LETKF B−A 평균 +0.0203 = **수준의 9.0 %**. 그러나 시드 0(+0.0529)이 끌고 있고 나머지 넷은
+0.0081…+0.0228 로 전부 미세하다. RESULT §6.5 가 기록하듯 **LETKF 는 필터 시드 1개(42)**,
median-of-3 로 눌리지 않았다. **조대해진 주파수 격자가 만드는 미세한 계통 편향**이면
이 패턴이 정확히 나온다. Bonferroni 후 family-wise p=0.125 는 RESULT 가 이미 옳게 기록했다.

artefact" 는 정확-ω 비닝에서만 참이고, 그 비닝은 바다에 적용된 적이 없다.**
⟹ **M=1 로도 N≥60 이면 계측기가 정의하는 의미의 주파수내 확산이 생긴다.** `dirs_per_freq` 를 만질 필요조차 없다.
⟹ 그리고 이것이 **진짜 식별 문제**다: **(coarse-F, M>1)과 (fine-F, M=1)은 생성기 안에서는 다른 물체지만
a1/b1 계측기에는 관측적으로 동등하다.** 실제 바다의 밴드 내 확산도 연속체에서 오는 것이므로 계측기는
둘을 구별하지 못한다. **식별 불가능성은 설계 공간이 아니라 추정대상의 정의에 있다.**

⭘ 공정 기록: `depth3_ceiling` 의 원래 주장(**측정된** D(θ,f) 를 밴드당 방향 1개로 이산화하면 across 항밖에
못 나른다, 21.78° / 대역 내 18.45° vs 실측 36.77°)은 **여전히 옳다** — 그것은 *주어진 측정 스펙트럼의
충실 재현*에 관한 주장이다. 다만 그 주장은 "밴드당 1방향"을 뜻하고, **N≥60 의 이 생성기는 밴드당
1방향이 아니다.** 그래서 그 천장은 "이 생성기는 within 을 못 만든다"로 **전이되지 않는다.**
