## 1. ★사전 지정 집계 규약 (결과 보기 전 고정) — 08-05 규율

- **PRIMARY**: `nRMSE`(짝별 델타 중앙, vs X-BASE)

## ★★내 사전등록 §0 의 동기 문장이 **인용금지 항목이었다** (자진 철회)
> ~~"⚠**그냥 끄면 안 된다**: `X-A0-notrack` 은 **+0.0072 악화**"~~

**내 손으로 사전등록의 동기 문장에 집어넣었다.** 철회하고, 동기는 아래 ①로 교체한다.

## ★★★① 레버는 벌점이 아니라 **변위 예산**이다 (attack 5: LANDS)
`tracking_steps 10 → 1` 이 **λ₁·λ_smooth 를 출하값 그대로 둔 채** 손상의 **87% 를 4/4 로 제거**
(medΔ **−0.0894 = MDE 의 3.3배**). `tracking_mode='phi_only'` 는 **98%**.
손상은 **변위 예산(steps × lr)의 완전 단조 함수**:
`1.0 / 0.5 / 0.25 / 0.1 / 0 → 회복 0 / 8 / 27 / 87 / 105 %`, **Spearman 1.000**.
★찬성측 자신의 D4·D8 도 **벌점을 유지한 채** 57%·39% 를 회수했는데 **그 두 칸이 K1–K5 에서 빠져 있었다**.
⟹ ★**"원인은 정규화 항"은 이 설계로 귀속 불가.** λ 를 0 으로 만드는 것과 **스텝을 줄이는 것이
같은 결과를 내며**, 둘을 가르는 대조가 K1–K5 에 없다.
✅**노브 추가: K6 = `tracking_steps`, K7 = `tracking_lr`** (2×2 요인과 직교하게 단일 스윕).
✅반대가 자기 후보를 스스로 죽였다: `S2-T1f` vs `S2-T4` 가 **12/12 소수 12자리 동일**
⟹ 오라클에서 **적응형-N 은 발화조차 안 한다**(prune/grow 는 탐색공간 밖).

## ★★② 배포 지점에서는 효과가 사라진다 (attack 1: LANDS)
오라클 **+0.1027 (12/12)** vs 배포 **−0.0074 (2/4, p=1.000)** = **13.9배 차이**,
배포 효과는 **MDE(0.0147)의 절반**.
오라클 init **0.0629** 는 최선의 **배포 가능** init(**0.2438**)보다 **3.88배** 정확하고,
E1 의 **최고 배치 개입조차 그 격차의 31.8%** 만 메운다.
수축모형 독립 재도출 `harm = 0.1230 − 0.4361·init` (R²=0.872, 토론 G 와 독립 일치)
⟹ **배치가 도달 가능한 어디서든 상금은 MDE 근처**.
★**단위 혼동 정정**: "WS−LETKF 격차의 5.0배"는 **틀렸다** — 같은 작동점에서는 **0.27배이고 부호도 반대**.
★"추적기가 배치 이득의 52% 를 먹는다"는 회귀 기울기 **b=0.564 와 같은 수**(독립 사실이 아니다).

## ★③ "손실의 77–92%가 정규화" 도 오라클 전용이었다 (attack 2: PARTIAL)
1,600 스텝 전수 계측: **값 84.0% / 기울기 40.5% / 실제 Adam 변위 11.5%**(⟹ **7.3배 과대**),
`cos(g_reg, g_tot)` 중앙 **+0.10**. 그리고 **"77–92%" 자체가 오라클 전용** — **배포에서는 20–38%**.
⚠단 D2p2(−88%, 3/3)가 살아 있어 **인과성 자체는 반증되지 않았다**.

## ④⑤ 나머지

⟹ *"추적기가 오라클 잔차의 주범이고 제거 가능하다"* 는 **참**이다.
깨진 것은 **그 양이 배포에서도 같다는 암시**와 **원인이 정규화로 특정됐다는 주장**뿐이다.
