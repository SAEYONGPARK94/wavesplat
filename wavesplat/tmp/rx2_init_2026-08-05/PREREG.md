## 0. 왜 이것이 1순위인가 (전부 MEASURED, 오늘)
오늘 하루 동안 **다른 모든 후보가 배포 작동점에서 NULL 로 죽었다**:
- **추적기**: 배포에서 완전 정지해도 `ΔnRMSE = +0.0000`(2/4, p=1.000). 오라클에서는 −0.0955(4/4)였다
- **격자 해상도**: 81 → 401 로 5배 촘촘히 해도 `nRMSE` **6/12, p=1.000**
- **성분 예산**: 검출률을 1.000 으로 올려도 `nRMSE` **−6%** 뿐(S1)
- **가지치기/성장**: 오라클에서 **12/12 소수 12자리 동일** = 발화조차 안 함
- **최소 간격 강제**: `U1M2 ≈ U1`, 무변화

**남은 것은 초기화 하나다**:
- 오라클 init **0.0629** vs 배포 가능한 최선의 init **0.2438** ⟹ **3.88배**
- 그 격차를 메우면 혼잡 `nRMSE` **0.2667 → 0.1671** 이고 **LETKF 를 4/4 로 앞선다**
- 지금까지의 **최고 배치 개입조차 그 격차의 31.8%** 만 메웠다
⟹ ★**이 프로그램에서 큰 상금이 남아 있는 자리는 여기뿐이다.**

## 1. ★사전 지정 집계 규약 (결과 보기 전 고정) — 08-05 규율 승계
- **주 통계량 = 짝별 델타의 중앙값**(에피소드 짝짓기). 방법별 차이의 중앙값 **아님**
- **부호 규약**: `nRMSE`·`init_nrmse`·`Hs_error`·`amp_rel_error` 작을수록 좋음 /
  `rho`·`skill` 클수록 좋음 / ★**`VR` 은 프레임별로 `|VR−1|` 계산 후 평균**(평균 후 변환 아님)
- **부호검정 = 양측**, `k/n` + p 동시 보고
- **시드**: 각 셀 **median-of-3**, 원장 **[1518–1818]** 에서 소비하고 소비분을 기록
- ★**`init_method` 를 전 셀에 명시**(W9 규율). 오라클 팔은 `oracle`, 배포 팔은 `v2_konly`

## 2. ★★두 작동점 필수 (Rx-1 의 교훈)
Rx-1 은 **오라클에서만 재서** −0.10 을 얻었는데 배포에서 **0.00** 이었다.
⟹ **모든 셀을 배포 배치(`v2_konly`, 사다리 [3,8,15])에서 반드시 재고**,
오라클은 **상한 표시용**으로만 병기한다. **배포 팔이 PRIMARY 다.**

## 3. 사전 지정 결과변수
- **PRIMARY**: `init_nrmse`(초기화 직후) **및** `nRMSE`(최종) — **둘 다 사전 지정**
  (오늘 배운 것: 초기화가 좋아져도 최종이 안 움직일 수 있고, 그 역도 가능하다)
- **SECONDARY**: `rho` · `|VR−1|` · `Hs_error` · `skill`
  ⚠**유효 결과가족은 3개**(`r(|VR−1|, Hs_error)=+0.934` 는 정의상 중복,
  `|r(nRMSE, rho)|`=0.94–0.98) ⟹ 다중성 계산은 **m=3**
- **기제 변수**: `m = (1−ρ²) + (√v−ρ)²` 프레임별 분해 — **탈상관 축과 수축 축을 분리 보고**

## 4. 방향 무관 사전 공약
- ★**초기화가 개선돼도 최종 `nRMSE` 가 안 움직이면 그대로 보고한다.** 오늘 그런 셀을 여럿 봤다
- ★**어떤 개입이 `nRMSE` 를 개선하면서 `|VR−1|` 를 악화시키면 그대로 보고한다** —
  토론 J 가 확립한 "부호 반대인 두 하위축"이 초기화 개입에서도 나오는지가 관심사다
- ★**전 셀 NULL 이면 그대로 보고한다.** ⛔단 그것을 *"초기화가 원인이 아니다"* 로 읽지 않는다 —
  **MDE 를 먼저 계산해 적고**, 검정력이 부족하면 NULL 은 **부재의 증거가 아니다**
- ⛔ 이 실험만으로 **기본값을 flip 하지 않는다**

## 5. 범위 / 알려진 한계 (사전 기재)
- **합성 전용**. 실측 전이는 이 실험의 범위 밖
- 혼잡 에피소드 n 이 작다 ⟹ **MDE 를 실행 전에 계산해 적는다**.
  n=4 양측 부호검정 바닥 **p=0.125** ⟹ ⛔**α=0.05 도달 불가, "유의" 금지, 셀 간 서열 주장 금지**
- ⛔**묶음 개입에 단일 원인 이름 금지**(이 프로젝트 재발 1위, 누적 5회).
  둘 이상을 동시에 바꾸면 **교차 셀을 따로 두고 상호작용을 명시 보고**한다
- ⚠**`detection_rate` 를 배치 품질 지표로 쓰지 않는다** — 한점-쌓기 널을 못 넘는다.
  쓸 경우 **같은 `n_est` 의 널을 반드시 병기**하고, `kx,ky` 를 덤프해 소급 재분석을 가능하게 한다
