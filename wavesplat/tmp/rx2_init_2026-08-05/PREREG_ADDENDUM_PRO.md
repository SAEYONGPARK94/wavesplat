## 1. ★ 왜 이 지렛대들인가 (코드 독해, 새 런 0건)

배포 사다리 `[3,8,15]` 는 원자를 **세 군데**서 놓는다:

| site | 원자 수 | 격자 | 잔차를 빼는가 | 위상 |
|---|---|---|---|---|
| `initializer.initialize_from_frames_v2` | **3** | 81 | ✅ **뺀다** (`z_residual -= amp·cos(ph)`) | `KONLY_RANDOM_WPHI` ⟹ U(0,2π) |
| `coarse_to_fine._beamform_residuals` | **12** | 61 | ❌ **안 뺀다** | `GROW_RANDOM_PHI` ⟹ U(0,2π), **적합 위상 폐기** |
| `sequential_update._adaptive_prune_grow` | 성장분 | 61 | ❌ **안 뺀다** | U(0,2π), **적합 위상 폐기** |

★**발견 1 (코드)**: 배포 원자의 **12/15 는 뺄셈 없는 greedy 로 놓인다.** 같은 잔차에 대해
`_beamform_refine` 과 `_linear_projection` 을 반복 호출하고, 파워맵의 `MIN_DK` 상자만 0 으로
만든다. 초기화기(3원자)는 뺀다. ⟹ **두 site 가 서로 다른 알고리즘을 쓴다.**
E1 의 `PEAK_SELECT_MODE` 는 `initialize_from_frames_v2` 안에서만 읽히므로 **이 결함에 닿은 적이 없다**
(E1 사전등록이 "지렛대 3/15" 로 스스로 공개했다).

★**발견 2 (코드)**: 두 잔차 site 는 `amp, _ = _linear_projection(...)` 로 **이미 계산한 위상을 버리고**
새 난수를 뽑는다. 진폭은 쓰면서 위상만 버린다.

★**발견 3 (사전 반증거리)**: 오라클 팔(S2-T1f)은 `w=0.01`, `φ~U(0,2π)` **난수 그대로**인데
`init_nrmse=0.0629` 를 낸다. ⟹ **위상 시딩(axis W)의 천장은 원리적으로 낮다.**
그래도 재는 이유는 "배치가 틀렸을 때는 다르다"가 시험 가능한 별개 주장이기 때문이다.
**W 가 NULL 이면 그것은 예측된 NULL 이며, 나는 그 예측을 지금 적어둔다.**

★**발견 4 (기존 데이터가 이미 배제한 것)**: "초기화기가 15개를 다 놓게 하라"(단일 스테이지)는
**이미 반증됐다** — S2-C1(`v2_konly`, N=N_gt, 1스테이지, 900스텝)이 `init_nrmse` **0.2852**로
출하 0.2612보다 **나쁘다**. ⟹ 사다리(적합→잔차→추가)가 실제로 일을 하고 있다.
그래서 axis S 는 "사다리를 없애기"가 아니라 **"사다리를 더 촘촘히/더 늦게"** 로 잡았다.

**버린 지렛대와 이유**
* `PAD_W` — `n_found < n_gaussians` 일 때만 발화, 배포는 n=3 이라 사실상 미발화. 지렛대 없음.
* 예산 증액(`max_n`, 스테이지 천장) — S1 이 이미 쟀고 토론 J 가 ⛔ 처리. 재판정하지 않는다.
* GT-free best-of-k 재시작 — 사전등록 검정 **이미 FAIL**(`tmp/RESTART_SELECTION_RESULT_2026-07-23.md`).
  집계가 이미 median-of-3 시드다. 중복.
* `init_k_lr_scale` 배포 적용 — 배포는 k 가 틀려 있으므로 동결은 **정의상 해롭다**(S2-T1f 의 이득은
  참값 동결에서만 나온다). 단일요인으로 해석 불가.

| 셀 | 바꾸는 것 (딱 하나, 명시) | 지렛대 |

| **P3** | P2 **＋** 억제 반경 `MIN_DK`→`RECOMPUTE_MIN_DK`(0.15→0.02) | 12/15 |
| **W1** | `KONLY_RANDOM_WPHI=False` (초기 3원자에 적합 w·φ) | 3/15 |
| **W2** | 성장 원자에 **적합 φ** 사용(난수 대신) | 12/15 |

| **G1** | coarse 탐색 범위 `(−4,4)`→`(−0.8,0.8)` **3 site 전부** = E1 셀 B 복제 | 15/15 |
| **G1P1** | ★**묶음** = G1 ＋ P1 | 상호작용 보고 |

**P1→P2→P3 은 한 번에 하나씩 더하는 사다리다.** 분리된 증분은 P1, (P2−P1), (P3−P2).
**G1P1·G1P3 은 묶음이라고 이름표를 붙였고**, 상호작용 = (G1Px − X-BASE) − (G1 − X-BASE) − (Px − X-BASE)
를 반드시 함께 보고한다. ⛔묶음에 단일 원인 이름을 붙이지 않는다.

⚠**S1 의 사전 공개 교란**: 스테이지가 5개가 되면 각 스테이지의 스텝이 200/200/500 → 180×5 로
재배분된다. 총 스텝 900 은 고정이지만 **N=15 구간이 받는 스텝은 500→180 으로 준다.**
이 교란은 S1 의 **양성을 약화시키는** 방향이므로 S1 이 개선되면 보수적, 악화되면 귀속 불가다.

## 3. 사전 지정 결과변수 · 집계 (상위 PREREG §1·§3 승계)

1. 셀×에피소드마다 **3시드 중앙값** → per-episode 값 (지표별 독립 중앙값)
2. **짝별 차** = (셀 − X-BASE) 를 에피소드마다
3. 보고 통계 = **짝별 차의 중앙값** (n=4) + `k/n` + **양측 정확 부호검정 p**
4. `|VR−1|` 은 **프레임별로 계산 후 평균** (드라이버 `absVR_framewise`). 평균 후 변환 금지
5. **기제 분해**: 프레임별 `m = (1−ρ²) + (√v−ρ)²`, `decorr`·`shrink` 를 **따로** 보고
6. **격차 회수율** (사전 고정 정의):
   `closure_e = (init_nrmse[X-BASE,e] − init_nrmse[cell,e]) / (init_nrmse[X-BASE,e] − init_nrmse[ORACLE,e])`
   per-episode 로 계산 → **중앙값 + k/4**. ⛔pooled 평균끼리 나눈 비율은 부수로만.
* **PRIMARY** = `init_nrmse` **및** `nRMSE` (둘 다). **SECONDARY** = `rho` · `absVR_framewise` ·
  `Hs_error` · `Skill_Score`. 유효 결과가족 **m=3**.

## 4. ★ MDE — **결과를 보기 전에 계산해 적는다** (`MDE_prespec.json`)

* **부호축**: n=4 양측 정확 부호검정 **바닥 p = 0.125** ⟹ ★**α=0.05 원리적 도달 불가.**
  ⛔이 실험의 어느 문장에도 **"유의"를 쓰지 않는다.** ⛔**셀 간 서열을 주장하지 않는다.**
  MDE(부호) = **4/4 일관 부호**.
* **크기축**: 짝지음 t, 양측 α=0.05, 검정력 80%, n=4 ⟹ **MDE = 2.1279 · σ_d**
  (비중심 t 로 수치해; 근사식 아님).
  plug-in `σ_d` 는 **저장된** S1-A0 혼잡 4ep 시드 range 에서: `σ̂ = range_med/1.693`,
  `SD(median-of-3) = 0.6698·σ̂`, `σ_d = √2 · 0.6698 · σ̂`.
