### 1.1 ★짝짓기가 우연이 아니라 구조적이다 (MEASURED, 생성 전 확인)
`jonswap_components` 는 `phases = rng.uniform(0,2π,n_components)` → `directions = rng.normal(...,n_components)`
순서로 뽑고, A 와 B 는 **n_components 가 똑같이 30** 이므로 **같은 시드에서 같은 난수 배열**을 받는다.
확인: 시드 0–4 전부 **위상 배열 비트 동일**, **전파방향 배열 max|Δθ| ≤ 2.2e-16**
(arctan2(k sinθ, k cosθ) 의 반올림뿐, k 가 달라서 생김).

⟹ A→B 는 **같은 30개의 (θ, φ) 쌍을 어느 주파수에 붙이느냐만** 바꾼다. 짝별 차의 잡음이 구조적으로 낮다.

### 1.1b ★ADDENDUM (에피소드 생성 중 · **성능 수치 0건 상태**에서 추가 확인, MEASURED)
저장된 파일에서 직접 재확인했더니 짝짓기가 §1.1 보다 더 강했다 —
**B 의 주파수 격자는 A 의 격자의 정확한 부분집합**이다:

- `B_omegas == A_omegas[1::3]` → **True** (10개가 30개 중 매 3번째와 정확히 일치)
  (대수: 중심 = 0.5ω_p + 2.5ω_p·(i+½)/n_freq 이므로 i = 3j+1 에서 일치)
- 위상 30개 **원소별 비트 동일** · 방향 30개 **max|Δθ| = 2.2e-16**
- 총분산 ∑A²/2 = **0.0900 vs 0.0900**
- `mesh_verdict` **양팔 ADEQUATE**, `lambda_min` **양팔 21.761 m**, `var_under_resolved` **양팔 0.0**

⟹ A→B 는 문자 그대로 **"같은 30개 wavelet 을 매 3번째 주파수로 접고 진폭을 √3 으로 나눈 것"**이다.
⟹ ★**렌더링 교락 없음**: 두 팔의 메시 판정·λ_min·미해상 분산이 **동일**하다(§1.4 G2 초과 달성).

### 1.2 ⚠**선언된 교락**: A vs B 는 "서로 다른 ω 개수"도 함께 바꾼다 (30 → 10)
고정된 성분예산 N=30 에서 주파수내 확산을 **0 이 아니게 만들려면** 주파수 수를 줄이는 것 외에 방법이 없다
(대수적 필연이지 설계 결함이 아니다). 그래서 M 은 **예산의 재배분**이지 예산의 증가가 아니다.
**arm C** 가 이 교락의 *방향과 크기*를 잰다: C 는 B 와 같은 10개 주파수를 갖되 주파수내 확산은 0 이다.
사전 예상(기존 측정 근거: N↔nRMSE 단조 결합, N=1→0.023 / N=15→0.047–0.071): **C 는 A 보다 쉬울 것**이다.
⟹ 만약 B 가 A 보다 나쁘다면, "주파수가 적어서"는 그 부호를 **설명하지 못한다**(교락이 반대 방향).
⛔ C 는 완전한 통제가 **아니다**: C 는 성분 수(30→10)와 총확산(24.2°→16.7°)도 함께 바꾼다. 한계로만 쓴다.

## 2. ★사전 지정 결과변수 · 열화 방향 · 집계 · **MDE 표**

**PRIMARY 지표 = `nRMSE` 하나**(다중성 방지). 나머지는 전부 SECONDARY/서술.
**집계 = 짝별 차 d_i = metric_B(i) − metric_A(i) 의 중앙값**(i = 시드 0–4, n=5).
각 에피소드의 metric 은 **추정기 시드 [42,123,456] 의 median-of-3**.

### 2.1 이 n 에서 가능한 검정 (먼저 확정)
- n=5 **양측** 부호검정 바닥 p = 2·(1/2)^5 = **0.0625** ⟹ ★**α=0.05 는 양측으로 원리적 불가**.
- 따라서 PRIMARY 는 **일측 부호검정**, 방향은 §4 의 사전공약(**B 가 더 나쁘다**)으로 사전 지정.
  기각 조건 = **5/5 가 예측 방향**, p = (1/2)^5 = **0.03125**.
- 보조로 일측 Wilcoxon signed-rank(n=5, 바닥도 0.03125) 병기하되 **결정에 쓰지 않는다**.
- MDE(80 % 검정력) : 5/5 를 80 % 로 얻으려면 에피소드당 부호 적중률 p = 0.8^(1/5) = 0.9565
  ⟹ **MDE = z(0.9565) · σ_d = 1.712 · σ_d**.

σ_d(짝별 차의 표준편차)의 두 경계 — 둘 다 **같은 레짐(BF4/30comp/uniform)의 기존 실측**에서:
- **바닥** σ_d^lo = √2 · σ_med3, σ_med3 = 1.16·σ_seed/√3 = 0.670·σ_seed (arms 가 완전 상관일 때)
- **천장** σ_d^hi = √2 · σ_ep (arms 가 무상관일 때)
σ_seed = 에피소드별 5시드 sd 의 중앙값, σ_ep = 5에피소드 중앙값들의 sd
(원자료 `tmp/rerun_2026-07-25/batchC_ws_phasefix.jsonl`, arm A 와 동일 에피소드·동일 코드경로).

### 2.2 ★이 표가 말하는 것 (결과 보기 전에 적는다)
- **nRMSE 외의 지표는 이 n 에서 사실상 계측 불가**다. ρ 는 기준값의 **48 %**, DirR² 는 기준값보다 **큰**
  변화가 있어야 5/5 를 80 % 로 잡는다. ⟹ 이들에서 **null 이 나와도 "차이 없음"이 아니라 "검정력 없음"**이다.
- nRMSE 조차 **최소 8.3 % 상대변화**가 필요하다. 그보다 작은 진짜 효과는 이 설계로 못 본다.
- ⟹ **결론 가능한 것은 "큰 효과가 있었나 없었나" 뿐**이다. 작은 효과의 부재는 주장하지 않는다.

## 4. 방향 무관 사전 공약

- ★**M=3 에서 성능이 나빠질 것으로 예상한다**(주파수내에 여러 성분이 겹치면 분해가 어려워진다).
  **그것은 실패가 아니라 3년간 시험 안 한 레짐의 첫 측정이다. 성능 하락을 이유로 M 을 되돌리지 않는다.**
- 반대로 **좋아져도 그대로 보고한다**(그 경우 "확산이 성능을 깎는다"는 기존 서사가 틀린 것이다).
- ⛔ 결과를 보고 층화·지표·검정 방향을 **재선택하지 않는다**(p-hacking). 위 표가 전부다.
- ⛔ 이 arm 은 **BF4 · 30comp · uniform · Tp=7 s** 하나의 셀이다. 일반화 주장 금지.
- ⛔ 실측(CDIP)에 대한 성능 주장 금지. B 의 within 20.74° 는 실측 중앙 29.28° 에 **미달**이다.
- ⚠ 타이밍 수치는 기록만 하고 **인용하지 않는다**(이 박스의 시계 결함, 08-04).
- 기존 100 ep 결과를 **대체하지 않는다**. 프로덕션 기본값(`dirs_per_freq=1`) **무변경**.
