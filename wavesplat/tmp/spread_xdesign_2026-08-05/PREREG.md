# PRE-REGISTRATION — 방향확산 교차설계 (확산을 **조작된 처치**로)

작성 2026-08-05, **에피소드 생성 전**. 근거:
- R3/§3 — n_comp 를 통제하면 살아남는 설명변수는 **확산 하나**(부분 ρ +0.460, p=0.0028),
  15comp 내부 연속상관 **WS↔확산 +0.503 (p=0.024)**.
- R4 — 3인이 지목한 유일한 novelty 후보 **(B) 표현-불일치 식별가능성**:
  *유한 이산 성분집합은 방향확산에 성분을 지불해야 하고, 국소화 격자 필터는 그렇지 않다.*
- R4 실행 — `direction_spread_deg` 배선 완료(커밋 `1ef776c`, 기본 30.0 에서 성분 비트 동일).

⚠ 지금까지 확산은 **관측된 공변량**이었다(층 정의 변수). 이 설계는 그것을 **조작**한다.
[[feedback-control-stratifying-variable]] 의 교훈이 여기서 갚아진다.

## 1. 명제 (사전 확정)
**H1**: 성분수를 고정한 채 방향확산을 올리면, **WS 의 열화가 LETKF 의 열화보다 크다.**
**H0**: 두 방법이 같은 크기로 열화한다(= 확산은 공통 난이도이지 표현 특유의 비용이 아니다).

## 2. 설계 — 2 × 2 요인, 짝지음
| 요인 | 수준 |
|---|---|
| 성분수 `n_components` | **5** (희소) · **30** (혼잡) |
| 명목 확산 `direction_spread_deg` | **30°**(현행 기본값 = 대조) · **60°**(처치) |
| 생성 시드 | **0, 1, 2, 3, 4** (기존 100ep 세트와 **동일 시드**) |

⟹ 20 에피소드. 그중 **확산 30° 팔 10개는 이미 존재**한다
(`data_finemesh_2026-07-23/episode_BF4_{5,30}comp_seed{0..4}_uniform.h5`,
`run_episode` 기본값이 정확히 30.0). **생성 비용은 처치팔 10개뿐**(~29분).
★단 **가정하지 않고 확인한다**: 대조팔 1개를 재생성해 **바이트 동일**을 검증한 뒤에만 승계.
불일치 시 20개 전부 재생성한다.

그 외 전부 고정: BF4 · uniform raydrop · `n_pts=50` · `duration=30 s` · `dt=0.1` ·
`depth=50` · mesh `200×167` (= `tmp/regen_run_finemesh.py` 기본값, 100ep 세트와 동일).

## 3. 팔과 프로토콜
- **WS**: `init_method='v2_konly'`, `use_dispersion/use_confidence=True`, `adaptive_n=True`,
  `tracking_window=3` (= WS-P1). 추정 시드 **[42,123,456] median-of-3 + 산포**.
- **LETKF**: `LETKFGrid` 스톡, 40×30 격자, `np.random.seed(42)` — `batchA_baselines.py` 와 동일.
- 두 팔 모두 **같은 20 에피소드**에 같은 세션에서 돌린다
  (⛔R1 교훈: 정확도와 타이밍이 다른 런이면 짝이 아니다).

## 4. PRIMARY 결과변수 — 상호작용 대비
성분수와 생성시드로 짝지어,
```
Δ_M(n, s) = nRMSE_M(spread 60°; n, s) − nRMSE_M(spread 30°; n, s)      M ∈ {WS, LETKF}
I(n, s)   = Δ_WS(n, s) − Δ_LETKF(n, s)
```
**n = 10 짝** (2 성분수 × 5 시드). `I > 0` = H1 방향.

**검정**: 양측 부호검정. **10/10 → p=0.0020 · 9/10 → p=0.0215 · 8/10 → p=0.1094**
⟹ α=0.05 는 **≥9/10** 에서만 도달. Wilcoxon signed-rank(정규근사) 병기.
층별(n_comp 5 / 30)은 각각 n=5 ⟹ **양측 바닥 0.0625, 원리적으로 α=0.05 불가 → 서술 전용**.

## 5. ★조작 점검 (이게 실패하면 실험 자체가 무효)
에피소드별 **실현 확산**을 성분 방향의 에너지가중 1차 원형모멘트로 측정해 보고한다:
σ₁ = √(2(1−|Σ aₙ² e^{iθₙ}| / Σ aₙ²)).
- **요구**: 60° 팔의 실현 확산 중앙값이 30° 팔보다 **명확히 크고**, 두 분포가 거의 겹치지 않을 것.
- R4 예비측정: 명목 30→60 에서 실현 확산 n=5/15/30 → **33.7 / 44.8 / 41.6°**
  (30° 팔 중앙 16.1°). 이 값이 재현되지 않으면 **결과 해석 금지**.
- ⚠ 이 σ₁ 은 **이산 성분집합**에 대한 것이라 CDIP 의 연속 D(θ) 와 같은 피적분 대상이 아니다
  (⛔#23). 그러나 본 설계는 **같은 표현 안에서의 30 vs 60 비교**이므로 ⛔#23 은 걸리지 않는다.
  ⛔ 실현 σ₁ 을 CDIP 백분위로 환산해 인용하는 것은 **금지**.

## 6. ★교란 점검 (사전 지정, 결과와 무관하게 보고)
같은 시드에서 명목 확산만 바꿨을 때 **방향 외의 것이 변했는가**:
- 성분 |k| 집합 · 진폭 집합 · Hs · Tp 의 분포 비교(30° vs 60°, 시드별 짝)
- 변했다면 **단일요인 조작이 아니며**, 그 사실을 결론보다 먼저 적는다.
- 메시 적정성 판정(`mesh_verdict`)이 두 팔에서 같은지 — 다르면 렌더링 교락
  (이 프로그램이 **2번 당한** 오귀속 경로).

## 7. SECONDARY (사전 지정)
Skill Score · Directional R² · Variance Ratio · Pearson ρ · `final_n` · per-frame ms.
**성분 검출률**(GT 성분 대비 매칭)은 확산이 검출을 통해 작동하는지 아닌지를 가르므로 함께 기록.

## 8. 방향에 무관한 사전 공약
- **I ≤ 0 이면 (B) 는 반증된다**: "이산 표현이 확산에 특별히 취약하다"는 유일한 생존 novelty
  후보가 죽고, 남는 것은 레짐 경계 보고뿐이다. **그대로 적는다.**
- **양팔 모두 열화하면** "확산은 공통 난이도"가 되고, 08-03 N5 층화의 해석
  ("경계의 한쪽에만 바다가 산다")은 유지되되 **기제 주장은 못 한다**.
- ⛔ 결과가 어느 쪽이든 **"최초"** 금지 (R4: 5개 표준명 선점 확인).
- ⛔ 실현 확산이 CDIP 중앙(35.3°)을 통과했다고 해서 **"실측 레짐에서 측정했다"**로 승격 금지
  — Tp 상한 9 s 결손은 그대로 남는다(08-05 문헌투사에서 재확인).

## 9. 시드 원장
생성 시드는 기존 세트와 **동일한 0–4**(짝지음을 위해 필수, 새 소비 아님).
추정 시드 [42,123,456] 은 08-03 프로토콜 그대로. **예약 시드 [1515–1818] 은 손대지 않는다.**

## 무엇을 바꾸는가
**§8 의 문장 "I ≤ 0 이면 (B) 는 반증된다" 를 철회한다.** 대체:

> **I ≤ 0 이면 B2 가 반증된다.** B2 = *"성분수를 고정한 채 **이산 원자를 각도상 더 넓게 흩뿌리면**,
> 유한 성분집합 추정기가 국소화 격자 필터보다 더 크게 열화한다."*
> **(B) 원문(연속 D(θ;f) 하의 표현-불일치)은 이 설계가 시험하지 않는다.**

## 왜 (사전등록 자체의 오류)
`wave_generator.py:222` 는 `rng.normal(dir_rad, spread_rad, n_components)` 로 **주파수 빈 1개당 방향 1개**를
뽑는다. 실현 `spread_band_deg` 중앙 = **3.9e−07°**(CDIP 실측 29.28°).
⟹ **합성 진리 자체가 유한 이산 성분집합이고, 모델 클래스가 진리를 정확히 포함한다. 근사 오차 = 0.**
`direction_spread_deg` 30→60 은 원자를 각도상 더 넓게 흩뿌릴 뿐 **주파수당 연속 D(θ) 를 만들지 않는다.**

⚠ 이 사실은 08-04 `DECONFOUND_spread_vs_ncomp.md` §4 에 **"주파수당 확산은 여전히 0 ⟹ 부분 시험"**
으로 이미 적혀 있었다. 내 사전등록 §8 이 그것보다 **강한 반증 공약**을 썼고, 그 모순을 독립 검토가 적발했다.
⟹ 고치지 않으면 I≤0 이 나왔을 때 **설계가 지지하지 않는 사망선고를 사전등록이 강제**하게 된다.
