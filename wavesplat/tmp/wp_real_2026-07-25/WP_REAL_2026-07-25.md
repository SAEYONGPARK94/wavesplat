**Clean structure:** the two records with NO collapse window (YS17, AA15b) are clean learned
LOSSES (0/6 each, medΔ −0.12 / −0.07). The three records WITH a collapse window sit at median Δ ≈ 0
— the collapse-fix pulls the record mean up, but the *typical* windows there still lose (median≈0,

**Proposal sparsity: real seas are proposed CROWDED, not sparse.** Pooled n_eff = **23.9** atoms
(range ~18–28); the M=32-JONSWAP-trained proposal emits ~24 dense components on every real window
regardless of regime. Real swell-dominated typical windows are effectively low-rank for the
analytic path (which resolves them well), so the dense over-proposal fragments energy and loses —
the same mechanism as the synthetic SPARSE control (0/12). The proposal does not adapt its
cardinality to the sea; it cannot "propose sparse."

**Beamform-map validity (mission-required check):** **0/30** windows have the beamform peak at the
k-grid edge; |peak k| ∈ [0.013, 0.221], all well inside the net's trained range [−0.6, 0.6]. So
`scene_real` real obs DO produce valid in-domain conditioning maps — the transfer loss is NOT a
k-range/normalization artifact; it is a prior/regime mismatch (synthetic-clean 32-comp vs real
broadband swell).

**Lead-averaged (context, normal-27):** hand 0.920 vs learned 0.997, meanΔ −0.078, 5/27, p=0.001 —
the learned deficit holds across the forecast horizon, not just nowcast.

## MEASURED vs ARGUED
**MEASURED (frozen protocol, GT untouched in the learned pipeline, median-of-5, zero-shot):**
1. Normal-27 primary: learned significantly WORSE than analytic (mean Δ −0.061, median −0.057,
   6/27, two-sided Wilcoxon p=0.0046, rank-biserial −0.608).
2. All 3 analytic collapse windows repaired (2/3 to <1.0; AA14_w0 2.31→1.07, AA15a_w3 1.12→0.79,
   LJ18g_w3 2.93→0.96); the learned arm never collapses (max 1.083).
3. Doppler (record-median U on YS17) improves BOTH arms 6/6 (hand +0.155, learned +0.125) but does
   not close the learned–hand gap.
4. Learned proposals are dense on every real window (n_eff ≈ 24); records without collapses are
   clean learned losses (YS17, AA15b 0/6).
5. Real-obs beamform maps are in-domain (0/30 edge peaks); hand arm reproduced the doppler_real /
   wp_realdata_fixed baselines bit-identically (e.g. YS17 w0 0.741, AA14 w0 2.309, LJ18g w3 2.925).

**ARGUED (interpretation, consistent with but not proven by the above):**
- Real swell-dominated typical windows fall in the SPARSE regime for the analytic path (which
  resolves them near-well), so the crowded-tuned dense proposal over-fragments and loses — the
  same crossover seen synthetically (crowded win / sparse loss). The n_eff≈24 diagnostic and the
  clean 0/6 on collapse-free records support this, but "regime mismatch" is an inference.
- The collapse repairs are an initialization/basin benefit: a global learned atom set avoids the
  greedy analytic path's catastrophic local optima. Supported by the 3/3 repair with no learned
  collapse, but the mechanism is not dissected here.

## Honest scope statement for the thesis (what the niche claim now covers)
- The learned set-proposal's accuracy niche is **in-distribution crowded SYNTHETIC seas** (Stage-2
  PASS, 39/40). **It does NOT extend to real data on accuracy:** on held-out Bergamasco stereo it
  is significantly WORSE than the analytic prior on typical windows (p=0.005). This is the
  pre-registered EXPECTED niche-hypothesis outcome and **leaves the synthetic crowded claim intact**;
  it also confirms the standing synthetic-clean→real transfer caveat
  (`d3_beamform_cond_diffusion.py:12`).
- The one defensible real-data contribution is **robustness, not accuracy**: the learned prior
  eliminates the analytic path's catastrophic basin collapses (3/3 real collapse windows repaired,
  e.g. LJ18g_w3 2.93→0.96). Report as failure-mode insurance / a hybrid init candidate, not a
  headline win.
- Current-Doppler is confirmed (again) as a **real but conditional** effect: ~13–16% benefit to
  BOTH estimators on the one record (YS17) with a stable estimable current, orthogonal to the prior
  and not rescuing the learned deficit. Consistent with 3a's "bounded, not general" verdict.
- Nothing here reopens the refuted γ/bank-MMSE-prior superiority axis; no default change, paper
  edit, or commit is licensed by this test.
